## 摘要
长时程LLM智能体随着交互历史增长面临一个基本分配问题：保留哪些信息、为其投入多少上下文，以及以何种粒度表示。现有记忆机制主要关注相关性、检索或压缩，使这一分配权衡隐含。我们提出MemPrice，将活跃上下文视为共享资源，并在不同记忆与表示层级之间动态分配。MemPrice将累积的记忆压力转化为上下文的自适应价格，仅当细节的估计保留价值足以证明其额外占用合理时才鼓励保留细节。这种压力在记忆刷新之间持续存在，使记忆内容能够演化，同时保持对上下文使用量的长期控制。我们表明，不可逆压缩会在沿自身记忆轨迹的事后最优基准下导致线性最坏情况遗憾，并引入一个同状态基准，在MemPrice实际实现的记忆状态上评估分配。MemPrice在每一轮强制执行硬性上下文预算，并通过自适应定价调节长期占用率，且无需预先知道交互时程。在定价前沿正则性条件下，当累积估计误差为次线性时，其相对于该基准的平均分配遗憾界趋于零。我们在匹配记忆预算下，在LongMemEval、LoCoMo、AppWorld和WebShop上跨三个基础模型评估该框架，涵盖查询盲记忆构建和目标导向智能体上下文管理。

## Abstract
Long-horizon LLM agents face a fundamental allocation problem as interaction histories grow: which information to retain, how much context to devote to it, and at what granularity. Existing memory mechanisms largely focus on relevance, retrieval, or compression, leaving this allocation trade-off implicit. We introduce MemPrice, which treats active context as a shared resource and dynamically allocates it across memories and representation levels. MemPrice turns accumulated memory pressure into an adaptive price on context, encouraging detail only when its estimated retention value justifies the additional footprint. This pressure persists across memory refreshes, allowing the contents of memory to evolve while preserving long-run control over context usage. We show that irreversible compression can force linear worst-case regret against hindsight following its own memory trajectory, and introduce a same-state benchmark to evaluate allocation on MemPrice's realized memory states. MemPrice enforces the hard context budget at every round and regulates long-run occupancy through adaptive pricing, without prior knowledge of the interaction horizon. Under priced-frontier regularity, its average allocation-regret bound against this benchmark vanishes when accumulated estimation error is sublinear. We evaluate the framework under matched memory budgets on LongMemEval, LoCoMo, AppWorld, and WebShop across three foundation models, spanning both query-blind memory construction and goal-directed agent context management.

## 1. 核心问题与整体含义

- **背景**：长时程 LLM 智能体（long-horizon agents）在推理、行动与交互中会积累大量历史，迅速超出活跃上下文窗口，记忆管理因此成为智能体设计的核心组件。现有工作主要沿着持久化记忆、层次化存储、检索、摘要压缩、自适应上下文构建等方向推进。
- **核心问题**：既有方法大多把记忆管理表述为“检索 / 相关性估计 / 压缩”问题，却把**上下文容量如何在竞争性记忆之间分配**这一权衡留成隐式。论文指出：**相关性不等于值得占用空间**——一条详细记录可能只比摘要多一点点价值，却占用数倍上下文；保留一项必然挤压其他项。相似度、重要性或预测相关性分数并不直接刻画记忆占用的**机会成本**。
- **关键洞察**：这一权衡随时间变化（新信息到达、用户信息需求演化），且压缩/丢弃在刷新前往往**不可逆**，早期分配错误可能无法挽回。因此应把活跃上下文显式视为**有限共享资源**，回答“哪些信息值得记住、以何种粒度、代价多少”。
- **整体含义**：论文将长时程智能体记忆管理形式化为**在线资源分配问题**，连接智能体记忆与在线资源分配、长期约束优化，并提出 MemPrice 框架。

## 2. 方法论

### 2.1 核心思想
- 把活跃上下文当作**共享资源**，在“记忆项 × 表示层级”的联合空间上做容量可行的分配。
- 用**持久虚拟队列**把累积占用压力转化为对上下文的**自适应价格**：只有当某条细节的估计保留价值足以抵偿其额外占用时，才保留更细粒度。
- 压力**跨记忆刷新持续存在**，使记忆内容可演化（语义刷新）而资源核算不被重置（解耦语义刷新与资源记账）。

### 2.2 问题形式化
- 交互时程 T 未知；硬容量 B；目标平均占用率 α∈(0,1]。
- 每轮在可行集 A_t(B) 内选择分配 a_t，最大化累积保留效用，同时满足平均占用约束。
- 每个记忆项可在 5 个有序表示层级中选择：**raw ≻ summary ≻ abstract ≻ keywords ≻ deletion**（由细到粗）。刷新窗口内压缩单向不可逆；删除占用为 0。占用 G_t(a)=Σ s_i^{(c_i)}，可行集同时受“不可细化”约束与 G_t(a)≤B 约束。

### 2.3 算法流程（Algorithm 1）
1. 初始化轮次 t←1、压力 Q_1←0、携带上下文 H←∅、窗口内条目 F←∅。
2. 每轮观察新交互项 θ_t，以 raw 加入 F，形成驻留集 R_t={H}∪F。
3. 向 LLM oracle 查询各可行表示的效用估计 û 与尺寸 ŝ。
4. 计算步长 η_t=c/√t，价格 λ_t=η_t Q_t。
5. 求解**价格调整后的多选择背包问题（MCKP）**：
   - 目标：max_{a∈A_t(B)} { Û_t(a) − λ_t g_t(a) }，等价于逐项最大化 û_i^{(c_i)} − (λ_t/B)·s_i^{(c_i)}；
   - 约束：每项选一个可行表示，总占用 ≤ B。
6. 应用 a_t，更新队列：Q_{t+1}=[Q_t+g_t(a_t)−α]^+（高于目标则压力上升，低于则缓慢释放）。
7. 每 L=10 轮（或容量压力触发）进入**记忆刷新边界**：原始记录归档到外部 archive，固定压缩–检索管线构造下一窗口携带上下文 H；Q_t 与全局 t **跨边界保留**。

### 2.4 理论分析
- **Proposition 1（线性下界）**：对任意非预期、容量可行的分配器，即使效用估计精确，存在 T 轮实例使独立状态事后最优比较下的遗憾 ≥ (T−M)/(M(M+1))，其中 M=⌊1/α⌋+1。这说明这是**信息损失壁垒**而非估计壁垒：硬容量迫使在线分配器在相关性揭示前丢弃候选细节。
- **同状态（GSS）基准**：在 MemPrice 实际到达的记忆状态轨迹上做反事实重分配，允许全局重新分配占用但不改变未来状态，从而隔离“分配质量”与“状态生成代价”。
- **Assumption 1**：效用有界 U、估计误差 e_t≤ε，累积误差 E_T。
- **Assumption 2（定价前沿正则性）**：各轮效用–占用前沿存在近似共同的影子价格，偏差 Δ_T=o(T)；附录 C 给出基于最优影子价格离散度的充分条件。
- **Theorem 1**：每轮硬容量 G_t(a_t)≤B 恒成立；Reg_gss ≤ c√T + 2E_T + Δ_T；占用违规 Viol_T ≤ B((U+2ε)/(αc)·√T+1)。即平均 GSS 遗憾在 E_T+Δ_T=o(T) 时消失，E_T,Δ_T=O(√T) 时累计遗憾 O(√T)；平均超额占用以 O(T^{-1/2}) 消失，且**无需预知 T**。c 越大占用反馈越强，占用界更紧但定价项更大，形成权衡。
- 附录 B 进一步给出**期望可行（EGSS）**版本（Theorem 2），与 Eq.1 的平均占用约束对齐。

## 6. 主要结论与发现

- **Setting I**：MemPrice 在三个骨干上均取得最佳受限预算总体成绩，LongMemEval-S 上在每个查询类别均排名第一；增益**高度不均匀**——单跳提升有限，多跳、时序、知识更新类提升显著，说明方法在长依赖、记忆项竞争容量时最有价值。LoCoMo 上总体仍最佳，但个别单跳/时序子集仍可能被 LRE-SelfSup 或 Dense Salience 占优。
- **Setting II**：三个骨干、两个 agent 基准上均优于所有基线，最强竞争者是 ZipAct；WebShop 上领先 2.7–3.3 分，AppWorld 增益较温和，Challenge split 增益更小，说明高难度任务失败更多来自规划与执行而非记忆。
- **与 Full Context 比较**：MemPrice 仍落后于无预算全上下文，表明更好的分配无法完全恢复硬预算删除的信息，但能缩小损失。
- **消融**：Raw/Delete 退化最大（说明中间保真度表示不可或缺）；Fixed Price 与 Reset Q 在记忆密集基准上退化明显（说明压力既任务相关又需跨时间持久）；Greedy 有一致但较小的损失（说明跨项协调重要）；No Recovery 在 AppWorld 尚可但在 LoCoMo/WebShop 退化（说明可恢复性对长交互重要）。
- **敏感性**：α 从 0.6 升至 0.8 质量持续提升，0.8→0.9 基本饱和；α 同时控制“记忆利用率 vs 推理成本”的系统级权衡。
- **理论**：独立状态比较下存在 Ω(T) 最坏遗憾（不可逆压缩导致的信息损失壁垒）；在同状态基准下，平均 GSS 遗憾在估计误差次线性累积时消失，占用违规 O(√T)，且全程满足硬容量、无需预知 T。

## 7. 优点

- **问题建模新颖且切中要害**：把“相关性≠值得占空间”显式化为机会成本，将记忆管理提升为在线资源分配问题，视角与检索/压缩类工作互补。
- **理论贡献扎实**：Proposition 1 的线性下界清晰揭示了独立状态比较的不可行性，进而合理引出同状态基准，避免“用不可达基准衡量在线算法”的常见问题；Theorem 1/2 给出含估计误差与定价前沿项的显式界，并同时保证硬容量与长期占用。
- **机制设计优雅**：持久虚拟队列跨刷新保留，解耦语义刷新与资源记账；自适应价格天然实现“竞争越激烈、细节越贵”的全局协调。
- **工程可实现**：5 级表示 + MCKP 精确求解，配合归档–检索恢复管线，兼顾不可逆窗口内压缩与跨窗口可

恢复性之间的平衡。

## 8. 不足与局限

- **效用估计器的质量未被单独刻画**：理论界中的 ε 与累积误差 E_T 是核心量，但实验没有直接操纵 oracle 的噪声水平（如注入随机扰动、替换为更弱的打分器、或比较不同 LLM 作为效用估计器的差异），因此“估计误差多大时方法会失效”缺少经验答案。理论中的 E_T=o(T) 条件在实践中是否成立，只能间接推断。
- **定价前沿正则性假设（Assumption 2）缺少经验检验**：附录 C 给出的是基于最优影子价格离散度的充分条件，但论文没有报告实际运行中各轮影子价格的离散程度、Δ_T 的经验增长曲线，因而该假设与现实数据的匹配度是开放问题。
- **开销与延迟未量化**：每轮需向 LLM oracle 查询各可行表示的效用与尺寸估计，并对 MCKP 求解；刷新边界还需运行压缩–检索管线。这些辅助调用带来的额外 token 消耗与端到端延迟对实际部署至关重要（尤其 α 较高时重分配更频繁），但论文只做定性讨论，未给出与基线在同等口径下的成本对比，也未报告“每单位质量提升所需额外 token”这类效率指标。
- **基线覆盖存在空隙**：Setting I 的基线以检索/显著性/最近性类方法为主，缺少与更强的层次化摘要智能体（如递归摘要、树状记忆结构）在同一预算下的对比；Setting II 中 ZipAct-B 是最强竞争者，但其他记忆增强型 agent 框架覆盖有限。此外，论文自述 LongMemEval-M 仅用于压力分析而未主报，削弱了在更长时程上的说服力。
- **性能仍受硬预算信息损失制约**：与 Full Context 的差距说明分配优化无法完全补偿删除，尤其单跳类任务增益有限；这既是方法边界，也提示“分配”与“表示/压缩质量”应联合优化而非仅靠定价。
- **增益的异质性解释偏定性**：论文将多跳/时序/知识更新的显著提升归因于“长依赖 + 竞争性容量”，但未提供细粒度的机制性证据（如分析被保留条目的类型分布、压缩层级选择随时间的演化、错误案例的归因统计），因此因果链条仍属合理推测。
- **超参数与任务耦合**：α、L、c、5 级表示与 0.6 压缩比等设定在开发集上确定，但未报告这些选择对下游质量的稳健性（除 α 外），跨领域迁移时的调参成本不明确。
- **在线框架的适用范围**：方法假设存在可枚举的记忆项与离散表示层级，并需要可靠的尺寸估计；对无法预先切分的长文档流、多模态记忆或工具返回的结构化大对象，如何定义“项”与“层级”尚未讨论。

## 9. 启示与可借鉴之处

- **把“容量”当作一等公民**：将上下文预算显式建模为共享资源、以机会成本而非相关性打分做取舍，这一视角可直接迁移到 RAG 上下文拼装、多智能体共享黑板、工具输出裁剪等场景。
- **持久虚拟队列 + 语义刷新解耦**的设计模式具有通用性：任何“周期性重建状态但需长期遵守资源约束”的系统（如流式摘要、缓存淘汰、带宽调度）都可借用“内容可重置、压力不可重置”的思路。
- **同状态（GSS）基准**是对在线记忆系统做公平评估的有力工具：它把“分配决策质量”从“状态生成代价”中剥离出来，可作为此类系统评测的通用反事实评估协议。
- **下界—基准—上界的三段式论证结构**值得效仿：先用信息损失壁垒说明朴素基准不可达，再定义可达基准，最后给出匹配的遗憾界，避免理论与实验脱节。
- **5 级有序表示 + 多选择背包**是把“保真度”离散化后仍可精确求解的实用折中，比连续粒度或启发式阈值更易实现与调参。

## 10. 总体评价

论文抓住了长时程智能体记忆管理中一个被普遍忽视却本质的问题：**相关性不等于值得占用空间**。它把活跃上下文显式化为有限共享资源，形式化为带平均占用约束的在线分配问题，并以持久虚拟队列驱动的自适应价格为枢纽，将“语义刷新”与“资源记账”解耦。理论上，Proposition 1 的 Ω(T) 下界诚实揭示了独立状态比较的不可行性，进而合理引入同状态基准，Theorem 1/2 给出同时保证硬容量与长期占用、且无需预知 T 的显式遗憾界；实验上，跨“查询盲/目标可观测”两类机制、4 个数据集、3 个骨干的对比与消融较为系统，结论方向一致且增益集中在长依赖与竞争性容量场景，符合方法预期。

主要短板在于**经验层面的成本与鲁棒性证据不足**：效用估计器质量、定价前沿正则性假设、辅助 token 与延迟开销均未量化，基线覆盖与超参数稳健性也有提升空间；与全上下文之间的差距则诚实地标示了“分配优化”的能力边界。总体而言，这是一篇问题定义清晰、理论—基准—算法闭环完整、工程可实现性较强的研究工作，其核心贡献（资源化视角、持久压力机制、同状态评估协议）具有超出具体方法的迁移价值，而成本核算与估计器鲁棒性是其走向实际部署前最需要补齐的一环。
