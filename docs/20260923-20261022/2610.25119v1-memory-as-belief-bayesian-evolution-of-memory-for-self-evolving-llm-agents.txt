Abstract 

Large language model (LLM) agents increasingly rely on ex-ternal memory to accumulate past experiences for contin-ual adaptation. However, effectively reusing memory requires accurately assessing its value, as retrieved experiences may become unreliable when transferred across task contexts. De-spite its importance, memory valuation remains largely un-derexplored, with existing methods relying on historical re-trieval success rates that overlook the context dependency of memory usefulness and the varying reliability of estimates under different amounts of evidence. Inspired by the Bayesian brain hypothesis, we propose BEAM (Bayesian-style Evo-lutionary Agentic Memory), a framework that reformulates memory value evaluation as a parameterized cognitive in-ference process, where memory value is represented as a context-conditioned dynamic belief rather than a passive his-torical statistic. Specifically, BEAM infers memory value be-liefs from current task contexts and continuously calibrates them using execution feedback as empirical evidence, trans-forming memory from passive storage into an adaptive cog-nitive mechanism for continual self-evolution. Extensive ex-periments across reasoning and code generation benchmarks demonstrate that BEAM consistently improves memory uti-lization and enables continual self-evolution of LLM agents. 

## Introduction 

Large language models (LLMs) have demonstrated remark-able efficacy in natural language understanding, code genera-tion, knowledge-intensive QA, and complex reasoning (Yao et al. 2023; Zhao et al. 2024; Jimenez et al. 2024; Singh et al. 2025). As LLMs increasingly serve as the foundation for autonomous agents, the deployment paradigm is shifting from static benchmark evaluations to continuous streams of open-world tasks (Xie et al. 2023; Xu et al. 2026a). However, when operating over continuous task streams, contemporary agent systems largely fail to learn from accumulated cross-task experience (Zhang et al. 2026a; Xu et al. 2026b). Since they process each task in isolation, agents repeatedly en-counter similar failures and overlook valuable transferable insights from related tasks (Ouyang et al. 2026). Therefore, enabling agents to accumulate and leverage valuable expe-riences across tasks has become a fundamental challenge toward achieving reliable self-evolving systems.

In practical deployment, continuously fine-tuning or online-updating model parameters could be computationally expensive and engineering-intensive (Zhao et al. 2023; Xia et al. 2025). External memory modules have therefore been widely adopted to store experience and knowledge that can be reused across tasks (Hu et al. 2025). However, effectively leveraging external memories remains challenging, as stored experiences are not always reliable and may become ineffec-tive or even misleading when transferred to new task con-texts (Ouyang et al. 2026). Existing studies (Xu et al. 2026b; Zhang et al. 2026a; Han et al. 2025) rarely provide a prin-cipled assessment of whether a retrieved memory remains valuable under the current task context. Recently, a few stud-ies predominantly estimate memory value through heuris-tic scoring mechanisms, such as historical retrieval success rates or manually designed importance scores (Zhang et al. 2026c; Xia et al. 2025; Zhong et al. 2024). However, these metrics implicitly treat memory value as a task-independent and scalar quantity. In reality, memory value is inherently context-dependent and subject to uncertainty based on accu-mulated evidence. For instance, a reasoning memory contain-ing a "depth-first recursive traversal" strategy may achieve a high success rate on small-scale algorithmic tasks, but fails when transferred to large-scale problems with strict compu-tational or stack constraints. Moreover, scalar metrics fail to distinguish a memory proven over hundreds of trials from one that succeeded merely once by chance. This raises a central question: How can agents dynamically evaluate and cali-brate context-dependent memory values under uncertainty, thereby enabling reliable and continual evolution rather than merely accumulating experiences? 

To overcome these limitations, we revisit memory value estimation from the perspective of the Bayesian brain hy-pothesis (Knill and Pouget 2004). This hypothesis posits that cognitive systems continuously update their probabilistic be-liefs about the world by integrating prior experience with incoming observations (Friston 2010; Pouget et al. 2013). In-spired by this principle, our key insight is to formulate mem-ory value evaluation as a parameterized cognitive inference process, where memory value is represented as a context-conditioned dynamic belief rather than a passive historical statistic. From this perspective, the parameterized cognitive system first infers the prior value of memories based on the current task context. After a memory is involved in reasoning arXiv:2610.25119v1 [cs.LG] 18 Oct 2026 and decision-making, the resulting execution feedback serves as empirical evidence for updating the posterior belief over its value. This belief calibration process transforms memory from passive storage into an adaptive cognitive mechanism, enabling LLM agents to continually refine their experience and self-evolve under open-world task streams. In this work, we propose BEAM (Bayesian-style Evolu-tionary Agentic Memory), a framework that enables LLM agents to perform continual memory valuation through context-conditioned belief modeling and evidence-driven calibration. The proposed framework consists of three com-ponents. First, we construct structured reasoning memories from historical trajectories by distilling transferable strate-gies while filtering task-specific details. Second, we de-sign a context-conditioned memory belief model, which is a lightweight LoRA-adapted estimator that carries out this cognitive inference without modifying the backbone LLM. Given the task context and candidate memories, it pre-dicts prior belief distributions over memory utility, enabling uncertainty-aware memory valuation and subsequent belief calibration. Third, we introduce an evidence-driven belief updating mechanism that leverages trajectory execution out-comes as empirical evidence to obtain memory-level super-vision and performs evidential calibration, preference-aware optimization, and selective regularization for continual value refinement. Extensive experiments across diverse reasoning and code generation benchmarks demonstrate that BEAM significantly enhances memory utilization and drives con-tinual self-evolution in LLM agents. Our contributions are summarized as follows: 

• Perspective. We revisit memory valuation through the lens of the Bayesian brain hypothesis, transforming memory from a passive storage structure into an adaptive cognitive mechanism capable of dynamic belief calibration. 

• Algorithm. We propose BEAM, a Bayesian memory evo-lution framework that integrates reasoning memory construc-tion, context-conditioned belief modeling, and evidence-driven belief calibration for continual memory valuation. 

• Experiments. Extensive experiments across diverse rea-soning and code generation benchmarks demonstrate that BEAM consistently outperforms state-of-the-art baselines in memory utilization and drives long-term continual self-evolution for LLM agents. 

## Related Work 

Large Language Model Agents. Large language model (LLM) agents extend the capabilities of language models on complex tasks by integrating task planning, tool use, and environment interaction (Wang et al. 2024a). To further enhance agent capabilities, existing studies have explored reasoning-action coordination, reflective refinement, and ex-perience reuse (Zhang et al. 2025). ReAct (Yao et al. 2022) interleaves reasoning and acting, allowing models to adapt subsequent actions based on observations; Reflexion (Shinn et al. 2023) uses verbal feedback to revise future decisions; Voyager (Wang et al. 2023) continuously explores open-ended environments and accumulates reusable skills; and Synapse (Zheng et al. 2024) retrieves historical trajectory exemplars to support long-horizon task execution. These studies demonstrate that feedback and accumulated experi-ence can enhance agents’ adaptability across tasks. However, many existing agents still rely heavily on current-context prompting, heuristic reflection, or limited historical exam-ples for capability improvement, lacking stable mechanisms for experience consolidation, value assessment, and online updating (Gao et al. 2025). How to accumulate reusable experience and continuously optimize its selection and use remains a key challenge for self-evolving agents. 

Agent Memory Organization. External memory allows agents to continually accumulate, organize and reuse inter-action experience without modifying the backbone model, making it an important mechanism for long-term adapta-tion (Wang et al. 2025a). Existing studies have explored diverse forms of memory representation and organization. MemoryBank (Zhong et al. 2024) and MemGPT (Packer et al. 2023) focus on long-term user memory and hierarchical context management; ReasoningBank (Ouyang et al. 2026) distills successful and failed trajectories into reusable reason-ing memories; A-Mem (Xu et al. 2026b), Zep (Rasmussen et al. 2025), and G-Memory (Zhang et al. 2026a) organize memories using graph-based or hierarchical structures; and LEGOMem (Han et al. 2025) and Buffer of Thoughts (Yang et al. 2024) abstract experience into procedural modules or thought templates to guide subsequent task solving. These efforts enable agents to accumulate and structure past ex-perience (Hu et al. 2025). However, stored memories may contain low-value or noisy experiences, leading to subopti-mal reasoning and decision-making (Wei et al. 2025). 

Agent Memory Value Evaluation. Since stored memories are not necessarily reliable or beneficial, evaluating their value has increasingly attracted attention (Yu et al. 2026). Ex-isting studies (Zhong et al. 2024) primarily explore heuristic-driven approaches to model and quantify memory utility, such as historical retrieval success rates. MemRL (Zhang et al. 2026c) estimates memory benefits using Q-values; From Experience to Strategy (Xia et al. 2025) updates strat-egy weights based on counterfactual reward differences; and PlugMem (Yang et al. 2026) quantifies the decision-relevant information gain per memory token from a utility–cost per-spective. Another line of work learns memory operations or update policies: Memory-R1 (Yan et al. 2026) and Mem-

α (Wang et al. 2025b) learn strategies for memory construc-tion, management, or updating, while MemSkill (Zhang et al. 2026b) and ReMe (Cao et al. 2026) further explore the dy-namic evolution of memory skills and procedural experience. Although recent studies have advanced memory utility esti-mation and management, they typically model memory value as a static scalar, overlooking its uncertainty and context-dependent reliability (Zhao et al. 2024). In contrast, we model memory value as a context-conditioned dynamic belief that is continuously refined through online feedback.

Context-conditioned Memory Belief Modeling 

Existing memory-augmented agents typically retrieve se-mantically relevant memories to facilitate task solving (Reza-zadeh et al. 2025), but fail to evaluate their reliability across changing task contexts. Recent studies estimate mem-ory utility using scalar statistics, such as historical success rates (Zhang et al. 2026c). However, these approaches suffer from two main limitations. First, they assume memory value is task-independent, ignoring the fact that a memory’s utility is highly context-dependent. For instance, a memory advocat-ing "depth-first recursive traversal" succeeds on small tasks but fails under strict stack constraints in large-scale settings. Second, scalar point estimates ignore evidence-based uncer-tainty, treating a single lucky success ( 1/1) identically to a proven record ( 97 /100 ). Therefore, memory value should be modeled as a context-dependent belief that captures both contextual relevance and evidence-based uncertainty. Inspired by the Bayesian brain hypothesis (Knill and Pouget 2004; Friston 2010), which posits that intelligent sys-tems continuously infer and update probabilistic beliefs by integrating prior knowledge with incoming evidence, we re-visit memory value estimation from an evidential perspec-tive. Instead of assigning each memory a deterministic util-ity score, we model its usefulness as a context-conditioned probabilistic belief. Specifically, given a task context xt, we represent the latent utility of a candidate memory mt,i as a random variable: 

vt,i ∼ Beta( αt,i , β t,i ), (5) where vt,i denotes the latent probability that memory mt,i 

provides beneficial guidance for the current task xt. We adopt the beta distribution, as it serves as the conjugate prior to the Bernoulli likelihood, which naturally aligns with the binary success-or-failure feedback of task execution. The parame-ters αt,i and βt,i characterize the accumulated positive and negative evidence, respectively. This allows the agent to ex-plicitly quantify both the expected memory utility and its associated uncertainty. To parameterize the context-conditioned memory belief, we introduce a lightweight LoRA-adapted value estimator based on a pretrained language model. Rather than learning memory values directly, the estimator is trained to infer the parameters of the Beta belief distribution by jointly consider-ing the current task context and candidate memory represen-tations. Specifically, given the current task xt and a candidate memory mt,i , the estimator produces the corresponding be-lief parameters: 

[ˆ αt,i , ˆβt,i ] = 1 + softplus ( gϕ(xt, m i)) , (6) where gϕ(·) denotes the LoRA-adapted estimator with frozen backbone parameters, and ˆαt,i and ˆβt,i represent the esti-mated parameters of the context-conditioned Beta belief. The softplus transformation ensures that the predicted evidence remains non-negative, while the unit offset corresponds to the uniform prior Beta(1 , 1) in the absence of supporting evidence. Consequently, when the estimator observes insuf-ficient contextual evidence for a memory item, the resulting belief remains close to an uninformative distribution rather than producing an overconfident utility estimation. As more evidence is accumulated through interactions, the belief can gradually become more concentrated, reflecting increasing confidence in the reliability of the memory. 

Evidence-driven Memory Belief Updating 

The context-conditioned belief estimation above provides an initial prior over memory utility before the current interac-tion. However, such priors are inevitably uncertain due to incomplete contextual information and limited historical ev-idence. Similar to humans who continually revise beliefs through new experiences, we treat the feedback ft obtained after applying retrieved memories as empirical evidence to calibrate and refine prior beliefs, enabling memory values to continuously evolve with accumulated experience rather than remaining fixed after initial estimation. Given a current task xt and a candidate memory mt,i , the context-conditioned belief estimator models its usefulness as a belief distribution Beta(ˆ αt,i , ˆβt,i ). To strike a balance between exploitation and exploration, we adopt Thompson sampling (Thompson 1933; Chapelle and Li 2011) to draw a stochastic utility score ˜vt,i directly from this distribution: 

˜vt,i ∼ Beta(ˆ αt,i , ˆβt,i ). (7) Unlike deterministic point estimates (e.g., predicted means), this sampling scheme intrinsically accounts for epis-temic uncertainty. Consequently, memories with limited ev-idence retain higher variance, naturally yielding greater op-portunities for exploration alongside the exploitation of well-supported experiences. Since effective reasoning often benefits from complemen-tary experiences (Xu et al. 2026b), the agent retrieves a set of top-K memories based on sampled utilities rather than selecting a single memory. However, the obtained feedback only reflects the joint effect of the retrieved memory set, mak-ing it difficult to determine the individual contribution of each memory. To address this challenge, we introduce leave-one-out counterfactual credit assignment to derive memory-level evidence. ## Experiments 

Experiment Settings 

Datasets. We evaluate BEAM on five benchmarks spanning mathematical reasoning, using AIME24 and AIME25 (Hug-ging Face H4 2024; OpenCompass 2025); scientific reason-ing, using GPQA-Diamond (Rein et al. 2023); philosophi-cal reasoning, using MMLU-Pro (Philosophy) (Wang et al. 2024b); multidisciplinary reasoning, using the valid text-only multiple-choice subset of HLE (Phan et al. 2025); and code generation, using BigCodeBench-Hard-Instruct (Zhuo et al. 2025). We report accuracy for reasoning benchmarks and Pass@1 for BigCodeBench. 

Baselines. We compare BEAM with six representative base-lines spanning diverse memory paradigms: No Memory, which solves tasks using only the frozen backbone lan-guage model; Self-RAG (Asai et al. 2024), which con-trols retrieval through self-reflection; Mem0 (Chhikara et al. 2025), a general-purpose long-term memory framework; A-Mem (Xu et al. 2026b), which organizes structured memory notes and semantic associations; Memp (Fang et al. 2026), which distills procedural knowledge from trajectories; and MemRL (Zhang et al. 2026c), which combines semantic re-trieval with learned Q-values. All methods use the same task streams, executors, output parsers, and evaluation protocols while preserving each baseline’s core memory mechanisms. 

Evaluation Protocol. Following Evo-Memory’s streaming search–predict–evolve protocol (Wei et al. 2025), we adopt a zero-reset task-stream setting. For each benchmark, the cor-responding task stream is partitioned into consecutive stages and processed in a strictly fixed order, without resetting the memory bank or value estimator at any point throughout the stream. For each task, inference relies exclusively on expe-rience accumulated from preceding tasks, while feedback from the current task is used only to update the system for subsequent tasks, preventing it from influencing the current prediction. Additional implementation details, including the key prompts used throughout BEAM, are provided in the supplementary material.

Two qualitative case studies illustrating BEAM’s end-to-end reasoning and memory-utilization process are provided in the supplementary material.

Belief-guided Memory Selection. When belief-guided se-lection is removed, the system selects memories solely ac-cording to semantic similarity, resulting in consistent perfor-mance degradation across all three benchmarks. This indi-cates that semantic relevance alone is insufficient to charac-terize the actual utility of a memory for the current task. In contrast, task-conditioned belief estimation helps filter out memories that are superficially relevant but only marginally useful or potentially misleading. 

Memory Synthesis. When memory synthesis is removed, the system still injects the selected raw memories but no longer constructs an additional working memory. The result-ing performance drop suggests that raw memories may still contain redundancy, conflicts, and task-irrelevant details. By distilling transferable reasoning principles and integrating complementary information, memory synthesis provides the executor with more focused and task-conditioned guidance.

Continual Self-Evolution 

To assess whether BEAM can progressively improve mem-ory use through continual interaction, we partition each task stream into consecutive stages and report stage-wise ac-curacy and the gain over the no-memory baseline: ∆ = Acc method − Acc no -memory . Neither the memory bank nor the value model is reset throughout the stream. Leave-one-out supervision from completed tasks is used only to update the value model for subsequent tasks, preventing it from af-fecting the current prediction. As shown in Figure 3, the stage-wise accuracy of all meth-ods fluctuates because task difficulty varies across stages. Nevertheless, BEAM generally achieves larger gains over the no-memory baseline as the task stream progresses, with more pronounced improvements in later stages. In contrast, other memory-based methods exhibit less stable gains, with some falling below the no-memory baseline at certain stages. This suggests that continual experience accumulation alone does not guarantee sustained improvement; memory qual-ity and selection remain critical. As counterfactual supervi-sion accumulates, BEAM’s belief model progressively cal-ibrates candidate-memory utility estimates, increasing the likelihood of selecting task-relevant memories while reduc-ing interference from mismatched ones. Although this trend may be affected by stage difficulty and finite-sample variabil-ity, the larger relative gains in later stages provide empirical evidence that BEAM gradually improves memory utilization through continual self-evolution. Cross-Task Transferability 

To examine whether BEAM’s value model transfers across related tasks, we initialize the AIME value network with parameters learned on MATH-500 (Hendrycks et al. 2021; Lightman et al. 2024) and compare it with a value model trained from scratch on AIME and a no-memory baseline. As shown in Figure 4, the transferred model achieves the best stream-level average performance and consistently out-performs the no-memory baseline across all stages. In partic-ular, it shows a clear early-stage advantage over training from scratch, indicating that memory-utility judgments learned on MATH-500 provide an effective initialization for selecting useful memories on AIME when target-task feedback is still scarce. As AIME feedback accumulates, the scratch-trained model narrows the gap and achieves a comparable gain in the final stage. These results suggest that cross-task transfer improves early adaptation, feedback efficiency, and overall stream-level performance, while having only a limited effect on final-stage performance. 

## Conclusion 

In this paper, we introduced BEAM, a framework that re-formulates memory valuation for self-evolving LLM agents as inference over context-conditioned probabilistic beliefs. Rather than assigning each memory a static scalar utility, BEAM jointly models its expected usefulness and uncer-tainty, and continually calibrates these beliefs using exe-cution feedback and counterfactual credit assignment. By integrating structured reasoning memory formation, belief-guided selection, and evidence-driven updating while keep-ing the backbone LLM frozen, BEAM enables reliable expe-rience reuse across continual task streams. Experiments on diverse reasoning and code-generation benchmarks show that BEAM achieves consistent gains over strong memory base-lines, progressively improves memory utilization through online interaction, and transfers learned utility judgments across related tasks. These findings underscore context-aware memory valuation as a promising foundation for reli-able and continual self-evolution in LLM agents.

## Implementation Details 

The memory belief estimator is initialized from Qwen2.5-7B-Instruct and equipped with a lightweight evidential Beta head that predicts context-conditioned belief parameters 

(α, β ) for each task–memory pair. The pretrained backbone remains frozen, while LoRA adapters are applied to the query, key, value, and output projection layers with rank 

r = 8, scaling factor αLoRA = 16 , and dropout 0.05 .Pairwise inputs are encoded with a maximum sequence length of 4,096 tokens. Dense retrieval is performed us-ing text-embedding-3-large embeddings stored in a local Qdrant vector database. For each task, six candidate memories are retrieved, and semantic similarity is combined with Thompson-sampled memory utility after z-score nor-malization. The value weight η follows a sigmoid schedule over [0 .10 , 0.50] according to task-stream progress. After reranking, up to three memories with semantic similarity scores above the injection threshold of 0.5 are retained for subsequent reasoning. The estimator is optimized online us-ing AdamW, with learning rates of 5 × 10 −5 for the LoRA adapters and 1 × 10 −3 for the evidential Beta head, and a batch size of 8. The weights of Levi , Lkl , and Lrank are set to 

1.0, 0.03 , and 0.6, respectively. Experiments are conducted on a Linux server equipped with multiple NVIDIA GeForce RTX 4090 GPUs. The memory belief estimator runs locally on one of the GPUs using bfloat16 precision, while external LLM and embedding services are accessed via APIs.

## Case Studies

More importantly, the resulting trajectory-level feedback provides contrastive evidence for memory for-mation. By comparing successful and failed reasoning paths, BEAM distills a concise, high-signal reasoning principle and stores it for future tasks. Thus, test-time scaling improves not only the reliability of the current prediction but also the qual-ity and transferability of newly formed memories. 

Case 2: Task-Conditioned Memory Utilization. Fig-ure 10 compares memory-free reasoning with BEAM. With-out memory, the executor identifies the relevant transfor-mation but fails to resolve the structural ambiguity. BEAM instead selects memories according to their estimated task-conditioned utility and synthesizes the applicable informa-tion into actionable guidance, enabling the executor to elim-inate incompatible candidates and reach the correct answer.
