## 摘要
基于大语言模型（LLM）的多智能体系统日益依赖记忆，将执行轨迹转化为可复用的程序性知识。然而，重复检索也会使记忆错误持续存在：当过时、证据薄弱或虚假成功的流程成为未来推理中反复出现的组成部分时，就会产生记忆污染。多智能体执行还引入了额外的结构性风险。当程序性知识脱离其被证明有效的协调范围，并在不兼容的决策层级上被反复复用时，就会发生范围坍缩，使局部错误影响下游决策级联。与此同时，任务级失败提供的监督具有歧义，因为它们很少揭示是哪些被召回的知识导致了失败。我们提出 AECG，一个面向多智能体系统的非对称经验巩固与治理框架。AECG 将记忆从静态经验存储转变为动态可靠性治理循环，保持协调范围，并使用多尺度、置信度感知的可靠性来检测退化。然后，它将退化与下游影响相结合，在有界审查预算下优先处理高风险知识，实施有针对性的干预，并且仅在配对重放之后重新激活修订后的技能。在三个多智能体框架和四个基准上，AECG 在 12 个框架—基准设置中的 11 个取得最佳分数，并相较最强的竞争记忆方法最高提升 10.23 个百分点；移除范围保持会使准确率最多下降 16.89 个百分点。因此，AECG 将多智能体记忆从被动积累重构为可审计的可靠性治理。代码见 https://github.com/fenhg297/AECG

## Abstract
Large language model (LLM)-based multi-agent systems increasingly rely on memory to transform execution trajectories into reusable procedural knowledge. Yet repeated retrieval also makes memory errors persistent: memory pollution arises when outdated, weakly supported, or spuriously successful procedures become recurring components of future reasoning. Multi-agent execution introduces an additional structural risk. Scope collapse occurs when procedural knowledge escapes the coordination scope in which it was shown effective and is repeatedly reused at incompatible decision levels, allowing local errors to influence cascades of downstream decisions. Meanwhile, task-level failures provide ambiguous supervision because they rarely reveal which recalled knowledge was responsible. We introduce AECG, a framework for asymmetric experience consolidation and governance for multi-agent systems. AECG turns memory from static experience storage into a dynamic reliability-governance loop, preserving coordination scope and using multi-scale, confidence-aware reliability to detect degradation. It then combines degradation with downstream impact to prioritize high-risk knowledge under a bounded review budget, applies targeted interventions, and reactivates revised skills only after paired replay. Across three multi-agent frameworks and four benchmarks, AECG achieves the best score in 11 of 12 framework--benchmark settings and improves over the strongest competing memory method by as much as 10.23 percentage points; removing scope preservation reduces accuracy by up to 16.89 points. AECG thereby reframes multi-agent memory from passive accumulation into auditable reliability governance. Code is available at https://github.com/fenhg297/AECG

## 1. 核心问题与研究动机

- **背景**：基于 LLM 的多智能体系统越来越多地借助记忆，把执行轨迹压缩为可复用的程序性知识（procedural knowledge），从而在后续任务中复用策略与技能。已有工作主要关注经验表示、技能抽象与记忆检索，却相对忽视了知识在持续复用下的**可靠性衰减**。
- **核心问题一：记忆污染（memory pollution）**。过时、证据薄弱或“虚假成功”的流程一旦被固化进长期记忆并被反复召回，局部错误就会成为未来推理的持久组成部分，造成跨任务的负迁移。
- **核心问题二：范围坍缩（scope collapse）**。多智能体执行跨越团队规划、协作事件、角色动作等多个层级；当程序性知识脱离其被证明有效的协调范围，在不兼容的决策层级被复用时，局部错误会沿依赖结构级联放大。
- **核心问题三：失败监督模糊**。任务级失败很少能指出“是哪条被召回的知识该负责”，因此无法直接把失败当作负证据。
- **三个待答问题**：①有效复用的边界在哪；②知识何时发生退化；③在有限审查预算下应如何干预。
- **整体含义**：论文主张多智能体记忆应从“被动积累”转向“持续的生命周期治理”，即同时治理**复用边界、可靠性、潜在影响**三个维度。

## 2. 方法论（AECG）

### 2.1 核心思想
把记忆从静态经验存储改造为“**非对称经验巩固 + 可靠性治理**”的闭环：约束知识在何处可被复用 → 以置信度感知的方式检测退化 → 结合下游结构影响在有限预算下优先审查 → 经配对回放验证后才让修订技能重新上线。

### 2.2 问题形式化
- 任务流 $\{x_t\}_{t=1}^T$，每次执行形式化为有向执行图 $G_t=(V_t,E_t)$，节点表示规划/协调/执行决策，边表示条件依赖；产出轨迹 $\tau_t$ 与二值结果 $r_t$。
- 每个节点映射到协调范围 $s(v)\in\{TEAM\}\cup\{EVENT(e)\}\cup\{AGENT(e,a)\}$。
- 维护两类带范围标签的对象：程序性记忆 $m$（基于轨迹）与技能 $k$（由受支持经验抽象而来）。

### 2.3 关键技术细节

**（1）范围保持（Scope-preserving）**
- 团队级、事件级、智能体级对象各自保留来源身份，**证据不跨层级池化**。
- 抽象时强制 $s(k)=s(m_{seed})$，召回与比较也按范围匹配，防止局部经验变成系统级知识。

**（2）非对称证据准入**
- 成功：对成功轨迹中被应用的技能给予置信加权正证据 $(y=1, c^+)$。
- 失败：只有通过“归因门”才转为负证据 $(y=0, c^{att})$，否则记为未决 $(∅,0)$，失败轨迹保留为 BadCase。
- 归因门：两个独立 LLM 裁判，可弃权；须二者均不弃权、识别同一技能与同一范围、该技能确在已应用记录中、平均置信度 ≥ 0.70。这是**保守的证据准入**，而非因果识别。
- 只有被准入的观测集合 $A_k$ 才更新可靠性信念。

**（3）技能形成与证据继承**
- 同范围就绪规则：$\text{Ready}(m)=\mu(A,B)-\sigma(A,B)$，需超过同范围活跃记忆均值加余量 $\delta_{prom}=0.05$ 才可晋升。
- LLM 将种子记忆抽象为同范围技能；邻近记忆只补充适用边界，不作主要证据。
- 证据继承：转移比例 $\kappa$ 的种子证据，慢状态保留全部折扣证据，快状态继承质量上限 $W$：
  $n^S_{k,0}=\kappa n_{seed}$，$n^F_{k,0}=\min\{W,\kappa n_{seed}\}$，$b^q_{k,0}=b_0+n^q_{k,0}e(\hat p_{seed})$，初始伪计数 $\alpha_0=\beta_0=1$。

**（4）双时间尺度可靠性估计**
- 每个技能版本维护两个 Beta 式伪计数信念：慢信念（$\lambda_S=1$，累积历史）与快信念（$\lambda_F=\lambda<1$，强调近期）。
- 更新式：$b^q_{k,u}=b_0+\lambda_q(b^q_{k,prev(u)}-b_0)+c_{k,u}e(y_{k,u})$。
- 均值 $\mu^q_k=\alpha^q/(\alpha^q+\beta^q)$；当前失败风险 $R^{fail}_k=1-\mu^F_k$。
- 均值层退化信号 $D_k=[\mu^S_k-\mu^F_k]_+$，用于区分“一直不可靠”与“近期相对自身历史退化”。
- 实现上用 Beta 采样估计不确定性感知的退化分 $R^{drift}_k$：对慢/快信念成对采样，减去中心化采样噪声基线后取正部；命题 1 证明其有界性 $0\le R^{drift}\le[\delta_k]_+$，且可理解为对阈值 $t\in[0,\delta_k]$ 的平均超越分数（$J=1024$ 次采样）。论文明确将其定位为**排序分数**而非校准概率或检验统计量。

**（5）风险与暴露感知的预算化治理**
- 暴露度量：对技能使用节点 $d$ 的所有可达后代按最短路径距离几何折扣求和 $e^{obs}_{k,u}=\sum_{v\in Desc}\gamma^{dist-1}$（$\gamma=0.5$），再结合近期平均暴露与上一时间窗使用频次得到 $E_k$。论文强调这是**潜在传播暴露**，非因果效应。
- 审查资格：置信门 $C^{deg}_k\ge\eta_{deg}=0.95$ 且 $R^{drift}_k>0$；按 $H_k=E_k\cdot R^{drift}_k$ 排序，取前 $B_{review}$ 个进入审查；合格的局部失败另走事件驱动预算。
- 证据路由干预：上下文局部失败 → **NARROW**（收紧适用条件，不改流程）；跨上下文缺陷 → **REPAIR**（修订流程，保留范围与意图）；证据不足则不生成候选。
- 回放门控：候选版本须在失败 fixture 上缓解问题，且在不相交的历史成功回归 fixture 上不低于父版本 $-\epsilon_{reg}$（0.05）才激活；否则按快信念置信度继续监控或隔离（$\eta_{unsafe}=0.95$）。**从不原地覆盖活跃技能**，而是版本化候选。

### 2.4 算法流程（Algorithm 1 概要）
执行（范围匹配召回）→ 若非成功则保留 BadCase → 按式(2) 路由证据 → 更新慢/快信念 → 就绪记忆抽象为同范围技能并继承证据 → 周期性审查：算 $R^{drift}$ 与置信门、算暴露 $E_k$、按 $H_k$ 选 top-$B$ → 对每个被审技能提出 NARROW/REPAIR 候选 → 配对回放门控 → 更新技能服务状态。
