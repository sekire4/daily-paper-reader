## 摘要
长期记忆使大语言模型（LLM）智能体能够利用历史交互来服务于未来任务。然而，现有记忆系统难以利用持续演化的历史信息，因为它们通常依赖静态记忆表示和单轮检索策略，无法跟踪事实变化或整合长期交互中分散的证据。为应对这些挑战，我们提出 EMIR$^2$，一个具有意图引导多轮检索的演化感知记忆框架，使 LLM 智能体能够维护不断演化的历史知识并自适应地检索相关证据。具体而言，EMIR$^2$ 构建状态演化记忆图（State-Evolving Memory Graph, SEMG），将长期记忆表示为由时间事件轨迹和证据关联支持的可演化知识状态。通过基于证据的更新来维护语义状态，SEMG 保留历史演化，并能够在复杂和冲突场景下进行证据追溯。在此基础上，我们引入意图引导的多轮检索机制，该机制迭代识别缺失证据，并基于累积信息扩展检索。在 LoCoMo 和 MemConflict 上的实验表明，EMIR$^2$ 提升了长期记忆利用率、动态与静态冲突处理以及复杂检索性能，在某些类别上取得超过 12% 的相对提升。这些结果凸显了联合建模记忆演化与自适应证据获取在长期智能体交互中的有效性。

## Abstract
Long-term memory enables large language model (LLM) agents to leverage historical interactions for future tasks. However, existing memory systems struggle to utilize continuously evolving historical information, as they often rely on static memory representations and single-round retrieval strategies, failing to track factual changes or integrate distributed evidence across long-term interactions. To address these challenges, we propose \textsc{EMIR}$^{2}$, an \textbf{E}volution-Aware \textbf{M}emory framework with \textbf{I}ntent-Guided Multi-\textbf{R}ound \textbf{R}etrieval, enabling LLM agents to maintain evolving historical knowledge and adaptively retrieve relevant evidence. Specifically, \textsc{EMIR}$^{2}$ constructs a State-Evolving Memory Graph (SEMG) that represents long-term memory as evolving knowledge states supported by temporal event trajectories and evidential associations. By maintaining semantic states through evidence-based updates, SEMG preserves historical evolution and enables evidence tracing under complex and conflicting scenarios. Building upon this, we introduce an intent-guided multi-round retrieval mechanism that iteratively identifies missing evidence and expands retrieval based on accumulated information. Experiments on LoCoMo and MemConflict demonstrate that \textsc{EMIR}$^{2}$ improves long-term memory utilization, dynamic and static conflict handling, and complex retrieval performance, achieving relative improvements of more than 12\% in certain categories. These results highlight the effectiveness of jointly modeling memory evolution and adaptive evidence acquisition for long-term agent interactions.

- **背景**：LLM 智能体正从短程交互走向长程任务，需要长期记忆持续积累、组织并利用历史交互；但长期记忆是动态演化的，不同时间获取的信息可能不一致甚至冲突。
- **核心问题**：现有记忆系统难以利用持续演化的历史信息，主要体现在两方面：
  - **记忆表示静态化**：现有方法多通过摘要、聚合、语义抽取等将历史压缩为紧凑表示，侧重“存储与检索”，很少显式建模语义状态如何随时间演化、事实如何被修订，以及状态转移的证据依据。
  - **检索策略单轮化**：主流方法基于当前查询做单轮语义相似度召回，难以利用记忆间关系，也缺乏基于已获证据扩展搜索的机制；面对需要跨多个历史事件、多阶段状态转移的复杂查询时，容易证据不全。
- **冲突类型**：论文用图 1 区分三类记忆冲突——动态冲突（新事实替代旧事实）、静态冲突（历史记录相互矛盾）、条件冲突（偏好随情境变化）。
- **整体含义**：长期记忆系统既要保留“事实如何演变”及其证据关系，又要能自适应地聚合分散证据，这是长程智能体推理的关键需求。

## 2. 方法论

### 2.1 核心思想

EMIR² 由两部分组成：
- **状态演化记忆图（SEMG）**：把长期记忆组织为“情节事件轨迹 + 语义状态演化 + 证据关联”的结构化图。
- **意图引导多轮检索**：在 SEMG 上迭代评估证据充分性、识别信息缺口、定向扩展检索，直至证据足够或预算耗尽。

### 2.2 状态演化记忆图（SEMG）

**（1）情节记忆构建**
- 从局部对话窗口抽取原子事件，每个事件节点包含内容、关联实体、时间信息、原始对话上下文引用。
- 事件按主题描述匹配归入主题链，无匹配则新建链；链内按时间排序，形成时序链：
  - \(T_c: e_{c,1} \rightarrow e_{c,2} \rightarrow \cdots \rightarrow e_{c,n_c}\)，箭头仅表示时间相邻，不表示因果。
- 引入跨事件关系：利用实体、事件内容、时间信号生成候选事件对，由关系分类器判定关系类型，包括 CAUSES、CONTRIBUTES TO、CONTEXT FOR、ENABLES、PART OF、FOLLOW UP OF、SAME EVENT；可跨主题链连接，形成“时间路径 + 关系路径”的情节图。

**（2）语义状态演化**
- 每个主题维护语义节点 \(s_c^{(k)}\)，包含当前有效事实集、状态摘要、时间有效性、支持证据。
- 新语义信息与当前状态对账，产生四类更新决策：
  - `reinforce`：新证据进一步支持已有事实（补充证据，不新建节点）；
  - `extend`：添加与当前状态兼容的新事实（不新建节点）；
  - `revise`：新信息替换或撤回已有事实，终止旧状态有效期并创建后继节点 \(s_c^{(k+1)}\)；
  - `uncertain`：证据不足，不修改状态。
- 状态转移形式化为：
  - \(Update(s_c^{(k)}, u) = Reinforce(\cdot)\) 若 reinforce；\(Extend(\cdot)\) 若 extend；\(s_c^{(k+1)}\) 若 revise；\(s_c^{(k)}\) 若 uncertain。
- 修订时前后语义节点通过 evolution/substitution 关系连接，保留历史知识以支持“过去状态”查询；事实自身维护独立有效时间，可与语义节点起始时间不一致。
- 事件与状态通过 SUPPORTS STATE、TRIGGERS STATE CHANGE、SUPERSEDES、CONTRADICTS 等关系连接。
- 设计要点：将“状态修订”与“事件到达”解耦，多个事件可共同支持同一语义节点，无需为每个事件新建状态。

### 2.3 意图引导多轮检索

- **流程**（算法 1）：
  1. 推断查询意图 \(z\)，判断是否需要问题分解，生成子问题 \(S\)；
  2. 初始检索得到证据 \(E_0\)；
  3. 每轮评估累积证据是否充分，识别缺失证据；
  4. 若充分则提前终止；否则基于意图与已有证据选择扩展源和检索动作；
  5. 检索新证据 \(\Delta E_t\)，去重合并，并用 \(Select_B\) 维持候选预算 \(B\)；
  6. 达到最大轮数 \(R\) 或证据充分后终止；
  7. 对候选重排序，返回 top-\(K\) 证据。
- **形式化**：
  - \((z, P_1) = Plan(q, E_0)\)
  - \(\Delta E_t = Execute(P_t, G)\)
  - \(E_t = Select_B(E_{t-1} \cup \Delta E_t)\)
  - \((\delta_t, P_{t+1}) = Assess(q, z, E_t, A_t)\)
- **动作约束**：可执行动作集 \(A_t\) 受查询意图、当前证据呈现的关系、已执行动作共同约束，不允许任意操作。
- **最终重排序**：
  - \(s(v) = \lambda s_M(v|q, E_T) + (1-\lambda) Norm(r(v))\)
  - 其中 \(s_M\) 为模型相关性评分，\(r(v)\) 为语义、稀疏、实体、精确匹配、证据面等信号的加权分；返回 top-\(K\)（\(K \le B\)）。
- **提示词设计**：包含问题分解门控、初始子问题规划、迭代证据评估、扩展源选择（最多 5 个“桥接/连接/实体/关系/因果/时间锚点”）、最终重排序等模块，强调不重复失败查询、依据证据缺口推导下一步检索。

## 6. 主要结论与发现

- **LoCo

MoMo 表现**：在 LoCoMo 上，EMIR² 在两种骨干模型下整体表现优于或至少不弱于主流记忆基线，优势主要体现在 Multi-hop 与 Temporal 两类问题上；Single hop 由于单轮语义检索已能较好解决，提升相对有限。这说明“状态演化图 + 多轮证据扩展”对需要跨事件聚合的查询更有价值。

- **MemConflict 表现**：在动态冲突与静态冲突上，EMIR² 相比 A-Mem、LangMem、Mem0 等基线具有优势，说明显式建模状态修订与保留历史证据有助于处理“新事实替代旧事实”和“历史记录相互矛盾”的情形；但在条件冲突上并未取得领先，平均 AA 低于 MemOS，也低于 Letta，表明“偏好随情境变化”这类条件性冲突仍是当前状态演化机制的薄弱环节。
- **消融结论**：去掉多轮检索后性能下降最明显，说明意图引导的迭代证据扩展是主要收益来源；去掉语义状态演化次之，验证了“区分 reinforce/extend/revise/uncertain 并保留状态转移”的必要性；去掉跨链关系的影响相对较小，甚至在某些设置下接近完整模型，说明当前跨主题关系边对最终答案的边际贡献有限，主题链内的时间与证据关系已覆盖多数有效信息。
- **效率与轮数**：随着最大检索轮数增加，证据召回率与完整证据召回率上升，但 token 成本同步增长，且收益呈递减趋势；\(R_{max}=8\) 在准确率、召回与成本之间较为平衡，继续增加轮数带来的提升有限。
- **控制器容量**：将轻量控制器 Qwen3.5-9B 替换为 Claude Sonnet 4.5 后，性能变化不大或仅有有限提升，说明该多轮检索框架对控制器容量并不高度敏感，轻量模型即可承担规划与评估职责，有利于降低部署成本。
- **检索行为**：多轮扩展主要围绕实体锚点、桥接实体、时间锚点与因果关系展开，重复执行失败查询的情况较少；这表明“基于证据缺口选择扩展源”的约束式动作设计确实改变了检索路径，而非简单增加召回数量。
- **总体判断**：EMIR² 的核心贡献在于把长期记忆从“静态摘要 + 单轮相似度检索”推进为“可修订的语义状态图 + 意图引导的多轮证据聚合”，在需要跨事件、跨时间推理的任务上具有明确收益；但其收益并非全场景占优，条件冲突与跨链关系利用仍是待改进点。

## 7. 局限性与不足

- **基准覆盖有限**：仅使用 LoCoMo 与 MemConflict 两个 benchmark，前者偏对话记忆，后者偏冲突记忆，尚未覆盖多模态记忆、工具调用轨迹、多智能体共享记忆等更复杂的长程场景。
- **条件冲突建模不足**：MemConflict 上条件冲突表现不突出，平均 AA 低于 MemOS，说明当前“状态修订”机制更擅长处理事实替代与矛盾，而对“同一偏好在不同情境下切换”的条件性语义缺乏显式建模。
- **跨链关系收益有限**：附录分析显示跨链边贡献不高，可能的原因包括关系分类器噪声、跨主题连接稀疏，以及主题链内证据已足够；这也意味着 SEMG 的图结构优势尚未被充分释放。
- **基线公平性**：MemConflict 部分基线结果直接引用原论文，未在完全相同的构建流程与评估环境下重跑；LLM-as-judge 评估也存在模型偏好与评分稳定性风险。
- **成本与算力报告缺失**：论文未报告 GPU 型号、数量、训练/推理总时长，也未系统比较记忆图构建与多轮检索的 token/延迟开销；考虑到记忆构建依赖闭源 API，实际部署成本难以从文中评估。

## 8. 启发与可拓展方向

- **从“存储检索”转向“状态演化”**：将记忆视为可修订的语义状态序列，而非静态摘要集合，有助于回答“过去某个时间点系统相信什么”“事实何时被替换”等时间敏感问题。
- **检索应成为证据充分性驱动的迭代过程**：先评估缺口、再选择扩展源，比固定 top-\(k\) 召回更契合多跳与时间推理；但需要控制轮数与候选预算，避免成本失控。
- **条件冲突值得单独建模**：可为偏好、约束类事实引入“情境条件”维度，将条件冲突从普通事实修订中分离，或设计条件化的状态节点与证据匹配机制。
- **跨链关系需要更精细的触发策略**：当前跨链边贡献有限，未来可只在主题链内证据不足时激活跨链扩展，或引入更强的关系置信度过滤，减少噪声边干扰。
- **成本感知的多轮检索**：可根据查询难度自适应决定轮数，而非统一设置 \(R_{max}\)；对简单查询提前终止，对复杂查询保留扩展预算，以提升性价比。
