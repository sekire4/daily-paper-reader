## 摘要
多模态智能体的长期记忆仍具挑战性，因为它必须在跨会话跟踪实体演变的同时保留细粒度视觉证据。现有基于抽象的记忆将图像压缩为文本，往往丢弃具有视觉判别性的细节；而保留像素的记忆虽保留原始观察，却难以可靠地将多样化观察与持久实体身份关联起来，并跟踪其演变状态。为解决这些局限，我们提出 MHG-Mem，一种多模态超图记忆，联合组织实体身份、状态演变以及到视觉证据的溯源关系。具体而言，MHG-Mem 将不同的实体提及及其观察事实表示为独立节点，并通过出现超边将身份一致的提及和事实分组。然后，它从这些分组观察中合成特定方面的演变状态，并通过演变超边和证据超边将其与支撑实体、事实和源证据相连。为导航这一结构化记忆，我们引入基于超图的智能体搜索，它自适应选择入口层，跨记忆层遍历类型化超边，并在需要细粒度验证时检查源观察。这些设计同时支持详细的视觉验证和对跨会话状态变化的推理。在三个基准上的大量实验证明了 MHG-Mem 的有效性，相较于最强基线将性能提升 8.20-9.98%。

## Abstract
Long-term memory for multimodal agents remains challenging, as it must preserve fine-grained visual evidence while tracking entity evolution across sessions. Existing abstraction-based memories compress images into text, often discarding visually discriminative details, whereas pixel-preserving memories retain raw observations but struggle to reliably associate diverse observations with persistent entity identities and track their evolving states. To address these limitations, we propose MHG-Mem, a multimodal hypergraph memory that jointly organizes entity identity, state evolution, and provenance to visual evidence. Specifically, MHG-Mem represents distinct entity mentions and their observed facts as individual nodes, grouping identity-consistent mentions and facts through occurrence hyperedges. It then synthesizes aspect-specific evolution states from these grouped observations and links them to supporting entities, facts, and source evidence through evolutionary and evidential hyperedges. To navigate this structured memory, we introduce hypergraph-based agentic search, which adaptively selects an entry layer, traverses typed hyperedges across memory levels, and inspects source observations when fine-grained verification is required. These designs support both detailed visual verification and reasoning over cross-session state changes. Extensive experiments across three benchmarks demonstrate the effectiveness of MHG-Mem, improving performance by 8.20-9.98% over the strongest baseline.

## 1. 核心问题与研究背景

- **背景**：LLM 智能体在跨会话的网页浏览、GUI 操作、具身交互和个性化助手等场景中，需要在上下文窗口之外复用历史经验。这类交互天然是多模态的（对话文本 + 截图/照片），因此“多模态长期记忆”成为关键能力。
- **核心矛盾**：长期记忆必须同时满足两个要求：
  1. **保留细粒度视觉证据**（如拉链是否有两个可锁拉头、画面中的颜色/数量）；
  2. **跨会话追踪同一实体的状态演化**（如某款背包的价格与库存从 $89 有货 → $69 售罄 → $75 已购）。
- **现有方法的两类缺陷**：
  - **抽象式记忆**（把图像压缩为文本描述/结构化记录）：便于组织与检索，但丢失判别性视觉细节，导致视觉细节类问题失败。
  - **像素保留式记忆**（保留原图供检索查看）：视觉证据完整，但检索到的图像只是孤立观察，没有记录“不同会话中的哪些观察指向同一实体”，也没有记录属性如何随时间变化，容易混淆相似实体或错误拼接属性。
- **研究问题**：如何把同一实体在视觉上差异很大的多次观察组织成连贯的状态历史，同时让每个状态都可溯源到其支撑证据？
- **关键洞察**：这种记忆结构本质上是**高阶（higher-order）**的——一次观察同时关联若干实体提及、事实与视觉证据；状态演化又需整合多次观察。因此适合用**类型化超边（typed hyperedge）**显式建模，而非孤立的实体/事实三元组。

## 2. 方法论：MHG-Mem

### 2.1 核心思想
构建一个**带属性的多模态超图记忆**，用三类节点 + 三类 n 元超边，把“实体身份（identity）—状态演化（evolution）—证据溯源（provenance）”统一在一个结构中；再用**基于超图的智能体搜索**在实体层、演化层、事实层之间自适应导航，并按需回溯原始对话与图像。

### 2.2 形式化定义
记忆表示为带属性超图：H = (V, E, ι, τ_V, τ_E)，其中 V = F ∪ U ∪ Z（事实节点、实体节点、演化节点），E = E_occ ∪ E_evo ∪ E_evd（出现超边、演化超边、证据超边），ι: E → 2^V 为关联映射；完整记忆 M_T = (H, ρ, K)，ρ 为源轮次引用映射，K 为嵌入索引。

- **FactNode（事实节点）**：f = (ℓ_f, I_f, t_f, s_f, δ_f)，即原子多模态观察的描述、图像 ID 集合、轮次、会话、日期。
- **EntityNode（实体节点）**：u = (n_u, c_u, μ_u, i_u, b_u)，即名称、类别、模态（visual / multimodal / text）、图像 ID、归一化 bbox；同一底层实体的多个提及构成**指称组（referent group）r**，每个提及仍是独立节点。
- **EvolutionNode（演化节点）**：z = (r_z, a_z, σ_z, S_z, κ_z)，即主体指称组、演化方面（如 price、color）、摘要、**有序状态–事实轨迹** S_z = ((v_j, f_j))_{j=1..m_z}、更新类型（replacement / correction / addition）。
- **出现超边**：ι(e_occ_r) = U_r ∪ F_r，把同一指称组的所有提及与其事实绑定。
- **演化超边**：ι(e_evo_z) = {z} ∪ U_subj_z ∪ U_co_z，连接演化节点与其主体提及及“共现参与者”提及。
- **证据超边**：ι(e_evd_z) = {z} ∪ F_z，把演化状态连到支撑事实。

### 2.3 记忆构建（三步，Algorithm 1）
1. **多模态事实抽取**：每轮 d_t 由 VLM 结合最近会话上下文 C_t（最多 3 轮前文、最多 8 张图）抽取原子事实，并接地为 FactNode（附图像 ID 与源元数据）。
2. **多模态实体抽取与出现链接**：
   - 对候选提及 u，按文本与视觉相似度的独立最大值给出现超边打分：
     s(u, e_occ_r) = w_T · max_{v∈U_r} c_T(u,v) + w_I · max_{v∈U_vis_r} c_I(u,v)，取 top-K（K=3）候选。
   - 由模型在 **UPDATE（并入已有指称组）/ ADD（新建组）/ SKIP（拒绝无效提及）** 中选择。
   - 事实按名称词法匹配挂接：A(f, e_occ_r)=1 当且仅当 ℓ_f 含该组某实体名。
3. **演化合成与接地**：Ẑ_r = LLM_evo(Order(F_r))，按观察时间排序、剔除重复值、识别同一属性/关系的变化；**保留条件**为：事实引用均属 F_r、时间单调、至少 2 个不同状态值（且观测跨至少 2 个会话）。随后构造演化超边（主体 + 共现参与者）与证据超边，S_z 保留“状态值 ↔ 事实”的逐项对应。
- **增量更新**：新会话边界只对获得新事实的指称组重合成；替换时更新派生节点、超边与嵌入，底层事实、提及与原始来源保留。

### 2.4 超图智能体搜索（Algorithm 2）
- **控制器**：LLM π_θ 依据查询 q 与搜索历史 h_k 逐步选择工具 a_k 并接收观察 o_k（式 8）。
- **六类工具**：`resolve_facts`（事实层）、`resolve_entity`（实体层）、`resolve_evolution`（演化层）、`search_image`（视觉检索）、`get_raw_verbatim`（源检查）、`submit_evidence`（证据装配与校验）。
- **分层检索打分**：
  - 事实层：s_F = λ_T·s_T + λ_TI·s_TI + λ_II·s_II（文–文、文–图、图–图余弦，视觉项取最佳匹配并对负值截零）。
  - 实体层：以名称/查询图像做最大文本与视觉相似度定位指称组，再沿出现超边取回 F_r。
  - 演化层：s_Z(q,z) = cos(φ_T(x_q), φ_T(a_z ‖ σ_z))，选中后沿证据超边取回按 S_z 排序的支撑事实。
- **跨层遍历**：Traverse(v, E′, V′) = ⋃_{e∈E′, v∈ι(e)} (ι(e) ∩ V′)。
- **源检查与装配**：沿 ρ(·) 从事实回溯原始对话与图像；`submit_evidence` 校验引用（事实须已注册、图像须属于被引事实的源轮次），非法引用被剔除，通过后形成证据链 E_q 交给 QA 模型。
- **理论保证（附录 B.4，命题 1）**：在“每个保留状态都引用可用的源事实”前提下，展开 e_evd_z 再经 ρ 可**恰好恢复** Src(z)（不多不少），且该性质在事实/提及新增与合法演化插入/替换下保持——即“源可恢复性”，与抽取准确性、摘要真值无关。
