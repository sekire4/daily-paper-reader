## 摘要
长期记忆使 LLM 智能体能够回忆过去的交互并在跨会话时保持一致，但记忆系统难以比较，因为它们在表示、索引、检索和评估方面往往各不相同。我们提出了一个基于共享 5W 风格对话记忆的受控评估框架。局部化图配置遍历一个共同的基础图；AdaptiveGraph 增加了时序边和个性化 PageRank 扩散。我们还在相同的抽取笔记上评估 BM25，并将 OpenClaw 作为原始输入的外部参照进行评估。检索排序会随记忆设置而变化。在 LongMemEval-S 上，AdaptiveGraph 是最强的图配置，MRR 为 0.844，但 BM25 达到 0.867，OpenClaw 达到 0.880。在 ATANT Core 上，局部化图遍历优于扩散和 BM25，而 BM25 在压力测试轮次中领先。在测试范围内缩减 LongMemEval-S 并不能复现 ATANT 中的扩散惩罚，但测试的最小存储仍大于 ATANT Core，因此无法排除存储规模的影响。在宽松的内容匹配标准下，该惩罚仍然存在。词汇归一化和抽取质量会显著影响图检索，且在前五名未命中结果中，抽取标签缺失很常见。因此，检索策略应与记忆设置联合评估，并与强词汇基线进行比较。

## Abstract
Long-term memory lets LLM agents recall past interactions and remain consistent across sessions, but memory systems are hard to compare because they often vary in representation, indexing, retrieval, and evaluation. We present a controlled evaluation framework based on shared 5W-style conversational memories. Localized graph configurations traverse a common base graph; AdaptiveGraph adds chronological edges and Personalized PageRank diffusion. We also evaluate BM25 over the same extracted notes and OpenClaw as a raw-input external reference. Retrieval rankings vary across memory settings. On LongMemEval-S, AdaptiveGraph is the strongest graph configuration at 0.844 MRR, but BM25 reaches 0.867 and OpenClaw 0.880. On ATANT Core, localized graph traversal outperforms diffusion and BM25, whereas BM25 leads the stress rounds. Reducing LongMemEval-S within the tested range does not reproduce the ATANT diffusion penalty, but the smallest tested store remains larger than ATANT Core, so store size cannot be ruled out. The penalty also persists under a permissive content-match criterion. Vocabulary normalization and extraction quality substantially affect graph retrieval, and missing extraction tags are common among top-five misses. Retrieval strategies should therefore be evaluated jointly with the memory setting and against strong lexical baselines.

## 1. 核心问题与研究动机

- **背景**：LLM 智能体需要跨会话的长期记忆，但上下文窗口有限且昂贵，因此通常采用“检索式记忆”——从外部存储中选出少量历史交互注入上下文。
- **核心痛点**：已有记忆系统（MemGPT、MemoryBank、Mem0、GraphRAG、HippoRAG、Zep、MAGMA、A-MEM 等）往往**同时改变表示、索引、图拓扑、遍历方式和评测协议**，导致无法判断性能增益究竟来自哪个组件，也无法确认图结构是否真的优于强词法基线。
- **研究问题**：在共享同一份对话记忆表示的前提下，图检索配置（局部遍历 vs. 扩散）与词法检索（BM25）在不同记忆场景下如何表现？抽取质量、词表归一化等因素如何制约图检索？
- **整体含义**：论文主张检索策略应与“记忆设置”联合评估，并始终对照强词法基线；不存在跨场景通吃的方法。

## 2. 方法论

### 2.1 核心思想

- 提供统一的 `remember()` / `query()` 接口和**共享的 5W 式对话记忆表示**，使不同检索配置在同一存储、同一本体、同一基础图上进行受控比较。
- 图配置共享抽取笔记、5W 本体和基础 tag–topic–file 图；局部配置直接遍历该图，AdaptiveGraph 额外加入时序边并使用个性化 PageRank 扩散。

### 2.2 记忆摄入与 5W 抽取

- 每个用户–助手交互存为一个 Markdown 文档，作为**原子检索单元**，保留原始对话。
- 用 LLM 抽取结构化字段：`Who / What / When / Where / Why / Extra / Summary`。
- 抽取原则：**精度优先于召回**；以用户陈述为主要记忆来源，助手回复仅用于澄清主题，不引入新事实；不推断用户身份、偏好、技能或长期目标。
- 概念表示为短层级本体标签（斜杠路径），如 `career/software_engineering`、`programming/python`；提示模型优先复用已有本体条目，但生成后不强制校验。
- 标签仅作为检索键，返回给智能体的仍是完整 Markdown 交互，避免丢失原始关系、数值和约束。

### 2.3 图构建

- **四类节点**：tag 节点（抽取概念）、topic 节点（聚合相关记忆）、file 节点（Markdown 交互）、ontology 节点（分类体系）。
- **边类型**：
  - tag–topic、topic–file：连接概念与记忆；
  - 相似度边：两个 topic 在 5W 类别中共享至少 3 个属性时相连；
  - ontology 边：编码父子关系；
  - AdaptiveGraph 额外加入**连续 file 节点之间的时序边**。

### 2.4 检索方法

- **OpenClaw（外部参照）**：对原始对话文本做 dense cosine 相似度（权重 0.7）与 BM25（权重 0.3）混合检索；不使用抽取存储或图，因此不属于受控消融。
- **BM25（受控词法基线）**：对同一批抽取笔记全文使用 Okapi BM25（`k1=1.5, b=0.75`），不使用本体或图边。
- **TagGraph（局部本体引导遍历）**：
  - 词法匹配查询与 tag，沿父子概念做有界 BFS 扩展；
  - 经 `Tag → Topic → File` 路径产生候选文件，按图距离打分，直接匹配优先于远端本体邻居。
  - 变体：
    - **Basic**：原始词法重叠；
    - **Stopwords**：移除在单个 case 内文档频率超过 15% 的查询 token，防止“how/use/get”等泛词打开过宽图区域；
    - **TFIDF**：在过滤基础上按语料 TF-IDF 加权内容重叠。
- **AdaptiveGraph（PPR 扩散）**：
  - 在基础图上加入时序 file 边；
  - 用匹配的 ontology tag 初始化 teleportation 向量，并将 TF-IDF 内容重叠分数直接赋给候选 file 节点；
  - 迭代公式：`x(k+1) = α Mᵀ x(k) + (1−α) s`，其中 `M` 为转移矩阵，`s` 为查询导出的 teleportation 向量，`α=0.85`，迭代 20 次；
  - 按最终 PageRank 概率对对话文件排序；直接 file seeding 在查询无法匹配有用本体入口时保留词法通路。

## 3. 实验设计

### 3.1 数据集与 Benchmark

- **LongMemEval-S**：
  - 500 道带类型标注的记忆问题，每题配约 40–50 个历史会话，仅一个或少数相关；
  - 问题类型包括 multi-session、temporal-reasoning、knowledge-update、single-session-assistant、single-session-user、single-session-preference；
  - 另设 **oracle 变体**（仅提供 gold sessions），作为无干扰上界检查。
- **ATANT**：
  - 覆盖 Career、Daily Life、Health、Learning、Life Events、Relationships 六个生活领域；
  - 评估 **Core** 与 **Stress R2–R5** 划分，后者使用独立故事集、每题更多问题；
  - ATANT 无 gold session 标签，相关性通过“笔记是否包含期望答案子串”判定（严格：包含全部子串；宽松：包含任一子串）。
- 两个 benchmark 形成互补：LongMemEval 是长历史、干扰密集；ATANT 是紧凑但持续演化的个人叙事。

### 3.2 对比方法

- 共 6 种：**OpenClaw、TagGraph-Basic、TagGraph-Stopwords、TagGraph-TFIDF、AdaptiveGraph、BM25**。
- 四种图方法共享摄入流程、本体构建、Markdown 存储和基础 5W 图；BM25 在相同抽取笔记上运行但不使用图；OpenClaw 为原始输入的外部生产参照。

### 3.3 抽取模型

- 三个指令微调模型：**Gemma、GPT-OSS、Qwen3-Small**。
- 固定同一抽取 prompt、temperature 0，使图检索差异可主要归因于抽取模型与检索配置，而非 prompt 工程。
