## 摘要
大型语言模型（LLM）智能体日益依赖外部记忆来积累过往经验以实现持续适应。然而，有效复用记忆需要准确评估其价值，因为检索到的经验在跨任务情境迁移时可能变得不可靠。尽管这一问题至关重要，记忆价值评估仍在很大程度上未得到充分探索；现有方法依赖历史检索成功率，忽略了记忆有用性的情境依赖性，以及在不同证据量下估计可靠性的差异。受贝叶斯大脑假说启发，我们提出BEAM（Bayesian-style Evolutionary Agentic Memory，贝叶斯式演化智能体记忆），该框架将记忆价值评估重构为参数化认知推理过程，其中记忆价值被表示为情境条件化的动态信念，而非被动的历史统计量。具体而言，BEAM从当前任务情境推断记忆价值信念，并利用执行反馈作为经验证据持续校准这些信念，从而将记忆从被动存储转变为面向持续自演化的自适应认知机制。在推理与代码生成基准上的大量实验表明，BEAM一致地提升了记忆利用率，并实现了LLM智能体的持续自演化。

## Abstract
Large language model (LLM) agents increasingly rely on external memory to accumulate past experiences for continual adaptation. However, effectively reusing memory requires accurately assessing its value, as retrieved experiences may become unreliable when transferred across task contexts. Despite its importance, memory valuation remains largely underexplored, with existing methods relying on historical retrieval success rates that overlook the context dependency of memory usefulness and the varying reliability of estimates under different amounts of evidence. Inspired by the Bayesian brain hypothesis, we propose BEAM (Bayesian-style Evolutionary Agentic Memory), a framework that reformulates memory value evaluation as a parameterized cognitive inference process, where memory value is represented as a context-conditioned dynamic belief rather than a passive historical statistic. Specifically, BEAM infers memory value beliefs from current task contexts and continuously calibrates them using execution feedback as empirical evidence, transforming memory from passive storage into an adaptive cognitive mechanism for continual self-evolution. Extensive experiments across reasoning and code generation benchmarks demonstrate that BEAM consistently improves memory utilization and enables continual self-evolution of LLM agents.

  - 以“历史检索成功率”等启发式标量打分，隐含假设记忆价值是**任务无关的标量**，忽略其情境依赖性（如“深度优先递归遍历”策略在小规模任务上成功率高，但在有严格栈/算力约束的大规模问题上失效）。

## 2. 方法论（BEAM 框架）

### 2.1 核心思想

- 借鉴**贝叶斯大脑假说**（认知系统通过整合先验经验与新观测持续更新概率信念），把记忆价值评估形式化为**参数化认知推断过程**：
  - 先由当前任务情境推断记忆价值的**先验信念**；
  - 记忆参与推理后，执行反馈作为经验证据，更新其价值的**后验信念**。
- 记忆效用被建模为随机变量 $v_{t,i}\sim \mathrm{Beta}(\alpha_{t,i},\beta_{t,i})$，其中 $\alpha,\beta$ 分别刻画累积的正/负证据；选用 Beta 分布因其是伯努利似然的共轭先验，天然匹配“成功/失败”二值反馈。

### 2.2 三大组件

**（1）推理记忆构建（Inference and Memory Formation）**

- 记忆增强推理：用价值估计器对候选记忆打分，检索 Top-$K$ 记忆集合 $\mathcal{C}_t$，并额外合成一条高可迁移的“工作记忆” $m_{syn}$，与任务 $x_t$ 一起注入**冻结的**骨干 LLM：$\hat y_t \sim A_\theta(\cdot\mid x_t,\mathcal{C}_t,m_{syn})$。
- 测试时扩展（test-time scaling）：对同一任务采样 $N$ 条轨迹，结合环境反馈进行反思，蒸馏出结构化记忆条目 $m_t=(u_t,d_t,c_t)$（标题、经验摘要、可复用推理原则），并写入记忆库。

**（2）情境条件化记忆信念建模**

- 采用**轻量 LoRA 适配的价值估计器**（骨干参数冻结），输入任务上下文与候选记忆，输出 Beta 分布参数：
  $[\hat\alpha_{t,i},\hat\beta_{t,i}] = 1+\mathrm{softplus}(g_\phi(x_t,m_i))$。
- softplus 保证证据非负；单位偏移对应无证据时的均匀先验 $\mathrm{Beta}(1,1)$，使证据不足时信念接近无信息分布而非过度自信；证据累积后分布逐步集中。

**（3）证据驱动的信念更新**

- **Thompson 采样**：从 $\mathrm{Beta}(\hat\alpha,\hat\beta)$ 采样效用分数用于排序检索，兼顾利用与探索（证据少的记忆方差大，自然获得探索机会）。
- **留一法反事实信用分配**：反馈只反映记忆集合的联合效果，故用 $A_{t,i}=R_t-R_t^{-i}$ 估计单条记忆的边际贡献（正为有益、负为有害干扰）。
- **记忆级监督目标**：$y^{evi}_{t,i}=\lambda\frac{1+A_{t,i}}{2}+(1-\lambda)\frac{R_t+\bar R^{ret}_{t,i}}{2}$，将边际贡献归一化到 $\{1,0.5,0\}$ 并与整体奖励、留一平均奖励融合。
- **三个训练损失**：
  - 证据损失 $\mathcal{L}_{evi}$：均值平方误差 + 方差正则（鼓励证据充分时分布集中）；
  - 成对排序损失 $\mathcal{L}_{rank}$：基于 $A_{t,i}>A_{t,j}$ 构造偏好对，margin 约束保持任务内偏好次序；
  - 选择性 Beta-KL 正则 $\mathcal{L}_{kl}$：对与目标不一致的证据（目标高时抑制负证据、目标低时抑制正证据）向无信息先验收缩，抑制无支撑的信念累积与过置信。
  - 总目标 $\mathcal{L}_{value}=\mathcal{L}_{evi}+\lambda_{rank}\mathcal{L}_{rank}+\lambda_{kl}\mathcal{L}_{kl}$。

### 2.3 关键实现细节

- 估计器初始化自 Qwen2.5-7B-Instruct，加轻量证据式 Beta 头；LoRA 施加于 q/k/v/o 投影层，rank=8、$\alpha_{LoRA}=16$、dropout=0.05；最大序列长度 4096。
- 检索：text-embedding-3-large + 本地 Qdrant 向量库；每任务取 6 条候选，语义相似度与 Thompson 采样效用 z-score 归一化后融合，权重 $\eta$ 随任务流进度按 sigmoid 从 0.10 升到 0.50；重排后保留相似度 >0.5 的最多 3 条。
- 优化：AdamW，LoRA 学习率 $5\times10^{-5}$、Beta 头 $1\times10^{-3}$，batch size 8；损失权重 1.0 / 0.03 / 0.6。

## 6. 主要结论与发现

- **整体性能最优**：BEAM 在两个执行器下均取得最佳平均成绩（DeepSeek 53.44% vs 最强基线 A-Mem 49.51%，+3.93pp；Gemini 54.57% vs A-Mem 52.14%，+2.43pp），在 AIME、GPQA-Diamond、HLE、BigCodeBench 上全面领先，MMLU-Pro 上保持竞争性。
- **外部记忆并非必然有益**：多个基线在不同任务上波动明显，部分甚至低于 No Memory，说明“语义相关”可能检索到看似相关但实际无用、甚至造成负迁移的记忆。
- **组件均有效**：去掉信念引导选择（退回纯语义相似度）性能一致下降；去掉记忆合成下降（原始记忆含冗余、冲突与任务无关细节）；组合感知的留一法信用分配优于“孤立评估”，说明多记忆交互建模重要。
- **损失项互补**：$\mathcal{L}_{evi}$ 贡献最大（平均下降 1.83pp，提供绝对效用标定），$\mathcal{L}_{rank}$ 强化候选区分度，$\mathcal{L}_{kl}$ 抑制过置信、稳定信念。
- **持续自演化**：随任务流推进，BEAM 相对 No Memory 的增益总体扩大且后期更明显，而其他记忆方法增益不稳定；说明单纯累积经验不足以保证持续改进，记忆质量与选择机制才是关键。
- **跨任务可迁移**：MATH-500 预训练的价值模型在 AIME 早期阶段明显优于从零训练，最终阶段两者趋近，说明迁移主要改善早期适应与反馈效率。

## 7. 优点与亮点

- **视角新颖**：将记忆估值从“静态标量打分”转为“情境条件化的概率信念”，用 Beta 分布同时表达期望效用与不确定性，直接回应 1/1 与 97/100 不可区分的问题，并天然提供探索-利用平衡（Thompson 采样）。
- **方法闭环完整**：记忆构建（多轨迹蒸馏 + 结构化三元组）→ 信念先验推断 → 检索与合成 → 反事实信用分配 → 后验校准，形成可在线运行的自我改进回路，且**骨干 LLM 完全冻结**，工程代价可控。
- **信用分配的巧思**：留一法反事实评估在“多记忆联合作用、反馈只有整体奖励”的困境下给出记忆级监督，且消融验证了它优于孤立评估。
- **损失设计有针对性**：选择性 Beta-KL 正则只惩罚“与目标冲突的证据”，比统一收缩更精细；均匀先验的单位偏移使无证据时不过度自信。
- **实验较克制且诚实**：主动设置测试时扩展的等预算对照排除混淆；分阶段结果明确承认波动与有限样本影响；案例研究具体展示了信念引导如何消除错误选项。

## 8. 不足与局限

- **奖励假设较强**：整套证据更新依赖二值（成功/失败）任务奖励，仅适用于有可验证结果的任务（数学、选择题、代码执行）；开放式生成、长程交互、部分成功等场景需要重新定义似然与信用分配。
- **在线成本高**：每条被检索记忆需 K+1 次执行（完整 + 留一法反事实）才能获得监督，加上多轨迹测试时扩展与共享 judge，实际推理开销显著；论文未量化该成本，也未与“微调/强化学习记忆策略”（如 Memory-R1、MemSkill、ReMe）做实验对比，仅在相关工作提及。

- **遗忘与容量管理缺位**：记忆库只增不减，未讨论条目淘汰、合并、时效衰减或冲突记忆的消解机制。当任务流足够长时，检索候选池膨胀、语义近重复条目增多，Top-$K$ 选择与 Thompson 采样的区分度可能下降；论文的实验流长度（每基准 3–5 阶段）尚不足以暴露这一问题。
- **二值似然与 Beta 共轭的强绑定**：Beta–伯努利共轭是方法优雅性的来源，也是其刚性所在。部分成功（如代码通过部分测试用例）、分级奖励、连续评分等更常见的反馈形态无法直接映射为 $\alpha/\beta$ 累加，需引入 Dirichlet、Beta 混合或序数似然等扩展，论文未给出可行路径。
- **judge 与解析器的潜在偏差**：多轨迹反思与共享 judge 依赖 LLM 判定正确性，论文未报告 judge 与人工标注的一致性，也未讨论解析失败样本的处理方式；不同基线的输出格式差异可能通过解析器引入非方法本身的性能差异。
- **基准污染与时效性**：AIME24/25、GPQA、MMLU-Pro、HLE 均为公开基准，执行器为闭源 API 模型，无法排除训练数据污染；跨阶段“自演化”增益中可能混入模型对同类题型的既有熟悉度。
- **统计严谨性不足**：未报告随机种子数、多次运行的均值±方差、显著性检验或效应量；主表增益（+3.93pp / +2.43pp）在题目量有限的基准上是否超出运行间波动，缺乏直接证据。

## 9. 启示与可拓展方向

- **把“不确定性”作为记忆系统的一等公民**：论文最有价值的迁移性洞见不是 Beta 分布本身，而是“记忆价值应携带可信度信息”这一建模立场。任何记忆增强智能体都可以在检索排序中引入方差惩罚或置信下界（如 LC(B) 式保守估计），以缓解小样本成功带来的过自信检索。
- **信用分配的可复用范式**：留一法反事实 + 归一化目标 + 成对排序损失的组合，为“只有集合级反馈、却需条目级监督”的普遍困境提供了低成本解法，可迁移至工具选择、提示词库演化、多智能体角色分配等场景。
- **可探索的改进方向**：
  - 用**层级/情境分簇的 Beta 信念**（每个记忆在多个任务情境下各有参数）替代单一全局信念，更彻底地实现情境条件化；
  - 引入**信息增益驱动的主动检索**，在证据不足时主动构造验证性子任务，而非被动等待反馈；
  - 用**衰减先验或滑动窗口证据**处理非平稳任务流，使旧证据随分布漂移而失效；
  - 将估计器与执行器的反馈闭环扩展到**开放式任务**（如用 LLM-as-judge 的细粒度 rubric 分数替代二值奖励）。
- **工程启示**：骨干冻结 + 轻量 LoRA 价值头 + 外部向量库的组合，使方法可在单卡部署，具备实际落地可行性；但 K+1 次反事实执行的成本结构提示，实际系统需在“信用分配精度”与“调用预算”之间做显式权衡（如仅在关键记忆或高不确定记忆上触发留一法）。

## 10. 总体评价

- **理论定位**：论文将认知科学中的贝叶斯信念更新与 LLM 智能体记忆管理做了较为自然的对接，问题刻画（情境依赖 + 证据不足导致的不确定性）准确且有现实针对性，属于“问题重构型”贡献而非单纯性能刷榜。
- **方法完成度**：从记忆构建、先验推断、检索决策到后验校准形成闭环，各组件动机清晰、相互支撑，消融实验也基本能定位各部分的独立贡献，方法内部自洽性较好。
- **实证强度**：覆盖 2 个执行器 × 5 个基准，并主动设置测试时扩展等预算对照，显示出对混淆因素的自觉；但受限于基准题目量、缺少多种子统计与成本核算，加之基线与 BEAM 在可训练参数与推理开销上不对等，性能优势的“纯度”仍需更强证据支撑。
- **适用边界**：方法在**有可验证奖励、任务流相对同质、记忆条目可结构化表达**的场景（竞赛数学、选择题、函数级代码）最为可靠；在开放式、长程、奖励稀疏或需细粒度部分信用的场景中，需先解决似然建模与信用分配的形式化问题。
- **综合判断**：这是一篇**思想清晰、方法自洽、实验较克制但统计与公平性论证仍可加强**的工作。其核心贡献（把记忆价值建模为带不确定性的情境化信念，并给出可在线训练的信用分配方案）具有较好的可迁移性，若能补充成本分析、统计显著性、遗忘机制与更广泛的反馈形式支持，将显著提升说服力与实用价值。
