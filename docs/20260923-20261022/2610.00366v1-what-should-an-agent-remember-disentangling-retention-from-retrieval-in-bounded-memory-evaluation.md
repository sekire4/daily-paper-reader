## 摘要
持续运行的智能体必须在信息到达时决定保留什么，并在查询出现后决定呈现什么，然而记忆评估可能混淆这些决策，因为它们比较的方法在保留和选择两方面均存在差异。我们构建了一个流式召回基准，交叉组合保留规则与选择规则，并在相同的300个带种子回合上评估每一种条件。在访问固定不变的情况下，查询感知选择将所需事实召回率提高15.5个百分点（95% CI：12.8至18.2），而同时改变历史访问的混合比较报告了68.7个百分点的优势，其中53.2个百分点可归因于访问。在有界保留下，查询感知选择、稠密选择和oracle选择均达到保留上限，并且有界近期性条件中观察到的全部319次失败均由逐出而非排序错误导致。当目标退入过去足够远时，召回率降至0%。在SQuAD上重复评估保持了保留上限，同时表明稠密检索在自然文本上可以优于词汇检索。这些结果表明，有界记忆评估应固定访问，并分别报告保留和选择。

## Abstract
A persistent agent must decide both what to retain as information arrives and what to surface once a query appears, yet memory evaluations can confound these decisions by comparing methods that differ in both retention and selection. We build a streaming-recall benchmark crossing retention and selection rules and evaluate every condition on the same 300 seeded episodes. Holding access fixed, query-aware selection improves required-fact recall by 15.5 percentage points (95% CI: 12.8 to 18.2), whereas a mixed comparison that also changes history access reports a 68.7-point advantage, of which 53.2 points are attributable to access. Under bounded retention, query-aware, dense, and oracle selection reach the retention ceiling, and all 319 observed failures in the bounded recency condition are caused by eviction rather than ranking errors. Recall falls to 0% as targets recede sufficiently far into the past. Repeating the evaluation on SQuAD preserves the retention ceiling while showing that dense retrieval can outperform lexical retrieval on natural text. These results show that bounded-memory evaluations should hold access fixed and report retention and selection separately.

## 1. 核心问题与研究动机

- **背景**：长期运行的智能体（persistent agent）会积累超出其可同时保持可用范围的观测，因此必须丢弃部分信息，记忆管理本质上是一个**容量预算下的控制问题**：给定 K 个条目的预算，哪些观测应在之后仍然可用？
- **两类被混淆的决策**：
  - **保留决策（retention）**：在每条观测到达时在线做出，必然是**查询无关**的（未来查询尚未出现）；
  - **选择决策（selection）**：在查询到来时做出，可以**查询感知**。
- **核心问题**：现有记忆评测往往用单一准确率数字比较方法，而这些方法可能同时在这两个阶段（甚至"历史访问权限"上）存在差异，导致**看起来的胜利无法归因**——是"记得更久"还是"检索得更好"，抑或只是"被允许看到别人已经丢弃的材料"。
- **对旧版评测的审计发现（问题实证）**：
  - 最强方法在查询时对**完整历史**重排序，最弱方法只能看到**有界缓冲区**——访问权限本身不对等；
  - 模板缺陷使查询中**不含标识目标事实的 token**；
  - 干扰项带有**字面标记**，任何词面重叠打分器都可利用；
  - 五个条件中有两个都保留了全部历史（共享同一访问机制），却被报告出巨大差距，这在原理上不可能反映记忆预算行为。
- **整体含义**：论文的贡献位于**评测方法论层面**（而非提出新记忆架构），主张有界记忆评测应**固定访问权限**，并**分别报告保留率与选择效果**。

## 2. 方法论

### 2.1 核心思想
构建一个**因子化（factorial）流式召回基准**，将"保留规则"与"选择规则"作为两个正交因子交叉，在同一批带种子的回合上评估每个单元格，从而把两个阶段的贡献拆开。

### 2.2 环境构造（合成生成器）
- 一个 episode = **10 条事实 + 2 条查询**；
- 所有事实表面形式统一为 `"The slot is value ."`，slot 在回合内**无放回抽取**，因此查询中的 slot 唯一确定一条事实；
- 干扰项比例 d（默认 0.3），来自**不相交的 slot 词表**但写法相同，故**词面上不可区分**；
- 每条查询均匀采样一个非干扰事实作为目标。

### 2.3 两个因子
**保留规则**（在线消费流，容量 K，永不接触查询）：
- `RECENCY`：保留最近 K 条；
- `RANDOM`：以 p=0.5 接纳，FIFO 逐出；
- `FREQUENCY`：逐出"迄今 token 最稀有"的条目，平局按 FIFO；
- `TYPE-ORACLE`：只接纳非干扰项——读取生成器真值标签，属**特权规则，智能体不可实现**；
- `UNBOUNDED`：全保留（无遗忘参照）。

**选择规则**（对幸存者排序，暴露 top-k，k=3）：
- `RECENCY`、`RANDOM`；
- `QUERY`：查询与事实 token 的 **Jaccard 重叠**，recency 作平局打破（作者强调这是"查询相似度"而非嵌入方法）；
- `DENSE`：MPNet（`all-mpnet-base-v2`，768 维）句向量余弦相似度，是唯一使用学习向量的规则；
- `ORACLE`：目标若在场则直接暴露。

### 2.4 查询信息量操纵
- **信息性查询**：`"What is the slot ?"`（点明目标 slot）；
- **非信息性查询**：`"What is the value?"`（value 不出现在任何事实中）；
- 二者**恰好相差一个 token**，从而把"查询信息量"与其他因素完全隔离。

### 2.5 指标与统计
- **必需事实召回率（required-fact recall）**：目标事实出现在 k 个暴露条目中的查询比例；
- **保留率（retention rate）**：目标在保留阶段幸存的比例，构成任意选择规则的**理论上界**；
- 每单元格 **300 个带种子回合（600 条查询）**；
- 置信区间用**按回合重采样的百分位 bootstrap（2000 次）**，因为同一流的两条查询不独立；
- 种子、配置与逐查询记录随结果保存。

### 2.6 真实文本复验流程（SQuAD）
- 对 SQuAD v1.1 dev 的 300 个问题，将目标段落切句，**含答案的句子为目标**，用无关段落的句子补足到 10 句作为干扰项（无任何标记），查询用**真实 SQuAD 问题**替代模板；
- 保留规则、选择规则、指标与 bootstrap **原封不动导入调用**。

## 6. 主要结论与发现

### 6.1 优势分解（RQ1）
- **混合单元格比较**（UNBOUNDED+QUERY vs RECENCY+RECENCY，即旧版评测的结构）：**+68.7 pp** [65.2, 72.0]；
- **固定访问、只变选择**：**+15.5 pp** [12.8, 18.2]；
- **固定选择、只变访问**：**+53.2 pp** [49.7, 56.8]；
- 即约**四分之三的"头条效应"来自对基线已丢弃材料的重排序自由**。

### 6.2 选择饱和与保留天花板
- 在所有有界行中，`QUERY`、`DENSE`、`ORACLE` 三列**恰好等于保留率**（46.8 / 46.8 / 45.8 / 70.3）；
- 768 维 MPNet 相对词汇规则与 oracle 选择器的召回变化为 **+0.00 pp [0.00, 0.00]**；50 个单元格中无一选择规则超过本行保留率；
- 逻辑本质：**暴露集是保留集的子集**，更好的检索器"在算术上不可能帮忙"；
- 作者明确区分：**"天花板"是普遍主张，"饱和"只是该生成器的性质**（SQuAD 上稠密检索确实更强，但仍不能越过天花板）。

### 6.3 记忆压力下的行为（RQ2）
- **预算**：recency 保留下召回 22.7 → 31.3 → 46.8 → 100 → 100（K=2,3,5,10,20）；**当 K ≤ k 时选择规则完全失效**（保留即全部暴露），各选择规则差距为零；
- **延迟**：recency 保留下 100% → 58.5% → **0.0%**（延迟 0–2 / 3–5 / 6–9）；type-oracle 100% → 97.5% → 31.2%；unbounded 恒为 100%。由于这些行中"选择已等价于 oracle"，**下降完全来自保留损失而非检索失败**；
- **干扰密度**：d 从 0.1 升到 0.7，recency 基本持平（47.3 → 50.5），type-oracle 从 54.0 升到 **100.0**——受益的恰是**需要答案键**的那条规则；FREQUENCY 反而从 47.5 跌到 23.5。

### 6.4 基准伪影造成的虚假增益（RQ3）
- **非信息性查询下**，`QUERY` 列**精确塌陷到** `RECENCY` 列（31.3, 31.3, 30.8, 30.2, 41.2）——无区分性 token 时全部打平，规则退化为平局打破策略；这正是旧版评测**无意中处于的状态**；
- **字面标记伪影**：给干扰项加字面前缀，可使查询感知规则在非信息性查询下提升 **+9.8 pp** [7.7, 12.2]（unbounded）与 **+9.0 pp** [7.0, 11.3]（bounded），其他规则不变——打分器检测的是标记，不是查询匹配；
- **稠密检索器无标记也复现该伪影**：非信息性查询下 DENSE 达 42.0%（机会水平 31.5%），看似"嵌入提取到了信号"，实则其暴露项中**干扰项占比

实则其暴露项中**干扰项占比显著高于保留集基线**——它匹配的是"事实句共享的模板 token"（`The slot is value .`）而非查询对目标的指称，因此只要模板相似度主导打分，任何采用同一句式的条目都会获得高分，查询是否含指称信息变得无关紧要。这说明：**在缺乏区分性查询 token 时，学习型检索器并不会"自动变得聪明"，而会退化为对表面句式的匹配**，从而在旧式模板基准上制造出虚假的"语义检索优势"。

### 6.5 真实文本复验（SQuAD）与结论的可迁移边界
- 在 SQuAD 的 25 个单元格上，**DENSE 确实优于词汇式 `QUERY`**，与合成环境中"+0.00 pp"的零差异形成对照——作者据此明确否定了"选择阶段普遍饱和"这一过强解读；
- 但**保留率天花板依然严格成立**：任何选择规则在任一行中都未超过该行的保留率，稠密检索的增益只在"目标尚未被逐出"的范围内兑现；
- 非信息性查询下的"塌陷"现象在真实问题上明显减弱（真实问题本身携带指称信息），提示该伪影主要是**模板基准的产物**而非检索方法的固有缺陷。

### 6.6 端到端问答与失败归因
- **FLAN-T5-large 端到端检查**：归一化精确匹配随召回率单调变化，方向与召回率一致，但**绝对水平系统性低于召回率**，说明"召回到"只是答案正确的必要条件而非充分条件（生成器还会引入额外损失）；因此用召回率作为诊断指标是合理的，但不能直接等同于下游性能；
- **319 次失败的逐条归因**：以 **eviction（目标在保留阶段已被丢弃）为主**，**displacement（目标幸存但被挤出 top-3）次之**，**similarity confusion（干扰项打分高于目标）最少**；
- 该分布与"保留是主要瓶颈、选择在多数单元格已接近饱和"的主结论**相互印证**，也解释了为何提升检索器规格难以带来实质收益。

## 8. 方法论启示

1. **评测必须固定"历史访问权限"**：否则方法间比较混合了"记忆能力"与"被允许看到多少"两个变量，效应无法归因；
2. **保留率应作为一等公民指标与上界报告**：任何选择指标都应附带其对应保留率，超出上界的结果即为评测漏洞的强信号；
3. **查询信息量需要显式操纵**：信息性/非信息性查询的对照是检测"打分器是否真在使用查询"的低成本探针；
4. **干扰项不得带字面标记**，且应做标记控制实验，否则词面重叠类方法会被系统性高估；
5. **报告失败归因分布**比报告单一准确率更有诊断价值，能直接指向应改进的阶段。

---

## 9. 总体评价

- **贡献定位准确**：论文不自称提出新记忆架构，而是提供一套**可分解、可审计的评测装置**与一组**反直觉但逻辑自洽**的实证结论（约 3/4 的头条增益来自访问权限不对等；选择阶段在特定构造下饱和；模板基准可制造虚假语义增益）；
- **论证严谨度较高**：配对种子、按回合 bootstrap、特权方法显式标注、构造上限与性能结果区分、主动用更强检索器自我反驳、并在真实文本上诚实报告自身结论不成立的部分——这些都超出同类评测论文的常见标准；
- **主要弱点在外推**：结论的强度受限于极小的合成环境与玩具级保留策略，"保留是瓶颈"这一定性判断很可能稳健，但具体的饱和数值与效应量不宜外推；
- **实践价值**：对记忆智能体的基准设计者与论文作者具有直接的方法论约束力（固定访问、报告上界、控制标记、操纵查询信息量），其"先分解再比较"的思路也可迁移到 RAG、长上下文与流式感知等相邻评测场景。
