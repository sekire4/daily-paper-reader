## 摘要
智能体能够从过去的执行中学习，但使不同智能体能够复用并基于彼此经验继续构建仍具挑战性。我们提出 EpiCon，一种用于智能体集体学习的共享多模态记忆框架，无需更新宿主模型参数。EpiCon 通过两个独立训练的 2B 模型——记忆控制器和树形自组织器——将问题级记忆演化与持久经验库相连接。控制器在多次尝试中联合细化文本指导与视觉证据，并选择性纳入视觉记忆。自组织器分层整合经验教训，并为新问题检索经验与规则。我们在涵盖四个多模态任务领域的十一个基准上评估 EpiCon，使用两套测试框架和多种骨干模型。即使仅进行一次求解尝试，冻结的经验库也能提升其他系统。第二套测试框架在十一个基准上将原始系统的宏平均得分提高 2.6 分。在四种宿主配置下，EpiCon 相比 No Memory 将宏平均得分提高 1.7 至 4.9 分，并相对于与骨干模型同等规模的记忆模型将记忆操作时间减少 67% 至 74%。

## Abstract
Agents can learn from past executions, but enabling different agents to reuse and build on one another's experience remains challenging. We introduce EpiCon, a shared multimodal memory framework for agent collective learning without updating host model parameters. EpiCon links question-level memory evolution to a persistent experience bank through two independently trained 2B models: a memory controller and a tree self-organizer. The controller jointly refines textual guidance and visual evidence across attempts and selectively includes visual memory. The self-organizer consolidates lessons hierarchically and retrieves experience and rules for new problems. We evaluate EpiCon on eleven benchmarks spanning four multimodal task domains, using two harnesses and multiple backbones. A frozen bank improves other systems even with a single solving attempt. A second harness raises the original system's macro-average score by 2.6 points across eleven benchmarks. Across four host configurations, EpiCon improves macro-average scores by 1.7 to 4.9 points over No Memory and reduces memory-operation time by 67\% to 74\% relative to backbone-sized memory models.

## 二、方法论

### 2.1 总体架构

- **EpiCon（Episodic Consolidation）**：由专用记忆 harness 与两个独立训练的 2B 模型组成：
  - **记忆控制器 \(C_\theta\)**：负责问题级文本与视觉记忆的联合更新；
  - **树自组织器 \(S_\phi\)**：负责共享经验库的维护、整合与检索。
- **共享经验库 \(B\)** 独立于 MAS 存在；宿主 MAS 保留自身编排与 backbone，参数不变。
- 维护更新形式化为：\(B^{(k+1)} = S_\phi(B^{(k)}, U_k)\)，其中 \(U_k\) 为第 \(k\) 个维护步接受的教训与修订批次。评估时经验库冻结，问题级更新仅作用于当前问题。

### 2.2 问题级多模态记忆协同演化

- 记忆表示为 \(W_{i,t}=(M^{text}_{i,t}, M^{vis}_{i,t})\)：文本记录可操作指导、适用条件与警示；视觉记忆指向源图中的支撑区域。
- 更新公式：\(W_{i,t}=C^{update}_\theta(W_{i,t-1}, x_i, \hat y_{i,t}, \tau_{i,t})\)，输入为上一状态、问题与图像、最新答案及执行轨迹。
- 控制器**联合提出**修订文本、源图像与区域，可保留、替换或删除视觉证据；harness 验证提案并生成裁剪，非法提案不改变记忆。
- **自适应视觉注入**：门控 \(g_{i,t}\in\{0,1\}\)，记忆输入为
  - \(g=0\)：\((T_{i,t}, \varnothing)\)；
  - \(g=1\)：\((T_{i,t}, V_{i,t})\)。
  - 门控只决定是否进入下一次输入，不删除已存储的视觉记忆；原始问题图像始终可用。

### 2.3 共享经验整合与复用

- **树形组织**：叶子存问题级教训，内部节点分组并总结相关经验；维护操作包括 Place、Merge、Split + Lift、Consolidation，由 harness 验证执行并可按容量分区。
- **规则抽象**：Consolidation 捕捉共性指导与冲突；harness 依据支持度、失败、冲突与证据强度决定抽象层级与规则资格，内部节点可保留合格摘要或成为可复用规则。
- **检索**：\(R_i = S^{retrieve}_\phi(x_i, \mathrm{Recall}(x_i, B))\)。先用冻结文本编码器从节点索引（主题、范围、问题锚点）召回候选，再由自组织器判断适用规则、具体经验或“无适用项”。
- 检索到的内容可供任意 harness 使用，视觉内容的投递由控制器控制。

### 2.4 监督数据与训练

- **教师模型**：Qwen3.8-27B 生成初始记忆更新、教训与树操作演示；Qwen3.8-Flash-Next 选择性修订失败更新、提升教训质量并纠正树操作目标。
- **源数据**：MathNet、MathV360K、ChartQA、InfoVQA、DocVQA、ChartNet，覆盖视觉数学、文档理解、图表与信息图推理三个领域；轨迹由 CAMEL、Codex、DeepSeek-Harness 采集。
- **Replay 筛选**：
  - **Repair**：新记忆使失败尝试转为成功则保留；
  - **Compress**：保持成功且满足 \(\text{tokens}(\ell')<\text{tokens}(\ell)\)、\(\text{area}(b')\le\text{area}(b)\)。
  - 得到约 **25K** 条记忆变换监督样本。
- **树监督**：约 **6.5K** 条操作演示，经 schema、节点引用、分区覆盖、选择约束与来源检查；包含合法空检索。
- **训练细节**：两个 Qwen3.5-2B 模型独立微调；LoRA rank 16、scaling 32，仅作用于线性层，冻结视觉编码器与 aligner；3 epochs、学习率 \(10^{-4}\)、最大序列 8,192、每设备 batch 2、梯度累积 8；按验证损失选 checkpoint（控制器 step 1,000，树自组织器 step 258）。
