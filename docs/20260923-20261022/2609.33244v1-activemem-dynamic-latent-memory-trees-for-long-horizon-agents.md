## 摘要
大语言模型（LLM）智能体日益依赖外部记忆来支持长时程推理与决策。现有记忆系统通常将历史轨迹或摘要作为独立的上下文片段进行检索，忽略了多步执行背后的过程依赖关系。随着记忆规模扩大，这种扁平化检索会引入上下文碎片化和跨任务干扰，导致推理轨迹在结构上不一致。我们提出 ActiveMem，一种分层记忆框架，它将智能体经验递归地组织为具有依赖感知的潜在执行树。ActiveMem 将轨迹抽象为可复用的子任务节点，同时显式保留执行转移，从而能够以当前执行状态为条件检索连贯的推理路径。为支持持续适应，ActiveMem 进一步通过强化学习学习动态记忆扩展、检索与剪枝策略。在多种智能体基准上的实验表明，相较于现有基于记忆的智能体，ActiveMem 持续提升了任务完成率、推理稳定性和记忆效率。此外，ActiveMem 使紧凑型开放权重模型能够取得与规模大得多的专有系统相竞争的性能。

## Abstract
Large Language Model (LLM) agents increasingly rely on external memory to support long-horizon reasoning and decision making. Existing memory systems typically retrieve historical trajectories or summaries as independent context fragments, overlooking the procedural dependencies underlying multi-step execution. As memory scales, such flat retrieval introduces context fragmentation and cross-task interference, leading to structurally inconsistent reasoning trajectories. We propose ActiveMem, a hierarchical memory framework that recursively organizes agent experiences into dependency-aware latent execution trees. ActiveMem abstracts trajectories into reusable subtask nodes while explicitly preserving execution transitions, enabling coherent reasoning-path retrieval conditioned on the current execution state. To support continual adaptation, ActiveMem further learns dynamic memory expansion, retrieval, and pruning policies through reinforcement learning. Experiments across various agent benchmarks demonstrate that ActiveMem consistently improves task completion, reasoning stability, and memory efficiency over existing memory-based agents. Moreover, ActiveMem enables compact open-weight models to achieve competitive performance with substantially larger proprietary systems.

## 一、核心问题与研究动机

- **背景**：LLM 智能体被越来越多地要求完成长时程任务（持续推理、自适应规划、多步环境交互）。由于上下文窗口有限、误差会逐步累积，外部记忆已成为长时程智能体的关键基础设施。
- **现有做法的缺陷**：主流记忆系统（ReAct 式原始轨迹累积、摘要压缩、向量库相似度检索、情景记忆单元）本质上是**扁平记忆池**，把历史轨迹或摘要当作**互相独立的上下文片段**检索，忽略了多步执行背后的**过程依赖（procedural dependency）**。
- **由此产生的两个具体问题**（见图 1）：
  - **上下文碎片化（Context Fragmentation）**：检索到语义相似但顺序不兼容的动作片段，拼接后推理链断裂。
  - **跨任务泄漏（Cross-Task Leakage）**：例如在订机票流程中盲目套用订酒店的步骤（选房型、填日期、加早餐），造成工作流错配。
- **核心洞察**：智能体行为本身是**层次化、因果受约束**的——高层目标逐级分解为可复用子任务，子任务之间存在执行转移依赖。因此记忆的关键不只是“存什么”，而是“**如何按执行结构组织与检索**”。
- **研究目标**：设计一种既能做**结构化抽象**、又能做**依赖感知检索**，并且能**随交互持续演化**的智能体记忆框架，且在冻结主干 LLM 的前提下生效。

## 二、方法论

### 2.1 整体形式化

- 交互建模为序贯决策：任务指令 $x$，冻结的 LLM 策略 $\pi_\theta$，环境 $\mathcal{E}$，轨迹 $\tau=(s_0,a_0,\dots,s_T)$。
- 历史前缀 $\tau_{<t}$ 被压缩为动态的**层次潜在记忆树（HLMT）** $\mathcal{T}_t$，通过离散更新函数演化：$\mathcal{T}_t=\text{TreeUpdate}(\mathcal{T}_{t-1},a^{tree}_{t-1})$。
- 检索得到路径 $P_t=f_{retrieve}(s_t,\mathcal{T}_t)$；轻量控制器 $W_\phi$ 融合“当前隐状态 $h_t$（冻结 LLM 末 token hidden state）+ 路径表示”产生共享表示 $u_t$，再分两路输出：**潜在记忆前缀 $m_t$** 与**树动作 $a^{tree}_t$**。
- 优化目标：$\max_\phi \mathbb{E}_{x\sim\mathcal{D},\tau\sim\pi_{\theta,\phi}}[R(\tau)]$，其中 $\pi_{\theta,\phi}(a_t|s_t)=\pi_\theta(a_t|s_t,m_t(\phi))$，即通过注入前缀隐式地参数化一个新策略。

### 2.2 层次潜在记忆树（HLMT）

- 节点定义为三元组 $n_i=(e_i,pa(i),ch(i))$：$e_i\in\mathbb{R}^d$ 为控制器产生的**压缩潜在摘要嵌入**，$pa(i)$、$ch(i)$ 为父指针与子节点集合。
- 选择**树**而非通用图：树显式编码语义层次——上层节点承载粗粒度任务语义，下层保留细粒度执行细节，使检索可以**由粗到细逐步收窄搜索空间**。
- 初始化为一个**虚拟根节点** $n_r$，不含任务语义，每个 episode 重置。

### 2.3 依赖感知检索

- 以 $h_t$ 为查询，从根开始做**递归贪心遍历**，每层选取余弦相似度最大的子节点：
  $$n_{k+1}=\arg\max_{n\in ch(k)}\frac{h_t\cdot e_n}{\|h_t\|\|e_n\|}$$
- 当最大相似度低于阈值 $\tau_{stop}$ 时停止，得到激活路径 $P_t=(n_1,\dots,n_d)$；若无子节点满足条件，则路径仅含根。
- 检索到的是**依赖一致的执行路径**，而非孤立历史片段，从而在结构上抑制无关分支的干扰。

### 2.4 双头记忆控制器

- **共享表示**：路径节点嵌入做均值池化 $\bar p_t=\frac{1}{|P_t|}\sum_{n_i\in P_t}e_i$（路径顺序已由遍历深度隐式编码），再经 2 层 MLP：$u_t=\text{MLP}_{shared}([h_t;\bar p_t])$。
- **潜在注入头（Latent Injection Head）**：$m_t=W_{latent}u_t\in\mathbb{R}^{l_p\times d_{model}}$，作为**动态软提示 / 记忆前缀**直接拼接到当前观测的输入嵌入（附录中进一步说明可拼接到选定注意力层的 KV cache：$\tilde K=[m_t;K],\tilde V=[m_t;V]$）。避免了逐层修改主干的开销；RL 梯度可穿过冻结 LLM 的计算图回传到输入层，从而端到端更新 $\phi$。
- **树动作头（Tree Action Head）**：$\pi_{tree}(\cdot|u_t)=\text{Softmax}(W_{tree}u_t)$，在离散拓扑操作上采样，并把优化**解耦为高频语义更新与低频效用维护**。

### 2.5 记忆树的在线演化与维护

- **即时执行（TreeUpdateImmediate）**，在每步交互中在线发生：
  - `insert`：新节点 $e_{new}=W_{ins}u_t$ 挂到检索到的叶子 $n_d$ 之下，显式保留时序层次；
  - `update`：用门控 $\alpha=\sigma(W_{gate}u_t)$ 精化叶子表示：$e_d\leftarrow(1-\alpha)e_d+\alpha W_{upd}u_t$；
  - 所有新插入/更新的嵌入均做 **L2 归一化**，防止 RL 连续优化导致表示坍缩。
- **延迟执行（TreeMaintenance）**，在 episode 结束时进行：
  - 统计节点情节效用 $S(n_i)$（对同 episode 内多次激活取平均，避免高频循环被过度计分），并用 EMA 平滑 $S_{EMA}(n_i)\leftarrow(1-\beta)S_{EMA}(n_i)+\beta S(n_i)$；
  - **剪枝**：$S_{EMA}<\tau_{del}$ 的节点被删除，其子节点重新挂到祖父节点以保持拓扑连通；
  - **合并**：兄弟节点相似度 $\text{sim}(e_i,e_j)>\tau_{merge}$ 时做平均池化融合，控制冗余。
- **异步提交策略**（附录 8.1）：解码期间检索只在**时间冻结的树快照**上进行，树动作先缓存，待 rollout 结束后再异步提交，避免自回归解码中拓扑并发变更导致的检索不一致。

### 2.6 训练配方（GRPO + 分层信用分配）

- 采用 **GRPO**（Group Relative Policy Optimization）替代 PPO，**不需要 critic 网络**，显著降低长时程场景的显存开销；对同一 prompt 采样一组轨迹 $G$ 做组内归一化。
- **过程可验证监督**：节点效用融合细粒度步骤奖励与最终回报 $S(n_i)=\sum_{k=t_i}^{T}\gamma^{k-t_i}r_k$，缓解长时程奖励稀疏问题。
- **分层优势**（式 5）：
  $$A_i=\lambda_g\frac{S(n_i)-\mu_G(S)}{\sigma_G(S)+\epsilon_0}+\lambda_l\left(S(n_i)-S(pa(i))\right)$$
  全局项衡量节点相对同组其它 rollout 的任务级有用性，局部项保留相对父节点的专门化增益；附录进一步给出深度折扣 $\tilde A_i=\gamma^{d_i}A_i$。
- **联合目标**（式 6）：$\mathcal{L}(\phi)=\mathcal{L}^{latent}_{GRPO}(\phi)+\lambda\mathcal{L}^{tree}_{GRPO}(\phi)$，两项均使用带 clip 的 GRPO 代理目标，潜在项另加 KL 惩罚 $-\beta D_{KL}(\pi_{\theta,\phi}\|\pi_{ref})$ 防策略坍缩；两头的梯度在共享表示上联合累积。
- 主干 $\theta$ **全程冻结**，只训练轻量控制器（附录提到 LoRA，$r=16$、$\alpha=32$、作用于 `q_proj`/`v_proj`）。

### 2.7 复杂度与理论分析（附录）

- **检索复杂度** $O(DB)\approx O(\log_B|\mathcal{T}|)$，显著优于扁平检索的 $O(|\mathcal{T}|)$；空间复杂度仍为 $O(N)$；控制器开销 $O(d_{model}\times d_{hidden})$，潜在注入带来与前缀长度线性相关的固定注意力开销。
- **命题 10.5（因果解耦）**：在“拓扑域隔离”假设（不同子任务路径除域根外拓扑不相交）下，路径式激活使无关历史混杂因子与当前动作的条件互信息 $I(Z^{irr}_L;Y|M_{tree})=0$，而扁平记忆因后门 collider 路径 $Z^{irr}_L\to M_{flat}\leftarrow Z^{curr}_H\to Y$ 必然 $>0$。
- **命题 10.6（树规模有界）**：在 $\tau$ 球覆盖与剪枝率 $\rho$ 下，$\lim_{N\to\infty}\mathbb{E}[|V_N|]\le\frac{1}{(1-\rho)c\tau^D}\in O(1)$，即终生部署下记忆规模不会随任务流线性膨胀。
- **命题 10.7（方差缩减）**：因主干冻结、可训练 MDP 的有效时域从 token 级 $T_{token}$ 压缩到树深 $T_{mem}$，$\text{Var}[\nabla J_{mem}]\le(T_{mem}/T_{token})^2\text{Var}[\nabla J_{token}]$，即二次方差缩减。
