## 摘要
大型语言模型（LLM）智能体复用外部记忆来指导新任务，但有效检索需要学习哪些记忆集合能够改进执行。此类学习依赖于昂贵的结果反馈：普通检索仅能观察到已执行的集合，而评估替代集合则需要额外的 rollout。我们提出 UpliftMem，它从相对于同一执行器在无记忆情况下的集合级执行提升中学习记忆检索。对检索偏好如何限制反馈覆盖的理论分析，促使我们对替代记忆集合进行有针对性的探测。探测选择遵循样本信息期望价值（EVSI）准则，该准则在相关高斯模型下以闭式形式导出，从而根据其对局部检索决策的预期改进来分配有限的训练 rollout。共享评分器在冻结执行器下训练，并在测试时无需探测即可选择记忆集合。在 ALFWorld、WebShop 和 BigCodeBench 上，UpliftMem 在主评估集上取得了所评估基线中的最佳成功率。受控固定存储与匹配探测预算的评估进一步表明，其记忆使用决策得到改进，并且对执行反馈的利用更有效。

## Abstract
Large language model (LLM) agents reuse external memory to guide new tasks, but effective retrieval requires learning which memory sets improve execution. Such learning relies on costly outcome feedback: ordinary retrieval observes only executed sets, while evaluating alternatives requires additional rollouts. We introduce \textsc{UpliftMem}, which learns memory retrieval from set-level execution uplift relative to the same executor without memory. A theoretical analysis of how retrieval preferences restrict feedback coverage motivates targeted probing of alternative memory sets. Probe selection follows an expected value of sample information (EVSI) criterion, derived in closed form under a correlated Gaussian model, to allocate limited training rollouts according to their expected improvement in local retrieval decisions. The shared scorer is trained with a frozen executor and selects memory sets without test-time probes. Across ALFWorld, WebShop, and BigCodeBench, \textsc{UpliftMem} achieves the best success rates among evaluated baselines on the main evaluation sets. Controlled fixed-store and matched probe budget evaluations further demonstrate improved memory-use decisions and more effective use of execution feedback.

## 1. 核心问题与研究动机

- **背景**：LLM 智能体通过外部记忆池复用过往经验（轨迹、程序性知识、反思），但“语义相关”的记忆并不必然改善执行。论文开篇给出反例：任务是找 60 美元以下防水背包，无记忆时智能体成功，检索到“推荐热门防水款”的记忆后却买了 89 美元商品。
- **核心问题一（监督信号的定义）**：应以什么为目标学习检索？论文主张用**集合级执行增益（execution uplift）**——同一执行器、同一任务下，带完整记忆集合与不带记忆的期望效用差，从而把“执行器本身就能成功”与“记忆带来的额外收益”区分开。由于记忆之间存在互补、冗余、冲突，效应必须在**完整集合**层面建模，而非单条记忆打分。
- **核心问题二（反馈获取的耦合）**：uplift 标签需要真实执行，成本高昂。普通检索只对**被选中的集合**产生直接反馈，未被选中的替代集合没有标签；而被低估的集合又更难被选中，形成“越不选越没数据、越没数据越不选”的循环。
- **整体含义**：论文把记忆检索重新表述为一个**“学什么经验可用”与“决定哪些缺失结果值得观测”相互耦合的学习问题**，在有限 rollout 预算下同时解决价值估计与反馈采集。

## 2. 方法论

### 2.1 效用与集合级 uplift 定义

- 执行效用同时纳入性能与成本：`U(τ) = R(τ)·[1 + γ·I(R≥ρ)·(1 − C/Cmax)]`，其中 R 为任务表现，C 为协议定义的成本（ALFWorld/WebShop 计动作数，BCB 计注入的实现证据 token 数），γ 为效率奖励权重，ρ 为性能阈值。
- 集合 uplift：`Δ(c,S) = V(c,S) − V(c,∅)`，标签为配对执行差 `y_S = U(τ(c,S)) − U(τ(c,∅))`。因 `V(c,∅)` 与参数无关，用 Δ 替代 V 不改变最优解；并强制 `Gθ(c,∅)=0` 作为锚点。

### 2.2 共享打分器与集合构造

- **参数化**：以 Qwen3-Reranker-0.6B 初始化，输入“任务上下文作 Query + 完整记忆集合作 Document”，取 yes/no token logit 经仿射校准映射到效用单位，LoRA 微调（含校准系数 a、b 联合优化）。
- **条件增益**：`gθ(m|c,S) = Gθ(c,S∪{m}) − Gθ(c,S)`，`gθ(STOP|c,S)=0`；沿路径求和可望远镜化为终端集合价值 `Gθ(c,S_ℓ)`。
- **训练采样**：按 `softmax(gθ/τ_tr)` 采样加记忆或 STOP 动作，记录完整路径用于策略学习。
- **测试推理**：宽度为 2 的 beam search，保留跨深度归档中的最高价值集合（含空集），允许保留负即时增益的中间集合以暴露后续互补性；复杂度约 O(W·N·K) 次打分。

### 2.3 理论分析：检索偏好如何压制反馈覆盖

- **Proposition 1**：对返回集合 B 的所有可行构造路径 a，其被采样概率满足 `p_B ≤ Σ_a exp(−d(a)/τ_tr)`，d(a) 为累积动作 deficit。即局部不被偏好的动作会指数级压低对应集合获得直接反馈的概率。
- **Corollary 3**：n 次独立运行下 `E[N_B(n)] = n·p_B`，首次到达时间 `E[T_B] = 1/p_B`，并给出零覆盖概率下界。
- **Proposition 4**：在允许集合间结果分布独立变化的模型类中，若 p_B 很小，则基于普通检索数据的最坏情形符号错误率至少为 `½(1−p_B)^n`；p_B=0 时该集合的 uplift 符号完全不可识别。
- **A.3**：将结论扩展到策略随训练变化的在线情形（用 ϵ_t 序列刻画），并给出独立探测批次把覆盖概率提升为 `1 − (1−p_B)^n(1−r_B)`。
- 这些结果直接**为“定向探测”提供理论依据**：仅靠改进估计器无法修复结构性缺失的标签。

### 2.4 决策感知探测（EVSI）

- **相关高斯代理**：`G̃(c,S) = Gθ(c,S) + φ(c,S)ᵀξ`，`ξ~N(0,Σ)`；测量模型 `y_Q = μ_Q + Φ_Qξ + ε_Q`，其中执行噪声 `Ω_Q = diag(ν_i²) + ν_0²·11ᵀ` 显式建模**共享无记忆参照带来的相关噪声**。
- **可分辨方差**：`s_j²(Q) = k_jᵀ W_Q⁻¹ k_j`，`W_Q = Φ_QΣΦ_Qᵀ + Ω_Q`；其关键性质是**与未来实际观测值无关**，因此可在执行前算出。
- **Theorem 2（闭式 EVSI）**：对局部比较 j，`E_j(Q) = s_j(Q)·ψ(|μ_j|/s_j(Q))`，`ψ(t)=φ(t)−tΦ(−t)`。该值等于“决策机会损失的期望减少量”，同时兼顾**可分辨不确定性与当前决策边际**；并证明 ∂E/∂s>0、∂E/∂a<0、上界 `s_j/√(2π)`。
- **批量选择**：聚合 `H(Q)=Σ_j E_j(Q)`；逐个贪心计算边际增量 `V_t(q)=Σ_j E_j(Q_t∪{q}) − Σ_j E_j(Q_t)`，按 softmax(V_t/τ_evsi) 采样下一个探测，选中后更新（用 Eq.45 的增量方差公式避免重复计算，Cholesky 求解避免显式求逆）。
- **探测池构造**：对采集窗口内每个任务的已选集 S，构造删除、添加、替换的一步编辑邻域，去重后作为候选；比较族 G 包含“保留 vs 删除”“扩展 vs 停止”“共享基座的替换对比”等局部决策。
- **理论定位**：Proposition 7 证明二元 EVSI 的最大值 ≤ 有限族选择 EVSI ≤ 其求和；A.6 说明在固定比较下互信息与 EVSI 排序一致，但跨比较时 EVSI 额外计入决策边际与效用尺度。

### 2.5 学习目标与记忆写入

- **价值监督**：`L_reg`（Huber，按 |y| 加权，w_mag 下限 w_min）+ `L_sign`（BCEWithLogits，排除 |y|≤ε_sign）+ `L_pair`（softplus 成对排序，要求同任务、同参照、标签差 > ε_rank），加权为 `L_value`。
- **策略监督**：`L_policy = −E[ sg(ω_i)·(1/L_i)·Σ log πθ ]`，ω_i 由终端集合 uplift 符号裁剪得到（`min(y,A_max)`，负值再乘 η_neg），stop-gradient 防止价值头被策略梯度污染；只回放当前打分器下采样的最新批次路径。
- **训练流程**：先 value-only warm-up，再联合优化 `L_value + L_policy`；执行器全程冻结；每 h=400 个任务触发一次采集，每次最多 B_p=300 条探测执行。
- **执行验证式记忆写入**：从完成轨迹蒸馏候选记忆，在**源任务**上单独验证其 singleton uplift `u_k`；若 `u_k > 0` 直接接受，否则最多修订 T=3 次并保留最优版本；无论是否入池，该标签都进入价值监督数据。
