## 摘要
检索增强生成（RAG）通过检索外部知识来提升大语言模型（LLMs）的性能。近年来，一些RAG方法将推理与检索交替进行，使LLMs能够逐步生成子查询并检索外部知识。然而，这些方法可能面临子查询冗余或无效以及查询探索多样性不足的问题。此外，由于推理与检索紧密交织，不断演化的推理过程如何影响查询意图仍不清楚。为了刻画推理过程中查询意图的演化，我们引入了搜索动量（search momentum），用于捕捉沿推理轨迹生成的子查询的历史变化所诱导的累积检索倾向。通过基于动量的分析，我们发现查询生成过程倾向于沿已有检索轨迹持续演化。基于这一观察，我们提出了MAPS，一种用于调控搜索动量并缓解查询意图漂移的宏自适应并行推理框架。MAPS首先保留已检索知识和精炼后的推理状态，从而降低历史推理轨迹对后续子查询生成的影响。随后，MAPS将传统的顺序推理过程扩展为并行推理范式。在每次迭代中，MAPS识别互补的检索方向，生成相应的子查询以进行并行检索，并整合检索到的证据以更新知识和推理状态。在六个问答基准上的实验表明，MAPS在不同骨干模型上均持续优于代表性的RAG方法。所有代码和资源见 https://github.com/NEUIR/MAPS。

## Abstract
Retrieval-Augmented Generation (RAG) improves the performance of Large Language Models (LLMs) by retrieving external knowledge. Recently, some RAG methods interleave reasoning and retrieval, enabling LLMs to progressively generate sub-queries and retrieve external knowledge. However, these methods may suffer from redundant or ineffective sub-queries and insufficiently diverse query exploration. Moreover, due to the tightly interleaved nature of reasoning and retrieval, it remains unclear how the evolving reasoning process influences query intent. To characterize the evolution of query intent during reasoning, we introduce search momentum, which captures the accumulated retrieval tendency induced by historical changes in generated sub-queries along the reasoning trajectory. Through momentum-based analysis, we find that the query generation process tends to continuously evolve along existing retrieval trajectories. Based on this observation, we propose MAPS, a Macro-Adaptive Parallel Reasoning framework for regulating search momentum and mitigating query-intent drift. MAPS first retains the retrieved knowledge and a refined reasoning state, thereby reducing the influence of historical reasoning trajectories on subsequent sub-query generation. Subsequently, MAPS extends the conventional sequential reasoning process into a parallel reasoning paradigm. At each iteration, MAPS identifies complementary retrieval directions, generates corresponding sub-queries for parallel retrieval, and consolidates the retrieved evidence to update the knowledge and reasoning states. Experiments on six question-answering benchmarks demonstrate that MAPS consistently outperforms representative RAG methods across different backbone models. All code and resources are available at https://github.com/NEUIR/MAPS.

## 一、核心问题与整体含义

- **研究背景**：检索增强生成（RAG）通过引入外部知识缓解大语言模型幻觉，但多跳问题所需证据常分散在多个文档中，单次检索不足。近期方法将推理与检索交错进行，让模型逐步生成子查询并检索证据。
- **核心问题**：交错式 RAG 在迭代中容易产生冗余或无效子查询，检索链过长、探索多样性不足；更关键的是，推理与检索紧密耦合，历史检索轨迹会持续影响后续查询意图，导致“查询意图漂移”。
- **概念贡献**：论文提出“搜索动量”（search momentum），用于刻画沿推理轨迹由历史子查询变化累积形成的检索倾向。分析发现，后续子查询会越来越沿既有检索轨迹演化，而不是通过推理自我纠正。
- **整体含义**：论文试图从“调控搜索动量”的角度抑制查询意图漂移，使迭代检索始终围绕原始信息需求展开，并通过并行推理扩展搜索方向。

## 二、方法论

### 1. 搜索动量的形式化与诊断

- 给定初始查询 \(q_0\) 和历史推理轨迹，模型在第 \(t\) 步生成推理步骤与子查询 \(q_t\)，检索文档并得到观察 \(o_t\)。
- 将子查询编码为语义向量，定义搜索动量：
  - \(m_t = \beta_t m_{t-1} + (1-\beta_t)(q_t - q_{t-1})\)
  - 其中 \(m_0=0\)，\(\beta_t\) 控制历史检索倾向的保留强度；动量方向表示检索意图的主要演化方向。
- 用动量预测下一步查询相对原始查询的偏移方向：
  - \(S_t = \cos(m_t, q_{t+1}-q_0)\)
  - 通过最大化方向对齐得分拟合 \(\beta_t\)，采用 L-BFGS-B 求解有界优化问题。
- 诊断结论：随推理推进，\(\beta_t\) 与 \(S_t\) 均上升，说明历史查询对后续查询生成的影响增强，查询更容易沿已有轨迹漂移。

### 2. MAPS 框架

MAPS 的核心思想是：**削弱历史检索轨迹对后续子查询的直接影响，并通过并行探索多个互补检索方向来校准搜索动量**。

- **推理解耦（Reasoning Disentanglement）**：
  - 不再把完整历史推理轨迹 \(R_{t-1}=(r_1,q_1,o_1,\dots)\) 显式输入后续推理。
  - 仅保留累积知识观察集 \(O_{t-1}=(o_1,\dots,o_{t-1})\) 和精炼推理状态 \(\tilde r_{t-1}\)。
  - 后续推理条件变为 \((r_t,q_t,o_t)=M_{\text{Reason}}(q_0,O_{t-1},\tilde r_{t-1})\)，从而减少历史子查询和推理痕迹对查询意图的传播。

- **并行推理与搜索方向校准**：
  - 用方向提议模型 \(M_{\text{Intent}}\) 从原始问题、累积知识和精炼状态中识别多个互补检索方向 \(\{s_t^1,\dots,s_t^N\}\)。
  - 用查询生成模型 \(M_{\text{Query}}\) 将每个方向实例化为独立子查询，形成查询集合 \(Q_t\)。
  - 每个子查询独立检索 top-\(K\) 文档，合并为证据集 \(D_t\)。
  - 用精炼模型 \(M_{\text{Refine}}\) 整合多方向证据，生成当前知识观察 \(o_t\)，并更新精炼推理状态 \(\tilde r_t\)。
  - 当累积知识满足信息需求或达到最大迭代次数 \(T\) 时终止，最终答案由 \(M_{\text{Reason}}(q_0,O_T,\tilde r_T)\) 生成。

- **方法特点**：不是简单增加并行子查询，而是先解耦历史轨迹，再在每一轮显式探索互补方向，以降低搜索动量被单一偏差方向主导的风险。

## 八、局限与不足

- **额外计算开销未量化**：每轮需进行方向提议、多个子查询生成、并行检索与证据精炼，检索调用数和推理 token 数明显高于顺序式 RAG；论文未报告延迟、吞吐、token 成本或 GPU 消耗，难以评估实际部署代价。
- **对方向提议模块的依赖较强**：并行方向的质量取决于 \(M_{\text{Intent}}\) 能否识别互补且不冗余的检索方向；若提议偏差，可能引入无关证据。方向数量 \(N\) 的选择、方向去重与冲突消解机制缺少敏感性分析。
- **推理解耦可能损失细粒度推理约束**：仅保留累积观察与精炼推理状态，虽能抑制查询漂移，但在强多跳约束问题中，某些中间推理前提可能被压缩掉；论文未系统分析哪些问题类型因解耦受益、哪些可能受损。
- **动量模型较为简化**：线性累积形式与余弦对齐拟合提供了可解释诊断，但真实查询意图演化可能非线性；\(\beta_t\) 的拟合依赖特定对齐目标与语义编码器，编码器选择对结论稳健性的影响未讨论。
- **评估维度有限**：以 Cover-EM 为主，缺少对证据覆盖质量、引用忠实度、答案可验证性等维度的评估；仅使用英文 Wikipedia 与两个 Qwen 模型，跨语言、跨检索器、跨模型家族的泛化性仍待验证。
- **统计严谨性不足**：未报告多次运行的方差或显著性检验；基线是否在相同提示、相同检索预算与调用成本下充分调优未明确说明，公平性仍有提升空间。
