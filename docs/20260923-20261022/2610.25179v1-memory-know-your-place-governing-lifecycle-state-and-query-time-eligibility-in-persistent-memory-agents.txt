ABSTRACT 

Persistent memory turns prior interactions into durable agent state, but existing systems provide limited control over whether that state remains valid and whether it should influ-ence a later query. We argue that reliable memory requires governance over both state formation and query-time influ-ence. We introduce PLACE , a factorized governance layer that adds write-side state certification and read-side authoriza-tion to a memory backend. A factorial evaluation on Mem0 with Qwen2.5-3B and Qwen2.5-7B isolates the contribution of each mechanism. Results show that write-side governance substantially improves lifecycle state correctness, while read-side governance eliminates measured causal leakage from in-eligible memory in the state-correct setting. Their combina-tion achieves the strongest joint performance while preserving query-relevant support. These findings show that reliable per-sistent memory requires explicit control over both maintained state and query-time information influence. 

Index Terms — Agent memory, memory governance, lifecycle state consistency, memory retrieval, LLM agents 

1. INTRODUCTION 

Long-running agents increasingly rely on persistent mem-ory to maintain continuity beyond a single interaction [1, 2]. Persistent memory allows agents to preserve evolving user and task states across sessions, so later responses can reflect information established in earlier interactions [3]. Recent memory-augmented systems have therefore moved beyond static-context formulations toward editable memory sub-strates that can be constructed, updated, retrieved, and reused over time [1, 4, 5]. Evaluation has likewise moved beyond isolated recall toward long-horizon settings involving tempo-ral reasoning, memory updates, forgetting, and state evolu-tion [6–8]. As persistent memory becomes more central to agent behavior, however, errors in what the agent stores or uses can also persist and affect later behavior [9]. Greater operational flexibility does not by itself make persistent memory governable. Prior systems improve how agents construct, update, and retrieve useful memory from earlier interactions [10, 11]. Recent benchmarks instead examine whether memory remains useful as information evolves across long interactions [8, 12]. Yet these advances do not establish whether the persistent backend itself rep-resents the correct current semantic state. An agent may answer correctly from nearby context even when obsolete information remains active in persistent memory [13]. Con-versely, it may maintain the correct current state while later exposing stale or query-ineligible memory to the answer model [14, 15]. Final-answer behavior alone therefore cannot reveal whether an error originates in memory state or in how that state is allowed to influence a query, making storage quality or answer accuracy alone insufficient to characterize memory correctness. We argue that reliable persistent memory requires gover-nance over two distinct but complementary problems. State correctness requires memory to maintain the currently valid semantic state as information evolves across an interaction history. Influence correctness , by contrast, requires ensuring that only memory eligible for the current query can affect the response, while preserving access to relevant and authorized memory. This distinction leads to two research questions: • RQ1: Can write-side governance improve lifecycle state consistency during memory updates? • RQ2: Can read-side governance prevent query-ineligible memory from influencing responses while preserving query-relevant memory utility? To address these questions, we propose PLACE , a factor-ized governance layer for persistent-memory agents. PLACE adds explicit control over how memory is formed and how represented memory is allowed to influence downstream be-havior. Specifically, its write-side mechanism maintains and verifies the semantic state physically realized in the back-end, while its read-side mechanism exposes only support authorized for the current query. We evaluate PLACE on Mem0 [1] with Qwen2.5-3B and Qwen2.5-7B [16] in a fac-torial design that isolates write-side and read-side effects. Across both model scales, write-side governance maintains a correct memory state, while read-side governance eliminates observed causal leakage when the state is correct. Combin-ing both yields the strongest overall performance, showing that reliable agent memory requires controlling both memory state and influence. 3. EXPERIMENTAL SETUP AND RESULTS 3.1. Experimental Design 

Implementation. We evaluate PLACE on Mem0 [1] with Qwen2.5-3B and Qwen2.5-7B [16] through Ollama, using Qdrant storage and Nomic embeddings. The same model drives Native memory updates and answer generation, while CSS and QASC are deterministic. 

Factorial design. We cross Native and CSS writing with Na-tive and QASC reading, yielding Native, CSS, QASC, and PLACE. Native and QASC share the same Native-produced state, while CSS and PLACE share the same CSS-produced state. Each producer is written once per update step to isolate read-side effects. 

Primary evaluation. Experiments use one prespecified 302-turn trajectory spanning four conversations, with persistent memory retained across session resets. It contains 105 state checkpoints and 48 queries across six governance families. Primary uses trusted user-level event and query semantics, without exposing the resulting lifecycle state, internal CSS transition, or authorized support. Read-side influence is fur-ther isolated with 48 causal pairs that hold the query and au-thorized state fixed while varying only irrelevant history. 

Diagnostics. Utility evaluates needed support, inappropriate exposure, and conflicting evidence over 72 probes. Closed Loop repeats the factorial setting while retaining prior assis-tant responses as non-authoritative dialogue context.

3.3. Results and Discussion 

3.3.1. Write-Side Governance Improves State Correctness 

Table 1 shows a clear write-side effect. StateCorrectness in-creases from 0.488 to 1.000 at 7B and from 0.414 to 1.000 at 3B, corresponding to StateGain values of 0.512 and 0.586, respectively. QASC does not change these values because it shares the Native state producer and does not modify persis-tent memory. The factorization check also holds across all 153 semantic checkpoints, with Native matching QASC and CSS matching PLACE at both model scales. These results indicate that the write-side gain reflects improved state for-mation rather than differences introduced at retrieval time. 

3.3.2. Read-Side Governance Reduces Ineligible Influence 

CSS and PLACE provide the cleanest read-side comparison because both realize the reference-correct state for all 48 causal pairs and differ only in their read policy. LeakageRate decreases from 0.125 to 0.000 at 7B and from 0.083 to 0.000 at 3B, with 95% pair-bootstrap intervals of [0 .042 , 0.229] and 

[0 .021 , 0.167] for LeakageDrop. The smaller eligible sets for Native and QASC arise from write-side state errors and are therefore not used as the primary read-side contrast. As shown in Table 2, Utility diagnostic shows that the re-duction in leakage is not achieved by indiscriminate suppres-sion. PLACE preserves 1.000 NeededSupport at both model scales while reducing ExposureRate to 0.000. Read-side au-thorization therefore removes measured ineligible influence while preserving all measured query-required support. 

3.3.3. Combining Both Controls Improves Joint Performance 

As shown in Table 1, CSS and QASC are most effective when combined. PLACE reaches a JointSuccess of 0.667 at 7B and 0.625 at 3B, compared with 0.417 and 0.354 for CSS, re-spectively, while QASC alone cannot recover failures caused by an incorrect Native state. InteractionGain is 0.250 at 7B and 0.271 at 3B, with sensitivity intervals of [0 .060 , 0.377] 

and [0 .069 , 0.377] . We therefore interpret the interaction as evidence consistent with complementarity rather than as population-level statistical synergy. Table 2 further shows that this pattern persists in the Closed-Loop setting. PLACE maintains StateCorrectness of 1.000 and ExposureRate of 0.000 at both model scales, with JointSuccess of 0.667 at 7B and 0.458 at 3B. These results indicate that the combined governance remains ef-fective even when prior assistant responses are retained as non-authoritative dialogue context. 

4. CONCLUSION AND FUTURE WORK 

In this work, we introduce PLACE, a factorized governance layer that separates persistent-state formation from query-time memory influence. Across Qwen2.5-3B and Qwen2.5-7B, write-side governance achieves perfect StateCorrect-ness, while read-side authorization eliminates measured causal leakage in the state-correct setting. Their combina-tion yields the strongest joint performance while preserving query-needed support. These results highlight two core con-tributions: 1) state correctness and influence correctness are distinct but complementary requirements for reliable persis-tent memory; and 2) improving retrieval alone is insufficient when the underlying persistent state is incorrect. Our cur-rent evaluation isolates governance using trusted user-level semantics rather than end-to-end automatic interpretation. Future work will therefore extend PLACE with learned se-mantic interpretation and evaluate it across independently replicated long-horizon trajectories with human validation. 5. ACKNOWLEDGMENTS
