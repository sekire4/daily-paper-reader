## 摘要
智能体记忆使大语言模型智能体能够复用过去的经验，然而即使检索到的记忆是良性的、被正确存储且被恰当检索，它们也可能扭曲推理。我们研究了这种失败模式，并将其称为记忆过度依赖。在不同基准和记忆架构上，我们发现：当过去经验能够迁移到当前任务时，记忆是有用的；但当只有部分证据发生迁移时，记忆可能产生误导。在查询与记忆仅部分重叠时，失败最为严重，这一模式也通过改变重叠证据数量的控制实验得到进一步证实。受此发现启发，我们提出 MEMTRIM，一个即插即用框架，在写入时对记忆证据建立索引，并在读取时控制其复用。MEMTRIM 移除重复或冲突的证据，同时保留有用的记忆特定信息，无需重新训练，并且适用于基于嵌入的和结构化的记忆系统。实验表明，在不同模型和记忆设置下，MEMTRIM 能够降低记忆过度依赖，同时保留有用记忆带来的收益。

## Abstract
Agentic memory allows LLM agents to reuse past experience, yet retrieved memories can also distort inference even when they are benign, correctly stored, and appropriately retrieved. We study this failure mode, which we call memory over-reliance. Across benchmarks and memory architectures, we find that memory is useful when past experience transfers to the current task, but can become misleading when only part of the evidence transfers. Failures are strongest under partial query-memory overlap, a pattern further confirmed by controlled experiments thatvary the amount of overlapping evidence. Motivated by this finding, we propose MEMTRIM, a plug-and-play framework that indexes memory evidence at write time and controls its reuse at read time. MEMTRIM removes repeated or conflicting evidence while preserving useful memory-specific information, requires no retraining, and applies to both embedding-based and structured memory systems.Experiments show that MEMTRIM reduces memory overreliance while preserving the benefits of useful memory across models and memory settings.

# 论文结构化总结：Understanding and Mitigating Inference-Time Overreliance Using Agentic Memory

## 1. 核心问题与研究动机

- **研究背景**：智能体记忆（agentic memory）让 LLM 智能体能够跨交互保存信息、复用过去经验，在长程任务中尤为重要（Mem0、A-Mem、MemGPT、Graphiti 等架构相继提出）。
- **核心问题**：作者指出一类此前未被充分关注的失效模式——**记忆过度依赖（memory overreliance）**：即使记忆本身**良性、被正确存储、被恰当检索**，它仍可能在推理时扭曲模型判断。
- **关键洞察**：问题不在于记忆“脏”或检索“错”，而在于**只有部分证据可迁移**到当前任务。当当前查询与记忆共享大量证据、但决定答案的信息已经变化（过时、冲突或无关）时，记忆会被错误地当作可直接复用的结论。
- **研究意义**：这区别于已有的记忆投毒攻击、检索噪声、知识更新等研究——失效无需攻击者、无需错误记忆，只需“情境条件改变”。作者据此把记忆过度依赖定位为**推理时的失效**，而非存储或检索层面的失效。

## 2. 方法论：MEMTRIM 框架

### 2.1 核心思想

- 提出 **MEMTRIM**（Memory with Trie-based Replicate-aware Inference Mitigation），一个**即插即用**的记忆读写控制层：不替换原有记忆系统、不重训 LLM，只在写入时建立证据级索引、在读取时控制哪些证据进入推理上下文。
- 核心原则：**显式识别被复制的证据，并控制其进入推理的方式**——去除重复证据、剔除冲突证据、保留仅存在于记忆中的有用信息，并对“旧答案”按任务是否变化做差异化处理。

### 2.2 关键技术细节

**（1）证据表示（Evidence Representation）**

- 将一次存储交互 \(m=(x_m, y_m)\) 解析为原子证据单元集合 \(E_m\)，每个单元为键值对 \(e=(k,v)\)，其中键包含实体、属性/关系与值类型。
- 同时抽取**任务签名** \(\tau_m\)（记录“要模型判断什么”，如 `founding_year`、`route_planning`），并把存储答案表示为带类型的结果 \(o_m=(\tau_m, y_m)\)。
- 为答案标注**支持集** \(H_m \subseteq E_m\)，即该答案所依赖的证据；不确定时采取保守策略（纳入 \(H_m\)），以避免支持证据已变却仍复用旧答案。
- 对当前查询 \(q\) 施加同一解析器，得到 \(E_q\) 与 \(\tau_q\)。

**（2）写入阶段：Trie 证据索引**

- 每个证据单元独立插入全局 Trie \(T\)：先沿规范化键 \(k\) 下行，再沿值 \(v\) 分支。
- **相同证据汇聚到同一节点**，**同一键的不同取值分叉到不同分支**（如 `founded_in=2016` 与 `founded_in=2017` 共享键、值处分叉）。
- 由于单元独立索引，即使共享证据在文本中不相邻（稀疏重叠，如 \(E_m=\{e_1,e_2,e_3,e_4\}\)、\(E_q=\{e_1,e_2',e_3,e_4'\}\)），仍能匹配 \(e_1\) 与 \(e_3\)。
- 完整记忆仍存于原记忆库，MEMTRIM 仅维护证据级索引。

**（3）读取阶段：复制感知的上下文构造**

- 对底层检索器返回的候选集 \(R(q)\)，把每条记忆 \(m\) 的证据划分为三类：
  - **共享证据** \(S_m(q)\)：键与值均出现在查询中；
  - **冲突证据** \(D_m(q)\)：键出现在查询中但值不同；
  - **仅记忆证据** \(U_m(q)\)：查询中不存在。
- 构造规则：共享证据**移除**（避免同一信息被重复支持）；冲突证据**移除**（当前查询已给出当前取值）；仅记忆证据**保留**。
- 旧结果 \(o_m\) 的处理由下式决定：

\[
e_m(q)=U_m(q)\cup
\begin{cases}
\{o_m\}, & D_m(q)\cap H_m=\varnothing,\ \tau_m=\tau_q\\
\{\mathrm{Type}(o_m)\}, & D_m(q)\cap H_m=\varnothing,\ \tau_m\neq\tau_q\\
\varnothing, & D_m(q)\cap H_m\neq\varnothing
\end{cases}
\]

  - 若答案所依赖的证据已与查询冲突 → **抑制旧答案**；
  - 若任务相同且无冲突 → 保留为“同一任务的先前答案”；
  - 若任务不同且无冲突 → 把旧答案**转写为带原任务标签的证据陈述**（如把“2016”转为 `(founded_in, 2016)`），使其作为上下文证据而非当前答案。

- 最后对多条检索记忆做**合并去重**，每个保留单元只输出一次；若多条记忆对同一键给出无法由查询消解的冲突值，默认**全部扣留**（除非底层系统提供可信时间戳等排序信号）。

**（4）工程实现要点（附录 A.1）**

- 使用固定的指令式解析器 + 约束结构化输出 + 确定性解码；每个单元保留原文 span 以校验可溯源性，无法溯源者丢弃。
- 解析失败时重试一次，仍失败则保留原始记忆但不通过 MEMTRIM 复用其结果，避免把未校验答案带入上下文。
- 任务签名对齐采取保守策略：无法确信对齐即视为不同任务。

## 6. 主要结论与发现

1. **记忆过度依赖真实存在**：在 TA 情形下记忆稳定提升准确率，但在 TD-Dup 情形下同一记忆会降低准确率，且 ✓→✗ 显著多于 ✗→✓（如 Qwen + Mem0 在 RippleEdits 上 ✓→✗ 达 11.6%，✗→✓ 仅 2.9%）。
2. **失效集中在“部分重叠”区间**：成功案例更多分布在重叠度的两端，失败案例集中于中等重叠，四类记忆系统上均统计显著（p < 0.05）。
3. **非单调因果效应**：控制实验显示，重叠度低时记忆影响有限；随重叠上升，负面影响增强并在中等重叠处最强；重叠接近完全对齐后效应反转为正向——形成“先恶化后恢复”的 U 形/非单调曲线。
4. **机制解释**：重叠同时提升记忆的“影响力”与“被误用的概率”，但不保证结论所依赖的证据也一并迁移；中等重叠恰好是“影响力足够大、关键信息仍不同”的危险区。
5. **MEMTRIM 有效且低代价**：在 TD-Dup 上把 ✓→✗ 从约 11.6%/9.7% 压到 0.6%/0.5%（RippleEdits），同时 TA 准确率不降反升（如 85.3→88.4）；在 A-Mem、MemGPT、Graphiti 上趋势一致；运行时变化很小，部分设置甚至更快。
6. **消融归因清晰**：保留共享证据

6. **消融归因清晰**：保留共享证据会重新引入“同一信息被重复支持”的放大效应，使 TD-Dup 上的 ✓→✗ 明显回升；保留冲突证据会让模型在查询给出的当前值与记忆中的旧值之间摇摆，甚至被旧值带偏；无条件保留旧答案、以及忽略任务签名变化（把跨任务答案当作当前答案复用），是退化最严重的两个变体，说明“按任务是否变化差异化处理旧结果”是该方法的关键而非附属设计；用嵌入相似度匹配替代 Trie 证据索引后，键值级对齐退化为整体语义相似，出现误删（把未冲突证据当作重复证据剔除）与漏删（共享证据未被识别）并存的错误。值得注意的是，这些消融变体在 TA 设置上的差异普遍小于 TD-Dup 设置，表明各组件的主要作用是**抑制误用**，而不是普遍提升记忆利用率。

7. **对抗鲁棒性是“顺带收益”而非设计目标**：在 PoisonedRAG（注入重复陈旧记录）、MINJA（经正常查询诱导写入）、ShadowMerge（向图记忆插入冲突关系）三类攻击下，MEMTRIM 相对基线降低了攻击成功率，并随注入量增加保持更平缓的退化曲线。原因在于这些攻击的生效机制与本文描述的过度依赖机制同源，都依赖“与查询高度重叠的旧证据被直接采信”。但作者也明确其边界：若投毒内容与查询几乎无证据重叠，或攻击直接篡改底层记忆库本身，MEMTRIM 缺乏可识别的共享/冲突结构，防护能力有限。

## 7. 讨论与实践启示

- **概念层面的贡献大于工程层面**：论文把“记忆失效”从存储质量、检索精度、抗攻击等既有框架中区分出来，提出第三类问题：**证据可迁移性判断**。这提示记忆系统的评价不应只报告“记忆命中率/检索相关性”，还应报告“记忆被误用的代价”。
- **“更多上下文”不等于“更好推理”**：在部分重叠区间，把完整记忆原文直接拼入上下文会同时提供支持与误导；结构化裁剪（去重、去冲突、保留独有信息）比简单截断或相似度过滤更贴合失效机理。
- **设计原则可外推**：复制感知（replicate-aware）的控制思路可迁移到 RAG 上下文构造、多轮对话历史压缩、以及工具调用结果的复用判断中——凡“旧结论 + 新条件”共存的场景，都存在同构风险。
- **工程友好**：不重训模型、不替换记忆后端、写入时一次性索引、推理时相对开销在 ±数个百分点内，使其较易集成到现有智能体栈中。

## 8. 局限性与待解问题

- **解析器依赖**：原子证据与任务签名的抽取质量直接决定后续判断；论文采用固定指令式解析器 + 结构化输出 + 可溯源校验来降低风险，但未单独量化解析错误率对最终准确率的传导幅度，也未报告解析器换用不同模型时的敏感性。
- **证据粒度需人工设计**：键的规范化方式（实体、属性、值类型）带有领域假设，粒度太细会造成匹配稀疏（共享证据识别不足），太粗会造成冲突误判（把可共存的多值当作矛盾）。
- **保守策略的代价**：“冲突即扣留”“无法确信对齐即视为不同任务”在需要时间推理、多值并存（如历任职位、阶段性事实）或部分可迁移的场景中，可能损失本可利用的记忆信息；论文主要在“答案唯一且时效敏感”的基准上验证，此类代价未被系统测量。
- **受限于底层检索召回**：MEMTRIM 只作用于已召回候选集，若相关记忆未被检索到，方法无从生效；因此它是记忆后处理层，而非检索改进方案。
- **生态效度**：三个基准均为高度受控的构造式设置（固定实体/前提/因果图，仅改动关键值），真实长程对话中的噪声、指代、隐含条件变化更复杂，外推需谨慎。
- **公平性缺口**：MEMTRIM 比提示类基线多了一次写入期解析与一次查询期解析，缺少“同样结构化解析但不去重/不冲突处理”的强对照，增益中“结构化”与“复制感知控制”的贡献尚未完全分离。
- **可复现性缺口**：未报告 GPU 型号、数量、总时长与能耗，仅有相对运行时变化，绝对成本不可核验。

## 9. 总体评价

- **问题定义清晰且有价值**：把“良性记忆也会致害”这一反直觉现象命名、量化并定位到中等重叠区间，配合非单调因果曲线，构成了较完整的“现象—机制—干预”论证闭环。
- **方法轻量、可插拔、与模型无关**，在 4 种记忆架构 × 2 个模型 × 3 个数据集上结论方向一致，并有消融、控制实验、对抗压力与运行时数据支撑，证据链较扎实。
- **主要保留意见**：证据解析的自动化程度与鲁棒性论证偏薄、保守策略的适用边界未充分刻画、与强结构化基线的对照不足、算力信息缺失。
- **适用建议**：适合“事实时效敏感、答案唯一、旧结论易被复用”的智能体记忆场景；对需要多值共存、时间线推理或高度非结构化文本的场景，建议放宽冲突扣留规则并配合时间戳等排序信号使用。
