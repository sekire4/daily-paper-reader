## 摘要
记忆对于使基于 LLM 的智能体在长程交互中保持连贯、个性化的行为至关重要。然而，现有记忆系统存在一个根本局限：它们从不主动测试自身记忆，只在真实查询暴露弱点后才进行修复。这种反应式范式意味着每次检索失败都对应一次真实交互，而代价已经付出。我们提出 MemDream，一个使 LLM 智能体能够进行自探测记忆演化的框架。该框架周期性进入离线“梦境”周期，在其中三个专门智能体（Dreamer、Analyst、Consolidator）协作在失败发生前探测、诊断并修复记忆图。通过组相对策略优化（Group Relative Policy Optimization）训练的策略学习哪些修复操作能带来持久的检索提升，而软衰减机制提供由同一预期信号驱动的可逆遗忘。在 LoCoMo 和 MemoryAgentBench 上的实验表明，MemDream 在 LoCoMo 上将答案 F1 提高 4.5 分，并在 MAB 上相较最强的反应式演化基线取得高 9.1 分的总体得分。

## Abstract
Memory is essential for enabling LLM-based agents to maintain coherent, personalized behavior over long-horizon interactions. However, existing memory systems share a fundamental limitation: they never proactively test their own memory, repairing it only after real queries expose weaknesses. This reactive paradigm means every retrieval failure corresponds to a real interaction in which the cost has already been paid. We propose MemDream, a framework that enables self-probing memory evolution for LLM agents. Our framework periodically enters offline dream cycles where three specialized agents (Dreamer, Analyst, Consolidator) collaboratively probe, diagnose, and repair the memory graph before failures occur. A policy trained via Group Relative Policy Optimization learns which repair operations produce durable retrieval improvements, while a soft decay mechanism provides reversible forgetting driven by the same anticipatory signal. Experiments on LoCoMo and MemoryAgentBench demonstrate that MemDream improves answer F1 by 4.5 points on LoCoMo and achieves a 9.1-point higher overall score on MAB over the strongest reactive-evolution baselines.

## 1. 核心问题与研究动机

- **背景**：LLM 智能体在长程多轮交互中必须持续积累、保留和检索信息，记忆质量直接决定回答的连贯性与个性化程度。
- **核心痛点**：现有记忆系统本质上是**反应式（reactive）**的——结构化记忆架构（MemGPT、MemoryOS、FluxMem 等）预先固定组织方式；多阶段检索管线（Self-RAG、HippoRAG 2 等）只优化检索而不改记忆；自演化记忆方法（Memory-R1、Mem-α 等）依赖已观测到的失败来更新。它们**从不主动测试自身记忆**，只有当真实用户查询暴露缺陷时才修复，而此时交互代价已经付出。
- **具体失败模式**：随着交互累积，记忆图会出现**碎片化**（相关信息散落在无连接节点）、**冗余**（多节点内容重叠稀释精度）、**陈旧**（过时信息与近期交互冲突）三类缺陷。
- **核心研究问题**：记忆系统能否在失败发生**之前**，自己构造修复信号、定位并修复“存得住但取不出”的潜在缺陷？论文将此概括为**自探测记忆演化（self-probing memory evolution）**，并类比睡眠期记忆巩固（complementary learning systems）提出离线“梦境周期”构想。

## 2. 方法论

### 2.1 核心思想
- 智能体在线正常应答，同时**异步**进入离线梦境周期：由 Dreamer 生成前瞻性探测查询 → Analyst 诊断检索失败原因 → Consolidator 执行针对性修复，循环直至检索 F1 收敛。修复信号来自系统**自己生成的未来式查询**，而非历史失败。

### 2.2 记忆架构与检索
- 三层记忆图 $G=(V,E)$：**STIM**（短期交互缓冲，LRU 淘汰）、**MTEM**（中期情景记忆，按会话分组）、**LTSM**（长期语义记忆，压缩知识条目）。节点携带内容嵌入、实体集、访问统计与检索权重 $w_v\in[0,1]$。
- 检索采用稠密 + BM25 的 RRF 融合并按节点权重加权：
  $$s(v,q)=\Big(\sum_{i\in\{\text{dense,BM25}\}}\frac{1}{k+\text{rank}_i(v,q)}\Big)\cdot w_v$$
  再经 cross-encoder 重排取 Top-k 构成上下文。
- 形式化目标：学习策略 $\pi:G\mapsto G'$，最大化未来查询分布 $Q$ 上的期望检索成功率 $\mathbb{E}_{q\sim Q}[\text{Success}(q,\text{Retrieve}(q,G'))]$。由于 $Q$ 未知，梦境周期负责“采样”该分布，把不可观测目标转为可训练信号。

### 2.3 三智能体梦境周期（共享 Llama-3.1-8B，各自 LoRA 适配器）
- **Dreamer（探测）**：为节点计算弱点分
  $$\phi(v)=\lambda_1\big(1-\tfrac{\deg(v)}{\max_u\deg(u)}\big)+\lambda_2\max_{u\in N(v)}\cos(e_v,e_u)+\lambda_3\tfrac{t_{now}-t_v}{T}$$
  分别刻画连接缺失、冗余、陈旧；对高分目标 $v^\star$ 按**共检索频率**（而非嵌入相似度）挑选桥接伙伴 $u^\star$，生成需同时用到二者的自然查询。**期望答案逐字复制自目标节点原文**，保证修复信号不被幻觉带偏。先 SFT 再以检索成功率为奖励做 GRPO。
- **Analyst（诊断）**：沿“节点内/节点间 × 召回/精度”两轴，将失败分为四类并一一映射修复操作：**buried→extract**、**scattered→synthesize**、**redundant→merge**、**noisy→prune**；输出目标节点 ID 与操作，按危害程度排序。作者称该分类在两轴上完备，可细化子类而不改动训练管线。
- **Consolidator（修复）**：执行四类操作。prune 采用**软衰减**而非硬删除：$w_v\leftarrow\gamma w_v,\ \gamma=0.2$；若后续周期发现重新相关则恢复 $w_v\leftarrow\min(1.0,\,w_v+\eta\cdot\text{success\_count}_v)$，实现可逆遗忘。
- **收敛准则**：$\frac{1}{|D|}\sum_{q\in D}\text{F1}(q,G)\ge\tau$ 或轮数达到 $T_{max}$。

### 2.4 GRPO 训练流程（三阶段）
- 各智能体有独立的可解释奖励：Dreamer（判别力、下游影响、覆盖度）、Analyst（可执行性、多样性、规模适中、结构合法）、Consolidator（QA-F1、覆盖度、时序线索保留、简洁性），权重为先验固定而非在评测集上调参。
- GRPO 损失：$L=-\frac{1}{N}\sum_{i=1}^{N}A_i\log\pi_\theta(a_i|s)$，优势 $A_i=\frac{r_i-\bar r}{\sigma_r+\epsilon}$，仅高于组均值的 rollout 获得正梯度（形成更难课程）。
- 三阶段：① 用 GPT-4.1 教师数据对三智能体分别 SFT；② 各自独立 GRPO；③ 冻结 Analyst，对 Dreamer 与 Consolidator 联合微调，联合奖励为新鲜探测查询上的 $\Delta\text{F1}$（修复前后记忆质量差）。
- 部署时模型参数固定，梦境周期只更新外部记忆。
