## 摘要
时间感知检索对于长时程LLM智能体有效利用不断增长的长期记忆至关重要。现有方法侧重于词汇或语义相似度，导致目标记忆被时间不匹配但语义相似的候选挤出。即使时间感知方法也仅在记忆组织或答案生成阶段注入时间线索，忽视了候选选择发生的检索阶段的时间约束——这正是目标记忆被挤出的根源。受人类情景记忆中的时间邻近效应启发，我们提出TIDER（时间区间驱动的双通道证据检索），一种时间感知的智能体检索框架。TIDER的核心是一个经强化学习（RL）训练的时间区间定位器，用于推断证据所在的时间窗口。RL将窗口定位作为离散、不可微的检索决策进行优化，并使用复合奖励将稀疏的答案监督转化为细粒度的检索反馈。这些时间窗口首先定义时间检索通道；随后将检索到的候选与语义通道的结果合并，并根据与窗口的接近程度重新排序。这种时间锚定使TIDER能够检索时间对齐的证据，否则这些证据会被大量语义相似但时间不匹配的记忆淹没。借助轻量级1.7B定位器，TIDER在两个长时程记忆基准上均取得最先进准确率——LifeBench上61.52%（+8.82%），LoCoMo上78.96%（+3.66%）——这表明在长期日常生活记忆的大量语义相似历史事件中，时间线索对于精确定位目标证据至关重要。

## Abstract
Time-aware retrieval is crucial for long-horizon LLM agents to effectively leverage ever-growing long-term memory. Existing methods focus on lexical or semantic similarity, leading to target memories being crowded out by temporally mismatched yet semantically similar candidates. Even time-aware approaches inject temporal cues only during memory organization or answer generation, overlooking temporal constraints at the retrieval stage, where candidate selection occurs - the root cause of the displacement. Inspired by the temporal contiguity effect in human episodic memory, we propose TIDER (Temporal Interval-driven Dual-channel Evidence Retrieval), a time-aware agentic retrieval framework. Central to TIDER is a reinforcement learning (RL)-trained temporal interval locator that infers the temporal windows in which the evidence lies. RL optimizes window localization as a discrete, non-differentiable retrieval decision, using composite rewards to convert sparse answer supervision into fine-grained retrieval feedback. These temporal windows first define the temporal retrieval channel; the retrieved candidates are then merged with results from the semantic channel and reranked by proximity to the windows. This temporal grounding enables TIDER to retrieve temporally aligned evidence that would otherwise be drowned out by the volume of semantically similar yet temporally mismatched memories. With a lightweight 1.7B locator, TIDER achieves state-of-the-art accuracy on both long-horizon memory benchmarks - 61.52% on LifeBench (+8.82%) and 78.96% on LoCoMo (+3.66%) - which indicates that temporal cues are crucial for pinpointing target evidence amid a vast pool of semantically similar historical events in long-term daily-life memory.

## 一、核心问题与研究动机

- **背景**：长时程 LLM 智能体（个人助理、长期对话）需要从不断增长的日常事件历史中检索证据。日常生活事件在表面语义上高度同质（如"和家人吃晚饭"一年可出现数百次），真正区分不同事件的关键线索往往是**发生时间**。在 LifeBench、ATM-Bench 等基准中，80–90% 的问题带有时间表达。
- **核心矛盾**：现有检索依赖词法/语义相似度，导致**语义相似但时间错配**的候选挤占目标证据。已有时间感知方法存在两类偏差：
  - 在**记忆组织**阶段注入时间（时间戳、时序知识图谱、时间树），或在**答案生成**阶段加强时序推理（神经符号、程序求解器、时序算子），却忽视了候选选择发生的**检索阶段**——这才是证据被挤出的根源。
  - 规则式时间归一化器难以处理"她生日那一周"这类模糊个人化表述；时间敏感编码器把时序与语义耦合在同一向量空间，需额外监督且损害语义召回。
- **理论灵感**：人类情景记忆中的**时间邻近效应**（temporal contiguity effect）——检索同时受语义关联与时间距离影响。
- **核心主张**：长时记忆需要一种**检索阶段、查询自适应、与语义编码器解耦**的时间机制。

## 二、方法论（TIDER）

### 1. 记忆池构建
- 用 LLM 从对话中抽取带时间戳的原子记忆条目，先按日期、再按语义相似度做**时间有界贪心聚类**（7 天日期窗 + 语义阈值 0.85 + 簇容量上限 40）。
- 得到时间锚定的事件记忆池 $M=\{m_i=(d_i,s_i,I_i)\}$，其中 $d_i$ 为日期跨度、$s_i$ 为事件摘要、$I_i$ 为原始条目集合。

### 2. 时间区间定位器 $\pi_\theta$（核心）
- 输入：查询 $q$ + 查询自适应时间线摘要 $S_q$（从 $M$ 中取 top-30 最相关时间线条目）。
- 输出结构化时间定位 $z=(\text{detect}, W_{pred})$：
  - `detect ∈ {true, false}` 门控时间通道；
  - $W_{pred}=\{w_\ell=[w^{start}_\ell, w^{end}_\ell]\}$ 为证据可能所在的时间窗集合。
- 由于窗口定位是**离散、不可微**的检索决策，采用 **GRPO** 强化学习训练（SFT 冷启动对齐 JSON schema + GRPO 在线自校正）。

### 3. 双通道约束检索
- **语义通道**：BGE-M3 稠密检索 + BM25，得分 $\text{sem}(q,m_i)$ 为余弦相似度。
- **时间通道**：`detect=true` 时开启，保留日期跨度 $d_i$ 与 $W_{pred}$ 有重叠的候选。
- **统一排序分数**：
  $$\text{score}(q,m_i)=\gamma(\text{dist}_i)\cdot\big[\text{sem}(q,m_i)+\lambda_{boost}\cdot\mathbb{1}[m_i\in\text{temporal channel}]\big]$$
  其中 $\text{dist}_i$ 为事件日期到 $W_{pred}$ 的最小天数距离；$\gamma$ 为分段衰减函数：缓冲区 $\tau_{buf}=14$ 天内不衰减，超出后按 $\rho=0.05$ 每日线性衰减，下限 $\gamma_{min}=0.3$。$\lambda_{boost}=0.3$。
- `detect=false` 时关闭时间通道，退化为纯语义检索。最终取 top-$k=20$ 送入下游 LLM。

### 4. 复合奖励设计（权重 0.10 / 0.25 / 0.20 / 0.45）
$$R=w_{det}r_{det}+w_{win}r_{win}+w_{evd}r_{evd}+w_{out}r_{out}$$
- $r_{det}$：检测奖励，`detect` 与 gold 标志一致得 +1，否则 −1。
- $r_{win}$：窗口定位奖励，用**双向最佳匹配 IoU** 聚合预测窗与金标窗的几何对齐。
- $r_{evd}$：证据覆盖奖励，LLM 逐条判断金标证据是否被 top-k 覆盖，返回覆盖率。
- $r_{out}$：结果奖励，多选题用 ExactMatch，开放式用 3 次独立 LLM 评判多数投票。
- 训练技巧：**难度分层 rollout（DAR）** 对非时间性（×10）与多窗口（×4）上采样；不可解析的 rollout 截断为 $R_{min}=0$ 并跳过评判。

## 三、实验设计

- **数据集 / 场景**：
  - **LifeBench**：长时程多源个人记忆（10 用户、每用户约 1.3 万条、2003 题），排除 Unanswerable 后评估 user-0/1 划分（408 题）；user-2~9 用于合成训练样本，**训练/评估用户不重叠**。
  - **LoCoMo**：超长多会话对话（约 600 轮、16K token），评估 1,540 题子集（排除对抗类）；**零样本泛化测试**，无 LoCoMo 数据进入训练。
- **评估指标**：官方端到端 QA 协议——Accuracy（LLM 评判、3 次多数投票）与 token 级 F1；另在相同记忆池上补充 Recall@k、nDCG@20、MRR@20（LLM 判定的二值相关性）。
- **对比基线**（三族，除 Oracle 外共享相同下游答案模型与 top-k 预算）：
  - 智能体记忆框架：MemOS、TiMem、Zep、Mem0；
  - 时间感知检索：TsContriever；
  - 时序推理：NeSTR；
  - **Oracle**（直接给金标证据）作为不可比上界。
- **下游模型**：LifeBench 用 GPT-5-mini，LoCoMo 用 GPT-4o-mini，所有基线固定一致。

## 六、主要结果与关键发现

- **端到端 QA 表现**：在两个基准上，TIDER 相对 MemOS、TiMem、Zep、Mem0 等记忆框架与 TsContriever、NeSTR 等时间感知/时序推理基线取得更优的 Accuracy 与 F1，且与 Oracle 上界之间仍留有差距，说明检索阶段的时间约束能回收相当一部分被语义相似度挤出的证据，但未完全消除检索瓶颈。
- **检索层指标**：在相同记忆池条件下，Recall@k、nDCG@20、MRR@20 的提升与端到端收益方向一致，支持"性能增益主要来自候选选择阶段"这一因果解释，而非下游生成阶段的偶然波动。
- **分层结果**：增益随金标窗口数量增加而更明显（multi-window 场景提升最大），说明双向最佳匹配 IoU 奖励与多窗口输出设计确实在复杂时间约束下发挥作用；non-temporal 子集上性能基本不降，体现 `detect` 门控对误触发时间通道的有效抑制。
- **消融结论**：
  - 移除时间通道或距离衰减重排均造成明显下降，验证"硬约束筛选 + 软距离衰减"的互补性；
  - 移除查询自适应时间线摘要的损失较大，说明定位器的输入构造（而非仅模型容量）是性能关键；
  - 奖励留一法显示 $r_{out}$ 与 $r_{evd}$ 贡献最大，$r_{win}$、$r_{det}$ 提供稳定的结构性引导，符合"结果信号主导、几何信号辅助"的设计预期。
- **定位器替换**：GRPO 训练后的 1.7B 定位器优于同规模 SFT-only 与零样本版本，并在成本远低于 GPT-5.2 的前提下接近其定位质量，说明该能力可由小模型通过结果导向的强化学习获得，而非必须依赖大模型先验。
- **泛化与效率**：零样本迁移到 LoCoMo 仍保持相对基线的优势，表明时间定位策略具有一定跨数据集通用性；0.41 秒/查询的额外开销相对下游 LLM 调用可忽略，工程可行性较好。

## 七、贡献与创新点

1. **问题定位的转移**：明确指出时间错配的根因在**检索阶段的候选选择**，而非记忆组织或答案生成，为时间感知长时记忆提供了新的切入视角。
2. **查询自适应的时间定位范式**：将"何时启用时间约束、约束在哪个时间窗"建模为结构化、可学习的离散决策，用 GRPO 直接优化检索层面的结果信号，绕开不可微的窗口选择难题。
3. **语义与时间的解耦架构**：时间信息以"通道约束 + 距离衰减重排"形式作用于排序分数，不污染语义编码空间，避免时间敏感编码器损害语义召回的问题，同时保留对模糊个人化时间表述（如"她生日那一周"）的处理能力。
4. **复合奖励与训练技巧**：双向最佳匹配 IoU 的窗口奖励、LLM 判定的证据覆盖奖励，以及难度分层 rollout，为同类"结构化检索决策"的 RL 训练提供了可复用配方。
5. **可信的实验协议**：训练/评估用户不重叠、跨基准零样本、统一下游模型与 top-k 预算、补充检索层指标，提升了结论的可解释性与可复现性。

## 八、局限与未来工作

- **评测覆盖有限**：仅两个基准、单一模型族作为下游，未验证在多语言、多模态（图像/音频记忆）与超大规模记忆池下的表现。
- **对 LLM 抽取与评判的依赖**：记忆条目抽取、证据覆盖奖励与答案评判均依赖 LLM，可能引入噪声与偏差；论文虽用多次投票缓解，但未系统量化评判器敏感性。
- **时间表示的粒度**：以日期跨度与天数距离建模，对同日内细粒度时序（上午/下午、事件先后顺序）与周期性事件（每周例会）处理能力有限。
- **训练成本偏高**：单次 GRPO 主循环约 100 小时（2×A100），虽推理便宜，但复现门槛不低；奖励中多项依赖 LLM 调用也带来训练期开销。
- **可扩展方向**：将窗口定位扩展为层次化/多粒度时间表示；引入事件因果与共指信息辅助定位；用更轻量的偏好优化替代完整 GRPO；探索与记忆写入阶段的联合优化。

## 九、总体评价

论文选题切中长时程智能体记忆检索的真实痛点，论证链条清晰：从现象（语义同质、时间关键）→ 归因（检索阶段缺失时间机制）→ 方法（查询自适应定位 + 双通道约束）→ 证据（多基准、多层级消融、零样本迁移）。方法设计克制且自洽——时间信息以约束与重排的形式"外挂"于语义检索，避免了耦合编码的副作用；用 RL 解决离散窗口决策也是合理的技术选择。实验在防泄漏与基线公平性上做得较扎实，消融维度覆盖模块、奖励与组件替换三个层次。

主要保留意见在于：评测规模与下游模型多样性仍不足以支撑"普适"结论；LLM 评判环节的可靠性缺少专门分析；对细粒度时序与周期事件的处理是明显空白。总体而言，这是一篇问题意识明确、方法针对性强的检索增强记忆工作，其"检索阶段的时间决策"视角对后续研究具有较好的启发价值。
