## 摘要
作为长期对话智能体的大语言模型（LLMs）需要能够支持在长程交互中进行可靠推理的记忆系统。然而，现有的检索增强生成（RAG）框架通常将记忆视为被动存储，难以区分带来源归因的信念与未归因的事件/事实记录，也难以连接分散在不同会话中的证据。我们提出 CogMem，一种基于 PEC$^2$F（Person-Event-Concept-Claim-Fact）图模式的认知记忆架构。专用的 Claim 节点保留主观陈述的来源和目标，而 Fact 和 Event 节点表示语义知识与情景知识。对话轮次被增量地转换为具有来源感知的图记录，整合为更高层级的事实，并在同一来源提供冲突更新时协调为具有时间范围的 Claim 视图。在检索方面，一个由 LLM 意图解析驱动的基于规则的控制器组合四个确定性图算子——锚定、遍历、交集和证据接地——来重构与查询相关的上下文。在 LoCoMo 和 LongMemEval 上的实验显示出优异性能，尤其是在多跳、时序和知识更新任务上。消融实验和语义坍缩探针支持了认知分离、整合和智能体式检索的互补贡献。代码：https://github.com/Silent-Rain02/CogMem。

## Abstract
Large Language Models (LLMs) serving as long-term dialogue agents require memory systems that support reliable reasoning over extended interactions. However, existing Retrieval-Augmented Generation (RAG) frameworks typically treat memory as passive storage, making it difficult to distinguish source-attributed beliefs from unattributed event/fact records and to connect evidence dispersed across sessions. We introduce CogMem, a cognitive memory architecture based on the PEC$^2$F (Person-Event-Concept-Claim-Fact) graph schema. Dedicated Claim nodes preserve the source and target of subjective statements, while Fact and Event nodes represent semantic and episodic knowledge. Dialogue turns are incrementally converted into provenance-aware graph records, consolidated into higher-level facts, and reconciled into temporally scoped Claim views when the same source provides conflicting updates. For retrieval, a rule-based controller driven by LLM intent parsing composes four deterministic graph operators---anchoring, traversal, intersection, and evidence grounding---to reconstruct query-relevant context. Experiments on LoCoMo and LongMemEval show strong performance, especially on multi-hop, temporal, and knowledge-update tasks. Ablations and a semantic-collapse probe support complementary contributions from epistemic separation, consolidation, and agentic retrieval. Code: https://github.com/Silent-Rain02/CogMem.

## 一、核心问题与研究动机

- **背景**：LLM 正从无状态文本生成器演变为自主个人智能体，长期对话记忆成为刚需。单纯扩大上下文窗口只能缓冲近期交互，无法刻画人类传记式记忆中结构化、可演化的叙事。
- **现有范式缺陷**：主流做法仍是"存储—检索"式被动 RAG，把对话切块向量化后平铺索引，作者认为存在两个关键问题：
  - **语义坍缩（Semantic Collapse）**：稠密向量空间中，事件记录（如"Jon 失业了"）与针对该事件的主观意见（如"Gina 认为 Jon 失业是个错误"）语义高度重叠，导致带来源的信念被当作无来源事实返回，造成记忆污染并损害心智理论（ToM）推理。
  - **检索缺乏意向性（intentionality）**：静态流水线无法依据中间结果动态调整搜索策略，难以完成跨会话、多跳的证据连接。
- **量化证据**：作者用 150 对人工构造的 fact–claim 对做探针实验，BGE-M3 平均余弦相似度达 **0.8231**；平铺 RAG 在查询事实记录时把主观 Claim 误返回 **64/150（42.7%）**，而基于 PEC²F 的类型约束检索将误归因降至 **9/150（6.0%）**。
- **整体含义**：论文主张长期记忆的核心不是"存得更多"，而是**保留来源、可审计、并通过任务适配的检索路径主动重构证据**，即从 passive retrieval 转向 agentic active recall。理论灵感来自互补学习系统（CLS）理论中快速情景学习与缓慢语义巩固的交互。

## 二、方法论

### 2.1 核心思想：PEC²F 认知图模式

- 将记忆建模为以人物为中心的有向图 \(G=(V,E)\)，节点集 \(V = V_P \cup V_E \cup V_C \cup V_{Claim} \cup V_F\)，即 Person、Event、Concept、Claim、Fact 五类。
- **无来源记录脊柱**：
  - Person 节点为人物锚点；Concept 节点由向量聚类得到的抽象实体，二者构成相对稳定的锚。
  - Event 节点记录有时空边界的特定交互（"Do"），遵循 Tulving 的情景记忆理论，链接参与者、时间与地点。
  - Fact 节点记录观察到的或自述的稳定属性与习惯（"Is"），是**操作性记录类型**，不保证独立验证的真值。
- **Claim 节点分离信念与事实**：主观陈述不存为直接属性，而表示为两跳路径  
  \((p_{jon},\ \text{CLAIMS},\ n_{claim}) \in E \ \wedge\ (n_{claim},\ \text{ABOUT},\ p_{gina}) \in E\)  
  该中间节点承载内容、情感、来源、目标与时间戳。即便嵌入相似，图结构仍能判定信息是"带来源信念"还是"事件/事实记录"。

### 2.2 在线摄入

- 每轮对话后增量更新图：原子抽取引擎（LLM 提示）把限时动作映射为 Event、稳定自述属性映射为 Fact、对他人/概念的评论映射为带 source/target 的 Claim。
- 人物与概念字符串先归一化并匹配已有锚点，再决定是否新建节点；每个节点保留来源轮次 ID 与时间戳，供 Evidence Grounding 回溯原文。

### 2.3 主动可塑性：智能体检索与四个认知算子

- **控制逻辑**：基于 ReAct 的规则控制器 + LLM 意图解析。算子本身与路由规则是确定性的，只有意图标签与"证据是否充分"判断由 LLM 给出。流程为：先强制锚定 → 循环选择算子 → 证据充分或达到后置步数上限 \(D_{step}=5\) 时终止 → 生成答案。
- **意图触发规则**：
  - 比较类词（compare/both/common/difference）→ 交集算子；
  - 询问某人对他者的看法 → 沿 Claim 关系遍历；
  - 时间表达（when/last year/after）→ 带时间门控 \(T\) 的遍历；
  - 验证/追问细节（did he really/why/evidence）→ 证据接地；
  - 其余 → 全关系遍历。
- **四个算子**：
  - **锚定 \(O_{anchor}\)**：混合评分 \(S(v,q)=\alpha\cdot I_{lex}(v,q)+(1-\alpha)\cdot\cos(\Phi(v),\Phi(q))\)，其中 \(\alpha=0.3\)，\(\Phi\) 为 BGE-M3 嵌入，返回 top-\(K_{anchor}=15\) 入口节点。
  - **时空遍历 \(O_{traverse}\)**：按边类型集合 \(R\) 与 LLM 抽取的时间窗 \(T\) 过滤邻居，每跳最多 \(K_{traverse}=15\)，最大深度 \(D_{trav}=2\)。
  - **交集 \(O_{intersect}\)**：对多实体邻域在 \(R_{sem}=\{\text{LIKES, USES, PARTICIPATED\_IN}\}\) 上求语义交集，每实体取 \(K_{intersect}=10\) 候选，用于回答"共同点/差异"。
  - **证据接地 \(O_{ground}\)**：依据节点记录的 source id 从原始语料 \(D\) 取回原句，在生成最终答案前校验图推断。

### 2.4 动态稳定性：记忆巩固

- **事件→事实合成**：离线图重写。同一 person–concept 在 \(\Delta t_{max}=30\) 天窗口内的事件簇 \(S_{p,c}\)，当规模 \(|S_{p,c}|\ge\tau=3\) 时，触发 LLM 参数化的抽象函数 \(\Psi\)，生成 Fact 节点及时间包络 \(T_{env}=[t_{start},t_{end}]\)，把隐式边模式提升为显式节点。
- **证据保留（Evidence Mounting）**：不删除原始事件，而添加 \((f_{new},\text{SUPPORTED\_BY},e_i)\) 溯源边，形成两级分辨率：高层问题直接取 Fact 节点降低开销，细节问题沿边回到情景层。
- **来源保留的 Claim 协调**：仅当 Claim 共享同一规范 source、target、predicate 时才协调，按时间排序并生成标记为 CURRENT / SUPERSEDED / CONFLICTING 的溯源视图；**不同说话者的 Claim 永不合并**，从而解决更新而不抹除分歧。

## 三、实验设计

- **数据集/基准**：
  - **LoCoMo**：10 段长多会话对话、约 1.5K 问答，分单跳、多跳、时序、开放域四类；报告 F1 与 BLEU-1，并按类别细粒度汇报、优先宏平均，以规避原始数据中开放域样本占比失衡的问题。
  - **LongMemEval**：500 个跨会话长历史问题，覆盖时序推理、知识更新、弃答、个性化回忆；按官方 LLM-as-judge 协议报告准确率。
- **骨干模型**：GPT-4o-mini（闭源 API）与 Qwen2.5-14B-Instruct（vLLM 本地部署）。
- **对比基线（四类）**：
  - 标准检索：Naive RAG；
  - LLM 记忆系统：Mem0、A-MEM、LightMem、GAM；
  - 启发式图检索：LightRAG、HippoRAG；
  - 学习式图遍历：RoG（因两数据集无训练划分，以官方预训练检查点零样本评测）。
- **可比性控制**：统一 BGE-M3（1024 维）嵌入、相同答案生成提示、相同答案模型上下文上限；温度固定 0.0；方法特定检索上限沿用官方配置。
- **主要结果**：
  - LoCoMo（GPT-4o-mini）：CogMem 单跳 59.20/56.40、多跳 50.70/46.10、时序 63.80/57.90、开放域 56.10/51.20（F1/BLEU-1），全面领先或持平最强基线 GAM。
  - LoCoMo（Qwen2.5-14B）：多跳 48.42 F1，超过 GAM 42.96、RoG 41.80、HippoRAG 34.78。
  - LongMemEval 总体准确率：CogMem 68.40（GPT-4o-mini）/ 66.50（Qwen），均为最高。
- **消融（Qwen2.5-14B）**：w/o Consolidation（多跳 43.56 / 知识更新 66.67）、w/o Claim（41.20 / 56.67）、w/o Agent 固定流水线（22.81 / 48.10），完整版 48.42 / 73.08。
- **补充实验**：语义坍缩探针（150 对）；人类盲评偏好研究（50 例多跳/时序，CogMem 胜 68%、平 20%、负 12%）；算子敏感性分析（锚定 K、遍历邻居数与深度、交集 K，共 4 张表）；巩固前后准确率与推理步数对比；100 例 LoCoMo 错误按四类各 25 例的根因分类；构建/推理 token 成本与理论复杂度分析。
