## 摘要
随着自主 LLM 智能体被部署于多会话环境中，传统记忆架构面临联想盲区（无法遍历多跳关系依赖）、脚手架遗忘（时间衰减驱逐核心人格不变量）和静态拓扑停滞（不可变图忽略使用动态）等问题。基于互补学习系统（CLS）原理，我们提出 EngramRAG，一种自适应记忆架构，将低延迟的清醒状态反射与异步后台梦境状态巩固周期相耦合。EngramRAG 引入：（1）使用调制个性化 PageRank（U-PPR），其转移概率通过赫布可塑性自适应，以将持久实体提升为高中心性的认知宏枢纽；（2）巩固激活的拓扑衰减（CATD），其按拓扑承载权重而非实际时间新近性缩放保留半衰期，并由冷启动宽限期（N_grace >= 4）保护；（3）有向 SUPERSEDES DAG 过滤，以在事实变更期间抑制过时状态；以及（4）三源混合检索，通过动态倒数排名融合（RRF）融合稠密向量、BM25 和 U-PPR。在 LoCoMo 基准中 10 段长期对话的全部 1,982 个问答对上评估，EngramRAG 相较稠密向量 RAG 在 Recall@5 上取得 +38.9% 的相对提升（53.21% 对 38.29%，p < 0.001），在 MRR 上提升 +43.1%（0.4203 对 0.2937），显著优于 Okapi BM25（48.66%）和孤立静态图检索（8.50%）。在时间推理上，EngramRAG 达到 62.33% 的 Recall@5（较稠密向量提升 16.67 个百分点）。在受控变更测试中，SUPERSEDES 将脑裂式幻觉从 70.0% 抑制至 0.0%；90 天模拟显示，在 26.21ms 的交互式检索反射下，脚手架保留率达到 100.0%。

## Abstract
As autonomous LLM agents are deployed across multi-session environments, conventional memory architectures suffer from Associative Blindness (inability to traverse multi-hop relational dependencies), Scaffolding Amnesia (temporal decay evicting core persona invariants), and Static Topology Stagnation (immutable graphs ignoring usage dynamics). Grounded in Complementary Learning Systems (CLS) principles, we propose EngramRAG, an adaptive memory architecture coupling a low-latency Waking State reflex with an asynchronous background Dreaming State consolidation cycle. EngramRAG introduces: (1) Usage-Modulated Personalized PageRank (U-PPR), where transition probabilities adapt via Hebbian plasticity to promote persistent entities into high-centrality Epistemic Macro-Hubs; (2) Consolidation-Activated Topology Decay (CATD), which scales retention half-life by topological load-bearing weight rather than wall-clock recency, protected by a cold-start grace period (N_grace >= 4); (3) Directed SUPERSEDES DAG filtering to suppress obsolete state during fact mutations; and (4) Triple-source hybrid retrieval fusing dense vectors, BM25, and U-PPR via dynamic Reciprocal Rank Fusion (RRF). Evaluating on all 1,982 QA pairs across 10 long-term conversations in the LoCoMo benchmark, EngramRAG achieves +38.9% relative improvement in Recall@5 (53.21% vs. 38.29%, p < 0.001) and +43.1% in MRR (0.4203 vs. 0.2937) over dense vector RAG, significantly outperforming Okapi BM25 (48.66%) and isolated static graph retrieval (8.50%). On temporal reasoning, EngramRAG reaches 62.33% Recall@5 (+16.67 points over dense vectors). In controlled mutation tests, SUPERSEDES suppresses split-brain hallucinations from 70.0% to 0.0%, while 90-day simulations show 100.0% scaffolding retention under a 26.21ms interactive retrieval reflex.

- **现有三条技术路线**：
  - 扁平向量 RAG（HNSW + 余弦相似度）；
  - OS 式虚拟内存（如 MemGPT，依赖昂贵的同步 LLM 工具调用分页）；
  - 静态知识图谱 RAG（如 HippoRAG 的静态 PPR、GraphRAG 的 Leiden 社区摘要）。
- **论文归纳的三大根本缺陷**：
  - **联想盲区（Associative Blindness）**：稠密向量只能捕捉孤立语义相似度，无法沿跨会话的多跳关联链传播；
  - **脚手架遗忘（Scaffolding Amnesia）**：基于墙钟时间的指数衰减 `e^{-λΔt}` 会驱逐用户身份、系统约束等基础不变量，仅因其未在每日对话中被提及；
  - **静态拓扑停滞（Static Topology Stagnation）**：图结构被视作不可变索引，边权不随实际检索使用反馈调整，且在事实变更时产生"脑裂式幻觉"（新旧事实共存并被同时召回）。
- **理论依据**：借鉴神经科学互补学习系统（CLS）理论，将记忆分为快速编码的"海马式"索引与离线巩固的"新皮层式"结构，对应系统的清醒态与梦境态。

## 2. 方法论

### 2.1 总体架构：双态（Dual-Brain）生命周期

- **清醒态（Waking State）**：面向实时交互的低延迟摄入与检索反射，预算 < 30 ms。
  - 事件驱动流式摄入：轻量二分类器做 Triage 过滤 → L0 去重（余弦相似度 > 0.95 时不新建节点，仅递增访问计数）→ 通过 Redis Streams 消费者组做**解耦双写**（Redis Stack 文档/向量库 + Neo4j 图库），写入以 O(1) 入队，隔离索引开销，并配置死信队列。
  - 三源混合检索：意图路由器动态分配权重，融合稠密向量 HNSW、Okapi BM25 与 U-PPR 图遍历，经 RRF 融合排序。
- **梦境态（Dreaming State）**：每约 6 小时触发的后台巩固，完全脱离读路径。
  - HNSW 加速的 DBSCAN 增量聚类（O(N log N)，ε=0.12，余弦 ≥ 0.88）合并近重复实体，胜者按历史访问数与全局 PageRank 中心性确定；
  - Louvain 社区划分（O(|E|)）生成主题模块与社区质心；
  - 重算 U-PPR 稳态分布并检测"认知宏枢纽"；
  - 执行 CATD 突触剪枝。

### 2.2 核心公式与机制

- **动态赫布边权**（式 1）：
  `W_ij(t) = α·cos(x_i,x_j) + β·Σ_{k=1}^{M_ij(t)} exp(−λ_access(t−t_k)) + γ·R_type(r)`
  其中 α=0.4、β=0.4、γ=0.2；第三项为结构类型先验（如 `R_SUPERSEDES = 2.5`）；中间项为共检索事件的时序衰减累加。即"共激活即增强"的 Hebbian 塑性。
- **使用调制个性化 PageRank（U-PPR）**：
  - 转移矩阵 `P(t)` 由 `W(t)` 行归一化得到；
  - 个性化传送向量 `p_i(q,t)` 为两项加权混合（θ=0.60）：语义相关度（归一化正余弦）与历史访问强度（`log(1+n_i)` 对数压缩 × `e^{−μ(t−t_i)}` 时间折扣，μ=0.05）；
  - 稳态解 `π*(q,t) = (1−d)(I − dP(t)^T)^{−1} p(q,t)`，阻尼 d=0.85，用幂迭代求解（I_PPR ≤ 20 次）；由 Perron–Frobenius 定理保证收敛。
  - **熵正则设计**：对数缩放 + 时间折扣 + θ 语义先验，用于抑制"富者愈富"的枢纽捕获。
- **认知宏枢纽识别**（式 4）：`π*_global(v) ≥ μ_π + 1.2σ_π` 且 `deg(v) ≥ 3`，经验上圈定约 top 5–8% 的结构性中转锚点，作为跨会话传播的稳定桥梁。
- **巩固激活的拓扑衰减（CATD）**：
  - 承重分数（式 5）：`Score_topology(v) = 0.4·min(3, |V|·π*_global(v)) + 0.3·min(2, deg(v)/3) + 0.3·Prior_type(v)`，其中类型先验 identity=1.0、preference=0.8、episodic=0.2；
  - 有效衰减率（式 6）：`λ_eff(v) = λ_base(type)·exp(−2.0·Score_topology(v))`，λ_base 分别为 identity 0.0001、preference 0.0008、episodic 0.08；
  - 物理驱逐需同时满足（式 7）：置信度 ≤ 0.10、休眠时长 > 4、度 ≤ 1、且类型不属于 {identity, preference}，并有 `N_grace ≥ 4` 个巩固周期的冷启动宽限期。
- **SUPERSEDES 有向 DAG 过滤**：U-PPR 遍历时禁止随机游走进入被 `[:SUPERSEDES]` 指向的过时节点（算法 1 第 8 行），从拓扑层面而非阈值层面消除新旧事实共存。
- **复杂度**：读路径 `O(K·d_embed + I_PPR·(|V|+|E|))`；合成扩展测试中 U-PPR 在 |V|=1,000 时 4–6 ms，|V|=10,000（59,980 边）时约 50 ms（单线程 CPU）；存储 < 50 MB。
- **存储规格**：HNSW 参数 M=16、efConstruction=200、efRuntime=50，384 维余弦；Neo4j 建模 `CO_OCCURS`、`ASSOCIATED_WITH`、`SUPERSEDES` 等类型化有向边。
