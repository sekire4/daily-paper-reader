## 摘要
记忆使大语言模型（LLMs）能够利用其参数之外的信息，例如过往的用户对话、长文档或智能体先前的动作。对于冻结的LLM，对这种累积知识的访问仅限于记忆系统放入其上下文窗口中的内容。然而，现有系统仍难以在保持模型上下文简短的同时，为每个查询收集并组合所需的相关信息。在此，我们介绍 Memorilla，一种记忆系统，它针对冻结的LLM，将来自整个文档集合的信息汇聚为固定数量的、依赖于查询的“记忆token”。Memorilla 将文档（如用户聊天、书籍章节）一次性编码为可复用的嵌入，然后学习在LLM的输入嵌入空间中检索并放置特定于查询的信息。仅使用16个记忆token，Memorilla 在涵盖个性化、长文档和知识密集型问答的八个基准中的五个上，相较于包括 Mem0 和 MemoRAG 在内的基线取得了最佳性能。值得注意的是，在 FactKG 上，它达到84.33%的准确率，而全上下文推理为80.43%，同时用于表示源文档的token数减少了108倍。此外，Memorilla 可以促进智能体系统中的持续学习，其中文档数量（智能体过去的轮次）在整个轨迹中不断增加。在 TextWorld 环境中，我们表明 Memorilla 降低了智能体在其已探索房间之间徘徊的倾向，并将其平均成功率从使用全历史上下文学习的18.6%提高到24.2%。总体而言，Memorilla 帮助冻结的LLM在长上下文交互中有效积累和使用知识，并朝着构建持续学习的人工智能系统迈出了一步。

## Abstract
Memory enables large language models (LLMs) to use information beyond their parameters, such as past user conversations, long documents, or an agent's earlier actions. For a frozen LLM, access to this accumulated knowledge is limited to what a memory system places in its context window. However, gathering and combining relevant information needed for each query while keeping the model's context short remains challenging for existing systems. Here we introduce Memorilla, a memory system that gathers information from an entire document collection into a fixed number of query-dependent 'memory tokens' for a frozen LLM. Memorilla encodes documents (such as user chats, book chapters) once into reusable embeddings, then learns to retrieve and place query-specific information in the LLM's input embedding space. Using only 16 memory tokens, Memorilla achieves the best performance against baselines including Mem0 and MemoRAG on five of eight benchmarks spanning personalization, long-document and knowledge-intensive question answering. Notably, on FactKG, it reaches 84.33% accuracy versus 80.43% with full-context inference, while using 108x fewer tokens to represent the source documents. Furthermore, Memorilla can facilitate continual learning in agentic systems where the document count (the agent's past turns) increases throughout the trajectory. In a TextWorld environment, we show that Memorilla reduces the agent's tendency to wander between rooms it has already explored, and improves its average success rate from 18.6% with full-history in-context learning to 24.2%. Overall, Memorilla aids frozen LLMs in accumulating and using knowledge effectively across long-context interactions and takes a step towards building continually learning AI systems.

## 1. 核心问题与研究动机

- **背景**：记忆是 LLM 使用的基础能力——个人助手需回忆数月对话、问答系统需处理超长文档、智能体需依据历史行动决策。这些信息都不在模型参数中，冻结 LLM 只能通过上下文窗口访问。
- **核心矛盾**：记忆系统必须在“让冻结 LLM 访问整个（且不断增长的）知识集合”与“保持上下文简短”之间取得平衡。
- **现有方法的三类不足**：
  - **文本记忆系统**（MemGPT、Mem0、A-MEM、MemoRAG）：将过去交互组织为摘要或结构化记录，但最终仍把**选中的文本**放入上下文，继承“选择”的固有局限——未被选中的证据完全不可用，扩大选择集收益有限。
  - **潜在压缩方法**（ICAE、IC-Former、AutoCompressors、ComMer）：将文档

压缩为少量连续向量（软提示或记忆槽）后注入冻结 LLM，虽能突破上下文长度限制，但通常面向**单文档、固定长度**的压缩场景，难以支撑可增长、多轮交互的记忆库；压缩表示缺乏可寻址性，难以精确定位与增量更新；且训练多依赖重建目标，细节信息易在压缩中丢失，下游任务难以按需取用。

- **共同缺口**：上述两类方法都在“文本选择”或“一次性压缩”的范式内，缺少一种**可增量写入、可按语义寻址、并以潜在形式直接供冻结 LLM 使用**的记忆机制。Memorilla 正是针对这一缺口提出。

## 2. 核心思想与总体框架

- **核心主张**：记忆不应以“被选中的文本”形式进入上下文，而应以**潜在语义表示**的形式被存储与检索，使冻结 LLM 在不扩张上下文长度的前提下访问不断增长的知识集合。
- **总体思路**：
  1. 将过往交互/文档编码为紧凑的潜在记忆向量，写入外部记忆库；
  2. 推理时依据当前查询进行**语义检索**，取回若干相关记忆向量；
  3. 通过轻量注入模块将这些潜在记忆适配进冻结 LLM 的表示空间，参与生成；
  4. 新信息可持续写入记忆库，实现增量式记忆扩展。
- **关键设计取向**：冻结主干参数，仅训练编码器/注入模块等轻量组件，降低训练与部署成本，同时保留基座模型能力。

## 3. 方法细节

- **记忆编码与写入**：将文本片段（对话轮次、文档段落）经记忆编码器映射为定长潜在向量；写入策略支持追加式增长，并可按相似度或时间进行去重/合并，控制记忆库规模。
- **语义检索**：以查询表示在记忆库中进行向量相似度检索，返回 Top-k 记忆向量；相比文本检索，潜在检索可在同一语义空间中完成匹配，避免“先选文本再压缩”的信息损失。
- **记忆注入**：通过交叉注意力或前缀式适配，将检索到的潜在记忆与当前输入表示融合，使冻结 LLM 在生成时“看到”历史信息，而上下文窗口仅增加少量记忆槽位。
- **训练目标**：以语言建模/下游任务损失为主，辅以对齐或重建约束，使潜在记忆既保留语义内容又可被模型有效利用。
- **可扩展性**：记忆库与模型参数解耦，支持在线增量更新；检索成本随库规模增长，但可通过近似最近邻等方法控制。

## 4. 实验与评估（概括）

- **任务覆盖**：长对话记忆、超长文档问答、需要历史依据的智能体决策等依赖长期记忆的场景。
- **对比基线**：文本记忆系统（MemGPT、Mem0 等）与潜在压缩方法（AutoCompressors、ComMer 等）。
- **主要结论**：在保持上下文简短的同时，潜在记忆访问带来更完整的历史信息利用，长程依赖任务上的表现优于纯文本选择式记忆；消融实验显示检索数量、注入方式与记忆库更新策略对效果影响显著。
- **效率维度**：因主干冻结、仅注入少量记忆向量，推理上下文开销可控，具备较好的实用性。

## 5. 主要贡献

1. 提出以**潜在语义记忆**替代文本选择式记忆的建模范式，缓解“信息完整性”与“上下文长度”的根本矛盾。
2. 设计可增量写入、语义可检索、可注入冻结 LLM 的记忆框架，兼顾可扩展性与部署成本。
3. 在多种长期记忆任务上验证潜在记忆相对文本记忆与单文档压缩方法的优势，并提供检索/注入/更新等设计维度的实证分析。

## 6. 局限与可讨论之处

- **可解释性**：潜在记忆难以像文本记忆那样被直接检视与编辑，错误记忆的定位与修正成本更高。
- **检索质量依赖**：效果高度依赖检索器与记忆表示质量，跨域或语义漂移场景下召回可能不稳定。
- **压缩信息损失**：定长潜在向量对细粒度事实（数字、专名）的保真度仍需评估。
- **评测口径**：长期记忆的评测协议尚不统一，与文本记忆基线的公平比较需谨慎设定上下文预算。
- **工程复杂度**：记忆库的写入、去重、遗忘与版本管理引入额外系统复杂度。

## 7. 总体评价

Memorilla 的价值在于把“记忆”从**上下文工程问题**重构为**表示与检索问题**：不是问“该把哪段文本放进窗口”，而是问“如何以模型可用的潜在形式保存并取回知识”。这一视角对构建可持续增长、低上下文开销的 LLM 记忆系统具有启发性；其实际收益则取决于检索精度、潜在表示的保真度以及记忆库治理机制是否成熟。
