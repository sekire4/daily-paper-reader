## 摘要
长期记忆仍然是大型语言模型（LLM）智能体跨会话时面临的一个根本瓶颈。现有系统通常采用先写入后检索的范式，存储依赖上下文的对话片段，并在连续嵌入空间中通过最近邻搜索进行检索。这种设计导致访问单元不稳定，并会系统性地遗漏逻辑相关但词汇距离较远的证据。我们提出 MemCode，一种将面向检索的写入与离散联想检索相结合的长期智能体记忆框架。MemCode 将对话重写为自包含的原子记忆单元（AMUs），通过同构语义量化（ISQ）将 AMUs 映射到可学习的码本中，并利用码本共现拓扑作为向量搜索的补充检索路径。对于长期记忆存储，MemCode 将在线原子写入与异步离线巩固分离。在 LongMemEval-S 和 LoCoMo 上，以 GPT-4o-mini 和 Qwen3-30B-A3B-Instruct-2507 为骨干模型，MemCode 取得了最佳总体准确率，同时将每段对话的记忆构建时间控制在约 40~130 秒内，使其比 LightMem 快 3~21 倍，比 A-MEM 和 MemoryOS 快一个数量级以上。

## Abstract
Long-term memory remains a fundamental bottleneck for large language model (LLM) agents across sessions. Existing systems typically adopt a write-then-retrieve paradigm, storing context-dependent dialogue fragments and retrieving them via nearest-neighbor search in a continuous embedding space. This design yields unstable access units and systematically misses logically related but lexically distant evidence. We propose MemCode, a long-term agent memory framework that couples retrieval-oriented writing with discrete associative retrieval. MemCode rewrites dialogue into self-contained atomic memory units (AMUs), maps AMUs into a learnable codebook with isomorphic semantic quantization (ISQ), and uses codebook co-occurrence topology as a retrieval path complementary to vector search. For long-term memory stores, MemCode separates online atomic writes from asynchronous offline consolidation. On LongMemEval-S and LoCoMo with GPT-4o-mini and Qwen3-30B-A3B-Instruct-2507 backbones, MemCode achieves the best overall accuracy while keeping per-dialogue memory construction within roughly 40~130 seconds, making it 3~21 times faster than LightMem and over an order of magnitude faster than A-MEM and MemoryOS.

# MemCode 论文结构化总结

## 1. 核心问题与研究动机

- **背景**：LLM 智能体正从单轮系统走向跨会话的持久助手，但模型参数（训练后基本静态）与上下文窗口（注意力开销随长度二次增长、长序列利用率下降）都无法承担跨会话记忆职责。因此外部记忆成为智能体系统的核心组件，主流做法沿用 RAG 范式：写入历史 → 查询时检索 → 回注上下文。
- **核心问题**：作者认为 RAG 式长期记忆的瓶颈不只是存储规模，而是 **“写什么”（what to write）与“怎么检索”（how to retrieve）两个设计选择未被联合建模**。
  - *写入侧*：存储依赖上下文的对话片段（含代词、相对时间）是不稳定的访问单元，脱离原对话后难以检索；而压缩摘要可能抹掉多跳召回所需的事实钩子。
  - *检索侧*：连续向量 + top-K 近邻继承了几何偏置，会系统性遗漏**逻辑相关但词汇/表面距离远**的证据；稠密检索器在任务分布变化时表现脆弱。
- **核心洞察**：人类记忆依靠海马体的“模式分离”（pattern separation）把相似连续输入编码为离散痕迹，并通过模式补全支持部分线索联想回忆。因此，**在连续向量之外增加离散锚点层**，可能是弥补几何偏置的关键。

## 2. 方法论

### 2.1 总体框架
MemCode 保留 RAG 式管线，但在写入、检索、长期维护全流程中加入离散表示层，分为四个阶段：**流式原子抽象 → 双路径索引 → 拓扑感知检索 → 异步巩固**。

### 2.2 流式原子抽象（写入侧）
- **交互分块与上下文注入**：原始流为消息序列，每条消息含角色、时间戳、文本。按真实交互轮分组为块 $B_k$；为避免严格切轮破坏指代，取上一轮末尾 $\omega$ 句作为**只读背景** $H_k$，拼接为 $X_k = H_k \oplus B_k$，背景只用于消解指代，不参与事实抽取。
- **语义规范化与原子抽取**：用 LLM 抽象引擎 $\Phi$ 在背景 $H_k$、时间锚 $T_{anchor}$、角色映射 $R_{roles}$ 条件下，把当前轮重写为自包含事实集合 $F_k$。每个**原子记忆单元（AMU）** 表示为三元组 $u=(c_{fact}, t_{abs}, \Lambda_{src})$：规范化事实、解析后的绝对时间戳、指向原始对话 span 的源指针。源指针在检索时可回溯邻近语句，重建更完整证据。
- **设计要点**：AMU 是“可独立检索的最小语义单元”，同时保留指向原文的指针，避免不可逆的抽象瓶颈。

### 2.3 同构语义量化 ISQ（离散索引）
- 以 VQ-VAE 为骨架，编码器为在 DailyDialog 上微调的 T5-base，得到 token 级隐状态序列 $H=(h_1,...,h_L)$。
- **步长为 1 的投影**（stride-1 Conv1d）保持 $L_{out}=L$，使时间戳、数字、实体 token 不被丢弃（这是与图像/语音中粗粒度压缩的关键区别）。
- 对每个投影向量 $z_t$ 在可学习欧氏码本 $E=\{e_j\}_{j=1}^{N_c}$（$N_c=1024$）中做最近邻量化：$\kappa_t=\arg\min_j\|z_t-e_j\|_2$，$\bar z_t=e_{\kappa_t}$；反向传播用 STE。
- **码本训练目标为预测编码而非重构**：给定量化后的上下文表示 $\bar Z$ 预测响应 $y$，损失为生成交叉熵 + VQ 损失（含 commitment 项，权重 0.10，VQ 损失权重 1.0，并加入熵使用正则 0.01）；码本用 EMA（衰减 0.99）更新，低频码字周期性从当前 batch 编码输出复活，防止塌缩。
- **指纹构造**：推理时删除相邻重复码 id，得到离散指纹 $S_{fp}(u)$；其唯一码集合 $U_{fp}(u)$ 用于构建共现拓扑（同一 AMU 内重复码只计一次）。**注意**：量化不替代存储文本，原始事实仍是喂给答案生成器的证据，指纹仅作辅助检索键。

### 2.4 拓扑感知双路径检索
- **隐式拓扑**：维护全局码 id 共现矩阵 $M_{ab}=\sum_{u\in F}\mathbb{1}[a\in U_{fp}(u)]\mathbb{1}[b\in U_{fp}(u)]\mathbb{1}[a\neq b]$，以及码频 $n(a)$；转移概率 $P(b|a)=M_{ab}/(\sum_{b'\neq a}M_{ab'}+\epsilon)$。
- **码本激活打分**：查询经同一 ISQ 得到查询码集 $Q_{fp}$，从源码 $a$ 到目标码 $b$ 的激活分数为
  $$S_{code}(b|a)=\underbrace{\log\frac{N_u+1}{n(a)+1}}_{\text{源端 IDF}}\cdot\underbrace{\max_{1\le h\le H_r}[P^h]_{ab}}_{\text{h 跳转移}}\cdot\alpha^h$$
  其中 $\alpha\in(0,1)$ 为邻域扩展衰减，$H_r$ 为固定扩展深度；**所有实验取 $H_r=1$**，防止递归传播放大噪声。
- **混合证据检索**：路径 A（稠密向量，FAISS L2，bge-base-en-v1.5 768 维）取 $K_v$ 条；路径 B 对每个 AMU 取指纹内最佳码得分 $S_{amu}(u)=\max_{a\in Q_{fp},b\in U_{fp}(u)}S_{code}(b|a)$，从**排除路径 A 已选**的候选中取 $K_c$ 条补充；最终 $R_{hybrid}=R_{vec}\cup R_{topo}$。
- **非对称合并**是有意设计：路径 A 提供高精度近邻，路径 B 只做补充，避免热门联想淹没答案上下文；随后沿源指针回溯原文 span 并按时间排序。默认预算为 20+20（最终证据 40 条 + 25/10 轮原始对话）。

### 2.5 异步记忆巩固（离线）
- 在线路径之外，后台回填稠密向量、过滤无效项，并用余弦距离的层次凝聚聚类（HAC）聚类，$d_{max}=1-\tau$；大簇按时间切分。
- **门控机制**：跳过计数敏感簇、限制更新敏感簇、避免跨说话人混合；通过的簇分配为 AGGREGATE / MERGE / UPDATE 三种操作（新事实数少于归档事实数时触发）。
- **指针前向（Pointer Forwarding）**：写回后把旧事实标记为归档并记录新事实索引，形成“新事实索引 + 原始源指针”的两级证据链，检索时用新事实替代旧事实。
- **时间跨度前缀**：若簇时间跨度超过分钟级，新事实加 `[Time Span: T_start to T_end]` 前缀。归档策略综合巩固模式、父事实数量、时间跨度、说话人来源决定替换或保留，降低不可逆信息损失风险。
