## 摘要
多模态模型与智能体已经出现，通过整合跨多个模态的信息，使 AI 系统能够更像人类一样从真实世界学习并与真实世界交互。然而，随着多模态智能体迈向长时程任务和终身设置，使其能够持续从复杂、异构的多模态数据中获取有用信息仍是一项重大挑战。应对这一挑战需要有效的记忆机制，这些机制能够维持跨会话的连续性、适应不断变化的用户和环境，并通过积累的经验来改进记忆管理策略。我们提出了一个面向多模态智能体记忆的双轴分析框架，围绕两个关键问题构建：多模态信息如何形成与表示（轴 I：形成与表示），以及其管理如何随积累经验而适应（轴 II：记忆管理）。轴 I（形成与表示）刻画了保留哪些信息以及如何对其进行编码（例如，模态特定嵌入、文本与结构化记录、潜在表示与参数化表示），以支持后续推理与行动。轴 II（记忆管理）区分三个层级：T1 静态记忆复用固定记忆；T2 动态记忆通过稳定策略更新记忆；T3 自演化记忆通过演化策略更新记忆。基于该框架，我们综合了反复出现的设计模式，并推导出若干原则：在源保真度与抽象之间取得平衡、保持时间有效性与来源溯源、将记忆使用建立在可恢复证据之上，以及随时间演化记忆策略。此外，我们讨论了多模态智能体记忆机制面临的挑战和潜在未来方向。

## Abstract
Multimodal models and agents have emerged to enable AI systems to learn from and interact with the real world more like humans by integrating information across multiple modalities. However, enabling multimodal agents to continually acquire useful information from complex, heterogeneous multimodal data remains a significant challenge as they move toward long-horizon tasks and lifelong settings. Addressing this challenge requires effective memory mechanisms that can maintain continuity across sessions, adapt to changing users and environments, and refine memory-management policies through accumulated experience. We introduce a two-axis analytical framework for multimodal agent memory structured around two key questions: how multimodal information is formed and represented (Axis I, Formation and Representation), and how its management adapts with accumulated experience (Axis II, Memory Management). Axis I, Formation and Representation, characterizes what information is retained and how it is encoded (e.g., modality-specific embeddings, textual and structured records, latent and parametric representations) to support subsequent reasoning and action. Axis II, Memory Management, distinguishes three tiers: T1 Static Memory reuses fixed memory; T2 Dynamic Memory updates memory through a stable policy; and T3 Self-Evolving Memory updates memory through an evolving policy. Based on this framework, we synthesize recurring design patterns and derive principles for balancing source fidelity with abstraction, maintaining temporal validity and provenance, grounding memory use in recoverable evidence, and evolving memory policies over time. Furthermore, we discuss the challenges and potential future directions for the memory mechanism of multimodal agents.

## 2. 方法论：双轴分析框架

### 2.1 总体结构

- **轴 I（Axis I, Formation and Representation）**：按"**最终供给下游推理器或行动策略的表示**"分类，而非按仅用于存储/索引的格式分类。
- **轴 II（Axis II, Memory Management）**：按"**部署期持久变化发生在哪里**"分三层（T1/T2/T3）。
- **跨轴分析（§5）**：推导每层对表示能力的**递增要求**，并做语料级统计。
- **系统层（§6）**：把逻辑记忆设计落到物理存储与运行时（驻留、搬运、索引、物化、写回、一致性）。
- **评测层（§7）**：给出共享 + 模态特定的评测维度，并与两轴映射。

### 2.2 轴 I：三类表示 + 混合

1. **源与模态特定表示**
   - *保留的感知源证据*：以原生模态保存可寻址条目（整图、区域/裁剪、文档截图、采样帧、视听片段、RGB-D、带时间戳与位姿的观察）。典型：PixelRAG（视觉嵌入只作索引，截图作为像素证据输入 VLM）、ToolMerge、HippoMM（事件中心）、M3-Agent（实体中心）、GraphEQA/DovSG（3D 场景图 + 图像记忆）。
   - *模态特定编码与几何状态*：存储被下游直接消费的特征/token/几何状态。视频：MovieChat（帧级 token + 固定容量 + 相邻合并）、MA-LMM（patch 级特征作 cross-attention 的 K/V）、Flash-VStream（粗到细）。具身：DynaMem（稀疏体素地图，含度量位置、历史、时间戳、VL 特征）、MemoryVLA（面向策略的感知历史 token bank）。音频：OMAC 作为可迁移机制（高重要性音频 token 作锚点 + 加权聚合）。
   - *代价*：压缩一般**不可逆**（采样/合并/聚类/体素化后无法从编码状态恢复），且**依赖模型接口**（需要兼容的 projector/Q-Former/策略接口）。
2. **跨表示显式记忆**
   - *感知→文本记录与摘要*：VideoAgent、Video-EM（事件记录含时间索引与 when/where/what/who 线索）、ReMA（时间戳对齐描述 + 重叠合并）、MIRIX（六类记忆组件 + embedding/BM25/字符串检索）。局限：**语义瓶颈**——写入时未被判定为显著的信息无法在检索时恢复。
   - *空间、时间与跨模态结构化记忆*：ConceptGraphs、DovSG、GraphEQA（层级 3D 度量—语义图，支持"是否需要继续探索"的前瞻决策）、PyraVid（三级图 + 分层聚合边 + 图遍历检索）、WorldMM（多尺度时间知识图 + 演化语义图 + Personalized PageRank）、TAME（动态状态记忆 vs 静态个性化记忆）、PolarMem（HAS / NOT_HAS 极性边，支持"验证不存在"）。
   - *代价*：构建与维护成本高；实体消解/关系抽取/模式扩展/一致性维护的错误会沿检索与规划传播。
3. **内化潜在与参数化记忆**
   - *持久多模态潜在状态*：hidden state、memory token、KV cache（ReKV、MuKV）、VisMem、TRAM（快/慢双递归状态，不同衰减率）、Light-Omni（混合：显式 episodic script + 生成式潜在特征）、L2-VMAS（感知记忆 + 思考记忆双 bank）、Mem-W（轨迹与过期会话压缩为 memory token）、LaMem-VLA（短期/长期 vault → 定长 latent token）。
   - *经验条件参数化记忆*：MemEIC（视觉/文本分离 LoRA + 显式编辑记录）、Frames2LoRA（Perceiver 超网络单次前向生成视频专属 LoRA）、SE-GA（显式仓库 + LoRA 自演化）、VLA-Pro（任务级 LoRA bank + 结构化程序状态检索 + 相似度加权融合）。
   - *代价*：难检查、难编辑、难溯源、难跨模型迁移；重复写入会引入干扰与遗忘。
4. **混合表示（系统级组合，非第四类）**
   - 关键子类是**源链接记忆（source-linked）**：抽象记录保留指向原始观察/证据的引用。
   - 代表：VimRAG（DAG 节点 + 多模态记忆库 + 按相关性/新近性/图位置动态调整视觉 token 预算）、FOLIO（短期缓冲 + 长期语义记忆 + 视觉证据缓存，记录含时间戳与关键帧引用）、MementoGUI（文本摘要 + 区域 bbox + 裁剪图 + 仅作组织的视觉嵌入）、VISTA（可修订文本笔记 + 无损逐帧视觉记忆，二者独立可寻址）、ObsGraph（room/view/object 三层观察中心场景图，缺失层级决定"换房间/细化视角/探索前沿"）、HiMe。
   - 核心挑战：链接在修订/合并/删除后仍须有效；抽象与支撑证据须一致；须学会"何时抽象足够、何时回取源证据"。

### 2.3 轴 II：三层管理

- **T1 静态记忆**：形成后内容、组织、索引、元数据均不变；设计变量是**索引与检索**（扁平序列、向量索引、层级、关系图、推理期潜在状态、参数模块；RAG、元数据/时空检索、关系遍历、规划器/工具辅助检索）。适用：静态语料、长视频、预建地图、可复用程序性知识。风险：形成期的遗漏与错误被永久固化。
- **T2 动态记忆**：通过**稳定策略**（硬编码启发式或部署前学得，推理期不变）更新记忆状态。五种基本操作：
  1. **更新**：追加/替换/改元数据；按表示类型不同——源保留（追加日志）、模态特征（同模态匹配 + 聚合/插入）、几何（配准 + 关联 + 融合/删除）、结构化（改属性/增删节点边/移动平均）、文本语义（提示 LLM 判定 增/改/确认/删/不变）、潜在（递归转移或 query-based 写模块）、参数（路由到参数子集 + 固定编辑目标优化）、混合（跨路径协调）。
  2. **整合/巩固**：特征空间压缩（平均/聚类/合并、按时间变化或语义显著性自适应）、语义抽象（ReMA 的重叠节点合并）、结构化合并（图对齐；风险是错误对齐会坍缩不同实体）、跨表示协调巩固（压缩 + 保留链接）。
  3. **修订**：空间与物体状态纠正、语义修订（确认/扩展/矛盾/取代）、跨表示冲突消解（先取回支撑证据再改派生表示）。
  4. **重组**：层级迁移（短期→长期、动态→静态；注意这是**逻辑角色**迁移而非物理驻留迁移）、图重连（局部子图重算、跨模态实体关联）、跨表示重建索引（移动平均更新检索键）。
  5. **遗忘**：主动证据驱逐（FIFO、蓄水池采样、频率/新近性、新近加权）、表示细节衰减（降采样、optical forgetting）、语义可及性衰减（时间衰减因子 + 复述恢复）、跨链接表示的协同选择性遗忘。
  - 两个多模态专属刻画维度：**表示处理模式**（局部 / 协调但可分离 / 跨表示投影融合）与**计算机制**（硬编码启发式 / 提示式 LLM / 训练好的功能更新模块 / 固定目标下的迭代优化）。
- **T3 自演化记忆**：反馈驱动的**策略**更新，形式化为
  - `M_{t+1} = U_{π_t}(M_t, x_t)`，`π_{t+1} = E(π_t, f_t)`（`x_t` 为当前经验，`f_t` 为任务结果/验证器判定/用户纠正）；
  - 三条子线：**写策略演化**（选择策略；变换策略含表示抽象粒度、归一化与接地、结构构建、源—记录映射修复）、**维护策略演化**（反馈驱动保留、反馈驱动抽象）、**检索策略演化**（搜索式化与控制、记忆选择与优先级）。
  - 判据要点：改**检索键/技能描述/使用统计**仍属 T2；只有**可复用管理规则/指令/程序/学习到的策略组件**被持久修订才算 T3。
