## 摘要
由基础模型驱动的自主智能体能够推理、规划和使用工具，但其固定权重和上下文限制阻碍了其在长期部署中从经验中持续学习。尽管外部记忆系统试图弥合这一差距，但它们大多充当被动的检索缓存，主要依据能否回忆起已存储的事实或过往交互来评估。记忆能否驱动真正的持续学习仍是一个开放问题。本文提出以记忆为中心的持续学习（MCCL），主张应以记忆是否改善未来行动来评判记忆，而不仅仅是其检索内容。MCCL包含三个主要部分。首先，一个三轴分类法按照状态存储位置（基底）、状态表现形式（资产）以及管理方式（策略）来组织记忆。这定义了一个双环生命周期：内环更新记忆状态，外环基于任务反馈优化管理策略。其次，一套评估协议衡量干扰下的保持、对变化的适应以及任务迁移，以将真实的行为增益与简单的上下文扩展区分开来。第三，一个记忆扩展框架建模智能体性能如何随经验、存储容量和计算预算在非参数记忆与参数记忆中的变化而扩展。这些组成部分共同将智能体记忆从被动查找重新定义为持续学习，为通向自我改进的自主智能体提供了一条原则性路径。

## Abstract
Autonomous agents powered by foundation models can reason, plan, and use tools, but their fixed weights and context limits hinder sustained learning from experience over long-term deployment. While external memory systems attempt to bridge this gap, they mostly act as passive retrieval caches, evaluated primarily by whether they can recall stored facts or past interactions. Whether memory can drive genuine continual learning remains an open question. In this paper, we introduce Memory-Centric Continual Learning (MCCL), arguing that memory should be judged by whether it improves future actions, not merely what it retrieves. MCCL has three main parts. First, a three-axis taxonomy organizes memory by where state is stored (substrates), what form it takes (assets), and how it is managed (policies). This defines a two-loop lifecycle that updates memory state in an inner loop while refining management policies in an outer loop based on task feedback. Second, an evaluation protocol measures retention under interference, adaptation to change, and task transfer to isolate genuine behavioral gains from simple context expansion. Third, a memory scaling framework models how agent performance scales with experience, storage capacity, and compute budgets across non-parametric and parametric memory. Together, these components reframe agent memory from passive lookup to continuous learning, offering a principled route toward self-improving autonomous agents.

## 2. 方法论

### 2.1 核心思想
MCCL 是一个**耦合动力系统**，由两个环构成：
- **内环（记忆状态环）**：序列部署经验更新持久记忆状态；
- **外环（策略适应环）**：任务反馈反过来精炼记忆管理策略，使智能体不仅积累经验，还改进“如何组织与使用经验”。

### 2.2 三轴分类法（Taxonomy）
用三个正交维度刻画记忆系统，避免把“存在哪里”“是什么形式”“怎么管理”混为一谈：

| 维度 | 含义 | 子类 |
|---|---|---|
| **Substrates（WHERE）** | 状态物理持久化的介质 | 上下文记忆、激活记忆（KV cache/隐状态）、外部可寻址记忆、自适应参数记忆 |
| **Assets（WHAT）** | 从经验中构造的可复用表征 | 情节性（episodic）、语义性（semantic）、程序性（procedural） |
| **Policies（HOW）** | 管理写/读/整合/修订/遗忘的机制 | 预定义（prescribed）、审慎型（deliberative，运行时 LLM 推理）、学习型（learned，基于结果更新） |

- 关键区分：**“拥有某类基底/资产”不等于“具备跨任务迁移能力”**，后者取决于策略。
- 混合基底是趋势：token/激活支持即时适应，外部存储提供持久可审计保留，参数更新选择性内化稳定技能。

### 2.3 双环生命周期（形式化）
- **内环状态转移**：
  $$M_{t+1} = \mathcal{T}(M_t, e_t; \pi^{mem}_t)$$
  其中 $M_t$ 为持久记忆状态，$e_t$ 为当前交互经验，$\pi^{mem}_t$ 为记忆管理策略。
- **行为生效条件**：更新后的状态必须在后续被访问并纳入推理，才产生下游行为效应 $\Delta \mathcal{B}_{t+k}$（$k>0$）。
- **外环策略演化**：
  $$\pi^{mem}_{t+1} = \mathcal{U}(\pi^{mem}_t, \mathcal{F}_{t:t+H})$$
  $\mathcal{F}_{t:t+H}$ 为未来 $H$ 步的下游反馈（任务结果、奖励、错误、用户纠正）。
- **五阶段生命周期**：选择性形成与写入 → 组织/压缩/整合 → 检索与利用 → 修订与遗忘 → 反馈驱动的策略演化。
- **三个反馈层级**：(1) 状态级写入；(2) 离线策略训练后冻结；(3) **在线策略演化**（部署中持续修改 $\pi^{mem}$，是高级层而非必需前提）。

### 2.4 评估协议（行为中心）
- **四道门保持级联（retention cascade）**：preservation（存住）→ access（取到）→ utilization（用上）→ effect（行为改善），并提出**最弱门瓶颈假设**。
- **匹配的有状态 vs. 重置对比**：
  $$\Delta P_t = P_{\text{stateful}}(t) - P_{\text{reset}}(t)$$
  配合 no-memory、full-history、static RAG、matched-compute 等基线，逐步排除“上下文变长”“额外推理”等替代解释。
- **三类核心行为结果**：
  - **Retention**：延迟 $d$ 与干扰 $m$ 后的归一化保持增益 $\Delta_i(d,m)/\Delta^0_i$；
  - **Adaptation**：检测延迟、恢复步数、陈旧错误持续时间、附带损伤；
  - **Transfer**：零样本目标增益/前向迁移、达到阈值所需交互数、显式**负迁移率**。
- **顺序评估四类观测机制**：snapshots → streams → reprobes → interventional panels；用 $R_{t,i}$ 矩阵（对角线=习得，下三角=保持/回溯影响，留出变体=迁移）配合事件账本。

### 2.5 记忆扩展框架（Scaling Law）
- **非参数记忆**：设累计经验 $E$、持久容量 $\bar{B}$、读预算 $R$、写/维护预算 $U$，则
  $$\epsilon^\star - \epsilon_\infty \asymp \max_{j\in A} a_j x_j^{-\alpha_j},\quad x=(E/E_0,\ \bar{B}/B_0,\ R/R_0,\ U/U_0)$$
  给出**资源受限区制**：性能随经验上升，遇容量/读写算力瓶颈后饱和；扩瓶颈资源可移动饱和点。均衡增长路径为 $\bar{B}/B_0 \propto (E/E_0)^{\alpha_E/\alpha_B}$、$R/R_0 \propto (E/E_0)^{\alpha_E/\alpha_R}$。容量指数可由长尾需求分布推出（$p_i \propto i^{-s}$ 时 $\alpha_B = s-1$）。
- **容量需求**：$B_{req}(E;p_0) \propto E^{\nu}$，独立事实 $\nu\approx1$，共享规则/技能 $\nu<1$。
- **复用经济学**：$C_N = \frac{C_{build}+C_{maint}(N)}{N} + C_{query}$，存在“复用次数交叉点”，决定轻量直读 vs. 昂贵预整合。
- **参数记忆**：引入**负载率**
  $$\rho_t = \frac{I(E_t)}{\kappa M}$$
  （$\kappa \approx 2$ bits/参数），并加入**干扰项**：
  $$\epsilon^\star - \epsilon_\infty \asymp \max_j a_j x_j^{-\alpha_j} + I_{s,\pi}(\rho_t)$$
  当 $\rho_t$ 超过临界值 $\rho^\star_{s,\pi}$（依赖基底 $s$ 与写策略 $\pi$）时，新写入覆盖旧内容。三条可检验预测：(1) 固定经验增大容量，先受干扰主导、进入安全区后呈幂律；(2) 固定容量增大经验，越过 $\rho^\star$ 后损失上升；(3) **不同容量下的负载曲线按 $\rho$ 坍缩为单曲线**（最直接检验）。
- **参数记忆容量需求**：$M_{req} \gtrsim \frac{I(E)}{\kappa \rho^\star_{s,\pi}} \propto \frac{E^\nu}{\rho^\star_{s,\pi}}$，因此改进基底/写策略可数量级降低所需容量。

### 5.3 可复现性
- 优点：明确给出基座模型版本（Qwen3-30B-A3B-Instruct-2507）、嵌入模型与维度、分词器（o200k_base）、Mem0 版本号（0.1.94）与运行模式，评测协议（stateful–reset、matched-compute 基线）描述较具体，具备较强可复现基础。
- 不足：未报告随机种子、温度/解码参数、prompt 模板、IdeaBench 检查点的具体来源与训练细节；cluster-bootstrap 的簇定义（按对话/按问题）未说明；未提供代码或数据链接（至少正文中未体现）。

## 6. 主要贡献与创新点

1. **概念重构**：把智能体记忆从“检索缓存”重新定位为“持续学习的基础设施”，明确提出“不改权重也能持续学习”的命题，并给出可操作的研究纲领。
2. **三轴正交分类法**：将 WHERE（基底）/WHAT（资产）/HOW（策略）分离，纠正了以往文献中“有外部存储=有记忆能力”的混淆，并指出**迁移能力取决于策略而非基底**这一关键判断。
3. **双环生命周期形式化**：用内环状态转移 + 外环策略演化刻画记忆系统动力学，并区分三个反馈层级（写入级、离线训练后冻结、在线演化），为后续工作提供了清晰的分级路线图。
4. **行为中心评估协议**：提出四道门保留级联与最弱门瓶颈假设、stateful–reset 匹配对照、以及 retention/adaptation/transfer 三类行为指标，弥补了以往只看“召回率”的评测缺陷；顺序评估的 snapshots→streams→reprobes→interventional panels 设计具有较强方法论价值。
5. **记忆扩展框架**：将非参数记忆与参数记忆统一到“资源受限幂律 + 饱和”的框架下，引入**负载率 $\rho_t$ 与干扰项**解释参数记忆的容量上限，并提出可证伪的坍缩预测；复用经济学 $C_N$ 给出了“直读 vs. 预整合”的决策依据。

## 7. 局限与批判性评估

| 维度 | 具体问题 | 严重程度 |
|---|---|---|
| 实证覆盖 | 仅 Mem0 与 Raw RAG 两个系统、三个数据集；未与 A-MEM、Zep/Graphiti、MemGPT、ReasoningBank、Voyager 等同台比较 | 高 |
| 理论—实证落差 | 扩展定律与负载率曲线为合成示意，核心预测（$\rho$ 坍缩）未检验 | 高 |
| 外环缺证 | 论文最核心的“策略也学习”主张无端到端实验支撑，双环模型实际只验证了内环 | 高 |
| 指标粒度 | 级联各门未拆解，负迁移/遗忘等仅在定义层面 | 中 |
| 规模 | LongMemEval 100 样本、计时实验 3 次重复，统计功效不足 | 中 |
| 算力透明度 | 未报告 GPU 资源与成本，难以评估方法的经济可行性 | 中 |
| 概念边界 | “记忆即学习”的强主张与“记忆只是改善上下文”的弱主张之间未做严格区分，存在被过度解读的风险 | 中 |

**总体判断**：本文更接近**立场论文（position paper）+ 研究纲领 + 小规模验证**的组合，而非一篇以实证取胜的系统性工作。其价值主要在于概念澄清、评估协议设计与可检验假设的提出，而非实验结论的强度。读者若将其视为“MCCL 已被验证”会高估其证据力；若视为“为记忆型持续学习建立共同语言与评测标准”则评价恰当。

## 8. 启示与未来方向

- **补齐外环实验**：设计让 $\pi^{mem}$ 在部署中依据下游反馈被修改（如学习写入阈值、检索预算分配、整合触发条件），并对比冻结策略，是验证 MCCL 主张的关键一步。
- **拆解保留级联**：为四道门分别设计诊断探针（如“已存内容强制注入”测 access 上限，“给定正确记忆”测 utilization 上限），才能检验最弱门瓶颈假设。
- **统一评测基准**：在相同 backbone、相同上下文与检索预算下横向比较主流记忆系统，并公开负迁移率与陈旧错误持续时间等“负面指标”。
- **检验负载率坍缩**：在固定基底、变化容量与经验量的参数记忆实验中，检验不同容量下的性能曲线能否按 $\rho$ 坍缩，这是本文框架最锋利也最易被证伪的预测。
- **成本视角**：复用经济学 $C_N$ 提示，记忆系统的优劣高度依赖复用次数分布；未来工作应报告“每单位行为增益的 token/延迟成本”，而非仅报告准确率。

## 9. 一句话总结

本文提出以记忆为中心、不改基座权重的持续学习框架 MCCL，通过三轴分类法、双环生命周期、行为中心评估协议与记忆扩展定律，为“智能体如何从经验中持续改进”提供了统一的概念语言与可检验假设；但其实证规模与理论—实验匹配度有限，核心的在线策略演化与负载率预测仍待验证。
