## 摘要
智能体记忆面临异构访问需求：单跳问题可能只需要一条证据，而多跳问题必须组合来自多个来源的证据。预定义的记忆工作流无法适应这些变化的需求。近期的自适应方法在记忆组件及其组合上进行搜索或学习，但设计空间本身仍是预定义的。我们提出 MemCodex，一个自演化的层次化记忆系统，它将经验组织为用于摘要、关系知识、可复用技能和潜在记忆的可执行记忆程序。开放式程序演化通过重写每一层的构建、索引、检索和路由方式，搜索层程序的开放设计空间，从而同时适配层内实现与跨层组合。查询时，读取按从粗到细的顺序遍历层次结构，并在找到足够证据后停止，必要时下降到原始历史记录。我们进一步开发了 MemArena，一个统一运行时，将异构数据和记忆系统置于通用接口之后。相对于最强的自适应记忆基线，MemCodex 将平均任务成功率提高 10.1%，同时上下文 token 用量减少为原来的 1/3.4，并实现 2.1 倍的推理加速。

## Abstract
Agent memory faces heterogeneous access needs: a single-hop question may require one piece of evidence, whereas a multi-hop question must combine evidence from multiple sources. Predefined memory workflows cannot adapt to these varying needs. Recent adaptive methods search or learn over memory components and their compositions, but the design space itself remains predefined. We introduce MemCodex, a self-evolving hierarchical memory system that organizes experience into executable memory programs for summaries, relational knowledge, reusable skills, and latent memory. Open-ended program evolution searches the open design space of layer programs by rewriting how each layer is constructed, indexed, retrieved, and routed, thereby adapting both within-layer implementations and cross-layer composition. At query time, reads traverse the hierarchy from coarse to fine and stop once sufficient evidence is found, descending to the original history when needed. We further develop MemArena, a unified runtime that places heterogeneous data and memory systems behind a common interface. MemCodex improves average task success by 10.1% relative to the strongest adaptive-memory baseline, while using 3.4x fewer context tokens and achieving 2.1x faster inference.

## 1. 核心问题与研究动机

- **记忆访问需求的异质性**：语言智能体长期运行中积累大量经验，但不同查询对记忆的需求差异极大——单跳问题只需一条原始证据，多跳问题需跨会话组合多条证据，时序问题依赖带时间戳的事件，重复性流程则需要可复用技能。
- **预定义流程难以适配**：MemoryBank、MemGPT、Mem0、A-Mem、MemoryOS、HMO 等手工设计系统把“有哪些记忆组织”和“如何在其中选择”都写死；已有研究（对 14 个记忆系统的考察）表明没有单一架构能在所有任务上占优。
- **现有自适应方法的局限**：
  - 一类方法在**预定义设计空间**内选择/组合编码、存储、检索模块（如 AutoMem、MemEvolve）；
  - 另一类学习“何时写、如何更新、如何检索”的策略（如 Mem-α）；
  - 但二者仍需同时决定“经验如何组织成记忆”与“查询如何访问记忆”，且**设计空间本身仍是预先给定的**。
- **最接近的工作 MemPro** 虽把设计本身开放给程序搜索，但只在**扁平记忆上演化单一整体程序**，缺少可独立演化、可独立访问的层次组件。
- **论文主张**：应把记忆建模为**分层可执行程序**，让“层内实现”与“跨层组合”都进入开放式演化，同时保证任何有损抽象都能回溯到原始证据。

## 2. 方法论

### 2.1 核心思想

- 将智能体记忆表示为一个**层次化可执行记忆程序体系**：架构 $g=(\lambda,\psi)$，其中 $\psi$ 是各层程序，$\lambda$ 是层开关掩码。
- 固定**五方法层接口**与运行时约束程序交互方式，但层内行为对演化开放。
- 文本层由粗到细排列：**skill → graph → summary → raw**，另有固定不演化的 **kv memory**（潜在记忆）。
- 写入与读取定义为：
  - $M \leftarrow \text{write}_g(M, R_i)$
  - $C = \text{read}_g(M, q)$，且 $|C| \le B$
  - $a = \pi(q, C)$

### 2.2 关键技术细节

- **层接口（每层五个方法）**：
  - 写侧：`admit`（过滤候选）、`index`（维护容量为 $K_\ell$ 的活跃索引）、`propose`（向上一层提交派生项）；
  - 读侧：`score`（排序并返回置信度）、`route`（返回 `Stop` / `Narrow` / `Descend`）。
  - 运行时负责 `assemble`，在预算 $B$ 内打包上下文。
- **证据保全（Evidence Preservation）**：
  - 原始层 $V$ 只追加、不可修改；
  - 每个派生项 $x$ 记录精确来源轮次 $\text{src}(x)$，递归定义为 $\text{src}(x)=\bigcup_{y\in\text{in}(x)}\text{src}(y)$；
  - 四条记忆约束：原始层只追加、派生项必须标注来源、`Narrow` 只能把搜索域收缩到 $\text{src}(x^\star)$、上下文不超过 $B$。
- **双通道**：
  - **内容通道** $C_{txt}$：把派生项文本直接放入上下文（类似摘要/画像/技能记忆）；
  - **路由通道** $C_{route}$：检索命中后沿 $\text{src}(x)$ 下探到原始轮次（类似 HippoRAG）。
  - 论文默认采用路由通道；示例中摘要遗漏“Paris”，但路由可回到含“moving to Paris in May”的原始轮次。
- **查询自适应读取（Algorithm 1）**：
  - 从最粗层开始，逐层 `score` 取 top 候选 $x^\star$ 与置信度 $c$；
  - `route` 决定：`Stop` 则组装上下文返回；`Narrow` 则把搜索域 $F$ 收缩到 $\text{src}(x^\star)$ 后继续；`Descend` 保持搜索域继续；
  - 到达原始层时取 top-$k$ 轮次；每个查询只付出其所需的读取深度。
- **写入路径**：每个 chunk 自底向上经 `propose → admit → index`；技能层要求程序在演示会话上**可重放并复现记录结果**才被接纳。
- **潜在记忆**：用 Metis-27B（带快速权重的记忆基础模型）的状态作为固定大小 KV 记忆，只写不读、不参与演化；通过 NL 接口（文本）或 KV 接口（仅开放权重模型）注入任务智能体。
- **程序演化（Algorithm 2）**：
  - **可归因编辑**：每个子代只重写**一个层的一个方法**，或翻转**一个层开关**；
  - **诊断驱动**：父代诊断 $D(g)$ 检查失败轨迹与被拒/被逐项，把失败归因到“第一个丢失金标轮次的方法”，兄弟子代针对不同方法；
  - **元智能体 $\rho$**：读取目标层代码、诊断与拒绝日志，返回只覆盖该方法的子类；
  - **有效性检查 $\mathcal{K}$**：在夹具查询上拒绝违反记忆约束的子代；
  - **接受检验**（式 4）：
    $$\text{Accept}(g\to g') \iff \Delta_{tok}\le 0 \wedge \Delta_{acc}\ge 0 \wedge [(\Delta_{acc}>0 \wedge p<\alpha)\vee \Delta_{tok}<0]$$
    其中 $p$ 为单侧精确 McNemar 检验值，$\alpha=0.05$；
  - **存档树**：接受者入档，拒绝者进入父代拒绝日志；父代采样权重结合准确率 logistic、子代数与准确率-成本 Pareto 前沿上的拥挤距离，鼓励“准确、少被展开、位于前沿”的节点。
- **MemArena 统一运行时**：
  - **数据接口**：源适配器把语料映射为 episode $e=(R,\mathcal{Q}_e)$，问题元组含 $(q,a^\star,G(q),y_q,t_q)$；
  - **访问接口**：记忆包装器暴露 `write(M,R_i)` 与 `read(M,q)`，智能体包装器暴露 `answer(q,C)`，实现记忆质量与智能体能力解耦；
  - 每条记录写入全新存储、按 20 轮分块，问题在 $t_q$ 前最后一块写入后提出；
  - **指标套件**：准确率、证据召回率 $\text{Rec}$、每问题上下文 token 数、推理时延。

## 6. 主要结论与发现

- **整体性能**：MemCodex 在四个 benchmark 上均最准确且读取 token 最少。
  - Qwen3.5-27B：平均 **60.8%**，比 MemPro（55.2%）高 **5.6 分**，比全上下文（53.6%）高 7.2 分；
  - GPT-5.4-mini：平均 **61.1%**，比 MemPro 高

- GPT-5.4-mini：平均 **61.1%**，比 MemPro 高约 6 分，且在两个骨干上均保持“准确率最高、每问题读取 token 最少”的双重优势。
- **效率优势**：MemCodex 的 Tok/q 显著低于全上下文与稠密 RAG 基线，接近或优于 MemPro；说明层次化路由让简单查询停在粗层、复杂查询才下探，避免了“对所有查询统一深度检索”的浪费。
- **跨骨干一致性**：在开放权重（可用 KV 接口）与纯 API（仅 NL 接口）两种条件下结论方向一致，表明收益主要来自层次化程序结构与自适应读取，而非某一特定模型的接口能力。

### 6.1 消融发现

- **层次深度**：1 层（扁平）明显退化，2–3 层收益最稳定，4 层在部分数据集上因写入开销与稀疏使用而无额外增益，提示层次并非越深越好。
- **证据通道**：纯内容通道在时序与多跳问题上证据召回下降；内容+路由通道在保持准确率的同时提升了 Rec，验证“抽象可回溯”的设计价值。
- **演化方式**：无演化 < 模块选择 < 层重写 < 程序重写，呈单调递增；说明“层内实现可演化”比“在固定模块库中选择”带来更大空间。
- **接受检验与存档**：去掉 McNemar 接受检验后，搜索出现准确率漂移与 token 膨胀；去掉存档后，后期轮次增益衰减更快。二者共同维持了搜索的单调改进性。

### 6.2 演化动力学

- **逐轮增益**：LoCoMo 上 7 次接受编辑带来持续但递减的增益，前期编辑集中在读取路由与摘要层，后期集中在技能层的准入条件。
- **相对基线**：与 MemPro、MemEvolve、AutoMem 相比，MemCodex 在相同 64 子代预算下增益更大，且方差更小（种子标准差 ≤0.8 分）。
- **停止层分布**：单跳问题多在最粗层 `Stop`，多跳与时序问题更多触发 `Descend`/`Narrow`，与“按需读取深度”的设计预期吻合。
- **自适应 vs 固定读取**：固定读取策略在简单问题上浪费 token、在复杂问题上召回不足，自适应读取在两端的折衷最优。

### 6.3 泛化与迁移

- **记录不相交划分**：性能下降幅度小于多数基线，说明学到的程序不是对特定记录的过拟合。
- **跨 benchmark 迁移**：在 LoCoMo 上演化出的架构迁移到 LongMemEval/MAB 时仍优于初始 $g_0$ 与 MemPro，但迁移收益小于同域演化，提示架构存在一定的任务族偏好。
- **证据召回**：路由通道使 Rec 提升，且在摘要遗漏关键实体（如“Paris”）时仍能回到原始轮次，直接支撑了“有损抽象可回溯”的核心主张。

## 8. 对领域的启示

- **把“记忆架构”本身作为可学习对象**：从“在固定模块库中选择”推进到“层内实现 + 跨层组合”的联合开放搜索，是记忆系统自适应的一条清晰路径。
- **接口固定、实现开放**是兼顾可演化性与可验证性的有效折衷：五方法层接口让子代编辑可局部化、可归因、可检查。
- **证据保全是层次抽象的前提**：`src(x)` 递归溯源 + `Narrow` 只能收缩到来源域，为“摘要/技能”这类有损表示提供了可审计的安全网，这一约束设计值得被其他层次记忆系统借鉴。
- **诊断驱动 + 单点编辑**降低了搜索的组合爆炸，使 LLM 元智能体能够在有限预算内做有意义的程序改进。
- **统一运行时（MemArena）**把记忆质量与智能体能力解耦，配合准确率/召回/token/时延的多维指标，为记忆系统的可比评测提供了可复用范式。

## 9. 总体评价

论文的核心贡献在于问题重述与方法框架：将智能体记忆形式化为**可演化的层次化可执行程序**，并以证据保全约束、查询自适应读取、可归因单点编辑与统计接受检验构成一个自洽的闭环。实验在 4 个 benchmark、2 个骨干、11 个基线上显示出一致的准确率与 token 效率优势，消融也较好地支撑了各设计选择的必要性。主要短板在于算力透明度、骨干与裁判的多样性、以及技能层与跨域迁移结论的统计强度。总体而言，这是一篇在“记忆架构自动化设计”方向上具有明确推进意义、工程完整度较高的工作，其接口与约束设计可能比具体搜索算法更具长期影响。
