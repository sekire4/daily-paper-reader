## 摘要
大语言模型越来越多地依赖外部记忆来回答基于长程历史的查询，例如多轮会话对话和长篇文档。然而，现有记忆方法通常分别优化检索与记忆构建，缺乏一个用于评估搜索、写入和停止决策的共享奖励空间。为此，我们提出一体化记忆（AiO-Mem），将这些操作组织为共享证据状态上的状态转移，并在统一奖励空间中直接评估每个动作的语义质量。AiO-Mem 将异构历史编译为可溯源的多视图事件，为检索和记忆写入提供共享基底。随后，一个统一的记忆策略执行者在共享证据状态上展开完整的交互轨迹。一个独立的、以轨迹为条件的过程奖励模型通过基于证据的监督微调和轨迹级 DPO 进行训练，为收集到的轨迹分配过程分数。这些分数被聚合为动作平衡的轨迹奖励，并由过程对齐 DAPO（PA-DAPO）用于优化记忆策略。在长上下文记忆基准上，AiO-Mem 在答案准确率上持续优于静态记忆系统和经强化学习训练的记忆智能体。

## Abstract
Large language models increasingly rely on external memory to answer queries grounded in long-horizon histories such as multi-session dialogues and lengthy documents. However, existing memory methods often optimize retrieval and memory construction separately, without a shared reward space for evaluating search, writing, and stopping decisions. To address this, we propose All-in-One Memory (AiO-Mem), which organizes these operations as transitions over a shared evidence state and directly evaluates the semantic quality of each action in a unified reward space. AiO-Mem compiles heterogeneous histories into source-traceable multi-view events, providing a shared substrate for retrieval and memory writing. A unified memory policy actor then rolls out complete interaction trajectories over this shared evidence state. A separate trajectory-conditioned process reward model is trained through evidence-grounded supervised fine-tuning and trajectory-level DPO to assign process scores to the collected trajectories. These scores are aggregated into an action-balanced trajectory reward and used by Process-Aligned DAPO (PA-DAPO) to optimize the memory policy. Across long-context memory benchmarks, AiO-Mem consistently improves answer accuracy over both static memory systems and RL-trained memory agents.

- **背景**：大语言模型在长程历史问答（多会话对话、长篇文档、持久用户画像等）中受限于静态参数知识与有限上下文窗口，因此越来越多地依赖外部记忆增强架构，涵盖稠密检索系统、知识图谱记忆以及持久记忆智能体。
- **核心矛盾**：记忆系统由“检索”和“记忆构建”两个紧密耦合的阶段组成——检索提供相关证据，构建将证据压缩为工作记忆；但记忆状态不断演化，会持续改变“下一步该检索什么、写入什么、丢弃什么”。
- **现有 RL 记忆方法的不足**（论文 Figure 1 对比）：
  - **检索导向方法**（如 Search-R1）只学习如何搜索；
  - **构建导向方法**（如 Mem-α）只学习何时插入/更新/合并记忆；
  - 两者目标分离、反馈信号部分割裂，导致两大缺陷：
    1. **缺乏共享证据状态空间**，难以协同判断“继续搜索 / 写入记忆 / 跳过冗余 / 停止”；
    2. **监督以结果为中心**，只奖励最终答案，对中间记忆操作缺乏过程级信用分配。相同最终答案分数的轨迹，在证据相关性、记忆忠实性、冗余控制、停止充分性上可能差异巨大。
- **整体含义**：论文主张将检索与构建统一为**单一记忆交互智能体在共享证据状态上的状态转移过程**，并用**统一奖励空间中的过程级语义评分**来优化记忆策略，从而让记忆操作本身变得可评估、可协调、可端到端训练。

## 2. 方法论：核心思想与关键技术细节

**核心思想**：把异构记忆操作（搜索、添加、跳过、停止）建模为有限时域 MDP 上的证据状态转移，用一个独立的、以轨迹为条件的过程奖励模型对每一步动作打分，再将分数聚合为动作平衡的轨迹奖励，用 PA-DAPO 优化记忆策略。

**四大组件**：

### (1) 可溯源多视图事件库（Traceable Multi-View Event Bank）
- 用结构感知编译器 $\mathcal{C}$ 将历史 $H=(h_1,\dots,h_N)$ 编译为事件库 $\mathcal{B}=\{e_m\}_{m=1}^M$；
- 每个事件 $e_m=(\{x_m^v\}_{v\in V},\ \ell_m)$，含四个互补视图：raw（保留词汇细节）、sum（宏观语义连贯）、anc（该事件可回答的假设性查询）、phr（低噪声语义标签）；
- 来源定位器 $\ell_m=(n,i_{start},i_{end})$ 将事件锚定回原始来源单元，保证可溯源；
- 检索时对每个视图分别排序，再用等权 Reciprocal Rank Fusion 融合：$\text{score}(e_m|u_t)=\sum_{v\in V}\frac{1}{\kappa+\text{rank}_v(e_m|u_t)}$；sum/phr 用稠密检索，anc 用 BM25，raw 用混合检索。

### (2) 证据状态转移建模（Evidence-State Transition Modeling）
- 状态 $z_t=(q,W_t,R_t)\in\mathcal{S}$：查询、当前工作记忆、最新候选列表；决策模式 $m_t\in\{\text{decide},\text{extract}\}$；
- 动作空间 $\mathcal{A}=\{\text{search},\text{add},\text{skip},\text{stop}\}$，通过模式特定动作掩码约束合法性（避免“未检索就添加”“未决定是否使用候选就再次搜索”）；
- 确定性转移：
  - search → $(q,W_t,R(u_t))$
  - add → $(q,W_t\oplus[n_t],R_t)$
  - skip → $(q,W_t,())$
  - stop → $(q,W_t,R_t)$
- 当选择 stop 或达到最大时域 $T_{max}$ 时回合结束，最终工作记忆交给冻结生成器 $\hat{y}=G(q,W_T)$；
- 轨迹 $\tau=(z_1,a_1,\dots,z_T,a_T,z_{T+1})$ 收集为 $\mathcal{D}_{traj}$。

### (3) 统一奖励建模（Unified Reward Modeling）
- 训练生成式奖励模型 $J_\phi$ 为轨迹中每一步分配密集过程奖励（只评估、不改变状态转移）；
- **Stage 1：证据锚定的 SFT**：定义未覆盖金证据 $E_t^{miss}=E^\star\setminus\text{Src}(W_t)$，对 search 计算新暴露证据 $\Delta_t^{ret}$，对 add 计算新提交证据 $\Delta_t^{write}$，用动作特定的确定性规则计算步级规则分 $r_t^{rule}$，对序列化轨迹 $x_\tau=\text{Serialize}(y^\star,E^\star,\tau)$ 做 SFT；
- **Stage 2：轨迹级 DPO 对齐**：用具备推理能力的模型基于完整轨迹上下文经思维链为每步打分 $v^{CoT}$，以 $v^+=v^{CoT}$ 为 chosen、$v^-=v^{rule}$ 为 rejected 构造偏好数据，最小化标准 DPO 损失（$\beta=0.1$）；
- 训练后 $J_\phi$ 直接输出每步动作的语义质量分 $\hat{r}_t\in\mathbb{R}$。

### (4) 过程对齐策略优化（PA-DAPO）
- **动作平衡轨迹奖励**：对每个动作类别 $c$，计算类内均值 $r_c(\tau)$，用 rubric 边界 $[r_c^{lo},r_c^{hi}]$ 归一化到 $[0,1]$，再对出现过的动作类别取平均：
  $$R_{AiO}(\tau)=\frac{1}{|\mathcal{A}(\tau)|}\sum_{c\in\mathcal{A}(\tau)}g_c(r_c(\tau))$$
  这样可避免高频的 search/add 主导低频但关键的 stop；
- **PA-DAPO**：在 DAPO 基础上把损失层级从 (group, token) 扩展为 **(group, action, token)**；组内相对优势 $\hat{A}_j=(R_j-\mu)/\sigma$（仅保留 $\sigma>0$ 的有奖励差异的查询），采用裁剪代理目标 $\Gamma_{j,k,t}=\min(\rho_{j,k,t}\hat{A}_j,\ \text{clip}(\rho_{j,k,t},1-\epsilon_{low},1+\epsilon_{high})\hat{A}_j)$，按动作步 token 数归一化后聚合。
