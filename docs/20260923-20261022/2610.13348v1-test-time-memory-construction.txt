## ABSTRACT 

Large Language Models (LLMs) struggle to answer questions over long interac-tion histories, where relevant evidence may be scattered across distant sessions. Existing memory systems typically construct and maintain sophisticated mem-ory representations offline, before user queries are observed, incurring substantial overhead and limiting their ability to adapt memory construction to query-specific information needs. In this paper, we propose T 2Mem, a Test-Time Mem ory con-struction framework that defers memory construction to inference and progres-sively builds memory along the reasoning process. Specifically, T 2Mem extracts lightweight episode-level metadata offline to capture key events and temporal as-sociations as retrieval cues, while retaining links to the original interactions to fa-cilitate the reconstruction of dependencies across episodes. At test time, the LLM adaptively retrieves and organizes metadata and raw interactions, progressively constructing query-specific memory as reasoning unfolds. Experiments on Lo-CoMo and LongMemEval show the effectiveness of T 2Mem by consistently out-performing strong baselines across different backbone LLMs while substantially reducing the overhead of memory construction. Further analysis demonstrates that deferring memory construction to inference enables the memory construction process to dynamically adapt to the information needs of individual queries. All code is available at https://github.com/OpenBMB/T2Mem .

## 1 INTRODUCTION 

Large Language Models (LLMs) have demonstrated strong emergent capabilities across a wide range of tasks (Yao et al., 2023; Li et al., 2025; Xin et al., 2026b; Liu et al., 2026). However, as user interactions grow longer, LLMs still struggle to reason over extended interaction histories due to limited context windows and the difficulty of effectively locating relevant information within long contexts (Hu et al., 2025; Liu et al., 2024; Hsieh et al., 2024). A straightforward solution is Retrieval-Augmented Generation (RAG), which segments historical interactions into chunks and re-trieves relevant ones at inference time (Lewis et al., 2020; Edge et al., 2024; Li et al., 2025; 2026b). However, chunk-level retrieval often treats historical interactions as isolated units, potentially dis-rupting temporal context and cross-turn dependencies among related interactions. This fragmenta-tion makes it difficult for LLMs to fully exploit the interconnected information embedded in long interaction histories (Xin et al., 2026a; Zhang et al., 2025). To address this limitation, recent memory systems (Chhikara et al., 2025; Kang et al., 2025; Fang et al., 2026) organize long interaction histories into manageable memory units. These methods intro-duce dedicated mechanisms to filter, summarize, and consolidate historical interactions into persis-tent memory representations, enabling efficient access in future interactions. However, constructing and maintaining such sophisticated memory representations can incur substantial overhead. In par-ticular, offline memory construction must anticipate diverse future queries and preserve sufficiently comprehensive information in each memory unit, resulting in considerable preprocessing and main-tenance costs that can hinder the scalability and practical deployment of memory systems (Peng

Recent efforts have therefore explored deferring memory construction to test time, reducing the reliance on costly preconstructed memory representations (Yu et al., 2026; Yin & Tang, 2026). Nevertheless, these approaches typically construct memory from an initially retrieved candi-date set, making it difficult to acquire additional evidence that is not retrieved initially but becomes necessary as the memory construction process unfolds. Recent advances in test-time scaling have demonstrated the potential of leveraging additional inference-time computation to elicit stronger reasoning capabilities from LLMs. By allocating more computation at inference time, LLMs can iteratively explore, verify, and revise intermediate solu-tions (Snell et al., 2025; OpenAI et al., 2024; Guo et al., 2025). This raises a natural question: Can memory construction similarly benefit from inference-time reasoning, allowing an LLM to dynami-cally determine what historical information to activate and organize as it reasons? We answer this question by treating memory not as a fixed representation constructed offline, but as an evolving state that is progressively constructed during inference. Based on this perspective, we propose T 2Mem, a Test-Time Mem ory construction framework that dynamically constructs memory during inference. T 2Mem draws inspiration from associative recall, where relevant memories can be progressively activated as retrieval cues emerge (Teyler & Rudy, 2007; Horner et al., 2015). Instead of constructing sophisticated memory representations offline, T2Mem first extracts lightweight episode-level metadata that captures salient events and temporal associations, while retaining backlinks to the corresponding raw interactions. The metadata provides a compact structure for associating related episodes and locating their underlying evidence. During inference, the LLM progressively reasons over the query and uses this evolving reasoning process to navigate the metadata and selectively activate corresponding raw interactions. In this way, mem-ory construction and reasoning are interleaved: each newly activated piece of evidence can inform subsequent reasoning and, in turn, guide the construction of a more relevant memory state. The final memory is therefore not predetermined before inference, but emerges progressively from the interaction between reasoning and memory activation. In our experiments, we evaluate T 2Mem on LoCoMo and LongMemEval with two backbone LLMs. Across both benchmarks, T 2Mem consistently outperforms strong memory and retrieval baselines under comparable total token budgets, demonstrating the effectiveness of dynamically construct-ing memory at test time. Further analysis reveals that deferring memory construction to inference allows T 2Mem to adapt the construction process to the specific information needs of each query. This advantage is particularly evident for queries that require deeper memory construction, such as multi-hop and temporal questions, where relevant evidence is distributed across multiple episodes and cannot be fully identified through a single initial retrieval step. Moreover, by leveraging episode-level metadata, T 2Mem enables the LLM to establish dependencies across episodes and trace these dependencies back to relevant source interactions during reasoning, facilitating more effective mem-ory construction without the substantial overhead of maintaining sophisticated memory units. 

## 2 RELATED WORK 

Large Language Models (LLMs) struggle to reason over long-horizon interaction histories due to limited context windows (Liu et al., 2024; Hsieh et al., 2024). Retrieval-Augmented Generation (RAG) methods address this limitation by segmenting interaction histories into chunks and retriev-ing query-relevant ones as context for answering user queries (Lewis et al., 2020; Edge et al., 2024). However, such chunk-based retrieval often breaks the contextual and temporal dependencies inher-ent in interaction histories (Xin et al., 2026a). Recent memory systems therefore introduce dedicated memory management mechanisms to organize, retain, and update historical interactions. For exam-ple, MemGPT (Packer et al., 2023) and MemoryOS (Kang et al., 2025) are inspired by operating systems and maintain memory states by continuously incorporating relevant information into ex-isting memory units. MemoryBank (Zhong et al., 2024) draws inspiration from human memory and incorporates the Ebbinghaus forgetting curve to regulate the retention and updating of mem-ory units. Despite their effectiveness, these approaches primarily focus on memory maintenance, while the structure and representation of memory units, which can directly affect how effectively memories are retained, updated, and accessed, remain less explored. To construct more effective memory representations, existing methods typically segment, compress, and consolidate interaction histories using different strategies. Specifically, HiMem (Zhang et al., 2Arxiv Preprint 2026) segments interaction histories along event boundaries to form coherent episodic memories, while LightMem (Fang et al., 2026) compresses and consolidates interactions by topic to preserve salient information. Subsequent approaches further organize these compact memories into higher-level semantic (Hu et al., 2026b) or temporal (Li et al., 2026a) structures, allowing evidence dis-tributed across interactions to be accessed at different levels of abstraction. To further enhance the traceability of memory representations, AnchorMem (Shen et al., 2026) links memory units to their original interactions, allowing fine-grained source information to be retrieved when needed. However, these approaches often incur substantial overhead in constructing and maintaining so-phisticated memory representations, which can hinder the practical deployment and scalability of memory systems (Peng et al., 2026). To alleviate the reliance of memory effectiveness on predefined memory representations, recent work has shifted toward query-time memory construction (Yu et al., 2026; Yin & Tang, 2026). These methods typically retrieve a broad set of query-relevant facts and reorganize them into mem-ory. While this paradigm enables more comprehensive memory construction, its retrieval process remains largely rigid and one-shot, focusing on retrieving more relevant information rather than actively identifying what information is actually needed to construct an effective memory. Such a passive retrieval process may therefore fail to acquire missing evidence that only becomes apparent from the partially constructed memory (Yao et al., 2023; Li et al., 2025). To enable LLMs to ac-tively acquire information according to their evolving needs, T 2Mem treats memory construction as a dynamic reasoning process at test time. Inspired by the test-time scaling of LLMs (OpenAI et al., 2024; Guo et al., 2025; Snell et al., 2025), T 2Mem allows the evolving memory state to actively de-termine what evidence should be retrieved and integrated next. This closed-loop process enables the model to seek information genuinely needed for memory construction, better distinguish between potentially conflicting or ambiguous facts, and progressively refine memory as reasoning unfolds. 

## 3 METHODOLOGY 

In this section, we introduce T 2Mem, a test-time memory construction framework for long-term conversational question answering. Unlike conventional approaches that construct a query-agnostic memory before inference, T 2Mem dynamically constructs memory at test time by progressively uncovering and organizing relevant information from the raw interaction history. We first revisit existing memory systems and show how T 2Mem decouples memory construction from the offline preprocessing stage, enabling memory to be constructed dynamically during inference (Sec. 3.1). We then present the architecture of T 2Mem, which leverages the reasoning capabilities of LLMs to progressively incorporate relevant information to construct tailored memory (Sec. 3.2). 3.1 DISENTANGLING MEMORY ORCHESTRATION FROM OFFLINE TO TEST TIME 

Given a long-term interaction history S = {s1, s 2, . . . , s n}, a memory system organizes informa-tion scattered across interaction sessions into manageable memory units M = {m1, m 2, . . . , m N }.These memory units focus on preserving factual knowledge, user preferences, and cross-session dependencies by resolving conflicts in the interactions and incorporating potentially useful infor-mation. Existing memory systems typically construct such memory representations offline, before future queries are presented to the LLM. In contrast, T 2Mem defers memory orchestration to test time, using the given query to incorporate acquired information into the reasoning trajectory, thereby organizing relevant knowledge dynamically during inference.

As illustrated in Figure 1, we detail how T 2Mem dynamically constructs query-specific memory at test time (Eq. 4) by progressively acquiring, distilling, and organizing relevant information during reasoning. At each step, the LLM reasons over the accumulated memory and the current observation, distills query-relevant information into the evolving memory state, and determines what additional information is needed. Based on this information need, it either terminates the process or selects an appropriate tool from T to access episode-level metadata or fine-grained raw information, thereby supporting subsequent memory construction. We first formulate this process as an iterative reasoning trajectory τ consisting of T memory con-struction steps: 

τ =  (r1, m 1, a 1), (r2, m 2, a 2), . . . , (rT , m T , a T ), (5) where rt, mt, and at denote the reasoning trace, newly constructed memory cache, and selected ac-tion at step t, respectively. The accumulated memory caches Mt generated throughout the trajectory are progressively concatenated to form the final query-specific memory MT :

MT = m1 ⊕ m2 ⊕ · · · ⊕ mT , (6) where ⊕ denotes the concatenation operation. The LLM then generates the final answer conditioned on the user query q and the resulting memory MT :

y = LLM( q, MT ). (7) 

Dynamic Memory Construction. We next describe how each step produces (rt, m t, a t) and up-dates the memory state. At step t, the LLM takes the query q, the accumulated memory Mt−1, the latest observation ot−1, and the available tool set T as input, and jointly produces a reasoning trace 

rt, a newly constructed memory cache mt, and the next action at:

(rt, m t, a t) = LLM( q, Mt−1, o t−1, T ), (8) where the memory is initialized as M0 = ∅. The initial observation is obtained by retrieving the top-k metadata entries in I most relevant to q:

o0 = Top- k(q, I), (9) where Top- k selects the k metadata entries in I that are most relevant to the query q. The reasoning trace rt guides the LLM in distilling query-relevant evidence from ot−1 into the newly constructed memory cache mt. The memory is then updated by appending mt to the accumulated memory: 

Mt = Mt−1 ⊕ mt, (10) thereby completing the memory update at step t. The process terminates when the current memory state satisfies the information need of the given query or when the maximum number of construction steps Tmax is reached. Let T ≤ Tmax denote the actual number of executed steps. Finally, the accumulated memory MT is used to help the LLM generate the final answer according to Eq. 7.

## 4 EXPERIMENTAL METHODOLOGY 

In this section, we describe the experimental setup for evaluating T 2Mem. We first introduce the datasets, baselines, and evaluation metrics, and then present the implementation details. 

Datasets. We evaluate T 2Mem on two widely adopted benchmarks for long-term memory, Lo-CoMo (Maharana et al., 2024) and LongMemEval (Wu et al., 2025). These benchmarks assess the ability of memory systems to retain, retrieve, and utilize information from long-term interaction histories. Further details are provided in Appendix A.2. 

Baselines. We compare T 2Mem with several representative baselines spanning three categories: retrieval-based methods, memory systems that construct structured memory representations offline, and recent test-time approaches that defer memory construction to inference. For retrieval-based methods, we evaluate Naive RAG (Lewis et al., 2020) and Search-o1 (Li et al., 2025), which directly retrieve relevant dialogue segments to support LLM-based answering. We then compare T 2Mem with representative memory systems. MemoryOS (Kang et al., 2025) draws inspiration from operating systems and continuously incorporates relevant information into existing memory units. LightMem (Fang et al., 2026) and HiMem (Zhang et al., 2026) construct compact memory units through topic-based consolidation and event-level organization, respectively. Ever-MemOS (Hu et al., 2026a) and xMemory (Hu et al., 2026b) further organize memory into higher-level semantic structures to facilitate subsequent retrieval. AnchorMem (Shen et al., 2026) preserves links between memory units and their source interactions, enabling the recovery of fine-grained de-tails when needed. Finally, we adopt LazyMem (Yu et al., 2026) as a test-time baseline, which follows a retrieve-then-construct paradigm to build memory from a broad set of retrieved candidates during inference. 

Evaluation Metrics. Following prior work (Fang et al., 2026; Xin et al., 2026a), we use accuracy as the primary evaluation metric and employ an LLM-based judge to determine whether each response is consistent with the ground-truth answer (Zheng et al., 2023). For a fair comparison, all methods are evaluated using Qwen3.5-Plus (Qwen Team, 2026) as the judge model. This subsection conducts ablation studies on LoCoMo to examine the contributions of different components in T 2Mem. Additional results on LongMemEval are reported in Appendix A.4. Specifically, we first examine the effectiveness of the lightweight episode-level metadata proposed in Sec. 3.1 by comparing it with two alternative representations. T 2Mem (Summary) replaces the metadata for each session with a concise summary (Tan et al., 2025), while T 2Mem (Graph) rep-resents the relations among entities and events within each session using a graph structure (Wu et al., 2026). We further investigate the roles of metadata and raw interactions during memory con-struction. T2Mem (w/o Metadata) directly performs dynamic memory construction over the raw interaction sessions without using metadata, whereas T 2Mem (w/o Rawdata) relies solely on the metadata. As shown in Table 3, T2Mem consistently outperforms both T 2Mem (Summary) and T 2Mem (Graph), demonstrating the effectiveness of its semi-structured metadata. This advantage can be attributed to the complemen-tary structural and semantic cues, such as timestamps, event information, and topics, which help LLMs capture dependencies among events during reasoning and identify relevant sessions for mem-ory construction. Furthermore, the performance degradation in T 2Mem (w/o Metadata) and T 2Mem (w/o Rawdata) highlights the complementary roles of these two knowledge sources. The metadata provides cues for locating relevant interactions, while the raw sessions preserve fine-grained events for recovering detailed evidence. Removing the rollout memory construction process reduces token consumption, but leads to a clear performance degradation in T 2Mem (w/o Rollout Construction). In this subsection, we analyze T 2Mem in terms of memory quality, token allocation, and test-time scaling, as illustrated in Figure 2. All experiments are conducted using Qwen3.5-27B on the Lo-CoMo dataset. Additional experimental details are provided in Appendix A.3. 

Quality of Constructed Memory. As shown in Figure 2a, we evaluate the quality of the memory constructed by T 2Mem, LightMem, and Search-o1 along five dimensions, with the evaluation crite-ria detailed in Appendix A.8. Specifically, Temporal Accuracy and Entity Coverage assess the ability to capture temporal dependencies and entity associations across interactions. Content Completeness 

and Factual Correctness measure whether the constructed memory contains sufficient information to answer the query and remains consistent with the ground-truth answer, respectively. Finally, De-tail Preservation evaluates how well the memory retains specific quantities and other details. Across all five dimensions, T 2Mem achieves the highest scores, indicating that it constructs more complete and reliable memory. This advantage can be attributed to its ability to progressively capture episode dependencies, thereby helping retrieve more accurate evidence to facilitate the LLM in answer-ing the query. In particular, the improvement in Detail Preservation suggests that T 2Mem retains finer-grained evidence beyond the core information needed to answer the query. This benefit stems from its iterative construction process, which allows the model to read additional metadata or access linked source sessions when the accumulated memory is insufficient to support construction. The higher Factual Correctness further demonstrates that T 2Mem can effectively incorporate supporting evidence, leading to better consistency with the ground-truth answers. 

Association between Token Consumption and QA Accuracy. As shown in Figure 2b, T 2Mem achieves the highest QA accuracy while consuming a comparable number of tokens to the three offline memory construction systems. This efficiency stems from a different computation allo-cation strategy: rather than constructing comprehensive memories offline, T 2Mem extracts only lightweight metadata in advance and shifts the remaining computation to test time, allowing mem-ory construction to adapt to the information needs of each query. To further investigate this property and its scaling behavior, we vary the token budget available to T 2Mem and compare it with Naive RAG and Search-o1. As shown in Figure 2c, T 2Mem consistently improves with additional test-time computation, whereas Search-o1 exhibits a weaker scaling trend and Naive RAG shows no consistent benefit, with its performance even declining as the token budget increases. These results indicate that effective test-time scaling depends not merely on increasing the computation budget, but on effectively translating additional computation into useful evidence for memory evolution. 

## 6 CONCLUSION 

This paper presents T 2Mem, a test-time memory construction framework for long-term conversa-tional question answering. T 2Mem extracts lightweight episode-level metadata offline as retrieval cues while retaining links to the original interactions, and adaptively retrieves and organizes meta-data and raw interactions at test time to progressively construct query-specific memory. Experiments 9Arxiv Preprint on LoCoMo and LongMemEval show that T 2Mem consistently outperforms strong baselines across two backbone LLMs while substantially reducing memory construction overhead. Further analy-sis demonstrates that deferring memory construction to inference enables the memory construction process to dynamically adapt to the information needs of individual queries. We conduct two analyses on LoCoMo to examine the effect of memory construction steps. We first vary the maximum construction budget Tmax to evaluate its effect on answer accuracy. We then examine the actual number of steps T and compare T 2Mem with Search-o1 across observed stopping steps. For T 2Mem, each construction step generates (rt, m t, a t) and appends the new memory cache mt to the accumulated memory. 

Effect of Construction Steps on Answer Performance. As shown in Figure 3, the answer accu-racy generally improves as the maximum number of construction steps increases, indicating that additional test-time computation benefits memory construction. Specifically, Single-Hop questions show clear gains when the number of steps increases from one to three, followed by a clear plateau, as their required evidence can often be recovered within relatively shallow construction. Temporal and Open-Domain questions exhibit a different trend, with performance continuing to improve as the construction depth increases to seven steps. These questions typically require resolving tempo-ral relations or recovering evidence distributed across interaction sessions, leaving more room for additional construction steps to contribute. Beyond this depth, the gains become less pronounced, reflecting diminishing returns from further extending the construction process. 

Performance Gains of T 2Mem over Search-o1 at Different Construction Steps. Figure 4 further compares T 2Mem and Search-o1 according to the number of construction steps taken before an-swering. At the first step, the performance gap remains relatively small, particularly for Single-Hop questions, where the initially retrieved evidence is often sufficient to answer. However, as the process extends to two and three steps, T 2Mem achieves substantially larger gains across all types of ques-tions. A.6 CASE STUDIES 

In Figure 5, we present a qualitative case study to illustrate how T 2Mem performs iterative memory construction to resolve temporal ambiguity across interaction sessions. The example involves a long-horizon conversational query where relevant evidence is scattered over multiple interaction sessions. The initial observation o0 contains episode-level metadata entries that mention a planned camping trip in June and a later report of camping. These entries do not establish when the June trip actually occurred. T 2Mem therefore performs additional metadata retrieval and source-session recovery to seek more specific temporal evidence. A subsequently retrieved entry from the June 27 session states that Melanie went camping in the mountains during the preceding week. The model distills this temporal information into a memory cache and appends it to the ac-cumulated memory. The resulting MT supports the final answer, illustrating how iterative memory construction incorporates answer-relevant information that is missing from the initial observation.
