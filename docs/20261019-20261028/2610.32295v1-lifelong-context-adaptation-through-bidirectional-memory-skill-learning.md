## 摘要
终身LLM智能体必须从不断扩展的交互历史中学习，同时在有限的上下文窗口内做出每个决策。记忆使过去经验可供利用，但智能体可能仍需要从检索到的记录中推断如何解决每个新任务。技能提供了可复用的流程，但可能遗漏应用它们所需的任务特定事实。由于检索到的记忆和技能会塑造智能体的行为，它们也会影响可供未来学习使用的经验。我们提出MemCryst，一个在冻结语言模型下通过记忆与技能的双向学习实现终身上下文适应的框架。存储在记忆中的重复出现的片段支持技能的创建与修订，而这些技能所引导的交互又为后续学习提供新的记忆。从记忆中检索到的事实与已学习的技能共同构成智能体的上下文，而任务结果会调整实际被提供的记录在未来的检索影响力，且不重写其内容。在涵盖具身控制、长文档阅读、对话、数学和代码的十个设置中，MemCryst在七项报告的比较中领先。在ALFWorld上，联合提供达到63.17%的成功率，而仅提供记忆和仅提供技能分别为59.83%和50.50%。代码可在https://github.com/tianyi0216/Memcryst.git获取。

## Abstract
Lifelong LLM agents must learn from an expanding history of interactions while making each decision within a bounded context window. Memory makes past experience available, but the agent may still need to infer how to solve each new task from the retrieved records. Skills provide reusable procedures, yet may omit the task-specific facts needed to apply them. Because retrieved memory and skills shape the agent's behavior, they also influence the experience available for future learning. We introduce MemCryst, a framework for lifelong context adaptation through bidirectional learning of memory and skills with a frozen language model. Recurring episodes stored in memory support skill creation and revision, and the interactions guided by those skills supply new memory for subsequent learning. Facts retrieved from memory and learned skills jointly form the agent's context, while task outcomes adjust the future retrieval influence of the records actually served without rewriting their content. Across ten settings spanning embodied control, long-document reading, conversation, mathematics, and code, MemCryst leads seven reported comparisons. On ALFWorld, joint serving achieves 63.17% success, compared with 59.83% for memory-only and 50.50% for skill-only serving. Code is available at https://github.com/tianyi0216/Memcryst.git

## 一、核心问题与整体含义

- **研究背景**：长期部署的 LLM 智能体需要从不断增长的交互历史中学习，但每次决策只能使用有限上下文窗口；模型参数保持冻结时，经验只能通过“外部上下文”影响行为。
- **核心矛盾**：
  - **记忆**能保存过往事实与片段，但智能体仍需从检索记录中重新推断“怎么做”。
  - **技能**能提供可复用流程，但往往缺少应用所需的任务特定事实与约束。
  - 记忆与技能还会反过来塑造智能体行为，从而影响未来可获得的新经验。
- **论文主张**：终身适应不仅是“存更多记忆”或“学更多技能”，而是要在有限上下文内协同学习**记忆内容**与**技能程序**，并将“记录内容”与“记录在检索中的使用影响力”分开更新。
- **整体含义**：MemCryst 试图在冻结语言模型条件下，通过外部状态的双向学习，把累积经验转化为更有用的上下文，而不是更新模型参数。

## 二、方法论

### 1. 核心思想

- 维护三类外部状态：
  - **情景记忆**：保存任务证据、结果诊断与可复用教训。
  - **类型化事实**：保存实体、声明、来源、重复支持等。
  - **技能目录**：保存适用条件、参数化流程及支持 episodes。
- 形成双向闭环：
  - **记忆 → 技能**：重复出现的 episodes 在睡眠边界被聚类、合成、审计为技能，并可继续修订。
  - **技能 → 记忆**：技能引导智能体行为，产生新的交互轨迹，再写回记忆，供后续技能修订。
- 同时分离两条更新路径：
  - **内容更新**：写入 episode、合并事实、创建/修订技能。
  - **使用更新**：根据任务结果调整已实际进入上下文的 facts/skills 的检索影响力，但不重写其文本。

### 2. 关键流程与公式

- **有效策略**：冻结模型 \(\pi_{\theta_0}\) 通过构造上下文 \(I_t=I(q_t;\Xi_t)\) 形成
  \[
  \pi_t^{\text{eff}}(\tau|q)=\pi_{\theta_0}(\tau|q,I(q;\Xi_t)).
  \]
- **外部状态**：
  \[
  \Theta_t=E_t\uplus F_t\uplus S_t,\quad \Xi_t=(\Theta_t,\rho_t),
  \]
  其中 \(E,F,S\) 分别为 episode、fact、skill 存储，\(\rho\) 为检索与结果统计。
- **检索与暴露**：
  - 检索器 \(R\) 按 scope、适用性、相关性和统计量排序并组装上下文。
  - 只有实际进入 actor 上下文的记录才记为 exposed，未进入上下文的 episodes 仍可用于后续技能学习。
- **更新顺序**：
  \[
  \Xi_t^{\text{ret}}=B(\Xi_t,o_t,\hat U_t),\quad
  \Xi_{t+1}=G(\Xi_t^{\text{ret}},\tau_t,o_t).
  \]
  - \(B\)：结果回报，只更新被服务记录的检索统计。
  - \(G\)：内容更新，包括记忆写入与睡眠边界的技能整合。
  - **先回报、后写入**，避免当前结果立即回报给当前新写入记录。

### 3. 记忆到技能

- 在睡眠边界对 episode 嵌入做 HDBSCAN 聚类，过滤噪声、按家族拆分，并用结果质量、簇大小、稳定性排序，最多处理 10 个候选簇。
- 每个候选簇选取高权重 episode，由冻结 LM 合成参数化技能；实例值转为参数槽，适用条件限定使用场景。
- 独立上下文中的审计器执行 13 项检查，至少 10 项 PASS 才允许进入目录。
- 若能力键匹配已有技能，则合并新旧支持 episodes 并合成修订；修订保留技能身份和累计 utility，经第二次审计后替换文本。
- 接受的技能会归档其来源簇，减少普通唤醒检索中的重复暴露，但仍保留用于溯源和后续睡眠挖掘。

### 4. 技能到新记忆

- 技能、检索事实和当前观察共同条件化 actor 行为。
- 任务完成后写入 episode，包含证据、诊断与教训；同时抽取允许的类型化事实。
- 事实合并按同实体、同 scope 且余弦相似度超过阈值 \(\eta=0.86\) 进行；匹配事实增加重复支持与来源，不改变原文和暴露统计。

### 5. 结果回报

- **事实**：记录暴露次数 \(n_f\) 与成功次数 \(h_f\)，使用平滑成功率
  \[
  C_f=\frac{h_f+1}{n_f+2}.
  \]
  仅被服务事实更新计数。
- **技能**：使用指数移动更新
  \[
  U_s\leftarrow U_s+\alpha_S x_s(y_t-U_s),
  \]
  论文实现中 \(\alpha_S=0.2\)。
- 事实步长随暴露增加而减小，技能固定步长更强调近期使用；二者均限制在 \([0,1]\)。
- 这些统计只表示“在暴露条件下的任务成功关联”，**不等同于事实真实性或单个记录的因果贡献**。

## 六、主要结论与发现

- MemCryst 在十个设置中**七项领先**，总体 52.26%，高于最强基线 SimpleMem 的 39.92%。
- ALFWorld 联合服务成功率 **63.17%**，高于 memory-only 的 59.83% 和 skill-only 的 50.50%。
- 允许技能修订比冻结技能文本提高 **1.17 pp**；双回报通道相对全关闭提高 **3.50 pp**。
- fact return 与 skill return 存在正交互，观测交互为 **+5.33 pp**，说明二者应协同调整。
- 五领域交错流中，一个共享、按领域限定 scope 的外部状态将平均分从 **28.30%** 提升到 **44.50%**，覆盖 1,018 个评分查询。
- 跨骨干均有效：Qwen3-1.7B、Qwen3-8B、GPT-4o-mini 上 ALFWorld 分别提升 14.17、11.67、11.67 pp。
- 冻结状态控制中，相关选择成功率 75%，随机选择 58%；技能上下文比 episode replacement 使用更少注入 token，但并未证明准确率优于 episode 上下文。
- 收益在对话记忆中最强，在数学和代码中较小；MBPP 上甚至低于 ReAct，说明方法并非普遍占优。
- 技能目录在覆盖任务家族后仍持续修订：600 任务流中 154 次接受修订、5 次新建，最终技能被服务 496 次、成功 338 次。

## 七、优点

- **问题拆解清晰**：将“记忆内容”和“检索使用影响力”分离，避免用任务失败直接改写事实文本。
- **双向闭环设计完整**：episode 支持技能创建与修订，技能引导行为再产生新记忆，形成可持续演化的外部状态。
- **冻结模型下的实用路径**：不训练参数，仅通过外部上下文适应，适合长期部署和低成本迭代。
- **技能表示紧凑**：参数化流程加独立事实检索，兼顾可复用程序与任务特定证据。
- **审计与溯源机制**：技能提案经独立审计，保留 episode ancestry 与 provenance，便于检查和修订。
- **实验覆盖面广**：跨具身、阅读、对话、数学、代码，并包含消融、交互因子、冻结状态控制和效率分析。
- **效率分析有价值**：ALFWorld 中成功率提升的同时 actor 调用减少约 15.22%；技能上下文显著减少注入 token。

## 八、不足与局限

- **结果回报粒度粗**：同一任务结果被分配给所有被服务 facts/skills，无法识别单个记录的因果贡献，也不验证事实真实性。
- **依赖成功信号**：需要可观测的 evaluator 成功信号；对错误反馈、噪声反馈的鲁棒性未测试。
- **技能审计非形式化保证**：LM 审计可筛选提案，但不能保证程序正确或适用。
- **跨领域迁移未建立**：交错实验使用 domain-scoped retrieval，不能证明技能可迁移到未见领域。
- **实验统计有限**：多数主结果单次运行，缺少多种子均值与置信区间；部分比较条件不完全一致。
- **领域表现不均衡**：数学与代码收益有限，MBPP 低于 ReAct；对话和具身控制收益更明显。
- **应用风险**：持久记录可能保留敏感或错误信息，重复检索可能放大偏差；结果回报奖励任务成功，不应被解释为事实正确或行为正当。
- **部署限制**：真实用户数据场景需要分用户/领域隔离、访问控制、保留与删除机制、人工复核等，论文未验证这些安全措施。
