Abstract —Long egocentric videos pose a central challenge for multimodal language models: the visual stream must be compressed into a memory representation that can be searched efficiently while still preserving the evidence needed for question answering. Building on an online textual-memory framework in which first-person videos are converted into temporally grounded captions, this work systematically studies the role of retrieval in episodic-memory video question answering. We evaluate how different retrieval units, query formulations, context budgets, and reranking strategies affect multiple-choice answering on QAEgo4D-Closed, isolating retrieval as the main variable while keeping the underlying generated memory fixed. Our best config-uration, P ARENT , matches fine-grained caption subchunks, then provides their full parent captions to the reasoner. It achieves 56.4% accuracy, matching strong full-memory and retrieval baselines while exposing only a small fraction of the textual memory at question time. More importantly, our analysis shows that better temporal coverage does not necessarily translate into better answers: increasing the retrieval budget improves temporal Hit@K and Recall@K, but can reduce accuracy by introducing visually plausible distractors and uncertain caption evidence. These findings suggest that retrieval-augmented egocentric mem-ory should not be optimized only for evidence recall, but also for the reliability, specificity, and answer-discriminative value of the retrieved context. The study motivates more structured episodic memories that move beyond raw caption retrieval toward evidence-aware representations for long-form egocentric reasoning. 

Index Terms —Egocentric Vision, Retrieval-Augmented Gener-ation, Episodic Memory, Video Question Answering. 

I. I NTRODUCTION 

Egocentric video question answering requires a model to reason over what a camera wearer saw, did, handled, and encountered across long first-person video streams. This set-ting is closely related to artificial episodic memory, where an agent should recall past events and use them to answer later queries [1]–[3]. It is also central to wearable assistants, lifelogging, and embodied perception, where questions may refer to objects, locations, actions, and state changes observed long before the question is asked [4]–[6]. However, ego-centric video exposes a fundamental scalability problem. A single recording may contain many visually similar moments, repeated objects, partial views, camera motion, occlusions, and small state changes. Directly processing the video at question

Recent work on Online Episodic Memory Video Question Answering (OEM-VQA) addresses this issue by processing the visual stream sequentially and retaining a compact memory that can be queried later, rather than reprocessing the full video for every question [7], [8]. Within this direction, textual-memory approaches convert egocentric clips into language descriptions, yielding memories that are compact, human-readable, and reusable across multiple queries [4]–[6], [8]. Prior work has shown that such memories can match dedicated state-of-the-art systems on QAEgo4D-Closed while using substantially less memory than approaches that retain visual features or cache large video representations [3], [7], [8]. This makes textual memory an appealing substrate for scalable and inspectable egocentric reasoning. This paper builds on this textual-memory paradigm and studies a narrower but crucial question: once the visual stream has been compressed into textual memory, which parts of that memory should be provided to the reasoner at query time? As illustrated in Fig. 1, our pipeline separates online memory construction from question-time retrieval and reasoning. Video clips are first converted into captions and stored in an online arXiv:2610.31284v1 [cs.CV] 22 Oct 2026 textual memory. When a question arrives, the system retrieves relevant subchunks and expands them to their parent captions, providing the reasoner with compact but contextual evidence. Retrieval-augmented generation (RAG) was introduced to equip large language models with explicit non-parametric memory [9]. In episodic video QA, however, retrieval does more than reduce context length, it changes the evidence distribution seen by the reasoner. A retrieval module must recover the relevant event, preserve enough surrounding con-text to disambiguate the answer options, and avoid introducing visually plausible but incorrect evidence from other moments in the same video. We therefore isolate retrieval as the main object of study. All configurations operate on the same generated textual memory and differ only in how memory entries are indexed, retrieved, transformed, or passed to the reasoner. We compare flat caption retrieval, subchunk retrieval, parent retrieval, hybrid dense–lexical retrieval, and reranking strategies. Our strongest configuration uses P ARENT retrieval: captions are split into fine-grained subchunks for embedding and matching, but the corresponding full parent captions are provided to the reasoner. This strategy reaches 56.4% accuracy on QAEgo4D-Closed, matching strong state-of-the-art baselines while using only 3,600 tokens per query on average. The main finding of our study is that retrieval quality and answer accuracy do not improve monotonically together. Increasing the number of retrieved captions raises temporal Hit@K and Recall@K, but answer accuracy peaks earlier and then declines. In long egocentric videos, additional retrieved context often contains repeated objects, similar locations, uncertain descriptions, or actions that are semantically close to the question but correspond to the wrong moment. As a result, a reasoner may become less reliable even when the retrieved set covers more of the annotated evidence window. This suggests that episodic-memory QA should not optimize retrieval only for temporal coverage, but also for the specificity and answer-discriminative value of the retrieved evidence. Our contributions are threefold:  

> •

We provide a systematic retrieval-centred study for textual-memory OEM-VQA, explicitly building on prior training-free memory construction pipelines and isolating retrieval as the main variable.  

> •

We compare multiple retrieval units, context budgets, and ranking strategies on QAEgo4D-Closed, showing that PARENT retrieval provides the best trade-off between fine-grained matching and contextual reasoning.  

> •

We analyze the mismatch between temporal retrieval metrics and final answer accuracy, showing that higher evidence coverage can introduce hard distractors and reduce the reliability of the final reasoner. II. R ELATED WORK 

A. Egocentric Video Question Answering 

Episodic memory in egocentric vision concerns the ability to answer questions about past first-person observations, such as where an object was placed, which action was performed, or what happened before or after a given event [1]–[3]. Ego4D formalized this problem through the Natural Language Queries (NLQ) benchmark, where models must localize the temporal segment containing the evidence needed to answer a natural-language query [2]. Early work on episodic-memory QA further studied open-ended question answering over egocentric videos [10], while Ground VQA introduced grounded question answering in long egocentric videos and the QAEgo4D-Closed multiple-choice setting [3]. This formulation reduces the ambi-guity of free-form answer evaluation, but still requires models to identify the relevant moment and distinguish the correct answer from plausible distractors. Recent work has increasingly focused on long-horizon and memory-based egocentric understanding [5]–[8], [11]. MM-Ego studies egocentric multimodal LLMs for video QA and highlights the difficulty of preserving visual details over long first-person videos [11]. Streaming video-language models such as VideoLLM-online address online video understand-ing by processing video streams incrementally rather than assuming that the full video can be reprocessed at query time [7]. Complementary textual-memory approaches decou-ple perception and reasoning by converting observed clips into language descriptions and answering later questions over the accumulated memory [4]–[6], [8]. Our work builds on this textual-memory paradigm, but focuses specifically on retrieval: given an existing temporally grounded textual memory, we study which evidence should be selected and provided to the reasoner at query time. 

B. Video Retrieval-Augmented Generation 

Retrieval-augmented generation was introduced as a way to combine parametric language models with explicit non-parametric memory [9]. In video understanding, this idea becomes more challenging because retrieval must also han-dle temporal grounding and modality compression. DrVideo converts long videos into document-like representations and retrieves relevant textual evidence to support long-video under-standing [12]. Video-RAG similarly uses retrieval-augmented mechanisms to improve long-video comprehension by select-ing auxiliary visual-textual evidence before generation [13]– [15]. Our work is complementary to these video RAG systems. Rather than training or designing a new video model, we iso-late retrieval within an online textual-memory pipeline whose captions have already been generated from the egocentric stream. This allows us to study how retrieval units, query formulation, context budget, and memory format affect down-stream multiple-choice answering. In this setting, retrieval is not only a way to reduce context length, it determines the evidence distribution seen by the reasoner and can therefore improve or degrade answer selection depending on the rele-vance and reliability of the retrieved captions.

However, the structure of the memory determines what can be recovered at query time. Long-context memory systems have shown that retrieval can benefit from organizing information beyond independent chunks, for instance through hippocampal-inspired memory and graph-based associations [16], [17]. This issue is especially important in egocentric video, where many questions are not answered by object presence alone, but by temporal and relational context: where an object appeared, when it was manipulated, what action preceded it, or how it related to other objects and locations [3], [18], [19]. For this reason, we analyze how retrieval over caption-based memories succeeds or fails when questions require temporally grounded object, action, and location evidence. Our results suggest that useful memory should preserve entities together with temporal anchors, actions, and locations [18], [20], but also keep the retrieved textual context compact. This indicates that caption-based episodic memories should optimize not only for evidence recall, but also for token efficiency, context specificity, and answer-discriminative value. III. M ETHOD 

Our retrieval-augmented formulation builds on the online textual-memory pipeline introduced in [8], where egocentric video clips are processed incrementally into a compact textual memory and later queried by a language-model reasoner. We extend this formulation by indexing the generated captions and retrieving a query-specific subset of memory entries before answering multiple-choice questions. The overall pipeline is shown in Fig. 2. It is organized into three main stages: an Online Memory Constructor , a Memory Manager , and a QA Handler . Given an incoming video stream, clips are processed incrementally. For each new clip, a multimodal descriptor model produces a natural-language caption. The caption is then passed to a chunking module, which de-composes it into smaller textual chunks, and each chunk is embedded by a text embedding model (Fig. 2(a)). Each chunk is stored with its temporal metadata and embedding in a vector database (Fig. 2(b)). At question-answering time, the input question and the candidate answers are used to form a retrieval query. A context retriever performs similarity search over the vector database and returns a retrieved context. Finally, a language-model reasoner receives the question, the candidate answers, and the retrieved context and predicts the final answer (Fig. 2(c)). This formulation standardizes all memory operations around indexed textual chunks. In contrast to treating a full caption as the only memory unit, our pipeline explicitly separates caption generation, chunk construction, embedding, indexing, retrieval, and reasoning. 

A. Online Memory Constructor 

Let V denote an egocentric video stream. The stream is divided into a sequence of temporally ordered clips 

V = {c1, c 2, . . . , c N }, (1) where each clip ci corresponds to a temporal interval [tsi , t ei ].When a new clip ci becomes available, a multimodal descriptor model D generates a natural-language caption: 

ni = D(ci). (2) The caption ni describes the visual content observed in the temporal interval [tsi , t ei ]. The caption is then passed to a chunking module, which decomposes it into a set of textual chunks: 

{ni, 1, n i, 2, . . . , n i,m i } = Chunking( ni), (3) where ni,j denotes the j-th textual chunk generated from caption ni, and mi is the number of chunks produced for clip ci.The output of the Online Memory Constructor is therefore a temporally grounded set of textual chunks. Each chunk inherits the temporal interval of the clip from which its parent caption was generated. This allows the memory to preserve temporal information while operating at a finer textual granularity. 

B. Memory Manager 

The Memory Manager is responsible for embedding, index-ing, and storing the textual chunks produced by the Online Memory Constructor. After processing the first i clips, the vector database con-tains the set of indexed memory entries

r(q, A) = [ q; a1; . . . ; aL]. (8) The notation [q; a1; . . . ; aL] denotes the textual concatenation of the question and all answer options. H. Evaluation 

We report answer accuracy as the percentage of questions for which the predicted answer matches the ground-truth an-swer. For retrieval diagnostics, we also report temporal Hit@K and Recall@K against the annotated evidence region of each question. Hit@ K measures whether at least one of the top-K

retrieved memory entries overlaps with the annotated evidence region for the question. Recall@ K measures how much of the annotated evidence region is covered by the temporal intervals of the top-K retrieved entries. By construction, Hit@K ≥

Recall@K, since Hit@K only requires a single overlapping entry while Recall@K measures the covered fraction of the evidence window. Together, these diagnostics evaluate the temporal quality of the retrieval module, while answer accuracy measures the performance of the full retrieval-augmented reasoning pipeline. IV. Each video is processed in a streaming setting using non-overlapping clips of 15 seconds. A. Analysis of Retrieval Strategies 

Table I reports the ablation of the proposed RAG config-urations using a fixed retrieval budget of K = 12 retrieved units. The best result is obtained by P ARENT , which reaches 56.4% accuracy, with a Hit@K of 79.0% and a Recall@K of 70.7%. The second-best configuration is F LAT , which achieves a comparable accuracy of 55.6% with slightly higher Hit@K and Recall@K. This suggests that flat retrieval is already competitive when the retrieved captions contain sufficient context, while the parent strategy provides a better balance between precise matching and contextual grounding. Interestingly, S UB -R ERANK obtains the strongest retrieval scores among the tested configurations, with the highest Hit@K and Recall@K. However, this does not translate into the best final accuracy. This gap indicates that retrieving more relevant subchunks is not sufficient by itself, since the reasoner also needs enough surrounding information to correctly interpret the evidence and select the answer. In this sense, retrieval granularity plays a central role. Fine-grained subchunks are useful for locating the relevant moment, but using them alone can fragment the context available to the model. Conversely, parent captions preserve the temporal and semantic context around the matched evidence, leading to more robust answer generation. B. Retrieval Budget and Temporal Coverage 

Figure 4 reports the retrieval budget curve for the best-performing P ARENT configuration. Increasing K steadily im-proves temporal coverage: Hit@K rises from 53.4% to 98.2%, and Recall@K rises from 42.7% to 97.9%. Accuracy, however, follows a different trend. It peaks at 56.4% for K = 12 , then decreases as additional captions are included. This result highlights that temporal recall is useful but not sufficient for answer accuracy. In egocentric video, repeated rooms, objects, screens, tables, and actions create plausible hard negatives. A larger retrieved context can therefore cover more of the annotated evidence while also introducing distrac-tors that make option selection harder for the reasoner.

V. C ONCLUSION 

This study presented a training-free textual-memory pipeline for egocentric video question answering. Our best config-uration, PARENT , retrieves fine-grained caption subchunks and expands them to their parent captions, achieving 56.4% accuracy on QAEgo4D-Closed while using a substantially smaller query-time context than full-memory reasoning. Our analysis shows that temporal retrieval coverage does not necessarily translate into better answer accuracy. As the retrieval budget increases, Hit@K and Recall@K continue to improve, but accuracy peaks at an intermediate budget, since additional captions can introduce plausible distractors in long egocentric videos with repeated objects, locations, and actions. These findings highlight the importance of retrieval design in textual-memory-based egocentric QA. Future work should move beyond treating captions as independent text units and develop evidence-aware episodic memories that preserve temporally grounded events, uncertainty, and answer-relevant support for downstream reasoning.
