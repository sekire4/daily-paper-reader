# Co 2In : a Bi-level Memory Incremental Learning Framework with Knowledge Encoding, Consolidation, and Integration 

## Wenju Sun, Qingyong Li, Boyang Li, Wen Wang, Siyu Zhang, Yi Wei, Yangli-ao Geng 

Abstract —Incremental learning (IL) aims to continually acquire new knowledge ( plasticity ) while retaining previously learned informa-tion ( stability ). However, striking a balance between plasticity and stability remains a significant challenge for intelligent systems. The human brain achieves exceptional balance, owing to various memory units that collaboratively encode and store information. Inspired by human memory mechanisms, this paper introduces an IL framework with knowledge en Co ding, Co nsolidation, and In tegration ( Co 2In ). 

Co 2In is designed as a bi-level memory architecture: a working memory for adaptive knowledge acquisition and a long-term memory dedicated to the persistent retention of information. The two memory modules work cooperatively during IL. The working memory first learns from new data to encode knowledge into parameters. Subsequently, Co 2In performs a consolidation process to identify underlying patterns in the learned parameters and re-express them into a compact knowledge representation. Next, the knowledge representation and the identified patterns are transformed into separate network layers and integrated into the long-term memory. These designs empower Co 2In to accumulate knowledge with high plasticity and stability. We evaluate Co 2In on CIFAR-10, CIFAR-100, and Tiny-ImageNet under exemplar-free Class-IL and Task-IL settings. Experimental results show that Co 2In achieves state-of-the-art performance with efficient memory consumption. 

Index Terms —Incremental Learning, Continual Learning, Catastrophic Forgetting, Class-Incremental Learning.

## 1 INTRODUCTION 

In an ever-changing environment, incremental learning (IL) emerges as a critical challenge for intelligent systems to continually accumulate new knowledge while retaining pre-viously acquired information [1]. In typical IL scenarios, a learner is required to learn a sequence of disjoint tasks. When learning a new task, only data from the new task are available. In this training schema, an effective IL learner should be able to flexibly learn and incorporate new in-formation from the current task ( plasticity ) while retain-ing previously acquired old-task knowledge ( stability ). To strike a balance between plasticity and stability, a variety of IL strategies have been developed based on distinct technical mechanisms [2], [3]. Among them, memory-based IL methods have shown superior performance [4]–[7]. As illustrated in Fig. 1 (a), memory-based methods typ-ically involve an auxiliary memory to store partial infor-mation from previous tasks. Rehearsal-based methods [4], [7], [9]–[14] adopt an exemplar memory (or a generative model) to store (or generate) samples or features from old tasks, replaying them to reinforce old-task knowledge during new-task learning. Alternatively, gradient-memory-based methods [5], [6], [15]–[17] choose to monitor gradient direc-tions that might impede old-task performance, updating the model only with gradients orthogonal to the stored ones. Both rehearsal-based and gradient-memory-based meth-ods adhere to a fundamental principle: the model must simultaneously acquire new knowledge while retaining old knowledge. However, knowledge acquiring and remem-bering typically interfere with each other, leading to the stability-plasticity dilemma [18]. For the rehearsal-based methods, fitting new tasks could overwrite old knowledge, particularly if the stored samples inadequately represent the data distribution of the old tasks, incurring compro-mised stability. On the other hand, gradient memory-based methods may hinder parameter updates along the direction of the steepest descent for loss minimization, especially in extreme cases where the entire gradient space is constrained, resulting in reduced plasticity. The layered struc-ture effectively segregates the tasks of information encoding and storage into different brain organs, endowing human memory with an ideal balance of plasticity and stability. Inspired by the mechanism of human memory, we in-troduce a bi-level memory framework for IL. As illustrated in Fig. 1(c), the framework consists of a working memory (akin to the short-term memory in the human memory model) and a long-term memory, each implemented as neu-ral networks but with distinct roles. The working memory dynamically acquires new knowledge, while the long-term memory consistently stores all learned information. This cognitively inspired framework decouples learning from remembering, ensuring sufficient plasticity and stability. Based on the bi-level memory framework, we propose the knowledge en Co ding, Co nsolidation, and In tegration (Co 2In ) strategy to continually accumulate knowledge. Upon encountering a new task, the working memory first encodes the new knowledge into trainable parameters. Acknowledging the inherent over-parameterization issue within these trained parameters [21], Co 2In executes a con-solidation process to identify the underlying patterns of the trained parameters. The identified patterns serve as a set of basis to construct a parameter space that encapsulates valu-able knowledge but with significantly lower dimensions. By projecting the trained parameters with respect to the pattern basis, Co 2In generates a compact representation of valuable knowledge involved in the trained parameters. Then, the long-term memory re-organizes the knowledge representa-tions and pattern basis of all learned tasks into independent layers, ultimately integrating them into a unified network. The unified network directly executes inference operations. Moreover, we equip Co 2In with a novel quadratic classifier, which establishes compact decision boundaries. As a result,

## 2 RELATED WORK 

2.1 Incremental Learning 

According to the techniques for balancing stability and plasticity, current IL methods can be classified into three categories: memory-based, regularization-based, and architecture-based. 

Memory-based methods typically preserve partial pre-vious tasks information to mitigate catastrophic forgetting. JOURNAL OF IEEE TRANSACTIONS ON PATTERN ANALYSIS AND MACHINE INTELLIGENCE 3

According to the stored information, memory-based meth-ods can be further split into rehearsal-based methods and gradient-memory based methods. Some rehearsal-based methods [4], [7], [9], [13], [24]–[27] store old-task samples as exemplars, and replay them alongside new data dur-ing learning. Other rehearsal-based methods [14], [28]–[31] maintain a generative model capable of producing pseudo-samples that mimic the distribution of old tasks, also known as generative replay. On the other hand, gradient-memory based methods [5], [10], [11], [15], [17], [32] adopt a different strategy by preserving the directions of gradients that could disrupt the performance on earlier tasks. These recorded gradients serve as constraints during model updates: only those gradient directions orthogonal to them are permitted for updating the parameters, thereby preserving previously acquired knowledge. Although Co 2In employs a bi-level memory structure, it avoids exemplar storage and gradient constraints by instead retaining low-rank knowledge pat-terns and representations. 

Regularization-based methods alleviate forgetting by incorporating regularization terms into the loss function. Learning without Forgetting (LwF) [33] first applies knowl-edge distillation to regularize the model, aiming to align the current model with a teacher model representing the old-task knowledge. As knowledge distillation is effective in reducing forgetting, this technique has become a standard IL baseline and has been widely adopted in many IL methods [33]–[37]. Another prominent regularization-based method is Elastic Weight Consolidation (EWC) [38]. EWC leverages the Fisher information matrix to estimate the importance of each parameter and punishes their changes during sub-sequent task training. Several IL methods follow a similar idea to alleviate forgetting, such as Synaptic Intelligence (SI) [39], oEWC [40], and Memory Aware Synapses (MAS) [41]. In this paper, we also propose a regularization term for 

Co 2In to encourage the model to reuse previously acquired knowledge patterns in new tasks. 

Architecture-based methods address forgetting by em-ploying specifically designed network structures. Some mask-based methods [42]–[45] learn a set of parameter masks that indicate the assignment of neurons. These masks facilitate the selective activation or deactivation of specific parts of the network for each task. Other expansion-based methods [31], [46]–[49] expand the width of networks to ensure sufficient network capacity for new-task learning. During inference, most architecture-based methods require explicit task identification of queries to adapt the param-eters accordingly, which limits their application in task-agnostic scenarios, e.g., Class-IL. To address this issue, some architecture-based methods leverage one-class classi-fiers [31], [47], [50] or confidence [51] to achieve task-wise discrimination. Our Co 2In increases the network capacity by dynamically expanding pattern basis. Moreover, similar to one-class classifier based methods, it learns compact decision boundaries using a quadratic classifier, enabling task-agnostic inference without explicit task identifiers. Additionally, various IL methods are inspired by the human cognitive process. Drawing inspiration from the phenomenon of synaptic expansion (neurons expand new synapses to acquire new information), Wang et al. [52] propose to expand new network branches when learning a new task. The parameters of the newly expanded branch are selectively merged with the original branch through knowledge distillation. Sarfraz et al. [53] suggest a multi-memory system to mimic the human memory structure, including episodic memory, working memory, and long-term memory. Co 2In shares a similar motivation with these approaches but with different underlying mechanisms. In 

Co 2In , all knowledge is stored in the long-term memory, while the working memory is solely responsible for ac-quiring knowledge. With this design, Co 2In decouples the roles of learning and remembering into different memory units, thereby achieving both high plasticity and stability. In contrast, the responsibilities of knowledge acquiring and remembering in existing cognitive-inspired IL methods are still concentrated within the same model. Some recent IL methods are designed for pretrained models, which benefit from a well-initialized, transferable representation space. Prompt-based methods insert learn-able prompts into frozen backbones, where L2P [54] dynam-ically selects input-dependent prompts, DualPrompt [55] disentangles task-shared and task-specific prompts across layers, and CODA-Prompt [56] further enables composi-tional prompt generation. Adapter-based methods intro-duce lightweight modules for task adaptation, including EASE [57], which learns task-specific adapters via prototype completion to mitigate feature–classifier mismatch; SSIAT [58], which maintains a shared adapter and performs uni-fied classifier retraining; and ACMAP [59], which improves scalability by merging multiple adapters. Other LoRA-based approaches constrain updates to low-rank subspaces, with InfoLoRA [60] constructing interference-aware subspaces and CL-LoRA [61] combining shared and task-specific LoRA modules. In this paper, the proposed Co 2In focuses on the training-from-scratch setting, while it can be naturally ex-tended to pretrained-based IL by learning a low-rank resid-ual branch, enabling seamless integration with parameter-efficient adaptation paradigms. 

2.2 Human Memory Mechanism 

Human beings exhibit remarkable plasticity and stability throughout their lives, owing to the brain’s multi-layered memory structure and effective memory mechanisms. The classical Atkinson-Shiffrin model [8] posits that human memory includes three main units: sensory memory, short-term memory, and long-term memory. Sensory memory acts as a cache for sensory activations like sounds or touches, transferring information to short-term memory when at-tention is concentrated. Short-term memory holds infor-mation for immediate use, and after repeated rehearsal, this information is consolidated into long-term memory for permanent storage. This hierarchical structure ensures both the plasticity and stability of the brain. This paper draws inspiration from the human brain’s memory mechanisms. The proposed Co 2In is feasible for both Task-IL and Class-IL. ## 4 BI-LEVEL MEMORY FRAMEWORK 

A naive IL solution is to train an independent model for each task, but storing and running all task-specific models lead to increasing memory and computational overhead. Our proposed approach involves using low-rank matrices to compactly represent incremental knowledge learned from each additional task and gradually expand the network width. This forms the bi-level structure introduced in this section, a novel IL framework that separates knowledge acquisition and retention into two distinct memory units. Before describing the bi-level structure, we first elaborate on two knowledge spaces that serve as a guide for organizing knowledge within these memory units. 

4.1 Knowledge Spaces 

In the context of neural networks, we define knowledge as the inherent capability to map a specific input into the cor-responding output. The network parameters can be thought of as an explicit representation of knowledge, and we define the space which resides in as Parameter Knowledge Space (PKS) . PKS often exhibits redundancy in dimensions, as current deep neural models are typically overparameterized [21]. 4.2 Bi-level Memory Structure 

We propose a bi-level memory framework based on PKS and CKS. As depicted in Fig. 1 (c), The framework consists of the following two memory units:  

> •

Working memory is responsible for adaptively ac-quiring new knowledge in PKS. It is implemented as a L-layer neural network, with parameters denoted as W = {W 1, ..., W L}. 

> •

Long-term memory dynamically maintains an entire CKS during incremental learning, including a set of pattern basis B = {B1, ..., BL} for each layer, alongside the projected knowledge representations for all learned tasks A = {A 1, ..., AT }.The bi-level memory framework decouples the roles of knowledge acquiring and remembering into specialized memory units, thereby ensuring high plasticity and stability.

5.4 Extension to Convolutional Neural Networks 

In previous sections, the discussion revolved around the application of Co 2In within fully connected neural net-works. This section presents a straightforward strategy for extending our method to convolutional neural networks. The fundamental principle behind this extension involves converting network layers between convolution form and matrix-multiplication form. 

Knowledge consolidation with matrix-multiplication form. Convolution is constituted by pixel-wise multipli-cations between the convolutional kernel and the image patches. This inherent linearity inspires us to reshape both the kernel and the patches into matrix form. As illustrated in Fig. 4, the l-th convolution layer with a kernel size of 

cl+1 × cl × kl × kl is transformed into a matrix of dimen-sions cl+1 × (cl × kl × kl). This transformation enables the seamless application of knowledge consolidation methods to convolutional layers without any modification. 

Knowledge integration with convolution form. After knowledge consolidation, the convolution kernel of l-th layer is factorized into two matrices: a pattern basis matrix with the size of cl+1 × rlt and a knowledge representation matrix with the size of rlt ×(cl ×kl ×kl). An intriguing aspect of this decomposition is that the pattern basis can be reinter-preted as a 1 × 1 convolution kernel, while the knowledge representation can be converted into a convolution kernel with dimensions rlt × cl × kl × kl, as visualized in Fig. 2 (c). 5.5 Quadratic Classifier 

Co 2In remains an inherent challenge in Class-IL: the lack of cross-task discriminability during inference because of the unavailability of task identification. Recall that Eq. (7) derives the classification result by comparing the prediction logits obtained from all t tasks, each functions as an au-tonomous subnetwork. However, as each subnetwork un-dergoes an independent training process, their output logits may not cross-task discriminative, potentially influencing the Class-IL performance of Co 2In .We conducted an exploratory experiment through a toy IL dataset to assess the cross-task discriminability of outputs from these independently trained subnetworks. The toy dataset consists of six classes, each sampled from a Gaussian distribution. As depicted in Fig. 6, the first four classes (colored purple) belong to task 1, while the remaining two classes (colored green) come from task 2. A two-layer fully connected model was trained exclusively on task-1 data. Contour maps were subsequently generated to analyze the behavior of logits across both tasks. Fig. 6 (a) demonstrates that the logits enable accurate classification within task 1, evidenced by higher values for corresponding class samples and lower values for other samples within the same task. Conversely, as depicted in Fig. 6 (b), the logits for task-2 samples become disproportionately large, leading to mis-classification as task-1 classes. This behavior highlights the infeasibility of directly concatenating these misleading logits described in Eq. (7). One potential explanation for the above issue can be attributed to the “push” factor [63] inherent in the cross-entropy loss. 6.1 Settings 

Datasets. We choose three datasets during the evaluation: CIFAR-10 [66], CIFAR-100 [66], and Tiny-ImageNet [67]. CIFAR-10 includes ten classes of 32 × 32 color images. We divide it into five incremental batches, with each batch containing samples of 2 classes. CIFAR-100 consists of 60000 

32 × 32 color images that fall into 100 classes. We split it into ten incremental batches in most of our experiments. Tiny-ImageNet comprises 200 categories of 64 × 64 color images. The 200 classes are divided into ten tasks equally, each including samples from 20 classes. 

Comparison baselines. We select several classic and lat-est IL methods for comparison, including Gradient Episodic Memory (GEM) [10], Dark Experience Replay (DER and DER++) [4], Contrastive Continual Learning (Co2L) [25], Hierarchical Correlations Replay [24], NPCL [68], Learning without Forgetting (LwF) [33], Synaptic Intelligence (SI) [39], Orthogonal Weights Modification (OWM) [69], DeepIn-version (DI) [29], ILCOC [47], Gradient Projection Memory (GPM) [5], Adam-NSCL [6], Prototype Augmentation and CIFAR -100 Tiny-ImageNet

Self-Supervision (PASS) [70], Efficient Feature Transforma-tions (EFT) [51], Always Be Dreaming (ABD) [14], Filter Atom Swapping (FAS) [71], Winning SubNetworks (WSN) [72], DCPOC [31], VDFD [36]. We also introduce a funda-mental method named Joint, which is trained on all task data jointly. Joint does not adhere to the IL training setup, which is generally seen as the upper-bound performance. In addition, we report the results of the conference version of our method, referred to as BMKP [23]. BMKP can be thought of as a simplified Co 2In without the knowledge integration and the quadratic classifier. 

Performance metrics. We follow [4], [10] and employ classification accuracy (ACC) on all learned tasks after IL as the primary metric for performance evaluation. To eliminate the stochasticity inherent in neural network training, we report the average performance of five runs with random seeds. We also provide memory usage in megabytes (MB) for certain methods that require additional storage beyond the network parameters. The additional storage includes exemplars for DER, gradient basis for GPM and Adam-NSCL, and long-term memory for BMKP and Co 2In .

Implementation details. To ensure a fair performance comparison, we evaluated the performance of all methods under similar memory constraints. For the projection-based methods (GPM, Adam-NSCL, BMKP, and Co 2In ) in which the memory usage depends on the width of the network, we follow [5] and employ a narrower version of ResNet18 [73]. In contrast, all the other baselines employ the standard ResNet18 as the network backbone. For rehearsal-based methods (GEM, DER, DER++, Co2L, HCR) that necessitate additional memory to preserve exemplars, we equip them with a buffer capable of storing up to 500 samples. 

Hyper-parameters. All hyper-parameters are searched through a validation set obtained by sampling ten percent samples from the training set. We optimize Co 2In with stochastic gradient descent (SGD) optimizer over 100 iter-ative epochs. We tailor the batch size to 32, 16, and 128 for CIFAR-10, CIFAR-100, and Tiny-ImageNet. The learn-ing rates are configured at 2e-3, 2e-2, and 2e-2 for the three datasets, respectively. The balance weight λ is tuned within the range of {0, 0.1, 1, 10 , 100 }, with the optimal values selected as 0.1, 1, and 10 for CIFAR-10, CIFAR-100, and Tiny-ImageNet. 6.2 Comparison Result 

This section provides a comparison between Co 2In and baseline methods. The performance is presented in Table 2 for both Task-IL and Class-IL settings. Additionally, Fig. 7 illustrates the memory usage of various methods. For the small-scale CIFAR-10 dataset, Co 2In is competi-tive with the rotate class augmentation technique 3, showcas-ing the best Task-IL performance and the third-best Class-IL performance among exemplar-free methods. Our empirical findings suggest that the rotate class augmentation is par-ticularly efficacious in enhancing performance in settings with limited numbers of categories. Section 6.5 details an in-depth examination of this augmentation. For CIFAR-100, Co 2In achieves the second-best Class-IL performance (37.54%) and the best Task-IL performance (84.21%), surpassing the second-best VDFD by 0.91%. For Tiny-ImageNet, under the Task-IL setting, the conference version BMKP obtains the best classification accuracy (70.36%), while Co 2In delivers the second-best performance (68.75%). 6.4 Analysis of Hyper-Parameters 

Sensitivity analysis of λ (Cf. Eq. (2) ). We first conduct experiments to evaluate the sensitivity of λ by setting dif-ferent values ( 0, 1, 10 , 100 , 1000 ), and further investigate the effectiveness of the representation compaction regularizer. The first row in Fig. 8 depicts the experimental results. when 

λ = 0 (i.e., the representation compaction regularizer is not applied), Co 2In consumes the most memory but yields rela-tively lower accuracy on both Task-IL and Class-IL. As the value of λ rises, the classification accuracy correspondingly increases, peaking at an optimal point before gradually declining. This phenomenon reveals that the representation compaction regularizer improves the performance of Co 2In ,which we attribute to facilitating the transfer of learned knowledge. Furthermore, the memory usage of Co 2In con-sistently diminishes as λ grows, signifying that the regular-izer efficiently improves the memory efficiency of Co 2In by encouraging the model to represent new knowledge using previous-established patterns. 

Sensitivity analysis of SVD ratio (Cf. Eq. (3) ). Subse-quently, we evaluate Co 2In with different SVD ratios: 0.95, 0.96, 0.97, 0.98, 0.99. The experimental results are depicted in the second row of Fig. 8. As the SVD ratio increases, both accuracy and memory usage remain stable and gradually increase monotonically. This phenomenon is owing to the fact that a larger SVD ratio allows Co 2In to preserve more basis during knowledge consolidation, thereby retaining more knowledge. We empirically determine an SVD ratio of 0.97 for CIFAR100 and 0.98 for Tiny-ImageNet to balance the performance and memory usage.

## 7 EXTENSION TO PRETRAINED MODEL -BASED IN-

CREMENTAL LEARNING 

Although this paper focuses on training from scratch, the proposed Co 2In can be seamlessly extended to pretrained model-based incremental learning. In this setting, the pre-trained model provides a strong and stable feature prior. Therefore, we freeze the pretrained backbone and learn a residual branch for each adaptable layer. For the l-th layer at task t, the effective weight is formulated as 

W lt = W lpre + ∆ W lt ,

where W lpre denotes the frozen pretrained weight, and 

∆W lt denotes the task-specific residual to be learned. The residual branch follows the same knowledge en-coding, consolidation, and integration pipeline as Co 2In .Specifically, the working memory initializes ∆W lt as a zero matrix with the same size as W lpre and optimizes it on the JOURNAL OF IEEE TRANSACTIONS ON PATTERN ANALYSIS AND MACHINE INTELLIGENCE 16 

current task. After training, the learned residual is consoli-dated into the long-term memory by decomposing it into a pattern basis Blt and a compact knowledge representation 

Alt. The long-term memory then integrates the basis and representations from all learned tasks into separate layers 

Bl and Al, enabling efficient parallel inference. We follow ACMap [59] and evaluate Co 2In using ViT-B/16 pretrained on ImageNet as the backbone. Three repre-sentative baselines are selected: Naive LoRA, which trains an independent LoRA module for each task and merges them during inference; InfoLoRA [60], a LoRA-based IL method; and ACMap [59], an adapter-based IL method. As shown in Table 13, with comparable memory consump-tion, Co 2In achieves the best Task-IL performance on both CIFAR-100 and Tiny-ImageNet, indicating that the proposed residual consolidation strategy effectively preserves task-specific knowledge. For Class-IL, Co 2In obtains performance comparable to existing pretrained IL methods, while clearly outperforming Naive LoRA. These results show that Co 2In 

is effective for pretrained-model-based IL.

## 9 CONCLUSION 

This work draws inspiration from the multi-level human memory system and proposes a bi-level memory framework for incremental learning. The bi-level memory framework consists of a working memory for acquiring new knowledge and a long-term memory for preserving previously learned information. With the separate memory units for knowledge acquiring and remembering, the bi-level memory frame-work ensures both high plasticity and stability. Furthermore, in light of the human memory mechanism, we devise a series of strategies for knowledge encoding, consolidation, and integration within the bi-level memory framework, which together constitute our Co 2In . Extensive experiments demonstrate that Co 2In effectively handles Task-IL and Class-IL with efficient memory and computation utilization. Nonetheless, Co 2In has some limitations, such as missing backward knowledge transfer and escalating memory con-sumption proportional to the number of tasks learned. In the future, we plan to improve Co 2In by integrating advanced pattern basis editing methods, such as meta-learning. These enhancements are expected to facilitate backward knowl-edge transfer and effectively curb the expansion of the pattern basis, further advancing the efficiency of Co 2In .
