## 摘要
在个性化搜索与推荐中，大型语言模型会产生高昂的训练和推理成本，因为不断增长的交互历史会延长请求输入，并反复将相同的物品文本暴露给模型。我们提出可组合与可复用物品记忆（Composable and Reusable Item Memory，CRIM）框架，该框架将物品级语义编码与请求级历史建模分离。一小组可学习的摘要 token 将每个物品压缩为紧凑的连续记忆，而片段级读出 token（REC token）在交互历史中引入预测监督。这些记忆独立于用户和查询，因此可以跨请求复用。在推理时，CRIM 按交互顺序组合缓存记忆，并结合可选的查询来生成个性化检索表示，从而减少重复的物品文本编码，同时保留依赖请求的上下文建模。我们进一步引入一种联合训练机制，将缓存记忆与采样的实时重编码相结合。每个请求仅重编码少量历史物品，使检索目标能够在有限计算成本下联合优化物品编码器和请求编码器，同时周期性缓存刷新可保持一致性。在 MovieLens-1M、Qilin 和我们新的 LazSeq 数据集上进行的大量评估与成本分析表明，在相同骨干规模下，CRIM 在显著降低推理成本的同时实现了最先进的检索性能，并在联合训练期间限制了物品重编码。我们将公开代码和数据集。

## Abstract
Large language models incur substantial training and inference costs in personalized search and recommendation, as growing interaction histories lengthen request inputs and repeatedly expose the same item text to the model. We propose \textbf{C}omposable and \textbf{R}eusable \textbf{I}tem \textbf{M}emory (CRIM), a framework that separates item-level semantic encoding from request-level history modeling. A small set of learnable summary tokens compresses each item into compact continuous memories, while segment-level readout tokens (REC tokens) introduce predictive supervision within the interaction history. These memories are independent of users and queries and can therefore be reused across requests. At inference time, CRIM composes cached memories in interaction order and incorporates an optional query to produce a personalized retrieval representation, reducing repeated item-text encoding while retaining request-dependent contextual modeling. We further introduce a joint training mechanism that combines cached memories with sampled live re-encoding. Re-encoding only a few history items per request allows the retrieval objective to jointly optimize the item and request encoders at limited computational cost, while periodic cache refreshes maintain consistency. Extensive evaluation and cost analysis on MovieLens-1M, Qilin, and our new LazSeq dataset show that CRIM achieves state-of-the-art retrieval performance with substantially lower inference costs at the same backbone scale, while limiting item re-encoding during joint training. We will publicly release our code and dataset.
