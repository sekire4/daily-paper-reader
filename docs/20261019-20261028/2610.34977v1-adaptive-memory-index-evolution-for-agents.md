## 摘要
长时程智能体会不断积累经验，但保留记忆并不能保证在需要时能够访问。现有系统可以同时适应记忆内容和访问方式；我们将持久访问更新分离为一个单独控制的适应层。我们将这一目标形式化为记忆索引演化，并用自适应记忆索引演化（AMIE）实例化：这是一个轻量级插件层，可从部署时的检索中演化每个记忆的访问状态，而不修改存储内容，也不重新训练宿主记忆系统。AMIE 将语义教师的保留/抑制判断蒸馏为以检索为条件的策略，并将其选择性动作累积为有界状态，从而对后续宿主检索重新加权。令人意外的是，即使是一个只累积检索频率的零调用策略，在若干设置中也能匹配或优于语义策略，这揭示了检索流量本身是访问适应的强信号；而当频繁检索的记忆仍然有用时，学习到的选择性可提升鲁棒性。在五个基于检索的宿主和三个基准上，训练后的 AMIE 在全部 15 组比较中提升了下游 F1 或准确率，提升幅度为 0.70--3.37 个百分点（相对提升最高 25%），并在全部 10 组比较中改善了检索。受控分析表明，持续抑制竞争项可以暴露此前未见的证据，而抑制反复有用的记忆则会造成互补的失败模式。总之，这些结果确立了持久记忆访问作为一种实用的适应层，独立于其所服务的内容，在基于检索的智能体记忆系统中发挥作用。

## Abstract
Long-horizon agents continually accumulate experience, yet retaining a memory does not guarantee access when it is needed. Existing systems can adapt both memory content and access; we isolate persistent access updates as a separately controlled adaptation layer. We formulate this target as Memory Index Evolution and instantiate it with Adaptive Memory Index Evolution (AMIE), a lightweight plug-in layer that evolves per-memory access state from deployment retrievals without modifying stored content or retraining the host memory system. AMIE distils a semantic teacher's keep/suppress judgments into a retrieval-conditioned policy and accumulates its selective actions into bounded state that reweights subsequent host retrievals. Surprisingly, even a zero-call policy that simply accumulates retrieval frequency can match or outperform semantic policies in several settings, revealing retrieval traffic itself as a strong signal for access adaptation, while learned selectivity improves robustness when frequently retrieved memories remain useful. Across five retrieval-based hosts and three benchmarks, trained AMIE improves downstream F1 or accuracy in all 15 comparisons, by 0.70--3.37 percentage points (up to 25% relative), and improves retrieval in all 10 comparisons. Controlled analyses show that persistent competitor suppression can expose previously unseen evidence, while suppressing repeatedly useful memories creates the complementary failure mode. Together, these results establish persistent memory access as a practical adaptation layer, distinct from the content it serves, in retrieval-based agent memory systems.

## 1. 核心问题与研究动机

- **背景**：长时程智能体（long-horizon agents）会持续积累观察、决策与成功经验，但"保留记忆"不等于"需要时能取用"。随着相似内容（如相似堆栈信息、配置笔记）不断累积，真正有用的经验可能在检索排序中被挤到后面——内容未被删除或改写，**变化的是访问（access）**。
- **现有工作**：Mem0、MemoryOS、A-MEM、Memory-R2 等系统同时适应"记忆内容"与"访问方式"（如回忆强度、访问新近性、图节点效用），但二者耦合在一起，难以单独评估。
- **核心主张**：论文将**持久访问更新**隔离为一个独立可控的适配层，形式化为 **Memory Index Evolution（记忆索引演化）**，并提出 **AMIE（Adaptive Memory Index Evolution）** 作为轻量插件层：在不修改存储内容、不重训宿主系统的前提下，从部署检索中演化每个记忆的访问状态。
- **形式化要点**：把记忆表示为 \(M_t=(C_t, I_t)\)，内容演化 \(C_{t+1}=G(C_t,O_t)\) 与索引演化 \(I_{t+1}=F(I_t,O_t)\) 分离；索引更新的价值必须**前瞻性**地（对后续查询）评估，而非归功于产生该更新的那次交互。
- **三大设计挑战**：C1 什么信号揭示访问干扰（只能来自部署实际查询流）；C2 哪些更新能泛化到未来查询；C3 如何在运行系统中通过宿主检索接口在线演化。

## 2. 方法论：AMIE 的核心思想与关键技术

- **总体分解**：\(F_\theta(I_t,O_t)=T(I_t,\pi_\theta(O_t))\)，即"检索条件策略 π 选择每记忆动作 + 状态转移 T 把动作转为未来访问状态"。策略离线学习、索引在线演化。
- **（1）检索条件索引策略 πθ**
  - 观察查询 \(q_t\) 与宿主原生反馈列表 \(B_t\)（区别于 AMIE 自己重排后的答案上下文 \(S_t\)），输出二元动作 \(a_{i,t}\in\{0,1\}\)：1 表示对该记忆累积抑制，0 表示保持（keep 不清除已有惩罚）。
  - 用 LLM 一次前向输出完整掩码，而非逐条文本判断；学生为 Qwen3-8B + LoRA（rank 8、scale 16）+ 10 槽线性头，读取末 token 表示 \(h_\phi(O_t)\)，\(p_{\theta,i}=\mathrm{sigmoid}(w_j^\top h_\phi+b_j)\)，阈值 0.5。
  - 训练目标：将教师（GPT-5.6-Sol）的 keep/suppress 判断做**类平衡二元交叉熵蒸馏**：\(\mathcal{L}(\theta)=\mathbb{E}\sum w_{y_{i,t}}\ell_{BCE}(p_{\theta,i},y_{i,t})\)，拟合集含 3676 keep / 5344 suppress 槽，类权重约 1.2269 / 0.8439；输入查询截断 300 字符、记忆 200 字符，上下文 4096 token，AdamW、学习率 \(10^{-5}\)、batch 1、两轮。
  - 部署时 θ 固定，适应只发生在持久索引状态中。
- **（2）有界持久访问动态**
  - 计数：\(n_{i,t+1}=n_{i,t}+a_{i,t}\)；有界状态：\(u_{i,t}=g(n_{i,t})=n_{i,t}/(n_{i,t}+\kappa)\)，κ 为半饱和事件数；重复决策增强惩罚但饱和封顶。
  - 记忆离开反馈列表后状态仍保留，使"过去的竞争"影响其下一次检索。
- **（3）宿主内分数重加权**
  - 经宿主单调仿射映射与正缩放得 \(\hat\sigma(q,i)\in[0,1]\)，最终分数 \(s_t(q,i)=\hat\sigma(q,i)(1-\lambda_p u_{i,t})\)，\(\lambda_p\in[0,1]\) 控制抑制强度；\(\lambda_p=0\) 精确恢复宿主原生选择，便于匹配对比。
  - **后封印更新约束**：查询 t 先读取 \(u_t\)、封印答案上下文 \(S_t\)，之后才提交由 \(B_t\) 导出的掩码；只有后续查询使用 \(u_{t+1}\)，保证效应被"结转"而非记到诱发它的答案上。
  - 理论性质（Proposition 1，附录 H 有证明）：在同一查询与候选池下，若目标记忆状态不变、其他竞争者状态非减，则任何竞争者分数不升，目标排名不会变差，且成对边际严格增大——即**无需观察到目标本身，仅靠压制竞争项即可让未见的证据浮现**（top-k 进入条件为 \(|P_{t+1}|<k\le|P_t|\)）。
- **三种共享同一状态与包装器的策略**：Trained（学习选择性）、Frozen（同骨干提示、不微调）、Count（全 1 掩码、零模型调用）。

## 6. 主要结论与发现

- **效用普遍提升**：trained AMIE 在全部 15 组下游效用比较中提升 F1/准确率 **0.70–3.37 个百分点**（最高约 25% 相对），10 组有检索测量的对在检索与效用上**同时**改善。
- **检索流量本身是强信号**：零调用的 count 策略在 LoCoMo BM25、MemoryOS 上接近甚至超过语义策略，说明"反复被检索"本身携带大量可用的干扰信息。
- **选择性在"记忆仍有用"时更鲁棒**：GroupMem MemoryOS 上 trained 比 count 高 3.61 点（count 在该处反而损失效用）；MemBench 上 trained 在 Mem0 取得最大 +3.37 点。
- **增益来自持久、条目特定、方向正确的状态**：置换惩罚、反转方向在相同平均分数位移下都会消除增益；少量历史即可冻结出有效状态；类别匹配状态优于交换状态（+2.16 vs +0.52，后者区间含零）。
