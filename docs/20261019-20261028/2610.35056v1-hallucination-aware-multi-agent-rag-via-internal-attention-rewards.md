## 摘要
检索增强生成（RAG）使语言模型以检索到的证据为依据，但其输出常包含证据无法支持的断言。近期的多智能体RAG系统将流程分解为协同决策，但通常以EM或F1等共享任务奖励来优化所有智能体，而这些指标衡量的是答案重叠度而非对证据的忠实性。我们提出一种幻觉感知的多智能体RAG框架，将任务奖励与由生成器注意力头范数计算得到的内部幻觉风险信号相结合。三个角色特定的LoRA适配器——查询规划器、证据选择器和答案生成器——共享一个冻结的主干模型。一个轻量级评判器在TruthfulQA的真实/虚假样本对上训练一次后保持冻结，提供补充风险分数，并在协同PPO训练中将其加入共享奖励。在三个主干模型（Qwen3-8B、Llama3-8B、Llama2-13B）和三个基准（RAGTruth、HotpotQA、2WikiMultiHopQA）上，我们的方法相较最强的多智能体基线提升了任务性能并降低了幻觉率。消融实验与评判器诊断表明，经TruthfulQA校准的信号提供了有效的奖励塑形，并可迁移到不同的RAG任务中。

## Abstract
Retrieval-augmented generation (RAG) grounds language models in retrieved evidence, but its outputs often contain claims unsupported by that evidence. Recent multi-agent RAG systems decompose the pipeline into cooperative decisions, yet they typically optimize all agents under a shared task reward such as EM or F1, which measures answer overlap rather than faithfulness to evidence. We propose a hallucination-aware multi-agent RAG framework that combines the task reward with an internal hallucination-risk signal computed from the generator's attention-head norms. Three role-specific LoRA adapters, a query planner, an evidence selector, and an answer generator, share a frozen backbone. A lightweight critic is trained once on TruthfulQA truthful/false pairs and then kept frozen, providing a complementary risk score that is added to the shared reward during cooperative PPO training. Across three backbones (Qwen3-8B, Llama3-8B, Llama2-13B) and three benchmarks (RAGTruth, HotpotQA, 2WikiMultiHopQA), our method improves task performance and reduces hallucination rates over the strongest multi-agent baseline. Ablations and critic diagnostics show that the TruthfulQA-calibrated signal provides useful reward shaping that transfers across RAG tasks.

## 1. 核心问题与研究动机

- **背景**：RAG 通过检索证据为语言模型提供依据，但生成结果仍常包含证据未支持的主张（如答对实体却凭空添加关系、日期、数字）。这类失败可能源于问题歧义、证据噪声，也可能源于生成器本身。
- **多智能体 RAG 的现有做法**：将流程拆为查询规划、证据选择、答案生成等可学习阶段，但通常用 **EM/F1 等共享任务奖励**统一优化所有智能体。
- **核心矛盾**：EM/F1 衡量的是**答案与参考答案的表面重叠**，只要命中参考片段就能拿到大部分奖励，而超出证据的附加主张几乎不受惩罚——奖励塑造的是“答案相似”，而非“逐条主张有据可依”。
- **现有忠实度监督的局限**：基于参考答案的指标与 LLM-as-a-judge 都只评估**最终表面答案**，且难以作为 RL 中的稠密奖励（前者只测重叠，后者每次 rollout 都需外部调用）。
- **可借用的信号**：可解释性研究表明，Transformer 内部表征（尤其**注意力头输出的范数**）已携带与真实性相关的信息，可在解码时低成本获取。
- **已有内部信号的用法**：用于事后幻觉检测，或推理时激活引导——二者都**不改变策略**，且只作用于生成器，无法约束查询规划与证据选择环节。
- **核心研究问题**：能否把内部注意力信号转化为奖励，引导多智能体 RAG 走向更忠实的生成？

## 2. 方法论

### 2.1 总体框架

- 将 RAG 建模为**固定顺序的回合制协作决策**：Agent Q（查询规划）→ Agent E（证据选择）→ Agent G（答案生成）。
- 三个智能体共享**冻结的主干** π_Θ，各自配一个**角色专用 LoRA 适配器** ΔΘ_u 与角色提示 p_u，策略为 π_u(·|x)=π_{Θ+ΔΘ_u}(·|p_u⊕x)。
- 一条轨迹 τ=(q, q̃, D, D̃, a)；回合结束获得**单一共享终端奖励**。
- 冻结主干与 critic 的双重冻结，保证 critic 校准时的头范数特征空间在 RL 中不发生漂移。

### 2.2 注意力幻觉 Critic

- **特征**：对每个注意力头 (l,h) 在答案 token 位置 t 取输出向量的 L2 范数 x_t^{l,h}=‖c_t^{l,h}‖₂，再在答案 token 上**均值池化**，得到每个头的标量特征；拼接成定维向量 φ(a)。
- **真值相关头选择**（基于 TruthfulQA 配对校准集）：
  - 对每个真/假答案对计算差值 Δx̄_i^{l,h}=x̄(s_i⁺)−x̄(s_i⁻)；
  - 按头的相关方向 sign^{l,h} 做配对投票，得到每个头的判别准确率 Acc^{l,h}；
  - 保留超过准确率阈值的头（实现中取 **0.90 分位数**），形成紧凑头集合 H_sel。
- **Critic 结构**：轻量 MLP，f_ξ: φ(a) → H∈[0,1]；每个入选头贡献均值、最大值、标准差、最小值 4 个统计量。
- **训练**：在 TruthfulQA 真/假对上用二元交叉熵训练一次，**此后永久冻结**，RL 中仅作为标量风险项被查询。

### 2.3 幻觉感知的多智能体 RL

- **共享终端奖励**：R = α·R_task − λ·H，其中 R_task = F1(a, a*)，H 为冻结 critic 的风险分；α、λ 在开发集上调（实现 α=1.0、λ=0.08）。
- **监督热启动**：先用指令跟随数据 SFT 三个适配器，教会其输出合法的查询计划、文档 ID 选择与答案格式，避免 RL 从零探索动作格式。
- **协作式 PPO**：
  - 三智能体共享同一 advantage A=R−b（b 为近期回合奖励的指数滑动平均基线），方差足够大时做批归一化；
  - 使用**长度归一化的序列级对数似然**构造序列级重要性比 r_i，再做 PPO 裁剪（ε=0.2）；
  - 额外加序列级正则项 ρ·(ℓ̄_θ − ℓ̄_old)²（ρ=0.1）抑制策略突变；
  - 总目标为三个智能体 PPO 损失与正则项之和，**各自独立优化器**，只更新 LoRA，主干与 critic 全程冻结。
- **信用分配逻辑**：所有智能体拿同一标量反馈，但只更新自己的适配器——查询规划器因“计划改善下游证据使用”而受奖，证据选择器因“选出的证据支持有据回答”而受奖，生成器因“答案正确且低风险”而受奖。

## 3. 实验设计

- **数据集 / 场景**：RAGTruth（QA 子集，含词级幻觉标注）、HotpotQA（distractor 设定，10 个候选段落）、2WikiMultiHopQA；三者覆盖单跳与多跳知识密集型问答。
- **统一设定**：**固定证据（fixed-evidence）**，所有方法拿到同一证据池，以隔离检索器差异、聚焦策略学习。
- **主干模型**：Qwen3-8B、Llama3-8B、Llama2-13B。
- **评价指标**：RAGTruth 用 Recall/EM/F1；HotpotQA 与 2Wiki 用 Acc/EM/F1；平均列用 R/A 表示（RAGTruth 取 Recall，多跳集取 Accuracy）。另在 RAGTruth 上报告 **Answer Hallucination Rate (AHR)**，由 GPT-4o-mini 作为自动评判，并用 Qwen2.5-7B 做交叉验证。
- **对比基线（8 个）**：Zeroshot w/ SFT、Vanilla RAG、Vanilla RAG w/ SFT、SelfRAG、MAIN-RAG、RAG-DDR、MA-RAG、**MMOA-RAG**（最接近、也是最强基线：多智能体 + MAPPO + F1 奖励，但无忠实度信号）。
- **消融**：w/o critic、w/o Agent Q 更新、w/o Agent E 更新、w/o Agent G 更新、Full（推理流程不变，仅冻结对应适配器）。
- **Critic 诊断**：TruthfulQA 留出 AUROC、RAGTruth 证据感知 critic AUROC、与答案长度/词重叠的相关性、**打乱分数对照（shuffled-score control）**、λ 权重校准（0.04 vs 0.08）、头判别热力图、token 级头范数轨迹、两个案例研究。

**规模概览**

- 主实验：3 主干 × 3 数据集 × 9 个系统（8 基线 + 本文）≈ 81 组主结果单元。
- 忠实度实验：3 主干 × AHR，另加 2 主干 × 第二评判模型的交叉验证。
- 消融：5 组变体 × 3 数据集（仅 Qwen3-8B）。
- Critic 诊断：约 6–7 类分析（AUROC、相关性、打乱对照、λ 扫描、头热力图、token 动态、2 个案例）。

**充分与客观之处**

- **跨主干、跨数据集**的一致性验证，说明增益不依赖特定模型族或单一任务。
- 忠实度评估采用**与训练校准源分离**的标注（TruthfulQA 训练 → RAGTruth 评估），降低了监督泄漏与“自评自”的风险。
- **打乱分数对照**设计得当：保留惩罚项的边际分布、只破坏样本级对应关系，有效排除了“critic 只是通用正则项”的替代解释。
- **两个独立评判模型**验证 AHR，降低了单一 LLM judge 的系统性偏差。
- 基线覆盖面较全（vanilla / 自反思 / 多智能体 / 可微奖励），且最强基线 MMOA-RAG 与本文共享相近的分解与 PPO 框架，构成较公平的“仅换奖励信号”对照。

- 消融**只在 Qwen3-8B 上做**，未验证结论在 Llama 系列上是否成立。
- AHR 只在 RAGTruth 上测；HotpotQA / 2Wiki 没有忠实度指标，多跳场景的幻觉变化未知。
- 无多种子 / 方差报告，增益幅度（如 +0.95 EM）是否超出随机波动无法判断。
- λ 只试了 0.04 与 0.08 两个值，调参空间探索较浅；α 未见敏感性分析。
- 缺少与“同样额外算力的更强 SFT/DPO 基线”的对照，难以完全归因于内部奖励信号本身。

## 6. 主要结论与发现

- **任务性能**：三个主干上平均指标全面领先。Qwen3-8B 上相对 MMOA-RAG 提升 **+2.35 R/A、+0.95 EM、+1.29 F1**；Llama3-8B 为 49.62/42.56/50.10；Llama2-13B 为 46.81/41.23/46.15，均为三者最优。
- **忠实度**：AHR 全主干最低——Qwen3-8B **21.24%**（较 MMOA-RAG 降 10.74 点）、Llama3-8B 24.65%（降 5.62）、Llama2-13B 27.69%（降 3.34）。**忠实度与任务指标同向改善**，未出现“更保守但更差”的权衡。
- **消融结论**：去掉 critic 后平均 R/A 降 3.31、F1 降 2.59，说明内部风险信号提供了任务奖励之外的额外信息；冻结任一角色都会掉点，**生成器更新影响最大**，查询规划与证据选择的影响较小但稳定为正。
- **Critic 有效性**：TruthfulQA 留出 AUROC **75.92%**；用同一特征在 RAGTruth 标签上另训证据感知 critic 可达 **74.05%**，说明头范数特征同时携带“一般真值”与“证据支持”信息；与答案长度相关 −0.1103、与词重叠相关 −0.1077，接近零，排除“长度/词汇重叠代理”的解释。
- **头级分析**：判别信号**集中在跨多层的少数头**上，而非全模型均匀分布，支持其头选择流程；token 级轨迹在实体与事实谓词等**内容承载位置**出现局部波动。
- **总体判断**：轻量模型内部信号作为**补充性奖励塑形**（而非替代任务监督或独立幻觉检测器）是可行且可跨 RAG 任务迁移的。
