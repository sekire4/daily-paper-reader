## 摘要
长期记忆对于执行多会话、长时程任务的自主大语言模型（LLM）智能体至关重要。然而，现有记忆常常不恰当地存储、保留或检索过度泛化、错误归因或隐私敏感的信息，我们将这一问题称为记忆错位。为研究该问题，我们构建了 MemAlign 基准，包含 1,079 个精心筛选的记忆案例，这些案例基于经过验证的合成多会话对话上下文，覆盖多种记忆错位分类。随后，我们提出 ConMem，一种将保留决策重新表述为前瞻性反事实因果推断的算法。ConMem 合成反事实交互场景，从相关任务执行、无关不变性检查和风险敏感边界偏移三个方面前瞻性审计下游干预效果。实验表明，ConMem 优于其他方法，达到 75.16% 准确率、64.15% 平衡准确率和 65.31% 的 Macro-F1，有效缓解过度保留偏差，同时不牺牲个性化效用。

## Abstract
Long-term memory is critical for autonomous Large Language Model (LLM) agents executing multi-session, long-horizon tasks. However, existing memories often inappropriately store, retain, or retrieve over-generalized, misattributed, or privacy-sensitive information, a problem we term memory misalignment. To study this problem, we construct \textbf{MemAlign}, a benchmark comprising 1,079 curated memory cases grounded in synthetic, validated multi-session conversational contexts covering diverse misalignment taxonomies. We then propose ConMem, an algorithm that reframes retention decisions as prospective counterfactual causal inference. \textbf{ConMem} synthesizes counterfactual interaction scenarios to prospectively audit downstream intervention effects across three aspects: relevant task execution, irrelevant invariance checks, and risk-sensitive boundary shifts. Experiments show that ConMem outperforms other methods, achieving 75.16\% accuracy, 64.15\% balanced accuracy, and a Macro-F1 of 65.31\%, effectively mitigating over-retention biases without sacrificing personalization utility.

- **现有方法缺陷**：已有记忆技术多在**孤立视角**下评估候选记忆（依赖抽取置信度、语义相关性、表层事实启发式），无法预判记忆将如何影响未来多轮交互，导致**过度保留**（over-retention）或**过度剪除**（over-pruning）两端偏差。

## 2. 方法论：ConMem

### 2.1 核心思想
将记忆准入（admission）从"静态文本分类"重构为**前瞻性反事实因果推断**：不问"这条记忆看起来对不对"，而问"若这条记忆可用，未来交互会发生什么变化"。以**反事实记忆处理效应（CMTE, Counterfactual Memory Treatment Effect）**作为准入依据。

### 2.2 四阶段流程（Fig.3）

**（1）未来探针构建**（Probe Construction）
给定历史上下文 $C$ 与候选记忆 $M$，构造三元探针 $Q=\{q_{rel}, q_{irr}, q_{risk}\}$：
- **相关探针**：$M$ 可提供非冗余、实质影响回答的用户特定信息；
- **无关探针**：回答质量本不应依赖 $M$，用于检验行为不变性；
- **风险敏感探针**：引入实体切换、事实更新、显式覆盖或范围变化，暴露不当记忆迁移。

**探针校验**：独立审计器检查语义角色是否成立、是否泄露候选记忆/金标签/基准痕迹；失败时依次执行"保留有效探针的重新生成 → 单角色定向修复 → 全新重建"三级修复。

**（2）受控反事实响应生成**
- 控制组：$R_i^0 = f(q_i)$
- 处理组：$R_i^1 = f(q_i, M)$
- 两组使用完全相同的模型配置，**仅记忆可及性不同**；历史上下文 $C$ 在两支生成中均被隐去，仅用于下游评估，以确保因果隔离。

**（3）双重解耦评估**
- **盲评质量判断**：判断器仅见 $C$、$q_i$ 与随机排序的 $R^0/R^1$（A/B 位置随机化抗位置偏差），输出 A/B/Tie，**不知晓记忆与处理条件**。
- **记忆归因审计**：审计器判断 $M$ 是否被实质使用、是否实质改变输出，并归类为 `utility / unnecessary / neutral / risk`。
- **响应级效应**：$E_i \in \{\text{HELPFUL, NEUTRAL, HARMFUL}\}$——未被实质使用则记 NEUTRAL；否则依盲评偏好定 HELP/LETHAL（Tie 记 NEUTRAL）。此设计避免把生成随机波动误读为记忆错位。

**（4）反事实评分与准入**

各探针的有符号贡献 $c_i$：

| 探针类型 | utility | unnecessary | risk |
|---|---|---|---|
| 相关 | +1.0 | — | −1.0 |
| 无关 | — | −0.5 | −1.0 |
| 风险敏感 | +0.5 | −0.5 | −1.5 |

$$\text{CMTE}(M)=\frac{1}{K}\sum_{i=1}^{K} c_i,\quad K=3$$

- **正值 → STORE，负值 → DO-NOT-STORE**；
- $|\text{CMTE}| \le \epsilon$（$\epsilon=10^{-12}$）时视为证据不足，调用**参数无关的平局裁决器**（不看数值权重与金标签，只读 $C$、$M$ 与原始反事实日志）。
- **事后原因分类**：准入结果固定后再分配结构化解释（`context_misapplication`、`over_inference`、`false_memory_use` 等 11 类），不修改预测与 CMTE。
