## 摘要
长期记忆使大语言模型（LLMs）能够在扩展对话中保持连贯且个性化的交互。然而，现有记忆系统面临两个关键挑战：（1）信息纠缠，即异构信息混杂在粗粒度记忆单元中；（2）组织失配，即主要基于语义相似度的记忆结构可能忽略其他关联。为应对这些挑战，我们提出 ETAMem，一种多视图记忆框架，用于解耦异构对话信息，并使记忆表示与组织同其各自的不同特性对齐。具体而言，异构信息解析提取原子记忆单元并识别情感信息。随后，视图特定记忆结构化将这些单元组织为三个互补的层次化视图：事件（Event）、情感（Affect）和时间（Time）。ETAMem 通过自适应校准阈值增量维护记忆结构。在检索方面，基于熵的检索为各视图分配查询特定预算，并在每个视图内执行层次化搜索。在 LoCoMo 和 LongMemEval-S 上的实验表明，ETAMem 优于最先进基线，分别实现 12.46% 和 7.96% 的相对准确率提升，同时保持具有竞争力的 token 效率。进一步分析表明不同记忆视图具有互补优势。

## Abstract
Long-term memory enables Large Language Models (LLMs) to maintain coherent and personalized interactions across extended conversations. However, existing memory systems face two key challenges: (1) Information Entanglement, where heterogeneous information is mixed within coarse-grained memory units; and (2) Organizational Mismatch, where memory structures based primarily on semantic similarity may overlook other associations. To address these challenges, we propose ETAMem, a multi-view memory framework that decouples heterogeneous conversational information and aligns memory representations and organization with its distinct characteristics. Specifically, heterogeneous information parsing extracts atomic memory units and identifies affective information. View-specific memory structuring then organizes these units into three complementary hierarchical views: Event, Affect, and Time. ETAMem incrementally maintains memory structures with adaptively calibrated thresholds. For retrieval, entropy-based retrieval allocates query-specific budgets across views and performs hierarchical search within each view. Experiments on LoCoMo and LongMemEval-S demonstrate that ETAMem outperforms state-of-the-art baselines, achieving relative accuracy improvements of 12.46% and 7.96%, respectively, while maintaining competitive token efficiency. Further analyses demonstrate the complementary benefits of different memory views.

## 1. 核心问题与研究动机

- **背景**：长期记忆是 LLM 对话智能体实现连贯、个性化交互的基础。现有记忆架构分为两类：
  - **扁平记忆**（MemoryBank、Mem0 等）：将抽取的信息作为独立文本条目，依赖嵌入相似度检索；
  - **结构化记忆**（TiMem、A-MEM、Zep、H-Mem、MAGMA 等）：用层次树或图组织记忆单元。
- **两大核心挑战**：
  - **信息纠缠（Information Entanglement）**：单个对话轮同时包含事实事件、个人偏好、时间上下文，现有系统以粗粒度对话轮/条目为基本单元，未显式区分异构信息类型，导致检索噪声；
  - **组织失配（Organizational Mismatch）**：现有结构主要按语义相似度、时间或关系组织，未让记忆表示与组织原则对齐不同信息类型的特性（如偏好类证据会被语义主题打散，难以集中检索）。
- **核心研究问题**：如何识别、表示并组织对话信息，以支持长期记忆检索？作者援引认知神经科学（情景记忆与情绪处理由功能专门化但相互作用的神经系统支撑）作为设计依据，主张**解耦异构信息并使记忆表示与组织对齐其特性**。

## 2. 方法论

### 2.1 核心思想
将对话解析为**原子记忆单元（AMU）**，按信息类型分派到**事件（Event）、情感（Affect）、时间（Time）**三个互补层次视图，各视图使用专属表示与组织原则；检索时按查询熵动态分配各视图预算。

### 2.2 异构信息解析
- **AMU 抽取**：用 LLM 将每个对话轮 $x_t=(d_t,\tau_t)$ 分解为语义完整的原子单元集合 $A_t=\{a_{t,1},...,a_{t,n_t}\}$，保持原信息不丢失。
- **极性标注**：用现成情感分类器 $f_{sent}$ 为每个 AMU 赋极性 $p_{t,i}\in\{\text{negative},\text{neutral},\text{positive}\}$（取最高分类别）。

### 2.3 视图特定记忆结构化
- **双编码器表示**：中性 AMU 用文本编码器 $\phi_{text}$，正/负极性 AMU 用情感编码器 $\phi_{affect}$。
- **三视图组织**：
  - **Event 视图**：按文本语义层次聚类中性 AMU，捕捉重复事件、实体与交互；
  - **Affect 视图**：按情感语义层次聚类正/负 AMU，捕捉持续偏好与态度；
  - **Time 视图**：固定时间层级 Session→Day→Week→Month，AMU 存于 Session 层，上层节点提供摘要。
- **树结构**：叶节点存 AMU，内部节点存子树文本摘要（由子节点摘要逐层生成）。

### 2.4 动态记忆维护
- **Attachment**：节点用子树 AMU 表示质心 $\mu_n$，以余弦相似度 $g(a,n)=\cos(r,\mu_n)$ 做 beam search（宽度 $B$）定位插入点，按匹配分 $\rho^\star$ 与阈值选择三种操作：
  - Attach（$\rho^\star\ge\theta_{attach}$）、NewLeaf（$\theta_{new}\le\rho^\star<\theta_{attach}$）、NewRoot（$\rho^\star<\theta_{new}$）。
- **Split**：叶节点 AMU 数超过 $M_{max}$ 或内聚度 $\kappa(n)$ 低于 $\theta_{coh}$ 时，用 cosine K-means 分裂为 $k=\max(2,\lceil m/M_{max}\rceil)$ 个新叶。
- **Merge**：会话结束时对 Event/Affect 视图检查节点对，质心相似度 $\ge\theta_{merge}$ 且合并后不超容量则合并，跨分支时置于最近公共祖先下。
- **Summary Update**：懒更新机制——结构变更只递增受影响节点及祖先的待更新计数器 $u_n$，当 $u_n\ge\delta$ 时才重生成摘要，降低 LLM 调用开销。

### 2.5 自适应校准
- **结构参数**：叶容量 $M^{(v)}_{max}$、分支因子 $b^{(v)}_{max}$、树深 $H^{(v)}$ 依据观测 AMU 数中位数/最大值按公式重算（如 $M_{max}=\max(2,\text{round}(\sqrt{\tilde n_v}))$），容量触顶时重校准。
- **维护阈值**：收集插入过程中 AMU 与候选节点的余弦相似度，用 **Otsu 方法**划分低/高相似子集，分别取 75 百分位（$\theta_{new}$）与 25/65/85 百分位（$\theta_{attach},\theta_{coh},\theta_{merge}$），再用 **EMA**（系数 $\eta=0.5$）平滑跨轮波动。

### 2.6 熵基检索
- **视图路由**：计算查询与各视图叶摘要的相似度并经 softmax（温度 $\beta$）转为分布，计算归一化熵 $\bar H_v$；以 $1-\bar H_v$ 为路由分并归一化得权重 $w_v$，按总预算 $K$ 分配各视图预算 $K_v=\max(1,\text{round}(Kw_v))$——分布越集中（信号越明确）的视图获得越多预算。
- **Beam Search**：每个视图内逐层搜索，节点得分 = 归一化语义相似度与 BM25 词汇相关度的加权组合（系数 $\lambda$），最终取每视图 top-$K_v$ 叶节点，跨视图合并去重为证据集 $E_q$。
- **Fallback**：若 LLM 判定证据不足返回“no information”，回退到原始对话轮 $D_q$ 重新生成。

## 9. 启示与展望

- **“解耦 + 对齐”可作为记忆系统的一般设计原则**：论文的价值不仅在于三视图本身，更在于提出“先区分信息类型，再为每类信息匹配表示与组织原则”的方法论；这一思路可迁移到关系记忆、任务记忆、多模态记忆等新视图的扩展。
- **检索预算显式化值得借鉴**：将检索视为跨视图的资源分配问题，并用分布熵刻画查询信号，为记忆检索提供了比“统一 top-k”更细粒度的控制手段；未来可探索学习型路由器或基于查询意图分类的预算策略。
- **工程机制与算法同等重要**：懒摘要更新、自适应阈值、结构参数重算等机制，使多视图记忆在 token 成本上具备可行性，提示后续研究应同时报告效果与构建/推理成本。
- **可延伸方向**：引入可学习或可增删的视图集合；对情感与偏好建模引入更细粒度维度（强度、时效性）；加入记忆遗忘、冲突消解与隐私控制；在更大规模、跨领域与多模态对话上验证；结合显著性检验与统一重跑的基线，进一步提升结论可信度。

## 10. 总体评价

ETAMem 针对长期对话记忆中的“信息纠缠”与“组织失配”提出了目标明确、结构完整的解决方案：以 AMU 为原子单元解耦异构信息，以 Event/Affect/Time 三视图实现表示与组织的双重对齐，并以熵基路由和懒维护机制兼顾效果与成本。实验在兩個主流基准上取得明显领先，消融与补充分析较充分地支撑了各设计选择的必要性。其主要不足在于对 LLM 与情感分类器的依赖、预设视图的覆盖边界、部分基线未统一重跑以及部署层面信息缺失。总体而言，该工作为结构化长期记忆提供了一条清晰且可复现的设计路线，具有较强的参考价值。
