## 摘要
LLM智能体需要长期记忆，以便从不断增长的交互历史中恢复精确且相互一致的证据，尤其是当答案依赖于事实之间的关系而非孤立的语义匹配时。当前记忆流水线在两个阶段仍然脆弱：索引错误可能将重复实体碎片化或将不同实体合并；在线检索往往将初始相似度分数视为最终结果，即使周围图提供了修正这些分数的证据。我们提出ActionRAG，一种将谨慎索引与查询时图重评估相结合的图记忆架构。其索引流水线协调类型标签并应用分层实体消解。给定查询时，双通道实体与三元组检索形成初始证据集并导出有界局部图。查询条件化的接收端归一化扩散利用局部路径结构精炼三元组分数。种子保护、枢纽惩罚通量和三元组物化在恢复遗漏连接的同时保留直接证据。我们在MemoryAgentBench（MAB）上评估ActionRAG，该基准测试准确检索、冲突解决、长程理解和测试时学习。在其八个确定性评分列上，ActionRAG达到55.1的平均准确率，比最强的基于检索的记忆基线提高5.4分。在MAB的查询时成本核算下，四个报告成本列上的平均合成成本保持在每查询低于\$0.001，并且在我们消费级Apple Silicon设备上，单独测量的检索侧p99分项之和为440.7 ms。

## Abstract
LLM agents need long-term memory that can recover precise and mutually consistent evidence from growing interaction histories, particularly when answers depend on relations among facts rather than isolated semantic matches. Current memory pipelines remain vulnerable at two stages: indexing errors can fragment repeated entities or merge distinct ones, and online retrieval often treats initial similarity scores as final even when the surrounding graph provides evidence for revising them. We introduce ActionRAG, a graph memory architecture that couples cautious indexing with query-time graph retroevaluation. Its indexing pipeline reconciles type labels and applies tiered entity resolution. Given a query, dual-channel entity and triple retrieval forms an initial evidence set and induces a bounded local graph. Query-conditioned receiver-normalized diffusion refines triple scores using local path structure. Seed protection, hub-penalized flux, and triple materialization preserve direct evidence while recovering missed connections. We evaluate ActionRAG on MemoryAgentBench (MAB), which tests accurate retrieval, conflict resolution, long-range understanding, and test-time learning. Across its eight deterministic-scoring columns, ActionRAG achieves 55.1 average accuracy, improving over the strongest retrieval-based memory baseline by 5.4 points. Under MAB's query-time cost accounting, mean synthesis cost stays below \$0.001 per query on the four reported cost columns, and the sum of separately measured retrieval-side p99 components is 440.7 ms on our consumer Apple Silicon setup.

## 1. 核心问题与研究背景

- **总体问题**：LLM 智能体在多轮交互中不断积累信息，需要一种长期记忆机制，能够从持续增长的交互历史中**精确检索并保持证据一致**；当答案依赖多个事实之间的关系，而不是单条语义匹配时，这一需求尤其突出。
- **现有范式的两类缺陷**：
  - **稠密 RAG（扁平索引）**：把历史切块后逐块独立打分。单跳事实召回尚可，但多跳推理时各块被孤立评分，丢失跨块结构；冲突消解时，被取代的旧事实与覆盖它的新事实语义高度相似，嵌入向量难以区分。
  - **图结构记忆**：GraphRAG、LightRAG 采用浅层启发式遍历，速度快但多跳信号损失大；HippoRAG/v2 先用 LLM 抽取查询实体，再以实体为种子做 Personalized PageRank，虽提供联想式检索，但**每次图搜索前都要调用 LLM**，且检索依赖该次调用保留的实体，谓词级线索（未表现为显著命名实体的关系）可能激活不足。
- **索引阶段脆弱性**：抽取式建图易出现类型标签不统一、重复实体被碎片化、不同实体被错误合并，破坏后续检索的一致性。
- **在线检索脆弱性**：初始相似度分数常被当作最终结果，即使周围图结构已提供修正证据。
- **论文主张**：查询通常只触及记忆图中一个很小的局部区域；应把“语义检索”视为**候选提议**，再用**查询条件化的局部图扩散**做二次评估（retroevaluation），同时以“谨慎索引”保证图本身的质量。论文发表于 ACML 2026（PMLR 353）。

## 2. 方法论

### 2.1 核心思想
- 将**持久化记忆构建（离线索引）**与**查询局部检索（在线精炼）**解耦。
- 离线：把多轮交互历史转成带类型的实体—关系图，保留来源 chunk 回溯指针。
- 在线：实体与具体三元组**双通道**召回 → 诱导有界局部图 → 用接收端归一化扩散修正三元组分数 → 种子保护、剪枝、高流量三元组物化 → 打包为 `[fact #N]` 证据送入生成器。**检索全程不调用 LLM**。

### 2.2 谨慎图构建（离线索引）
- **结构化抽取与时间落地**：LLM 输出带类型的实体提及与有向 `(head, relation, tail)` 三元组及描述；类型词表作为**软约束**，允许提出更具体的新类型；日期、时长、时间短语写入实体/关系描述而非建节点；有会话时间戳时把“昨天/上周”等相对表述解析为绝对日期。
- **标签调和（label reconciliation）**：按名称与描述相似度对候选类型分组，尽量映射到已有规范类型，未匹配组注册为新类型；先解析别名链，再把类型映射应用到整批数据。
- **分层实体消解**：
  - 归一化名称相同且类型兼容的唯一节点 → 直接复用；
  - 否则仅当模糊名称匹配是**明显最优候选**时才复用；
  - 其余按“归一化名称 + 规范类型 + 描述相似度”分组，**在写入任何关系之前**每组只建一个节点，避免并行 worker 产生重复节点；
  - 重复观测合并到同一条边，每个图项保留源 chunk 链接。
- **时序图摘要**：对多次提及支持的节点/关系做层次化摘要，保留日期与源链接，并重新嵌入；图提供紧凑语义表示，原始证据仍可回溯。

### 2.3 查询时证据精炼（在线检索）
- **双通道提议**：查询编码一次，分别在实体描述与具体三元组描述上做近邻搜索，取并集后做有界扩展，得到初始项集 \(V_0\)（项 = 三元组或孤立实体）；种子分数 \(s_i=\max(0,\cos(z,\phi(v_i)))\)。
- **查询条件项图**：在 \(V_0\) 端点周围取有界实体图；对三元组 \(\tau\) 定义相关性 \(r_\tau=\cos(z,\phi(\tau))\)、正相关 \(r^+_\tau=\max(0,r_\tau)\)、遍历代价 \(c_\tau=\max(\delta,1-r_\tau)\)。对项对 \((v_i,v_j)\)，在跳数上限 \(H\) 内找最小代价路径 \(\pi_{ij}\)，长度 \(d_{ij}\)，路径相关性取路径上最大正三元组相关性，共享端点时 \(r_{ij}=1\)。亲和度：
  \[
  A_{ij}=\exp(-\beta d_{ij})\,r_{ij}\quad(i\neq j,\ d_{ij}\le H),\ \text{否则 }0
  \]
  即“短路径 + 查询相关证据”才产生强交互；遍历代价负责选路，跳衰减限制长桥。
- **接收端归一化扩散**：\(D=\mathrm{diag}(A\mathbf{1})\)，\(P=D^{-1}A\)（孤立项整行为零），
  \[
  x=\alpha s+(1-\alpha)Px \;\Rightarrow\; x=\alpha\big(I-(1-\alpha)P\big)^{-1}s
  \]
  每个项把自身语义证据与邻居的“相关性加权平均”结合；归一化在**接收端**完成，使算子成为证据平滑器而非概率质量传输；\(\alpha\in(0,1)\) 时谱半径 \(<1\)，不动点唯一、闭式解良定义。
