## 摘要
主动式LLM智能体从持续观测与积累的历史中预判服务机会。现有方法侧重近期上下文或相关记忆的检索，难以为验证反复出现的行为规律并评估其与当前事件的相关性提供充分支持。我们提出主动记忆（ProactMem），将历史组织为近期事件、时间轨迹与行为规律。轨迹事实会与源事件进行核验，行为规律则通过历史回放进行评估，然后再与当前条件进行匹配。我们还构建了ProactiveStream，这是一个覆盖三种应用范围的纵向基准，其中智能体在具备情节感知机会标签的条件下按时间顺序处理孤立的事件流。在ProactiveStream上，ProactMem取得52.6%的总体有效性（F1），相较五个外部基线中最强基线实现21.4%的相对提升。代码见：https://anonymous.4open.science/r/ProactMem-5351/。

## Abstract
Proactive LLM agents anticipate service opportunities from ongoing observations and accumulated history. Existing approaches emphasize recent context or retrieval of related memories, providing limited support for validating recurring behavioral regularities and assessing their applicability to the current event. We propose Proactive Memory (ProactMem), which organizes history into recent events, temporal trajectories, and behavioral regularities. Trajectory facts are checked against source events, and regularities are assessed through historical replay before being matched to current conditions. We also construct ProactiveStream, a longitudinal benchmark covering three application scopes, where agents process isolated event streams chronologically under episode-aware opportunity labels. On ProactiveStream, ProactMem achieves an overall effectiveness (F1) of 52.6%, a 21.4% relative improvement over the strongest of five external baselines. Code is available at: https://anonymous.4open.science/r/ProactMem-5351/.

- **现有方法的不足**：
  - 现有工作（如 ProactiveAgent、ContextAgent、Mem0、A-MEM、Graphiti）主要依赖**近期上下文**或**相关记忆检索**；
  - 这类方法难以**验证反复出现的行为规律**（如“用户通常在傍晚散步”），也难以判断这些规律**是否适用于当前事件**；
  - 在单一事件流中，还需要同时评估记忆累积、当前适用性与机会变化，这构成核心挑战：**如何把积累的历史转化为可靠证据，用于决定何时提供协助？**
- **论文整体含义**：提出“主动记忆”框架 ProactMem，并配套构建纵向事件流基准 ProactiveStream，试图让智能体在长时历史中提炼并验证可复用的行为证据，从而更精准地识别服务机会、减少误打扰。

## 二、方法论（核心思想与关键技术细节）

### 核心思想
- 将智能体历史组织为**三个互补的记忆层**：近期事件（Event Memory）、时间轨迹（Temporal Trajectory Memory）、行为规律（Behavioral Regularity Memory）；
- 记忆构建阶段强调**来源保真**（source fidelity）与**历史支撑**（historical support）双重校验；
- 决策阶段将当前观测与适用历史证据结合，经**上下文评估 + 干预控制**后输出“介入/弃权”决定。

### 三层记忆构建
1. **有界事件记忆**：保留最近原始粒度事件，时间窗口 Δ=72 小时、容量 K=100（即最多 99 条历史 + 当前事件）；另有独立缓冲保留当日已提交事件用于轨迹构建。
2. **事实校验的时间轨迹记忆**：每个本地日结束时，LLM 将当天事件汇总为带区间、类型化事实与来源引用的轨迹片段；校验条件为
   - `F(d) ⊆ ∪_{e∈E(d)} F(e)`（轨迹事实须被源事件覆盖）
   - `E(d) ⊆ E_u^{completed day}`（引用事件须属于同一实体当日已完成事件）
   - 校验实体、区间、引用与规范化标量值，拒绝无支撑细节，防止错误传播到后续规律。
3. **回放评估的行为规律记忆**：每周合并 7 条日记录，LLM 提出触发条件 g、期望行为 p、时间窗口、可选星期限制与来源日 ID；通过历史回放计算：
   - 置信度 `conf_replay = nf / (nf + nv)`（nf 为满足日数，nv 为违反日数）
   - 提升度 `lift = conf_replay / base(p)`（base 为同等时间/星期限制下行为的基准频率）
   - 激活门槛：`nf ≥ 3`、`confidence ≥ 0.5`、`lift ≥ 1.0`；缺失观测记为删失（censored），不适用的日子排除，每个日期最多计一次。
   - 生命周期：连续 2 次违反 → weakening（降低检索优先级）；4 次 → dormant；满足观测可恢复 active。

### 检索与决策
- **规律检索**：匹配同实体触发上下文、星期与时间适用性（30 分钟提前 + 宽限），排除已满足（fulfilled）与删失（censored）状态，按发生状态、生命周期、置信度、时间距离排序取 Top-3。
- **决策上下文**：`Ct = (et, St, Wt, Rt, Qt)`，即当前事件、近期事件、轨迹、选中规律与可观测情节状态。
- **干预控制**：将提议服务与历史已允许干预比较，重复项转为 abstain；状态变化、服务标识变化、规律变化或跨本地日可重新评估；所有介入均源于 LLM 提议。
- **因果执行顺序**：当前事件先决策、后提交入记忆，记忆维护只影响后续决策，保证无未来信息泄漏。

## 六、主要结论与发现

- **总体效果**：ProactMem 总体 F1 达 **52.6%**，较五个外部基线中最强者**相对提升 21.4%**；三个范围的 effectiveness 与 balance 均优于全部外部基线。
- **分范围表现**：
  - Sports：更“选择性”，relevance 35.8%、intrusion 46.1% 优于 Mem0（覆盖高但误报多）；
  - Home：coverage 73.7%、F1 58.6%，显著高于基线，且误报低于高频的 A-MEM/Graphiti；
  - Code：coverage 89.7%、F1 55.4% 最高，Mem0 误报更低但机会恢复大幅减少。
- **模型缩放**：从 Luna → Terra → Sol，effectiveness 上升、intrusion 下降，说明更强骨干同时改善规律构建与使用。
- **记忆层作用**：加入轨迹记忆在各范围提升 effectiveness（Code 提升最大），主要贡献于机会恢复；完整三层进一步降误报。
- **校验机制作用**：去掉回放门控或轨迹校验均降低 relevance 与 effectiveness，去掉回放门控的下降更大；Code 上轨迹校验与更少误报相关。
- **干预控制**：Code 上抑制去掉 66 个假阳性、17 个真阳性，提升 relevance/F1 但降低 coverage（99.4% → 89.7%），体现覆盖与选择性的权衡。
- **核心发现**：在多个时间尺度上维护经过验证的历史证据，能在恢复更多服务机会的同时减少误打扰。

## 七、优点（方法与实验设计亮点）

- **分层记忆设计清晰**：近期事件 / 时间轨迹 / 行为规律三层职责分明，兼顾原始细节与抽象规律。
- **双重校验机制**：轨迹的“来源事实校验”+ 规律的“历史回放（置信度 + lift + 支撑数）”有效抑制无支撑信息传播，lift 的设计能区分“高频行为”与“真正由触发条件驱动的行为”。
- **因果与隔离严谨**：实体隔离、当前事件先决策后入库、标签离线拼接，避免未来信息泄漏。
- **基准设计有针对性**：纵向事件流 + 情节感知标签 + 首个可行动窗口标注，贴近真实主动服务的时序特性；同时评估机会恢复与打扰成本（intrusion），避免单一指标误导。
- **实验分析细致**：除主对比外，还做了模型缩放、跨家族、两层消融、参考敏感性、情节级诊断与干预控制分析，并对标签敏感性诚实披露。
- **可复现性**：公开代码链接，附录详述字段处理、生命周期转移、接口配置与流选择规则（SHA256 固定种子）。

## 八、不足与局限

- **场景覆盖有限**：仅涵盖 Sports、Home、Code 三类**低风险**场景；医疗、高风险安全决策需单独验证与防护。
- **评估独立性不足**：基准与方法为联合开发后固定协议，缺少独立留出评估与跨模型家族的构造记忆迁移验证。
- **标签主观性与敏感性**：参考标签依赖标注协议，独立团队重标注后 Home/Code 的绝对效果明显下降，说明绝对分数对“何为可行动机会”的定义敏感。
- **诊断分析的局限**：Code 抑制诊断固定后续状态，非真正顺序对比；情节诊断依赖参考构建与语义匹配，属探索性结果。
- **回放的前瞻性未验证**：历史回放评估的是已观测支撑，行为变化下的前瞻有效性仍需进一步研究。
- **指标为离线代理**：仅评估机会检测，未测量接收者实际收益、打扰负担、端到端成本与部署安全性。
- **算力与成本信息缺失**：未报告推理调用量、成本或硬件资源，难以评估实际部署开销。
- **泛化性待验证**：更广泛人群、观测条件与模型家族的泛化仍需额外实验。
