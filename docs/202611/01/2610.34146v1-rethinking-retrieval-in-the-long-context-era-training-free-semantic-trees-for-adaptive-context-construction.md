## 摘要
长上下文语言模型日益能够处理整篇文档，使全上下文提示成为段落检索的一种实用替代方案。然而，更大的容量决定模型能接收多少信息，而不决定哪些信息最能支持查询。这一区别促使我们重新思考检索：当完整文档已能容纳时，选择并组织其中的证据能否提升问答表现？挑战在于保留支撑事实与关系，同时使上下文聚焦于问题。为协调这些目标，我们提出了本文方法，一个免训练框架，利用语义抽象指导选择，同时保留原文用于回答。本文方法在一次生成中从完整文档构建可复用的语义层次结构，将节点描述链接到源文本片段。给定查询时，结构—语义评分和细粒度词汇归因共同提名共享源节点；这些节点与祖先上下文的并集保留了结构关系和完整的局部文本。在四个前沿答案模型上，本文方法在三个 LongBench 任务上相比全上下文提示将平均 QA-F1 提升 1.72 分，在四模型平均值上超过所评估基线，同时将答案上下文长度减少 58.55%。代码可在 https://anonymous.4open.science/r/treefuse-ECFE 仓库获取。

## Abstract
Long-context language models can increasingly process entire documents, making full-context prompting a practical alternative to passage retrieval. However, greater capacity determines how much information a model can receive, but not which information best supports a query. This distinction motivates rethinking retrieval: when the full document already fits, can selecting and organizing its evidence improve answering? The challenge is to retain supporting facts and relations while keeping the context focused on the question. To reconcile these goals, we introduce \ours, a training-free framework that uses semantic abstraction to guide selection while retaining original text for answering. \ours constructs a reusable semantic hierarchy from the full document in a single generation, linking node descriptions to source spans. Given a query, structural--semantic scoring and fine-grained lexical attribution nominate shared source nodes; their union with ancestor context preserves structural relations and complete local text. Across four frontier answer models, \ours improves average QA-F1 by 1.72 points over full-context prompting on three LongBench tasks, surpassing the evaluated baselines on the four-model average while reducing answer-context length by 58.55\%. Our code is available at the $\href{https://anonymous.4open.science/r/treefuse-ECFE}{repository}$.
