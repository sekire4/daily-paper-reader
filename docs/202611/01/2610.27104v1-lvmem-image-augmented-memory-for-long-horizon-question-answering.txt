# LVMem: Image-Augmented Memory for Long-Horizon Question Answering 

Victoria Khoruzhaya 1, Maksim Kalmykov 1, Tuong Do Minh 1, Tatiana Zemskova 1,2, Yixin Zhu 3, Dmitry Yudin 1,2

Abstract — Reliable language-guided perception is essential for embodied agents, where questions about objects, events, and their locations must be answered from long observation histories. Unlike conventional visual question answering, real-istic robotic settings require reasoning over extended temporal horizons and persistent scene memory. We build upon the view-based memory paradigm and propose an efficient framework for long-horizon spatio-temporal question answering. While existing view-based systems typically store either text captions or visual embeddings, we extend the ReMEmbR-style memory with image paths that link each stored description to its original visual content. To make the stored annotations more informa-tive, we replace uniform sampling during memory construction with an optical-flow-based frame selection strategy (PSFR) and store an object-centric descriptive scene representation instead of plain captions. We further equip a VLM-based agent with an adaptive retrieval tool that returns the image associated with the most relevant caption, allowing the agent to decide when visual inspection is needed. On the OC-NaVQA benchmark, LVMem outperforms ReMEmbR on binary and positional metrics with both backbones and matches or exceeds a 4D scene graph DAAAM baseline on binary accuracy, while operating on a lightweight view-based memory that requires no explicit graph construction. Our code is available at https://github.com/comprock15/LVMem. 

I. I NTRODUCTION 

Embodied agents that operate over hours or days accumu-late vast streams of visual experience. A warehouse robot, for example, may be asked: “Which shelf had the damaged box?” or “What did the loading dock look like when you passed it?”. Answering such queries goes beyond retrieving a text snippet: the agent must recall what it actually saw, where, and when. This demands a memory that preserves visual evidence across long horizons, remains spatially and temporally consistent, and can be queried efficiently as it grows. We formalize the problem of long-horizon spatio-temporal question answering as follows. Given a continuous stream of RGB observations with associated poses and timestamps, and a natural language query about objects, events, or states in the environment, the goal is to produce an accurate answer. This requires building a memory representation from the observation stream and reasoning jointly over visual appearance, spatial locations, and temporal ordering.

This challenge becomes especially difficult in realistic robotic scenarios, where the environment evolves over time and the robot must reason over extended temporal hori-zons. A robot may observe the same object from multiple viewpoints, encounter changes in object locations, and need to combine information collected at different moments in time. Multimodal large language models have demonstrated strong capabilities in visual reasoning and language under-standing [1], [2], but they still struggle with long video sequences [3], [4], persistent scene memory [5], and effi-cient retrieval of relevant information from large observation histories. Structured scene representations offer a promising direc-arXiv:2610.27104v1 [cs.CV] 19 Oct 2026 tion for addressing these limitations. In particular, scene graphs provide a compact and interpretable representation of objects, their attributes and interactions [6], and have been extended to dynamic 4D settings where nodes correspond to entities, edges encode semantic and spatial relations, and temporal information captures scene evolution [7], [8]. Recent approaches such as DAAAM [9] have explored 4D scene graphs for robotics, yet they rely on explicit geo-metric reconstruction and per-object description generation. Such representations are attractive for robotics because they support persistent memory and enable reasoning across long horizons. However, constructing and maintaining explicit 4D scene graphs in large-scale environments remains computa-tionally demanding. An alternative line of work stores annotated observations in a structured memory index, such as a vector database, which can be queried efficiently without explicit 3D re-construction. Recent approaches like ReMEmbR [10] have shown promising results on spatio-temporal question answer-ing using this paradigm, achieving efficient retrieval through text-based indexing of frame annotations. However, these methods rely solely on textual descriptions for retrieval and reasoning, which limits the agent’s ability to verify visual details or resolve ambiguities that require direct inspection of the original image content. In this work, we build upon the view-based memory paradigm of ReMEmbR [10] and propose an extension that improves long-horizon question answering by providing the agent with access to visual evidence beyond textual descriptions and by selecting more informative frames during memory construction. Our contribution can be summarized as follows:  

> •

We introduce LVMem, a view-based framework for long-horizon spatio-temporal question answering over recorded robot observations. LVMem represents obser-vations as object-centric scene descriptions and links each to its source image, timestamp, and pose, equip-ping a VLM agent with a selectively invoked visual retrieval tool. This enables the agent to inspect visual details omitted from the stored descriptions while retain-ing text-, position-, and time-based access to memory, without explicit 3D reconstruction.  

> •

We propose motion-guided memory construction under a fixed frame budget by integration of the existing Patchwise Sparse-Flow Retention (PSFR) method into segment-level scene description generation and evaluate it against uniform sampling with identical segment lengths and frame counts. With six frames per 10-second segment, PSFR improves binary accuracy by 8.96 percentage points and reduces mean positional error from 89.98 m to 68.16 m, demonstrating the importance of frame selection for downstream memory-based question answering.  

> •

Through comparisons with ReMEmbR and DAAAM methods and ablations on OC-NaVQA, we examine how frame selection, visual retrieval, text retrieval depth, and scene description configuration affect answer quality. LVMem improves binary and free-form text ac-curacy over ReMEmbR by 10.95 and 15.15 percentage points with Qwen3.5-9B, and by 19.90 and 5.05 points with GPT-5-Mini, respectively. Our ablations further show that visual augmentation depends on retrieval con-text: additional images can improve descriptive answers while degrading positional estimates or destabilizing temporal predictions. II. R ELATED WORK 

Long-horizon embodied question answering requires rea-soning over extended observation histories, where relevant evidence may be sparse and distributed across time. Existing approaches differ mainly in how they represent, retain and retrieve this information. 

A. Long-Horizon Question Answering 

Recent MLLMs perform well on short clips but degrade as observation histories grow beyond the available context window. VideoARM [11] performs agentic reasoning over a hierarchical memory for long-form video understanding. Benchmarks such as FindingDory [12] and HourVideo [4] highlight the difficulty of retrieving sparse evidence over long temporal horizons. Spatial reasoning remains challeng-ing: GPT4Scene [1] and ST-Think [2] study scene-level and 4D reasoning, while Spatial4D-Bench [5] and Video-MSR [13] expose persistent weaknesses in spatio-temporal reasoning. Other approaches encode structure directly into video representations: Video-3D LLM [14] introduces 3D-aware position encoding, and LITA [15] uses explicit time tokens for temporal localization. Both require end-to-end training tied to a specific backbone, and such representations are typically consumed within the model context rather than retained as persistent, independently queryable mem-ory. OnlineSI [16] moves toward persistent spatial memory through incremental semantic reconstruction, but its bounded representation is still passed directly to the language model rather than selectively queried. 

B. Scene Graphs and Knowledge Representations for Robotics 

Scene graphs explicitly organize observations into persis-tent spatial and semantic structure. HOV-SG [17] constructs hierarchical open-vocabulary graphs over floors, rooms, and objects, while ConceptGraphs [18] associates multi-view 3D objects with open-vocabulary semantic descriptors and inter-object relations. Clio [19] extends hierarchical scene graphs to online, task-driven construction, and Khronos [20] models short-term motion together with long-term environ-mental change. GraphEQA [21] combines an online hierar-chical scene graph with task-relevant images for embodied question answering. Among structured-memory approaches, DAAAM [9] builds a hierarchical 4D scene graph for long-horizon spatio-temporal QA, while EGG [7] introduces explicit event nodes and VL-KnG [8] constructs spatio-temporal knowledge graphs from video without explicit 3D reconstruction. Such graph-based representations provide rich global structure but require explicit graph construction or maintenance. 

C. Knowledge Retrieval and Agentic Reasoning over Struc-tured Memory 

Persistent memory is only useful if relevant evidence can be retrieved efficiently. WorldMM [22], EventMemA-gent [23], and StreamReady [24] use episodic, semantic, or hierarchical memory for long-form reasoning, focusing on temporal abstraction rather than spatially grounded represen-tations. ReMEmbR [10] stores VLM-generated captions in a vector database and uses an iterative agent for text-, position-, and time-based retrieval, but the agent reasons only over stored textual descriptions. STaR [25] additionally retrieves keyframes for visual inspection through task-conditioned selection. Graph-based memories such as DAAAM [9], EGG [7], and VL-KnG [8] combine structured represen-tations with agentic or hybrid retrieval. Beyond retrieval, Surprise-Gated Memory [26] studies selective episode re-tention, while UQ-DAAAM [27] quantify uncertainty over object descriptions and actively refine them. A tension per-sists: text-based memories scale efficiently but may discard visual detail, whereas multimodal memories retain richer evidence that must be selectively retrieved and integrated. LVMem retains the lightweight ReMEmbR representation while linking retrieved descriptions back to their source images, enabling a study when visual evidence actually helps. III. M ETHOD 

We present a framework for long-horizon spatio-temporal question answering that extends the existing view-based memory system of ReMEmbR [10]. Rather than redesigning the memory from scratch, we augment it in three ways. First, we replace uniform frame sampling during memory construction with an optical-flow-based selection strategy (PSFR) [28]. Second, we replace the plain captions with an object-centric descriptive scene representation and augment the memory entries with image paths that point to the corresponding source frames. Finally, we equip the VLM agent with an adaptive retrieval tool that returns the images corresponding to the most relevant descriptions, enabling joint reasoning over textual and visual evidence (see Fig. 2). 

A. Memory Construction 

We follow the memory-building pipeline of Re-MEmbR [10], which splits a video stream S into fixed-length temporal segments {s1, . . . , s L}, each spanning T seconds. We introduce two modifications to this pipeline. First, instead of uniform frame sampling within each segment, we apply PSFR [28], a training-free optical-flow-based method that selects the most informative frames while discarding static or redundant content. C. Visual-Enhanced Answer Generation 

At the final reasoning step, we replace the LLM of ReMEmbR with a VLM that jointly processes retrieved texts and images. Before calling the VLM, the agent checks whether the image retrieval tool was invoked during the retrieval phase. If it was and the corresponding image paths were collected, these images are loaded and attached to the prompt; otherwise, generation proceeds in text-only mode. A. Dataset 

Following prior work [9], [10], we evaluate our approach on the OC-NaVQA benchmark [9]. The dataset comprises 7 video sequences from the CODa dataset [30], featuring 210 questions about the robot’s long-horizon navigation experience. Questions are categorized into spatial, temporal (point-in-time and duration), and descriptive (binary and text) types. For evaluation, we report Binary Accuracy (%), Text Accuracy (%, LLM-as-a-judge with Qwen3.5-0.8B), Positional Error (meters), and Temporal and Duration Errors (minutes) for all categories. 

B. Baselines 

We compare our approach against two baselines: Re-MEmbR [10] in its original configuration (VILA1.5-3b [31] captioner, original prompt) and DAAAM [9]. LVMem in-stead uses the object-centric descriptive scene representation (Qwen3.5-9B, structured prompt) and its retrieval tool returns the images linked to the 5 most relevant scene representa-tions. We evaluate all methods with two VLM backbones: Qwen3.5-9B and GPT-5-Mini, to analyze the impact of the reasoning agent. We use SGLang [32] for local inference of open-source VLMs and OpenRouter for API-based access to proprietary models. 

C. Results 

Table I reports the comparison on OC-NaVQA. LVMem outperforms ReMEmbR on binary and text accuracy with both backbones, and reduces positional error substantially in both configurations. With GPT-5-Mini, LVMem attains the highest binary accuracy among all methods and remains competitive on text accuracy, though its duration error is higher than DAAAM’s, while its temporal error falls be-tween ReMEmbR and DAAAM. With Qwen3.5-9B, LVMem improves over ReMEmbR on binary, text, positional, and temporal metrics; the two methods are close on duration errors. DAAAM with GPT-5-Mini achieves the strongest text accuracy and the lowest temporal and duration errors, but it is highly sensitive to the choice of backbone: switching to Qwen3.5-9B substantially degrades its binary and text accuracy, below both ReMEmbR and LVMem. LVMem, in contrast, remains stable across backbones and improves with Qwen3.5-9B on binary and positional metrics, while ReMEmbR shows the opposite trend, with GPT-5-Mini out-performing Qwen on text. This suggests that the optimal backbone depends on both the memory representation and the question type. Overall, LVMem offers the most consistent performance across backbones, while DAAAM achieves the strongest results only with GPT-5-Mini. Figure 3 illustrates a failure mode of text-only memory: when a question targets a fine-grained visual attribute, the stored description may omit it even if the corresponding observation was recorded. Here, both baselines store a de-scription of the sculpture but neither mentions its color, and DAAAM’s scene graph node, though linked to the correct object, describes only its reflective surface. LVMem avoids this failure because the adaptive retrieval tool lets the agent fetch the source frame and answer from the image itself, rather than from the stored text alone.

Attaching images at shallow retrieval depth improves bi-nary accuracy monotonically, with the gain growing as more images are added. At deep retrieval depth, however, the effect disappears: binary accuracy is flat across image counts. The two information sources therefore act as substitutes rather than complements — images supply information the agent otherwise lacks only when the textual context is shallow, and contribute little once the prompt already contains many descriptions. Positional error follows the opposite pattern. It is lowest with no images, at both retrieval depths, and increases once images are attached at every non-zero setting. The effect is systematic rather than run-to-run variation. We hypothesize that when images are present, the VLM shifts toward visual grounding and produces less accurate spatial estimates than when reasoning from the positional metadata embedded in the retrieved descriptions. Retrieval depth does not improve accuracy: moving from 

k = 5 to k = 20 leaves binary accuracy unchanged at every image count, and positional error improves only modestly. We therefore adopt k = 5 in all remaining experiments. Finally, we compare the adaptive tool against a variant that always attaches images from the last retrieved documents on every query. This non-adaptive variant attains competitive binary accuracy but suffers from a higher duration error. This confirms that selectively invoking the visual tool matters: indiscriminately attaching images to every query degrades temporal reasoning. Overall, a moderate number of images per tool call provides the best trade-off between accuracy and stability, while more images yield the highest binary accuracy at the cost of increased variance. The two configurations differ both in model capacity and in prompt design: VILA receives a generic free-form prompt from the original ReMEmbR codebase, while Qwen is guided by a structured prompt that enforces explicit object enumeration with colors from a fixed palette, prohibits negations and hedging language, and limits the output to 110 words. The structured output is post-processed into continuous prose to ensure consistent embedding. Binary accuracy improves with Qwen across all image settings, with the largest gain at one image. Positional error is also lower with Qwen at every image count, and both improvements exceed the run-to-run standard deviation, indicating a robust effect rather than an artifact of a particular configuration. The gain can be traced to the coverage of stored en-tities: VILA descriptions omit objects such as ATMs and police emergency poles that Qwen descriptions include. For questions about such objects, VILA-based retrieval returns irrelevant documents, while Qwen-based retrieval finds the correct entry, cutting positional error by up to an order of magnitude. Text accuracy, however, does not improve: VILA is higher in three of four image settings. Such questions require distinguishing between similar objects (e.g., “the bike rack closest to the trash can”), and mentions of common objects such as bike racks increase by an order of magnitude in Qwen descriptions, diluting retrieval and returning a plausible but incorrect entry. The structured prompt thus improves the inclusion of rare objects at the cost of disambiguation among frequent ones. Temporal error for Qwen at zero images is inflated by a single outlier of in one of the three runs; the remaining tem-poral and duration values are comparable between models and show no consistent advantage for either model. V. L IMITATIONS 

Our approach has several limitations. First, increasing the number of images returned by the visual retrieval tool does not monotonically improve performance. While additional images can help resolve queries that require fine-grained visual details, they also introduce noise: at five images per tool call, temporal error is dominated by outliers, and a non-adaptive variant that always attaches images to every query degrades duration estimation by several orders of magnitude. This confirms that selective invocation matters, but also that the number of images per call requires careful tuning. Second, the observed gains are concentrated on binary and free-form text accuracy, where LVMem improves con-sistently over ReMEmbR. Duration estimation, in contrast, shows no consistent improvement across backbones: LVMem is better with Qwen3.5-9B but worse with GPT-5-Mini. This is expected, since our method targets visual details that are lost in the stored descriptions, and such details matter most for descriptive queries. Finally, our method operates on a lightweight view-based memory and does not build an explicit 3D representation. This design choice reduces memory construction cost but may limit performance on questions that benefit from ex-plicit spatial or temporal structure: LVMem improves over DAAAM on binary and positional metrics with some back-bones, but remains behind on text accuracy and duration estimation. VI. C ONCLUSION 

We presented LVMem, a framework for long-horizon spatio-temporal question answering that extends the view-based memory of ReMEmbR with visual content and im-proved frame selection. We make three contributions: we augment the memory index with image paths that link each stored object-centric descriptive scene representation to its source frame, we introduce an adaptive visual retrieval tool that allows the agent to request images when textual descriptions are insufficient, and we replace uniform frame sampling with existing PSFR [28], an optical-flow-based strategy that selects more informative frames for scene description generation. On the OC-NaVQA benchmark, our method improves over ReMEmbR on binary, text, and positional metrics with both backbones, and substantially reduces temporal error, while remaining competitive with the 4D scene graph method DAAAM without requiring explicit graph construction. Ab-lations confirm that both PSFR and adaptive image retrieval contribute to these gains, and that indiscriminate image attachment degrades performance. These results suggest that visual augmentation of view-based memory is a practical and effective direction for long-horizon question answering, improving scene perception for embodied agents.
