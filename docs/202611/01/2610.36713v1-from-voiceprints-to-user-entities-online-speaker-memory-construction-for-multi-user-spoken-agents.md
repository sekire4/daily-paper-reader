## 摘要
个性化语音智能体必须先识别说话人，才能访问用户特定记忆，然而现有记忆基准通常假设历史记录已被正确归属。我们认为声纹是身份的观测，而非身份本身，并提出在线说话人记忆构建，以在声学证据不断演化时维护持久的用户实体。我们引入 EvoSpeakerMem，这是一个免训练层，用于因果说话人路由、选择性声学状态更新，以及通过可替换的文本记忆后端进行按身份分区的记忆写入与检索。我们还构建了 LoCoMo-ID，一个语音记忆基准，包含隐藏说话人身份、说话人敏感查询、模拟录音条件偏移以及四说话人身份混淆测试。在纵向 SMIIP-TV 上，在冻结的近注册阈值下，真实探针拒绝率在约一年内从 29.8% 升至 55.6%。在 LoCoMo-ID 的说话人敏感查询上，门控更新在干净和偏移条件下分别使身份门控问答相较固定表示提升 3.86 和 11.62 个百分点，且未出现错误用户授权。该优势在四说话人测试中依然存在。然而，减少碎片化与提升问答性能可能同时伴随错误的跨用户链接，揭示出仅靠问答无法捕捉的碎片化—污染权衡。

## Abstract
Personalized spoken agents must identify speakers before accessing user-specific memory, yet memory benchmarks typically assume correctly attributed histories. We argue that voiceprints are observations of identity, not identities themselves, and formulate online speaker-memory construction to maintain persistent user entities as acoustic evidence evolves. We introduce EvoSpeakerMem, a training-free layer for causal speaker routing, selective acoustic-state updates, and identity-partitioned memory writes and retrieval through a replaceable text-memory backend. We also construct LoCoMo-ID, a spoken-memory benchmark with hidden speaker identities, speaker-sensitive queries, simulated recording-condition shifts, and four-speaker identity-confusion tests. On longitudinal SMIIP-TV, genuine-probe rejection under a frozen near-enrollment threshold rises from 29.8% to 55.6% over approximately one year. On LoCoMo-ID speaker-sensitive queries, gated updating improves identity-gated QA over fixed representations by 3.86 and 11.62 percentage points under clean and shifted conditions, respectively, with no wrong-user authorizations. The advantage persists in the four-speaker test. Yet reducing fragmentation and improving QA can coexist with incorrect cross-user links, revealing a fragmentation--contamination trade-off that QA alone cannot capture.

## 一、核心问题与研究动机

- **背景定位**：个性化语音智能体（spoken agents）需要依靠用户画像与交互历史维持跨轮次、跨会话的一致性；但在共享语音环境中，系统必须先判断"这段话是谁说的"，才能决定把内容写入谁的记忆。
- **现有基准的盲点**：LoCoMo、LongMemEval、CarMem、VoxMem 等记忆评测大多假设历史记录已带有正确的参与者归属，主要考察"记忆读取"；而真实多用户智能体还必须先"构建历史"，即为每一段到来的语音解析身份并路由到对应用户记忆。
- **声纹不等于身份**：同一说话人的声学观测会随会话、环境、设备、用户状态（如疲倦、生病）而变化。论文援引说话人验证领域的会话变异、模板老化与自适应研究，以及 SMIIP-TV 的纵向录音证据，指出固定注册声纹作为长期身份键并不可靠。
- **身份错误是有状态的**：
  - 把回访用户误判为新用户 → 同一人的历史被拆散到多个档案（**碎片化 fragmentation**）；
  - 把两个用户混淆 → 一个档案被另一人的信息污染（**污染 contamination**），并影响后续个性化回答。
- **核心论点**：声纹是身份的"观测"（observations of identity），而非身份本身。据此论文提出**在线说话人记忆构建**（online speaker-memory construction）这一新问题：智能体在声学证据逐步累积的过程中，因果地创建、链接、更新持久用户实体，并把归属内容写入对应记忆分区。
- **相关工作缺口**：Audio LLM 在说话人验证、归属与"谁说了什么"的推理上仍显薄弱（MSU-Bench、M3-SLU、VoxMem）；PAChat、AFA、EgoMem、并发工作 VoxPolyMem 虽已把身份与个性化记忆相连，但不完美在线身份分配对持久记忆完整性的后果仍缺乏系统理解。

## 二、方法论

### 2.1 问题形式化

- 语音轮次 \(\{x_t\}_{t=1}^T\) 按时间顺序到达；时刻 \(t\) 只能观测当前音频 \(x_t\) 与已有状态 \(U_{t-1}\)，无说话人标签、不可见未来轮次。
- 状态由若干本地用户实体组成 \(U_{t-1}=\{u_1,\dots,u_K\}\)，每个实体
  \[
  u_k=(c_k,\ n_k,\ H_k)
  \]
  其中 \(c_k\) 为说话人嵌入中心，\(n_k\) 为归属观测计数，\(H_k\) 为从归属轮次抽取的原子文本事实。
- 路由决策 \(r_t\in\{u_1,\dots,u_K,\text{NEW}\}\) 同时决定身份归属与记忆分区。

### 2.2 在线声学实体路由（EvoSpeakerMem 核心）

- **嵌入与打分**：说话人编码器把音频映射为长度归一化嵌入 \(e_t\)；对中心式策略按余弦相似度打分
  \[
  s_{t,k}=\frac{e_t^\top c_k}{\|e_t\|\,\|c_k\|}
  \]
- **创建 / 链接规则**：若注册表为空，或最高分 \(s_t<\tau_{\text{merge}}\)，则用 \(e_t\) 初始化新实体；否则链接到最高分实体。
- **阈值设定**：\(\tau_{\text{merge}}\) 取参考语音上真伪评分等错误率（EER）工作点，并在整个在线过程中固定（LoCoMo-ID 中为 0.489，由 VoiceDesign 音色库校准）。
- **关键设计——分配与更新解耦**：无条件更新虽可适应声学漂移，但一次错误链接会被后续更新自我强化。因此中心仅在 \(s_t\ge\tau_{\text{update}}\)（且 \(\tau_{\text{update}}>\tau_{\text{merge}}\)）时才修改：
  \[
  c_k\leftarrow\frac{n_k c_k+e_t}{n_k+1}
  \]
  计数 \(n_k\) 在每次被接受的 LINK 上都增加（即使中心未变），使一轮语音可以贡献文本事实而不改变未来匹配所用的声学表示。文中 \(\tau_{\text{update}}=0.58\)。
- **三种维护策略对比**：
  - **FIXED**：永久保留首个嵌入；
  - **UPDATE**：每次 LINK 都更新中心；
  - **GATED UPDATE**：仅在满足更严格阈值时更新。
- **多示例变体（All-exemplar KNN）**：保存被接受的历史嵌入集合 \(E_k\)，以 top-\(\min(m,|E_k|)\) 个余弦相似度的均值打分（\(m=5\)，最多存 20 条），嵌入只在身份分配之后追加。

### 2.3 语音支撑层与记忆构建流水线

- **写入路径**：每轮语音由 Audio LLM 生成转录，同时由说话人嵌入模型提取声学身份证据；路由器判定归属到已有实体或新建实体；随后将"转录 + 实体 ID + 时间戳"交给**可替换的文本记忆后端**（LightMem），在其对应用户的记忆分区内抽取并索引原子事实。
- **解耦原则**：转录语义不参与声学路由与中心更新，避免文本内容反向影响身份判断。
- **读取路径**：查询时对注册表做只读声纹匹配，识别请求者实体并**硬性限制**检索到该实体分区；不匹配的请求不返回任何个人记忆。同一实体 ID 同时统管写入与读取。
- **免训练性**：整个层不需要训练，路由由确定性工具完成；LLM 的角色只是按提示调用 `extract_segment_embedding` 工具，不得自行猜测说话人身份。

## 三、实验设计

### 3.1 数据集与场景

  - 静态验证：按注册—探针时间间隔分桶，报告 EER 与 Below-\(\tau\)；
  - 因果多用户回放：组织成 2–4 人的流，覆盖 6 种时间/环境/状态变化条件，每条件 5 个随机种子。
- **LoCoMo-ID（本文新建基准）**：
  - 保留 LoCoMo 10 段历史、5,882 轮、1,986 条 QA 与参考答案；

  - **语音合成**：Qwen3-TTS VoiceDesign 生成候选音色，ECAPA 多样性筛选保留 120 中的 50 个；Qwen3-TTS Base 克隆合成历史与查询；每段对话 3 套音色分配 → **30 个干净集合、17,646 条历史音频轮、5,958 条查询音频**；

  - **录音条件偏移**：按会话确定性地施加房间冲激响应卷积、设备带宽滤波、增益控制、噪声混合与峰值归一化，保留文本、说话人—音色绑定、轮次顺序与查询音频；
  - **四说话人交错压力测试**：保留原两人故事，另造结构相同但事实冲突的平行故事，共享角色名但使用不相交音色对，按会话边界交错，共 10 个干净集合、11,764 轮、40 个金标说话人；查询只指向原故事事实，正确答案依赖说话人分区而非文本姓名。

### 3.2 对比方法与指标

- **声学证据两种配置**：仅逐轮 ECAPA 声纹；Parakeet 会话内说话人日志（diarization）+ ECAPA 跨会话关联。
- **四种维护策略 × 两种证据模式 = 8 种策略**（FIXED / UPDATE / GATED UPDATE / All-exemplar KNN）。
- **路由指标**：采用"因果首见绑定"协议（实体首次创建时不可变地绑定金标说话人，仅用于事后评分），把每轮分为新说话人—CREATE、新说话人—LINK、已知说话人—CREATE、已知说话人—正确 LINK、错误目标 LINK 五类；报告 B³ F1、FNUR、Clusters/Gold、CREATE 精确率/召回率、LINK 精确率、已知用户解析召回率、Online ID 准确率。
- **下游指标**：全记忆 QA（不识别请求者、跨集合检索最多 60 条）、身份门控 QA（Top-1 授权为硬过滤，\(QA=\frac{1}{N_q}\sum \mathbb{1}[A_q=\text{correct}]J_q\)）、条件 QA（\(QA|Correct\)，仅在正确授权内计算）、正确/错误/拒绝授权计数 C/W/D。
- **后端配置**：Qwen3-Omni-30B-A3B-Instruct 负责转录、事实抽取、回答与 LLM-as-judge；bge-small-en-v1.5 做文本嵌入；Qdrant 向量库；LLMLingua-2 预压缩（rate 0.6）。
- **补充对比**：用更强的 ReDimNet2-B6 编码器在 205,765 条共同语句上复现静态验证与因果回放，检验结论是否依赖 ECAPA。
