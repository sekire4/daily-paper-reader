# DIA LONG : Benchmarking Reminiscence in Long-Context Dialogues

## Center for Language and Speech Processing, Johns Hopkins University 

## Abstract 

How well can transformer-based Large Lan-guage Models (LLMs) retain and recall mem-ories in long contexts of dialogue? LLMs are known to forget long-range factual informa-tion in their context, yet the field lacks a com-prehensive benchmark to quantitatively assess these shortcomings. We present D IA LONG , a long-context dialogue dataset and accompany-ing memory task that standardizes evaluation in this space. It consists of 100 unique conver-sations created by humans and then augmented with LLMs, extending beyond lengths found in existing datasets. Our selected memory task is fact recall: classify 40 candidate facts about a dialogue as true or false. This task directly probes the model’s ability to actively retain and retrieve information, serving as a critical mea-sure of memory within extended conversational contexts. In testing both the latest LLMs and proposed memory enhancements on D IA LONG ,we demonstrate that more work needs to be done to enable LLMs with better memory per-formance. By enhancing memory capabilities, LLMs can improve in maintaining coherence, relevance, and human-like interaction over ex-tended conversation. Improving these capabil-ities will help LLMs fulfill diverse user needs and expectations in various conversational sce-narios. 

## 1 Introduction 

Large Language Models (LLMs) are constrained by limited context length, which hinders their abil-ity to perform natural language processing tasks. They are deployed in various contexts and appli-cations (Brown et al., 2020), one notable example being conversational agents, which have recently seen a surge in popularity (OpenAI, 2022)(OpenAI, 2023)(Touvron et al., 2023). Chatbots powered by LLMs are conversational tools capable of under-standing and responding to human language effec-

tively. The unique application of LLMs in chatbots, as opposed to other NLP tasks, lies in their inher-ent requirement to mimic and produce human-like interactions during dialogues (Brandtzaeg and Føl-stad, 2017) (Johari and Nohuddin, 2021). Memory is an essential part of human conversation, allowing for context retention, coherent responses, and build-ing relationships over time. As defined by Zlotnik and Vansintjan, memory is the process of acquiring, storing, retaining, and retrieving information (Zlot-nik and Vansintjan, 2019). LLM-powered chat-bots inherently lack long-term memory when com-pared to humans, hindering their ability to maintain human-like conversation. Forgetfulness, the tendency of an LLM to lose track of earlier information, is a major limitation. This problem is exacerbated with long contexts, arXiv:2610.25463v2 [cs.CL] 20 Oct 2026 as anything bumped outside of the context win-dow is immediately forgotten. Directly from Ope-nAI’s API documentation, tokens that do not fit within a model’s limit are lost 1. This is one of the most significant challenges faced by modern LLMs, their performance in long contexts. It is clear that the limited context window is the main culprit of forgetfulness, as depicted in Figure 1. A popular approach to address this problem is extend-ing the attention window (Vaswani et al., 2023) (Chen et al., 2023b) (Su et al., 2023). The premise is that by enabling a model to process more ex-tensive contexts during inference, it enhances its capability to store, retain, and recall information, thereby extending its memory reach. This approach is limited for two reasons. Firstly, contexts in general, especially conversations, can carry on for extremely long periods of time, which would re-quire an impractical length context window. This is infeasible because extremely long context win-dows demand excessive computational resources (Chen et al., 2023c), stemming from the quadratic complexity of self-attention computation (Vaswani et al., 2023). Additionally, it has been shown that merely extending the context window results in a considerable degradation in performance for longer contexts (Liu et al., 2023). Another culprit for the lack of performance with conversational data is that dialogue presents an-other problem to LLMs. Conversational prob-lems are uniquely challenging in that the corpus of knowledge from which the LLM must use to re-ply grows continuously. It requires more than just memorization of a training dataset to do well on such tasks, it additionally requires a clever use of the never-before-seen dialogue between the chatbot and the user during inference time. An approach to address both this and the limited context window is to augment the LLMs with a memory solution such as those discussed in Section 2. These solutions ap-pear to work at the surface, but we demonstrate that they do not evaluate as rigorously as they should. Current conversational datasets and methods of evaluation do not focus on both long contexts and memory, and are not a good fit for evaluation of such conversational models.

Beware that if a message is removed from the messages input, the model will lose all knowledge of it.“ (OpenAI, 2023)

We introduce D IA LONG , a long-context dia-logue dataset accompanied by a novel memory benchmark, specifically designed to rigorously evaluate the capacity of current LLMs and emerg-ing memory solutions to sustain and retrieve infor-mation across prolonged dialogues. This endeavor underscores a crucial gap in existing methodolo-gies, which predominantly assess models using considerably shorter dialogues, insufficient to cap-ture the intricacies of extensive conversational con-texts. Our comprehensive evaluation reveals a pressing need for advancing research to enhance LLMs’ memory functions, emphasizing that signifi-cant improvements are imperative for these models to achieve and sustain coherence, relevance, and human-like interactions over lengthy conversations. Through D IA LONG , we aim to catalyze the devel-opment of LLMs that are not only more adept at handling long-context dialogues but also capable of delivering outputs that are coherent, accurate, and trustworthy, thereby better meeting the complex needs and expectations of users in diverse conver-sational scenarios. 

## 2 Related Work 

Relevant literature can be separated into a few main categories. We highlight and discuss prior work on the problem of a limited-context window for LLMs. We then discuss some of the work that has been done towards solving these issues. First, we highlight research focusing on the performance of models on a variety of tasks in long contexts. Next, we cover the main themes and proposed solu-tions which enable increased memory capabilities in long contexts, especially those beyond the con-text window. We then mention existing dialogue datasets and show that while they are great for their specific scenarios, a new dataset is needed to evalu-ate memory abilities in long-context settings. This brings us to the creation of D IA LONG .

Similarly, ‘Lost in the Middle: How Language Models Use Long Contexts‘ (Liu et al., 2023) authors find an unwanted U-shaped performance curve in LLMs, where the models process information well at the beginning or end of a context, but struggle with details in the mid-dle. These results highlight a notable performance degradation as context windows expand and pro-vide further motivation for work beyond merely extending the context window. 

Remembering in long contexts. In order to mit-igate these struggles, researchers have employed many strategies. Recent advancements in efficient attention mechanisms are addressing such limita-tions of processing long inputs. Techniques like Luna (Ma et al., 2021), alternative attention mecha-nisms (Shen et al., 2020)(Li et al., 2020), Transient Global (Guo et al., 2022), CoLT5 (Ainslie et al., 2023), Focused Transformer (Tworkowski et al., 2023), and LM-INFINITE (Han et al., 2023) en-hance LLMs’ ability to handle extended sequences, with some claiming to enable up to 256k tokens. In-novations such as the Synthesizer (Tay et al., 2021), fixed-size memory attention (Britz et al., 2017), and dilated attention (Ding et al., 2023) further optimize processing efficiency and improve perfor-mance with significantly longer input contexts than base models. Other researchers are exploring positional embedding schemes to enhance the ability of Transformer-based LLMs to generalize to longer sequence lengths than those encountered during training. Techniques like Absolute Positional Em-beddings (Vaswani et al., 2023), Relative Positional Embeddings (Shaw et al., 2018) (Huang et al., 2018) (Dai et al., 2019) (Chen et al., 2023b), Rotary Position Embeddings (Su et al., 2023), and ALiBi (Press et al., 2022) (Workshop et al., 2023) aim to improve LLMs’ handling of longer sequences by modifying how positional information is integrated. Despite these advancements, the effectiveness of these schemes in enabling LLMs to effectively re-member and perform in long contexts varies, with some showing promising results in specific tasks, while others struggle with length generalization (Taylor et al., 2022) (Kazemnejad et al., 2023) (Anil et al., 2022). Beyond the scope of Transformers, researchers are exploring alternatives tailored for efficiently handling long contexts without relying on tradi-tional attention and positional embeddings. Tech-niques like state space models (SSMs) (Fu et al., 2023), the Hyena operator (Poli et al., 2023), and the Block-State Transformer (Fathi et al., 2023) are being developed to process extended sequences with near-linear computational complexity, improv-ing long-range recall and token comparison. Ad-ditionally, recurrent neural network (RNN) based approaches, such as the Receptance Weighted Key Value (RWKV) (Peng et al., 2023), leverage RNN architectures, combining Transformer-like paral-lelization with RNN efficiency, to effectively man-age long sequences in large-scale models. 

Remembering beyond context window. The fol-lowing papers are all proposals augmenting LLMs with some sort of memory solution. Often, these systems will incorporate context that has occurred beyond the context window, crucial for the problem we are talking about. In many cases, the solution is some form of retrieval augmentation, as is discussed by Shus-ter (Shuster et al., 2021). Zhu et al. A few retrieval augmented genera-tion techniques include a self-retrieval model (Ru-bin and Berant, 2023), a recursive summarization technique (Wang et al., 2023a), a self controlled memory system (Liang et al., 2023) and the cre-ation and querying of a memory tree (Chen et al., 2023a). It is clear that this problem is well recognized in the research community. We applaud the work and efforts made by the various researchers to solve the memory problem of LLMs. However, these proposed solutions all lack a benchmark evaluation methodology with which to prove their efficacy at remembrance in long contexts. 

Existing dialog benchmarks. Dialogue datasets with which to evaluate come in a variety of forms. The Persona-Chat dataset is one of the most well known datasets for dialogue (Zhang et al., 2018). Turkers were given a set of personality traits and told to converse with another Turker based on their written personality. The result was a collection of short human-written dialogues. This work was extended into MultiSessionChat (Xu et al., 2021), where two Turkers were given an original Persona-Chat entry and told to continue the conversation. The result is a human written, 4 session, up to 14 utterance dialogue dataset. While this is an increase in length, this is still too short for eval-uating memory in long contexts. We find similar problems in all other dialogue datasets, where they do not include enough context to be constituted as “long“(Lowe et al., 2015) (Li et al., 2017) (Sun et al., 2019) (Rashkin et al., 2019) (Dai et al., 2022) (Kim et al., 2022) (Wu et al., 2022) (Lee et al., 2022). Additionally, (Shuster et al., 2020) presents dodecaDialogue which encompass 12 tasks to eval-uate various abilities of a conversational agent to interact with humans. All of these tasks are evalu-ated in short context settings and lack evaluation in long contexts. The main goal of our work is to provide a long-context dialogue dataset and accom-panying tasks to evaluate memory performance. ## 3 DIA LONG 

DIA LONG is a long-context dialogue dataset, parsed into four distinct sessions between two users, with an accompanying list of true and false facts about each session. 

MultiSessionChat. Building upon the Per-sonaChat (Zhang et al., 2018) framework, the Mul-tiSessionChat (Xu et al., 2021) dialogue dataset represents an evolutionary step in dialogue data. Although it extends previous work, we recognize a need for even longer dialogues for our specific research. Notably, the dialogues in MultiSession-Chat, despite their structured design, often appear somewhat artificial, lacking natural transitions be-tween topics. Nevertheless, the dataset has certain attractive features. One key aspect is the division of conversations into four distinct sessions, which is crucial in pinpointing performance variations at different stages of the dialogue. Another significant factor is the human authorship of the dataset, which is vital for our evaluation of LLMs, as it provides a realistic benchmark for assessing their competency in mimicking human conversation. 

Augmenting and extending. To achieve a long and harmonious dialogue, we utilize one of the cur-rent state of the art LLMs, GPT-4 (OpenAI, 2023). The original MSC dialogue is augmented and ex-tended in a multi-step pipeline before achieving the final result. We begin with improving fluency, in which we feed each 250 token MSC session into the LLM with a carefully engineered prompt. This prompt requests GPT-4 to rewrite the original dialogue in order to add smoother transitions while retaining all of the key points. The prompt used for this can be found in Appendix A. The next step is to extend the length of the dialogue. Each of these augmented sessions are sent back into GPT-4 with a different prompt asking it to continue the conversation. This extends each session to ∼ 1000 

tokens. The prompt used for this can be found in Appendix B. The result is polished and extended dialogues, each ∼ 4, 000 token (4 sessions x 1,000 tokens) and originally written by humans. Thus, we achieve the desired human-written, long-context dialogues. 

Fact bank. With the dialogues in place, the next step is to design a task to assess memory capa-bilities. We’ve selected fact retrieval as this task. Leveraging the extensive, natural dialogues, we in-struct GPT-4 to craft both true and false statements about each character in every session. For authen-ticity, true statements are based strictly on explicitly mentioned facts, not on inferences. In parallel, we ask GPT-4 to deliberately create false statements, again relying only on explicit content. To validate these facts, we have the model cite the specific line number where each fact can be confirmed or re-futed. This approach enables meticulous manual verification and enhances the model’s ability to pro-duce contextually accurate facts. These prompts are available in Appendices C and D. The result is D IA LONG , a long, realistic di-alogue dataset, with true and false facts associ-ated with each, and originally written by humans. Source code for the entire process as well as gener-ating more dialogues will be released in the future. Figure 2 demonstrates the entire pipeline of dataset creation.

## 4 Experimental Setup: Benchmarking Memory with D IA LONG 

To rigorously benchmark memory in dialogue con-texts, we have designed an experimental setup with DIA LONG , leveraging the dialogues and facts to create memory tasks. 

Task Creation. In this setup, we randomly select 40 facts per session from the dataset. This ran-domization ensures a diverse and unbiased sample, crucial for a comprehensive assessment of memory capabilities. Each session’s facts are then woven into memory tasks : starting with the dialogue, followed by a list of candidate facts specific to the session, and concluding with clear instructions for response. We direct the model to identify the candi-date facts it deems true based on the dialogue, and importantly, to also indicate any uncertainties. This allowed for granularity in the responses with re-spect to the model self-reporting when it is unsure. For a view of these instructions, refer to Appendix E. The approach slightly differs for human trials, as outlined in Appendix F. 

Task Configuration. Following the task creation phase, we specifically configure these memory tasks to facilitate an in-depth evaluation of mem-ory performance. These tasks are designed with varying lengths, ranging from a single session (ap-proximately 1,000 tokens) to eight sessions (ap-proximately 8,000 tokens). This variability is for testing the memory capacity across different lengths of dialogue, both within and out of the con-text window. For each configuration, we generate specific memory tasks relevant to the sessions included. For instance, in a setup involving four sessions, separate tasks are created for each session, yet all four are presented together in the dialogue context. This approach tests the model’s memory at individual points and assesses its ability to retain and recall information across longer contexts. For a 4,000 max token count LLM, the memory tasks 

with 1 through 4 sessions evaluate within context memory, while those with 5 through 8 sessions evaluate out of context memory. This configuration enables a nuanced analysis of an entity’s performance throughout the dialogue. By observing how well facts are remembered from different parts of the conversation – be it from the beginning, middle, or end – we gain insights into the strengths and limitations of LLMs in handling extended dialogue scenarios. Furthermore, the unique nature of each dialogue in D IA LONG allows for even more extensive con-figurations. By concatenating multiple dialogues, we can create scenarios simulating extremely long conversations. For example, a scenario where there are one hundred sessions present there would be approximately 100,000 tokens. This scalability provides a robust framework for testing memory in contexts that far exceed the standard capacities of current LLMs. Such extensive dialogues offer a stringent test bed, where questions about content from any session – like the thirteenth in a hundred – remain unique and verifiable. When we are evaluating performance on a 

memory task that is too long to fit into a con-text window, we cut tokens from the beginning of the conversation until it fits. For example, if there is a 5,000 token dialogue to be processed by a 4,000 token context window, we remove the beginning 1,000 tokens. As in base LLMs, once you surpass the token count, the context first seen is erased. If we are evaluating with a model that has an augmented memory module but can only process certain amounts of tokens at a time, we in-put the conversation sequentially. We choose to do this as it simulates exactly what happens to these chatbots beyond their context window. 

Reasoning The crux of our experiment is the use of true/false fact identification as the primary method for memory evaluation. We favor this ap-proach over traditional question-answering formats due to its definitive nature in assessing memory ac-curacy. True/false questions offer a clear metric to evaluate an LLM’s ability to recall, understand con-text, and discern between accurate and inaccurate statements. This method provides a more direct measurement of memory, encompassing both re-call and comprehension abilities, thus serving as an effective tool for our memory benchmarking objectives The human-written dialogues of D IA LONG are pivotal to our study, enabling a direct comparison of LLM performance against human memory ca-pabilities in a conversational context. The exten-sive length of these dialogues challenges LLMs to process and recall information over long con-texts, mirroring real-life conversational memory demands. The dataset’s structure, with distinct sessions, further allows for a granular analysis of memory performance across different stages of the dialogue. The choice of 40 facts per session aligns with the average fact count generated per dialogue, provid-ing a consistent and manageable task design. The token length of each task mirrors the typical 4,000-token capacity of popular LLMs, ensuring our tasks are representative of real-world LLM processing limits. The design inherently supports scalability, as multiple sessions and unique conversations can be concatenated, maintaining task integrity and rel-evance across a broader range of contexts. Our selection of 100 conversations, resulting in approximately 370K tokens, is deliberate. This token count is longer than the longest context win-dow, and can therefore test well beyond the maxi-mum of memory capabilities in LLMs today. 

## 5 Quality Control and Human Trials 

To ensure the integrity and validity of the D IA -LONG dataset and associated tasks, meticulous quality control measures were implemented at ev-ery stage of the data creation process. The preci-sion in task formulation is crucial, as the reliability of our benchmarking for memory rests on the ac-curacy and clarity of the tasks presented. This involved iterative refinement of prompts, crafted to be highly specific and directive in nature. A thor-ough manual review of numerous dialogues was undertaken by members of our team to confirm the consistency and realism of the interactions, as well as the correctness of the accompanying facts. For external validation of our dataset and tasks, human trials were conducted via Amazon Mechan-ical Turk. Participants were assigned memory tasks analogous to those designed for LLMs, with a focus on evaluating their ability to discern true from false statements based on the dialogue con-text. This dual-purpose approach not only verified the feasibility and accuracy of the tasks but also provided a comparative baseline between human memory capabilities and LLM performance. To maintain high standards of response quality, which has been shown to be questionable in some cases (Kennedy et al., 2020): • A control fact was embedded within each set of 40 facts, crafted to be evidently false and unrelated to the dialogue. This acted as a qual-ity filter; incorrect responses to this control fact indicated a lack of diligent engagement with the task. • Specific criteria were set for participant se-lection: We targeted ’Master’ Workers with a HIT Approval Rate of over 95%, based in the US, and with more than 5000 approved HITs. This ensured a pool of experienced and reliable participants. • Participants were compensated at a generous rate well above the United States national min-imum wage at $3.50 per task, equating to an approximate hourly rate of $15. This rate was based on the average time required to com-plete a task and aimed to attract diligent and thoughtful engagement. The results from these human trials served a twofold purpose: validating the correctness and solvability of the tasks, and providing a human per-formance benchmark for memory tasks, highlight-ing the differences in memory capabilities between humans and LLMs. This is a distinctive feature of D IA LONG ; earlier work rarely validated data against human baselines. 

## 6 Results: Benchmarking Memory with DIA LONG 

We ran a multitude of experiments using D IA LONG .To begin, we started with evaluating the memory of out-of-the-box models as our baseline and showing that there is much work to be done. We then evalu-ated a proposed memory-augmented solution from the paper ‘Unleashing Infinite-Length Input Ca-pacity for Large-scale Language Models with Self-Controlled Memory System‘ (Liang et al., 2023), showing that these solutions do work but are far from perfected. Finally, we conduct human trials which prove that the tasks can be accurately com-pleted irrespective of length. 

Baseline: Standard LLM Memory. Modern LLMs have good memory within context, are able to report when they do not know something, and lack performance out of context.

In order to determine the memory capabilities of current standard LLMs, we conducted experiments on some popular open-sourced and private LLMs. Both GPT-3.5 and GPT-4 had high marks across the board when evaluated on these memory tasks and they can see the context. However, as the dia-logue gets bumped out of the context window, we see a sharp decline in performance. This highlights the need for DiaLong, as it is a task that modern LLMs have yet to complete. Interestingly, GPT-4 was able to identify quite well when it did not know the answer to a question, observed by high out-of-context precision. This further emphasizes that the problem lies inherently in the model’s memory rather than some form of reasoning and comprehen-sion shortcoming. As GPT-4 is considered one of the top performing state-of-the-art modern LLMs, this performance reflects all base out-of-the-box models without special memory augmentation to date.

## 7 Conclusion 

We show the limitations of current LLMs in pro-cessing long dialogue contexts which are a sig-nificant barrier to achieving human-like conversa-tional capabilities. We introduce D IA LONG , a long-context dialog dataset and evaluation framework, useful for benchmarking the memory performance of LLMs in extended dialogues. Our findings re-veal a need for further advancements in the mem-ory domain, emphasizing the importance of models that can sustain coherent, accurate, and engaging conversations over long contexts.
