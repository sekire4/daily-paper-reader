# Abstract 

An LLM agent can retrieve a memory correctly yet use it incorrectly after its validity state changes. We study 

governance-state corruption : faults that alter which re-tained records enter model-visible context while stored content and tasks remain fixed. Across six providers, 731 benchmark-grounded bases yield 2,080 matched fault pairs. In offline control-plane checks, corruption changes the operative projection in 96.25% of pairs, while oracle-backed enforcement restores it in 100%. For downstream evaluation, a deterministically selected, non-probability LongMemEval/Memora panel resolves 298 of 300 matched triplets (238 distinct bases). Clean-minus-corrupted con-trasts are 40 .54 percentage points in LongMemEval binary correctness (95% base-cluster interval [30 .32 , 50 .71]) and 30 .60 points in rescaled Memora FAMA ([23 .31 , 37 .69]); both sources also show recovery. OAKS Novel native op-tion parity holds for all 6,714 resolved outputs. Full-cohort frozen-scorer corruption/recovery effects ( −27 .55 / + 27 .51 points) remain descriptive proxies, not validated native semantic population effects. These bounded findings mo-tivate evaluating memory control-state integrity alongside retrieval accuracy. 

Keywords: Large language model agents; Long-term mem-ory; Memory governance; Control-state corruption; Reliability; Trustworthy AI 

# 1 Introduction 

Consider an assistant asked to list a user’s current weekly to-do items. In an audited Memora case, two relevant items, u and v, remain stored. With source-supported governance metadata, both enter model-visible context. When a missing-metadata fault excludes u, however, only 

v remains visible to the model, although the task and stored item content do not change. Oracle-backed restora-tion makes both items visible again. In existing six-provider runs, frozen-proxy correctness follows a correct– incorrect–correct pattern. This case illustrates a control-plane failure; it does not establish native FAMA correct-ness independently (Section 4.5). We separate stored evidence (the data plane ) from lifecycle and validity state (the control plane ) governing what enters the model’s context. Deletion, supersession, and temporal updates can invalidate retained evidence without altering its content. Our question is: How does an agent behave when retrieved memory content is held fixed but the state controlling its use is corrupted? Here, governance denotes benchmark-supported currentness and lifecycle validity; it does not always represent an explicit user authorization policy. We create matched clean , corrupted , and enforced con-ditions for the same task, oracle, evidence, prompt, and model. Clean uses source-supported control state; cor-rupted injects a supported fault; enforced restores the source-supported state before context construction. Thus, enforcement tests an oracle-backed upper bound , not au-tonomous repair. We study the pathway G → A → C → Y

(governance, admission, model-visible context, output) while measuring operative context directly rather than identifying each mediator separately. Across LongMemEval (Wu et al., 2025), Memora (Ud-din et al., 2026), and OAKS (Kim et al., 2026), 731 benchmark-grounded bases yield 2,080 supported fault pairs and 4,891 conditions, evaluated with six providers. An offline audit finds projection changes in 96.25% of pairs and restoration in 100%. A separate, non-probability 

native-style Formal-300 validation resolves 298 Long-MemEval/Memora triplets (238 distinct bases): corrup-tion reduces LongMemEval binary correctness by 40.54 points and Memora FAMA by 30.60 points, with recov-ery under both metrics. The full-panel −27 .55 / + 27 .51 point effects are frozen deterministic-scorer proxies , not validated population-native effects; OAKS has a separate resolved-option parity check. Our research questions examine (RQ1) control-plane and downstream sensitivity, (RQ2) supported fault dif-ferences, (RQ3) event-associated differences, and (RQ4) oracle-backed recovery and provider/source robustness. We contribute: (i) a governance-state corruption formula-tion distinct from retrieval or content errors; (ii) a matched 1arXiv:2610.30698v1 [cs.AI] 22 Oct 2026 sibling-intervention benchmark with explicit source–event– fault support; (iii) six-provider frozen-proxy results and source-specific native-style validation with dependence-aware resampling; and (iv) audited context propagation and bounded recovery evidence. We explicitly separate source-confounded descriptive contrasts from supported intervention claims. 

# 2 Related Work 

Long-term agent memory. MemGPT introduced virtual-context management for persistent agents (Packer et al., 2023); Mem0, A-Mem, and LangMem develop ex-traction, organization, consolidation, and retrieval mecha-nisms (Chhikara et al., 2025; Xu et al., 2025; LangChain, 2025). LongMemEval and its successor evaluate retention, multi-session reasoning, updates, and abstention (Wu et al., 2025, 2026). These systems and benchmarks mainly ask whether an agent retains or retrieves the right evi-dence. That is necessary but insufficient: a retrieved item may be authentic evidence of an earlier state while no longer being valid as the current answer. We evaluate this distinction without modifying the content retrieved from the frozen benchmark. 

Governance, forgetting, and temporal validity. 

GateMem studies shared-memory access control and ac-tive forgetting; Memora evaluates deletion and update-aware memory through forgetting-sensitive criteria (Ren et al., 2026; Uddin et al., 2026). Safety-governed memory and MemGuard propose verification, lifecycle signals, and controlled admission (Lam et al., 2026; Wang et al., 2026). MemConflict distinguishes temporal validity, factual cor-rectness, and contextual applicability (Tao et al., 2026). These works motivate explicit control state but differ from our paired state-corruption stress test, which fixes task and stored evidence and changes the state selecting what becomes operative. In particular, Memora’s FAMA evaluates memory-presence and forgetting-absence crite-ria, while our full-panel frozen scorer is a Boolean proxy. This makes scoring correspondence part of the empirical question rather than an assumption. Our independent native-style subset is explicitly limited to cases where the corresponding source-specific evaluation can be carried out. 

Control-plane foundations. Complete mediation and fail-safe defaults require trustworthy authorization checks (Saltzer and Schroeder, 1975); Usage Control (UCON) treats access-related attributes and decisions as mutable (Park and Sandhu, 2004). We adapt this control-state perspective to agent memory as a G → A → C → Y

pipeline. This lineage motivates a measurable boundary between lifecycle state, admission, and the resulting con-text, rather than assuming the language model can repair invalid evidence after receiving it. Our work neither in-troduces a new access-control model nor demonstrates autonomous recovery: it measures projection integrity, scorer-dependent behavioral degradation, and restoration when benchmark-supported control state is provided. Un-like an end-to-end compliance benchmark, it deliberately leaves the original memory evidence and task fixed, mak-ing the control-plane transformation inspectable; it does not make event types or benchmark datasets causally interchangeable. 

# 3 Problem Formulation 

We distinguish retained memory evidence from the gover-nance state that determines whether it can enter model-visible context. 

## 3.1 Memory Content and Governance State 

Let a benchmark base example be 

b = ( q, X, y ⋆),

where q is the downstream query or task, X denotes the benchmark-native memory evidence associated with that task, and y⋆ is the benchmark-supported scoring target. We represent an individual memory item as 

m = ( x, g ),

where x is the underlying content and g is governance state associated with its use. Governance state is source-dependent: it may encode whether a memory is current, active, superseded, deleted, or otherwise admissible for the present task. For a collection of retrieved memory items R ⊆ X, let 

G = {gm : m ∈ R}

denote the corresponding governance state. A retrieved item can therefore be factually accurate yet invalid to use.

## 3.3 Four-Stage Control Pipeline 

We model downstream execution as 

G → A → C → Y, 

where G is governance state, A is the enforcement or admission decision, C is model-visible context, and Y is downstream behavior. More explicitly, 

A = E(R, G, q ),C = H(R, A, q ),

and 

Y = M (q, C ),

where E denotes enforcement, H constructs the model-visible context, and M is the downstream language model. We observe operative context changes, not every arrow as a separately identified statistical mediator. Figure 1 shows the three siblings. ## 3.5 Scope of the Causal Claim 

Causal sensitivity refers only to these fixed-input sib-ling interventions. Oracle-backed enforcement does not show autonomous state reconstruction, deployed fault prevalence, or downstream harm, and a fault need not propagate to an output error.

We instantiate the control-plane formulation as a frozen intervention benchmark designed to isolate the effect of governance-state corruption from variation in task content, oracle, prompt, or model identity.

## 4.2 Frozen Main Cohort 

All eligibility decisions and intervention manifests were frozen before the formal cross-provider runs. The 731-base manifest contains 380 deletion, 169 tem-poral, and 182 update examples, yielding 4,891 conditions: 731 clean, 2,080 corrupted, and 2,080 enforced. All 380 deletion bases come from Memora, so deletion-versus-other-event contrasts also compare different datasets and evaluation targets. Balanced event sampling does not remove this source–event confounding. Source-specific condition totals are 1,111 (Long-MemEval), 2,660 (Memora), and 1,120 (OAKS); event totals are 2,660 deletion, 957 temporal, and 1,274 update conditions. ## 4.3 Governance Fault Operators 

Missing, stale, flipped, and conflicting operators are de-terministic source-grounded state projections (Section 3). Across the corrupted and enforced conditions, they ac-count for 1,462 missing, 702 stale, 760 flipped, and 1,236 conflicting rows. Source-native support is intentionally unequal; no downstream outputs determine eligibility or fault assignment. 

## 4.4 Condition Construction and Oracle-Backed Enforcement 

We instantiate the clean, corrupted, and enforced siblings defined in Section 3.4 from the frozen manifest. Clean exposes the benchmark-supported projection; corrupted applies a supported fault; enforced begins from the same base–fault pair and restores the benchmark-supported projection before context construction. The enforcement transformation is deterministic and operator-matched. A missing-state corruption is corrected using the supported governance fields that were omitted; a stale corruption restores the supported current state; a flipped corruption restores the benchmark-supported decision or state; and a conflicting corruption resolves the projection to the benchmark-supported operative state. We do not use the downstream answer produced by the model to perform this correction. 4No downstream answer is used for correction; model, task, evidence, oracle, prompt, and inference settings are identical across siblings.

## 4.10 Scoring and Failure Handling 

Full-panel scoring is deterministic, but its independent semantic validity is source dependent. In a separate scorer-validity check of the frozen scorer against separately gen-erated native-style reference judgments, LongMemEval agrees on 60/96 answers (62.50%, Cohen’s κ = 0 .259). Memora’s 508 reference units are atomic criteria spanning 42 answers, whereas the frozen scorer assigns one Boolean per answer; no defensible same-unit agreement estimate exists for Memora. The unaligned pooled 604-unit per-centage is therefore not an interpretable scorer-validity measure. We retain the original frozen results as proxy-score effects , without treating them as validated full-panel semantic accuracy. OAKS has a separate native option-parity comparison, described next. After configured retries, genuine final provider or parse failures are retained and scored as zero in the primary analysis. A complete-case analysis is used as a sensitivity check. Systematic truncation caused by insufficient output-token budget is treated as a measurement artifact rather than model failure. Affected rows are rerun under a documented larger budget and merged into the formal artifact before analysis.

# 6 Discussion 

State integrity versus retrieval quality. A faith-fully retrieved memory can be invalidated, superseded, or deleted. Our interventions isolate governance projec-tion changes while holding stored evidence fixed. The selected LongMemEval/Memora native-style panel sup-ports damage and recovery within its respective outcome units ; OAKS option parity is a separate check, and full-panel effects remain scorer-dependent proxies. 

Confounding and heterogeneity. Stale-state corrup-tion has the largest observed frozen-proxy damage on its supported bases, including matched stale–missing and stale–conflicting comparisons, but stale–flipped lacks com-mon support. Deletion is present only in Memora, pre-cluding source-adjusted event rankings. Across the six provider subsets, Formal-300 effects have consistent over-all directions, although small provider–source cells can have intervals spanning zero; shared-base resampling does not make non-probability samples representative. The full-panel provider agreement under the same proxy is therefore not six independent confirmations of semantic accuracy. Conversely, the selected native-style panel pro-vides convergent evidence for the direction of damage without calibrating the magnitude of the broader proxy results. 11 Recovery and architecture. Oracle-backed enforce-ment restores every audited model-visible projection, but native-style Memora scoring retains a residual clean– enforced gap. This is not evidence of autonomous in-ference of missing state or identification of admission and context as distinct causal mediators. In practice, memory systems should preserve provenance and current-version status, fail closed on unverifiable control state, separate historical records from operative records, and log admis-sion decisions alongside model-visible projections. The 60-block clean-repeat control shows that generation noise is nonzero; its wide intervals do not support an exact decomposition of intervention and stochastic effects. A deployment-ready extension would need to verify the state reference without access to the benchmark oracle, retain provenance for conflicting versions, and independently log whether failure originated in state assignment, admission, context assembly, or the model response. The present propagation audit covers the operative-context boundary, not each stage as a separately estimated causal mediator. 

# 7 Limitations 

Scoring and sampling. The full-panel six-provider ef-fects ( −27 .55 /+27 .51 points) use a frozen Boolean correct-ness proxy . Against independently evaluated native-style answers, only 60/96 same-unit LongMemEval decisions agree ( κ = 0 .259); Memora’s 508 criteria spanning 42 answers cannot be compared to Boolean proxy decisions as though they shared a unit. OAKS native option parity holds on 6,714 resolved outputs, but does not validate the mixed-source event macro. Formal-300 uses a deter-ministic, non-probability selection (300 selected triplets; 298 resolved; 238 distinct bases) excluding OAKS. Its LongMemEval binary and Memora continuous FAMA outcomes are not one shared accuracy metric; pooled point differences and base-cluster bootstrap intervals are 

descriptive within this selected panel, not population pre-cision. Small provider–source cells, including DeepSeek– Memora and Grok–Memora, can have damage intervals covering zero. The Memora enforced-minus-clean gap is −4.35 points. No full-panel LongMemEval/Memora native re-evaluation was performed. 

Identification and generality. Causal claims apply to paired governance interventions with task, evidence, oracle, model, and protocol fixed, not to deployed fault prevalence or user harm. Source/event/fault support is incomplete: deletion occurs only in Memora, no base supports both stale and flipped, and source-specific va-lidity rules are not a universal authorization ontology. Balancing and matched support cannot identify all inde-pendent severity effects. The offline projection diagnostic does not observe admission and context as distinct medi-ators. Providers also differ in API behavior and baseline performance. Clean-repeat includes only one additional response per 60 blocks and has wide intervals; its cross-source mixed-unit average is not a shared metric. 

Audit and reproducibility boundaries. The de-identified case-trace example is a single existing frozen-proxy trace; local v2–v3 correspondence was verified, but original text and model responses cannot be publicly inspected. The 731/731 governance evidence audit veri-fies provenance and schema consistency against the same 

construction assumptions, so shared interpretation errors remain possible. The aggregate-only repository ships code, prompt templates, configurations, hashes and summary statistics, not licensed source texts, instantiated prompts, per-request outputs, retry/timestamp histories, or adju-dication records. It does not permit independent end-to-end reproduction from the ZIP alone. Finally, oracle-backed restoration assumes correct state is available and is not a deployment-ready mechanism for authentication, malicious-state detection, or synchronization. 

# 8 Conclusion 

Accurate retrieval does not ensure that retained memory is valid to use. Across 731 benchmark-grounded bases, state faults change the operative projection in 96.25% of supported pairs, and oracle-backed enforcement restores the clean projection in 100%. A separate native-style se-lected panel resolves 298 LongMemEval/Memora triplets (238 distinct bases): LongMemEval binary correctness shows +40 .54 points of corruption-associated damage and +39 .19 points of recovery, while Memora native FAMA shows +30 .60 points of damage and +26 .24 points of re-covery on its rescaled metric. All six generating-provider subsets have directionally positive within-panel effects; base-cluster resampling preserves the qualitative pattern, but some smaller subgroups remain uncertain and Mem-ora shows a residual recovery gap. OAKS native option parity holds on all 6,714 resolved outputs. Neither the selected non-probability validation nor OAKS option par-ity validates the full-panel frozen-scorer proxy contrasts (−27 .55 / + 27 .51 points) as native semantic population ef-fects. These bounded findings motivate explicit integrity checks for memory control state alongside benchmark-appropriate downstream outcome evaluation.
