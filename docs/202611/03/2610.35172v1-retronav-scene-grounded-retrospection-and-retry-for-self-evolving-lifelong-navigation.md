## 摘要
现有机器人导航方法主要关注孤立任务，忽视了在重复导航回合中积累知识与经验的需求。尽管近期的终身导航方法探索了跨任务知识积累，但它们主要关注场景知识，而忽略了历史导航经验及其与场景证据的联系，限制了反思过去错误并改进未来决策的能力。为解决这一局限，本文提出 RetroNav，一种无需训练的自演化导航框架，集成了导航、记忆积累和失败反思。具体而言，我们开发了一个统一记忆系统，将几何与语义场景知识与历史导航经验相连接，并区分客观观察与任务相关解释。每次导航尝试后，独立评估器判断是否需要重试。若需要，回溯智能体利用积累的场景知识和导航记录重新审视历史决策，生成基于证据的重试简报以指导下一次尝试。RetroNav 在五个导航基准上取得了最先进性能。我们的方法将在 https://github.com/3dv-casia/RetroNav 开源。

## Abstract
Existing robot navigation methods primarily focus on isolated tasks, overlooking the need to accumulate knowledge and experience across repeated navigation episodes. Although recent lifelong navigation methods have explored cross-task knowledge accumulation, they mainly focus on scene knowledge while neglecting historical navigation experience and its connection to scene evidence, limiting the ability to reflect on past mistakes and improve future decisions. To address this limitation, this paper presents RetroNav, a training-free self-evolving navigation framework that integrates navigation, memory accumulation, and failure reflection. Specifically, we develop a unified memory system that connects geometric and semantic scene knowledge with historical navigation experience, distinguishing objective observations from task-dependent interpretations. After each navigation attempt, an independent evaluator determines whether a retry is necessary. If so, a Retrospection Agent revisits historical decisions using accumulated scene knowledge and navigation records, generating an evidence-grounded retry brief to guide the next attempt. RetroNav achieves state-of-the-art performance across five navigation benchmarks. Our method will be open-sourced at https://github.com/3dv-casia/RetroNav .
