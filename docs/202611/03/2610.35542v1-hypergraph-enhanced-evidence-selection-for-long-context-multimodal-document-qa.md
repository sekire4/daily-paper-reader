## 摘要
长上下文多模态文档问答（QA）已成为现代视觉语言模型（VLM）的一项重要且具有挑战性的任务，因为它需要在有限的输入预算内，对分散于不同页面和模态中的证据进行推理。当前流程采用检索增强生成（RAG）为下游 VLM 选择多模态证据。然而，现有系统主要依赖对页面或块等固定粒度检索单元的静态选择规则，导致检索过程中信息损失以及下游推理性能欠佳。为缓解这些问题，我们将核心任务建模为结构化文档证据上的预算感知证据选择，并提出 HyperDoc，一种在保留文档关系的同时构建紧凑且充分证据的文档 RAG 框架。具体而言，HyperDoc 构建文档超图，以显式捕获多模态文档元素之间的结构、逻辑和跨模态关系。在该结构化证据空间上，HyperDoc 根据查询意图和输入预算执行自适应且代价感知的超边选择。在三个代表性基准上的大量实验表明，HyperDoc 优于多种类型的最先进基线。

## Abstract
Long-context multimodal document question answering (QA) has become an important yet challenging task for modern vision-language models (VLMs), as it requires reasoning over evidence dispersed across pages and modalities within limited input budgets. Current pipelines adopt retrieval-augmented generation (RAG) to select multimodal evidence for downstream VLMs. However, existing systems mainly rely on static selection rules over fixed-granularity retrieval units such as pages or blocks, resulting in information loss during retrieval and suboptimal performance in downstream reasoning. To alleviate these issues, we formulate the core task as budget-aware evidence selection over structured document evidence and propose HyperDoc, a document RAG framework that constructs compact yet sufficient evidence while preserving document relations. Specifically, HyperDoc constructs a document hypergraph to explicitly capture structural, logical, and cross-modal relationships among multimodal document elements. Over this structured evidence space, HyperDoc performs adaptive cost-aware hyperedge selection based on query intent and input budget. Extensive experiments on three representative benchmarks demonstrate that HyperDoc outperforms various types of state-of-the-art baselines.

- **任务背景**：长上下文多模态文档问答（如科研报告、财报、技术手册）要求模型在有限输入预算内，对分散于多页、多模态（文本、表格、图表、版式）的证据进行联合推理。

- **现有 RAG 的两大缺陷**：
  1. **关系孤立的证据构建**：以页（ColPali 式）或 OCR 块为固定检索单元，割裂了层级包含、跨页段落、图表—标题—正文等文档原生关系，造成检索信息损失与推理碎片化。

- **整体含义**：论文将问题重新形式化为**预算感知的结构化证据选择**（budget-aware evidence selection），并主张用超图（hyperedge 可连接任意节点子集）来直接表达“多元证据组”这一文档原生检索单元，从而在保留关系的前提下构建紧凑而充分的 VLM 输入。

## 二、方法论

### 2.1 核心思想
- 两阶段框架：**离线构建文档超图**（显式编码结构、逻辑、跨模态关系）+ **在线查询感知超边选择**（按意图路由、按预算贪心裁剪），最终线性化为紧凑的图文上下文供 VLM 推理。

### 2.2 离线：文档超图构建
- **多模态解析**：每页渲染为图像；用 PaddleOCR 解析出布局感知块 \(b_i=\langle id_i,\tau_i,pg_i,bbox_i,text_i\rangle\)，类型含文本、标题、列表、图、表、题注；图表等视觉/版式依赖元素保留原图，定义为视觉锚点集合 \(A_D\)。
- **视觉中心上下文超边**：对每个视觉锚点 \(a_i\)，聚合题注集合 \(C^{cap}_i\)（按空间邻近与版式对齐）、章节标题集合 \(C^{sec}_i\)（阅读顺序前置标题）、以及按多模态相似度 top 检索的相关文本块 \(R_i\)，构成
  \[
  e^{ctx}_i=\{a_i\}\cup C^{cap}_i\cup C^{sec}_i\cup R_i
  \]
- **结构超边**：
  - 页面包含超边 \(e^{page}_k=\{vp_k\}\cup A^{page}_k\)（保留物理边界）；
  - 章节包含超边 \(e^{sec}_j=\{s_j\}\cup A^{sec}_j\)（保留逻辑层级）。
- **统一超图**：\(G_D=(V_D,E_D)\)，\(E_D=E^{ctx}_D\cup E^{str}_D\)，节点含页节点与块节点，超边同时承载跨模态绑定与结构作用域。

### 2.3 在线：查询感知超边选择
- **Step 1 意图分析**：用 VLM 将查询解析为意图状态 \(\pi(q)=\langle t,\ell,C^{hard}(q),C^{soft}(q)\rangle\)。
  - 意图类型 \(t\)：LOCATE / COUNT / ENUMERATE / COMPARE / CROSS REASONING；
  - 范围 \(\ell\)：SINGLE / MULTI / DOCUMENT-WIDE；
  - 约束：硬约束（ID、页码、章节等结构定位符）与软约束（关键词、实体、属性等语义线索）。
- **Step 2 候选提议**：按 \(\pi(q)\) 路由激活工具集 \(\Omega(\pi(q))\subseteq O\)（find_by_id、find_by_page、find_by_section、keyword_search、global_count、enumerate、visual_search），在超图上执行并去重得到候选池 \(H(q)=\mathrm{Dedup}(\tilde H(q))\)；其中可在线实例化查询诱导的聚合超边（如计数/枚举）。
- **Step 3 代价感知超边选择**：
  - **覆盖目标**：定义意图条件覆盖 \(\mathrm{Coverage}_t(S,q)=(\mathrm{Cov}_{hard},\mathrm{Cov}^t_{soft})\)，字典序比较——先满足硬约束，再最大化软覆盖。
  - **代价模型**：\(\mathrm{Cost}(S)=\sum_{u\in M(S)}\kappa(u)\)，按渲染后文本 token 与视觉 token 估计；边际代价 \(\Delta\mathrm{Cost}(h|S)\)。
  - **问题形式化**：
    \[
    H^*_q=\arg\max_{S\subseteq H(q),\,|S|\le K}\big(\mathrm{Cov}_{hard}(S,q),\ \mathrm{Cov}^t_{soft}(S,q)\big)
    \]
    其中 \(K=\lfloor B_{vlm}/c_{max}\rfloor\) 是由模型预算导出的**可行性上界**，而非固定检索截断。
  - **理论结果**：定理 1 通过从 Maximum Coverage 归约证明该问题是 NP-hard。
  - **贪心算法**（Algorithm 1）：先做硬覆盖初始化，再按边际效用密度
    \[
    \rho(h|S,q)=\frac{\Delta_{soft}(h|S,q)}{\Delta\mathrm{Cost}(h|S)}
    \]
    排序；SINGLE 用直接软覆盖（式16），MULTI 只计超出当前最优支持 \(\beta_i(S)\) 的增量（式17）；当 \(\rho(h^*|S,q)<\alpha_\rho\rho_1\) 时自适应停止（\(\rho_1\) 为首个软超边密度）。
- **Step 4 证据整合**：约束对齐重排序（按约束/实体/子问题组织证据顺序）+ 块级二次贪心剪枝（锚点与题注作为固定结构种子，仅保留边际增益足够的辅助块），最终拼接为 \(E_q=\bigcup_{h\in\tilde H^*_q}h\)。

## 六、主要结论与发现

- **总体性能**：HyperDoc 在全部 3 个骨干、3 个基准上均取得最佳或接近最佳结果。以 Qwen3-VL 8B 为例：MMLB-Doc ACC 53.2（次优 MDocAgent 32.8）、LDU ACC 61.7（次优 58.4）、DocBench 75.8（次优 73.7）；32B 下为 54.7 / 66.2 / 78.2。
- **关系保留有效**：MoLoRAG、MDocAgent 优于纯页检索基线，说明关系组织优于相似度检索；HyperDoc 进一步以超边显式建模，增益更大。
- **自适应选择优于固定 top-K**：M3DocRAG 从 top-5 到 top-10 提升有限甚至在 32B 下退化，说明盲目扩大检索预算会引入冗余噪声。
- **检索层面**：recall@budget 在文档级 COUNT / ENUMERATE 上提升最明显（聚合超边可跨页补全

分散证据），而在 SINGLE 范围的 LOCATE 类查询上增益相对有限，说明结构化超边的主要价值在于跨页、聚合与多源联合取证，而非替代精确局部检索。
- **意图分析有效性**：混淆矩阵显示多数意图类别可被 VLM 较稳定识别，但相邻意图（如 ENUMERATE 与 COUNT、COMPARE 与 CROSS REASONING）存在一定混淆；由于后续路由与覆盖目标依赖意图标签，意图误判会向下游传播，构成方法链路上的主要误差来源之一。
- **效率权衡**：HyperDoc 通过预算约束与自适应停止控制输入 token 量，整体在取得更高准确率的同时未出现随 top-K 增大而成本失控的问题；但离线超图构建、页图像存储与在线工具调用带来额外工程开销，属于“以离线索引换在线紧凑推理”的典型折中。
- **消融结论**：移除结构超边、意图路由、代价感知选择或自适应停止等关键组件均导致性能下降，表明增益并非仅来自更多上下文或更强骨干，而是来自“关系保留 + 意图条件选择 + 预算约束”的组合；\(\alpha_\rho\) 在较宽范围内性能稳定，默认值具有合理性。
- **案例研究**：定性案例展示了跨页图表—题注—正文的联合证据组织能力，以及文档级计数/枚举时通过聚合超边补全分散证据的过程，较好支撑了方法动机。

## 七、局限性与潜在问题

- **解析依赖较强**：超图构建依赖 OCR 与版式解析质量，扫描件、复杂表格、公式、低质量图像或非拉丁语种文档可能产生块边界错误与题注/标题错配，进而污染超边关系。
- **超边构建含启发式**：题注聚合、章节标题归属、视觉相似文本召回等规则带有经验设定，缺少对超边质量的自监督评估或纠错机制；超边“错连/漏连”会直接影响候选池与覆盖计算。
- **预算与代价模型较粗**：以渲染后文本 token 与视觉 token 估计代价，未充分建模不同 VLM 的视觉编码器分辨率、图像切块策略与真实显存/时延差异，预算上界 \(K\) 与实际可承受输入之间可能存在偏差。
- **意图分类误差传播**：意图状态由 VLM 解析，分类错误会改变工具路由、硬/软约束与覆盖目标；论文仅在单一骨干上评估意图分类，跨模型鲁棒性不足。
- **理论保证有限**：NP-hard 结论说明问题难度，贪心算法仅有覆盖最大化的近似直觉，论文未给出与预算约束、字典序覆盖目标相匹配的严格近似比。
- **评测覆盖仍可扩展**：仅使用三个长文档基准，未覆盖多语言、超长（数百页以上）、强表格/公式或开放域文档；也未与 HyperGraphRAG、Hyper-RAG 等超图/高阶结构 RAG 直接对比。
- **统计与复现细节不足**：主结果缺少多次运行方差与显著性检验；算力披露不完整；部分基线在其原设定下复现，存在基线配置未完全对齐的风险。
- **存储与工程成本**：页图像与超图索引带来显著存储开销，离线构建虽近似线性扩展，但在大规模文档库场景下的索引更新、增量构建与检索服务化问题尚未讨论。

## 八、启发与可借鉴点

- **将“证据组”而非“证据块”作为检索单元**：超边思想把图表—题注—正文、章节—子块、页面—元素等文档原生关系显式化，为长文档 RAG 提供了一种比固定页/块切分更贴合推理需求的中层表示。
- **预算感知的选择范式**：把 top-K 截断改为“在模型预算内最大化意图条件覆盖”，并将 \(K\) 解释为可行性上界而非检索超参，这一视角可迁移到其他受限上下文的多模态/文本 RAG。
- **查询意图驱动的工具路由**：先解析意图与硬/软约束，再激活相应检索工具，避免对所有查询使用同一检索策略，对文档级聚合与局部定位混合的基准尤其有价值。
- **离线结构化索引 + 在线轻量选择**：免训练框架降低了部署门槛，离线构建关系、在线贪心裁剪的架构适合工程落地，也便于替换解析器、嵌入模型与骨干 VLM。
- **可解释的证据组织**：约束对齐重排序与块级剪枝使最终输入可追溯到具体超边与约束，有利于错误分析与高风险场景审计。

## 九、总体评价

HyperDoc 针对长上下文多模态文档问答中“关系孤立”和“意图无关静态截断”两个核心痛点，提出了结构清晰、动机充分的两阶段框架：离线以多模态超图保留文档原生关系，在线以意图分析和预算约束的贪心选择构建紧凑证据集。方法在三个长文档基准、三种规模骨干上取得一致领先，消融与效率分析基本支撑其设计选择，工程可落地性较强。其主要不足在于超图构建依赖启发式与解析质量、意图误差会传播、理论保证与统计严谨性有限，且算力与复现细节披露不充分；与超图/高阶结构 RAG 的直接对比缺失也使“超图”本身的相对贡献边界不够清晰。总体而言，这是一篇问题定义准确、方法组合合理、实验覆盖面较广的工作，适合作为“结构化证据选择”方向的重要参考，但其结论的稳健性仍需在更多语言、更长文档和更严格复现条件下进一步验证。
