## 摘要
LLM智能体可能正确检索到某条记忆，但在其有效性状态发生变化后错误地使用该记忆。我们研究治理状态损坏：即在存储内容和任务保持固定的情况下，改变哪些保留记录进入模型可见上下文的故障。在六家提供商上，731个基于基准的基座产生2,080个匹配故障对。在离线控制面检查中，损坏在96.25%的配对中改变了生效投影，而基于oracle的强制机制在100%的配对中将其恢复。对于下游评估，一个确定性选取的非概率LongMemEval/Memora面板解析了300个匹配三元组中的298个（238个不同基座）。干净减损坏的对比在LongMemEval二元正确率上为40.54个百分点（95%基簇区间[30.32, 50.71]），在重新缩放的Memora FAMA上为30.60个百分点（[23.31, 37.69]）；两个来源也都显示出恢复。OAKS Novel原生选项一致性对所有6,714个已解析输出均成立。全队列冻结评分器的损坏/恢复效应（-27.55/+27.51个百分点）仍是描述性代理指标，而非经过验证的原生语义总体效应。这些有界发现促使人们在评估检索准确性的同时评估记忆控制状态完整性。

## Abstract
An LLM agent can retrieve a memory correctly yet use it incorrectly after its validity state changes. We study governance-state corruption: faults that alter which retained records enter model-visible context while stored content and tasks remain fixed. Across six providers, 731 benchmark-grounded bases yield 2,080 matched fault pairs. In offline control-plane checks, corruption changes the operative projection in 96.25% of pairs, while oracle-backed enforcement restores it in 100%. For downstream evaluation, a deterministically selected, non-probability LongMemEval/Memora panel resolves 298 of 300 matched triplets (238 distinct bases). Clean-minus-corrupted contrasts are 40.54 percentage points in LongMemEval binary correctness (95% base-cluster interval [30.32, 50.71]) and 30.60 points in rescaled Memora FAMA ([23.31, 37.69]); both sources also show recovery. OAKS Novel native option parity holds for all 6,714 resolved outputs. Full-cohort frozen-scorer corruption/recovery effects (-27.55/+27.51 points) remain descriptive proxies, not validated native semantic population effects. These bounded findings motivate evaluating memory control-state integrity alongside retrieval accuracy.

## 1. 核心问题与研究动机

- **核心问题**：LLM 智能体可能“正确检索到某条记忆，却在其有效性状态改变后错误使用”。论文将这一现象形式化为**治理状态损坏（governance-state corruption）**——在存储内容与任务均保持不变的前提下，故障改变了“哪些保留记录进入模型可见上下文”。
- **背景与动机**：
  - 现有长期记忆系统（MemGPT、Mem0、A-Mem、LangMem）与基准（LongMemEval、Memora、OAKS）主要关注“是否保留/检索到正确证据”，但检索正确并不等于“当前有效可用”。
  - 一条记忆可能是早期状态的真实证据，却已因删除、取代、时间更新而失效。
  - 作者区分**数据平面（存储证据）**与**控制平面（生命周期与有效性状态）**，主张控制状态完整性应作为独立评测维度。
- **研究问题（RQ）**：RQ1 控制面与下游敏感性；RQ2 不同故障类型的差异；RQ3 事件相关差异；RQ4 oracle 恢复与提供者/来源鲁棒性。
- **整体含义**：将记忆评测从“检索准确率”扩展到“控制状态完整性”，为可信 AI 与记忆治理提供可测量的压力测试框架。

## 2. 方法论

- **核心思想**：固定任务、证据、oracle、提示与模型，仅操纵治理状态，构造**清洁（clean）/ 损坏（corrupted）/ 强制恢复（enforced）**三兄弟条件，测量配对因果效应。
- **形式化定义**：
  - 基准基座 \(b=(q,X,y^\star)\)，记忆项 \(m=(x,g)\)，其中 \(x\) 为内容、\(g\) 为治理状态。
  - 故障算子 \(G_{corr}=\phi_f(G_{clean})\)，且 \(X_{corr}=X_{clean}=X\)（仅控制面干预，非内容损坏）。
  - 四阶段流水线 \(G \to A \to C \to Y\)：治理状态 → 准入/执行决策 → 模型可见上下文 → 下游输出。
  - 强制恢复：\(G_{enf}=G_{clean}\)，使用基准支持的治理状态在上下文构建前恢复，属于 **oracle 支持的上界**，不是自主修复。
- **四类故障算子**：
  - **Missing**：移除判定可采纳性/时效性所需的治理信息。
  - **Stale**：使已取代/过期的状态生效。
  - **Flipped**：翻转基准支持的治理决策或状态。
  - **Conflicting**：同时激活不兼容状态且不保留基准支持的胜者。
- **配对估计量**：
  - 损坏效应 \(\Delta^{corr}=Y_{corr}-Y_{clean}\)；恢复效应 \(\Delta^{rec}=Y_{enf}-Y_{corr}\)。
  - 主估计量为**事件宏平均**：先在每个事件内对基座等权（基座内多故障先平均），再对 deletion/temporal/update 三个事件等权。
  - bootstrap 按基座聚类重采样，保留基座内故障对与兄弟三元组。
- **离线控制面诊断**：对 2,080 个基座–故障对计算投影改变指示 \(Z_{chg}\) 与恢复指示 \(Z_{rest}\)，并按是否改变分层比较下游效应。
- **评分体系**：
  - 全面板使用**冻结确定性正确性代理评分器**（非基准原生语义评估器）。
  - 另设 **Formal-300 native-style 验证面板**（种子 20261010 确定性分层抽样），LongMemEval 用二元正确性、Memora 用原生 FAMA 连续指标。
  - OAKS 使用原生确定性选项一致性检查。

## 6. 主要结论与发现

- **控制面传播**：2,080 个支持对中，96.25%（2,002 对）的损坏改变了模型可见投影；oracle 强制恢复在 100%（2,080 对）中恢复清洁投影。
- **Native-style 验证（298 个三元组）**：
  - LongMemEval 二元正确性：clean−corrupted = **+40.54 个百分点**（95% 基簇区间 [30.32, 50.71]），恢复 +39.19。
  - Memora 原生 FAMA：损坏 **+30.60 个百分点**（[23.31, 37.69]），恢复 +26.24。
  - 混合单位描述性合并：损坏 +35.54，恢复 +32.67（非统一原生准确率）。
- **全面板冻结代理（描述性）**：六提供者平均损坏 **−27.55 个百分点**、恢复 **+27.51 个百分点**；所有提供者区间均排除零。
- **故障类型差异**：stale 在每种提供者上退化最大（−32.19 至 −58.40）；conflicting 最小；在匹配支持上，stale 比 missing 额外多退化 12.25–13.68 点，比 conflicting 多 31.09–62.61 点，所有提供者区间均低于零；stale vs flipped 无共同支持，无法识别。
- **事件差异**：update 事件退化通常最大；deletion 与 Memora 来源完全重合，无法与来源/任务/评分差异解耦。
- **恢复效果**：强制恢复后各提供者条件级准确率距清洁基线约 2.4 个百分点内；但 Memora 原生 FAMA 仍存在 −4.35 点残余差距（区间 [−8.29, −0.66]）。
- **评分器效度**：LongMemEval 同单位一致率 60/96（62.50%，Cohen's κ=0.259）；Memora 原子标准与布尔代理不同单位，无法给出可解释的一致率；OAKS 选项一致性 6,714/6,714。
- **核心结论**：**准确检索不保证记忆有效可用**；应在检索准确率之外评估记忆控制状态完整性；全面板代理效应不能作为原生语义总体效应外推。

## 7. 优点

- **问题新颖且形式化清晰**：将“治理状态损坏”与检索错误、内容错误明确区分，提出可检验的 \(G \to A \to C \to Y\) 控制面框架。
- **配对兄弟干预设计严谨**：固定任务、证据、oracle、提示、模型，仅操纵治理状态，因果解释边界明确。
- **显式源–事件–故障支持**：不强行套用统一策略本体，尊重各基准原生语义；对不支持的故障单元如实留空。
- **测量层次分明**：离线投影审计（确定性）+ 下游冻结代理 + 独立 native-style 验证 + OAKS 原生选项检查，层层区分证据强度。
- **统计处理审慎**：基座等权事件宏平均、依赖感知的基座聚类 bootstrap、匹配支持比较、文档聚类与留一文档鲁棒性。

- **可复现性意识**：提供聚合级复现包（代码、提示模板、配置、哈希与汇总统计），并说明许可限制导致的复现边界。

## 9. 对研究与实践的启示

- **评测维度扩展**：记忆系统评测应在“检索命中率/证据保留率”之外，单列**控制状态完整性**指标（如损坏敏感度、恢复上界、故障类型分层退化），并将其作为与准确率并列的报告项。
- **系统设计启示**：由于 stale 类故障退化最大，生命周期管理中的**取代与时效判定**应优先加固（例如显式的 supersedes 链、时间有效区间、失效标记的强一致传播），而非仅优化检索召回。
- **诊断工具化**：论文的离线投影审计（\(Z_{chg}\)、\(Z_{rest}\)）提供了一种低成本、确定性的“控制面单元测试”思路，可在不调用下游模型的情况下先行筛查治理状态缺陷。
- **报告规范建议**：作者的做法——明确区分“描述性代理效应”与“原生语义效应”、显式声明源–事件–故障支持矩阵、披露评分器效度——可作为记忆类基准报告的参考范式。

## 10. 总体评价

- **贡献定位**：论文的主要贡献不在于提出新记忆架构，而在于**提出并操作化了一个此前被混淆的失效类别**，并给出可测量、可复现（在聚合层面）的配对压力测试协议。其价值更偏向“评测与治理框架”而非“方法创新”。
- **证据强度分级清晰**：作者自觉地将证据分为三层——确定性离线投影审计（最强）、native-style 小样本验证（中等，298 三元组）、全面板冻结代理（最弱但覆盖最广），并在结论中严格限制外推范围。这种分层是本文方法论上最值得肯定之处。
- **核心论断的可信度**：就“检索正确 ≠ 当前有效可用”这一核心论断而言，离线投影层面 96.25% 的投影改变率与 100% 的 oracle 恢复率提供了强支持；下游效应方向在六家提供者上一致（全面板均值为负、恢复为正），方向性结论稳健；但**具体效应量**受代理评分器效度（κ=0.259）与非概率抽样制约，应视为量级参考而非精确估计。
- **主要短板**：评分器效度是最实质的威胁——LongMemEval 上代理与原生判断的一致率仅 62.50%，意味着全面板效应中可能混入相当比例的分类噪声；加之 deletion 与 Memora 完全重合导致事件效应不可分离，论文在“哪类事件最脆弱”这一问题上只能给出弱结论。
- **适用边界**：结论适用于“单用户、对话/叙事型、以删除–时效–更新为主要治理操作”的长期记忆场景；对多主体、权限敏感、高对抗环境下的记忆治理，本文的故障算子集尚不充分。

## 11. 一句话总结

论文以严格配对的 clean/corrupted/enforced 三兄弟设计证明：**即使证据被正确检索，治理状态的损坏仍会显著削弱 LLM 智能体的下游表现，且此类损坏在 stale 型故障下最为严重、可由 oracle 治理状态恢复至接近基线**；因此记忆评测必须把控制面完整性作为独立维度，但受代理评分器效度与非概率抽样限制，其效应量应作描述性解读而非总体外推。
