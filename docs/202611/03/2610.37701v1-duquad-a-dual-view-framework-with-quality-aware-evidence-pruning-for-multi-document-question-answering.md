## 摘要
具有检索增强生成能力的大语言模型会系统性地未能充分利用多文档上下文中间部分的证据，这一现象被称为“迷失在中间”（Lost in the Middle）。现有缓解策略，如文档重排序和注意力引导，虽可降低边界偏差，但在噪声环境中仍然脆弱：不准确的相关性估计和虚假文档仍会掩盖中心位置的有用证据。我们提出 DuQUAD，一种通过双视图推理和质量感知证据剪枝来缓解位置偏差的多文档问答框架。DuQUAD 将受结构融合分数（Structural Fusion Score）引导的局部智能体与对完整文档集进行推理的全局智能体相结合，从而同时提供有针对性的证据恢复和广泛的上下文理解。该框架进一步使用显式质量评分过滤候选证据，并在句子级别对其进行精炼以减少噪声。DuQUAD 持续优于强基线，包括混合检索与重排序、多智能体推理和上下文优化等 Lost-in-the-Middle 缓解方法，在最强竞争基线基础上平均提升准确率 3.0%，金证据召回率提升 9.4%，同时相比现有多智能体框架大幅降低计算成本。

## Abstract
Large language models with retrieval-augmented generation systematically underutilize evidence in the middle of multi-document contexts, a phenomenon known as Lost in the Middle. Existing mitigation strategies, such as document reordering and attention steering, can reduce boundary bias but remain brittle in noisy settings, where inaccurate relevance estimation and spurious documents still obscure useful evidence in central positions. We propose DuQUAD, a multi-document QA framework that mitigates positional bias through dual-view reasoning and quality-aware evidence pruning. DuQUAD combines a Local Agent guided by a Structural Fusion Score with a Global Agent that reasons over the full document set, providing both targeted evidence recovery and broad contextual understanding. The framework further filters candidate evidence using explicit quality scoring and refines it at the sentence level to reduce noise. DuQUAD consistently outperforms strong Lost-in-the-Middle mitigation baselines, including hybrid retrieval and reranking, multi-agent reasoning, and context optimization methods, improving accuracy by 3.0% on average over the strongest competing baseline and gold evidence recall by 9.4%, while substantially reducing computational cost compared to existing multi-agent frameworks.

## 1. 核心问题与研究背景

- **核心现象**：检索增强生成（RAG）的大语言模型在多文档上下文中存在显著的**位置偏置**，即“迷失在中间”（Lost in the Middle, LiTM）——模型过度关注上下文首尾的文档，而系统性低估中部位置的证据。
- **细粒度观察**：作者复现了 NQ 上的注意力 z-score 分布（图 1），发现当金标文档位于中间位置时，注意力在整体 U 形偏置之上会出现**局部尖峰，形成 W 形模式**，但边界注意力仍占主导，中部证据依旧未被有效利用。
- **噪声放大问题**：检索集中存在答案无关或弱相关的干扰文档（contextual noise），会分散注意力并引入误导性线索；而现有的文档重排序、注意力引导（如 FiM、注意力排序）依赖语义相似度或原始注意力这类**校准较弱的信号**，在噪声场景下依然脆弱。
- **研究含义**：单纯“重排位置”或“修改注意力”只处理症状，未解决推理阶段证据被抑制的问题；需要一个能同时**精准定位局部证据**与**保留全局上下文**、并显式**过滤低质量证据**的框架。

## 2. 方法论

### 2.1 总体思想
采用“先排序—再双视图推理—后质量剪枝—终裁决”的分层流水线：用结构融合分数（SFS）挑出高潜力文档喂给局部代理，同时让全局代理看全量文档，二者输出经 DocScore 过滤与句级压缩后，由 Judge Agent 融合出最终答案。

### 2.2 结构融合分数（SFS）
融合三路异构信号，各自先做 softmax 归一化再加权：

- **语义相关性 Φ_sim**：用 GTE（gte-large-en-v1.5）编码查询与文档，取余弦相似度。
- **结构推理 Φ_ppl**：用与主推理模型相同的骨干 LLM 计算查询在给定文档条件下的 token 级平均负对数似然（困惑度式指标），越低表示文档对查询的生成支持越强；不引入额外打分模型以避免跨模型不一致。
- **注意力对比 Φ_cont**：先对文档级平均注意力 a_i（末位查询 token 对所有层、所有头的注意力在文档 span 上的均值）做 z-score 标准化得到 z_i，再取二阶差分
  Φ_cont,i = z_i − (z_{i−1} + z_{i+1})/2，
  类比离散拉普拉斯算子/边缘检测，压制平滑的位置趋势、突出局部尖峰；边界文档采用单边有限差分（附录 I）。
- **融合公式**：Φ_i = α·S(Φ_sim,i) + β·S(−Φ_ppl,i) + γ·S(Φ_cont,i)，其中 S(·) 为检索集上的 softmax，Φ_ppl 取负以统一方向。权重 α=0.5、β=1.0、γ=0.5，经 NQ 网格搜索按平均金证据召回选定（附录 E，Table 6）。
- 取 Φ 排名前 **k=6** 的文档构成局部子集（k 由召回–精度权衡确定，附录 D）。

### 2.3 双视图代理协作
- **Global Agent**：在完整检索文档集上推理，保留跨文档依赖与全局上下文。
- **Local Agent**：仅在 SFS 重排后的 6 篇精简子集上推理，专注被位置偏置/噪声压制的证据。
- 两者独立生成带引用（[DOC i] + 引文片段）的答案，并各自以固定 JSON 格式返回最多 3 个“重要文档 ID”。
- 设计意图：局部视图负责“捞回”证据，全局视图补偿过滤造成的信息损失，形成互为鲁棒。

### 2.4 质量感知证据剪枝（两阶段）
- **阶段一 重要文档选择（召回导向）**：D_imp = D_G ∪ D_L，最多 6 篇候选，作为粗筛。
- **阶段二 LLM 质量打分（精度导向）**：Score Agent 对每篇候选输出 DocScore p_i∈[0,1]（该文档单独能否回答问题的置信度）及最佳答案片段；按 D_keep = {D_i | p_i ≥ τ} 保留，**τ=0.4**（附录 C 显示 0.3→0.4 召回不变，>0.4 开始丢金标）。
- **句级压缩**：对保留文档先由 DocScore 阶段生成文档级临时答案，再按词/关键词重叠选出**最相关的 2 句**作为证据片段，降低 Judge 的输入负担。

### 2.5 最终裁决
Judge Agent 联合输入：问题 Q、全局与局部的推理历史 H_G/H_L、句级证据集合 S、以及保留文档的 DocScore p，输出最终答案；避免对单一分数或单一证据来源的过度依赖。完整流程见 Algorithm 1。

## 6. 主要结论与发现

- **性能**：DuQUAD 在 Table 1 的全部 14 个 accuracy 设置上均为最优，平均较最强竞争基线提升 **3.0 个百分点**；Llama 骨干下 MuSiQue +2.5、HotpotQA +2.9，Qwen 骨干下多跳任务的 Acc/EM/F1 全部第一。唯一指标例外是 Llama 下 HotpotQA 的 EM（52.6% vs Hybrid+RR 的 54.4%），作者归因于严格串匹配对语义正确但表述不同的答案不友好。
- **位置鲁棒性**：NQ-15 上较最强多代理基线 MAIN-RAG 提升 **13.8%**、较 ToA 提升 **25.1%**；文档数从 20 增至 30 时仅下降 **0.5 点**（Vanilla −6.2、Hybrid(RRF) −7.4）。
- **召回**：SFS 的金证据 Recall@6 达 **90.8%**，比最佳单信号（注意力对比 81.4%）高 **9.4%**，比最佳双信号组合高 4.0%；注意力对比是单信号中最强的（81.4% > 结构推理 75.4% > 语义 69.0%），说明 W 形尖峰确实是有效信号。
- **效率**：相较 MAIN-RAG 减少 **10×** LLM 调用、2.35× tokens、**3.29×** 时延；相较 ToA 减少 5.65×/2.81×/**3.88×**，同时精度更高。
- **机理验证**：Local 与 Global 各有独占正确案例（分歧率 13.5%–24.3%），Judge 在分歧样本上正确率 74.5%(NQ)/67.2%(MuSiQue)/58.5%(HotpotQA)，证明两视图互补而非冗余。
- **DocScore 稳定性**：金标文档平均分显著高于非金标（Llama 0.647 vs 0.324；Qwen 0.722 vs 0.348），跨模型对金标选择一致率 **90.4%**，而对干扰文档选择差异达 90.1%，说明其捕捉的是“可答性”而非骨干特有行为。
- **失败模式**：MuSiQue 上 **52.3%** 样本两个代理同时答错，错误发生在最终综合阶段的中间实体跟踪（如四跳链中误取印尼总统而非东帝汶总统）。

## 7. 优点

- **问题刻画有新意**：把 W 形注意力尖峰显式形式化为可计算的“注意力对比”，借用拉普拉斯/边缘检测思想做二阶差分，压制平滑位置趋势、保留局部峰，物理直觉清晰且实现简单。
- **多信号互补而非堆叠**：语义（静态嵌入）+ 生成似然（动态支持）+ 注意力对比（位置不变性）三者从不同角度覆盖，且都用同一骨干计算，避免引入额外打分模型与跨模型偏差。
- **免训练、即插即用**：不需要微调，可直接作用于现成开源模型，工程落地门槛低；Local/Global 可并行执行进一步降时延。
- **双视图 + 显式剪枝的组合设计合理**：局部保证召回、全局保证覆盖、DocScore + 句级压缩保证精度与低幻觉，三层职责分离，且每层都有消融支撑。
- **实验扎实**：36 组 bootstrap 显著性检验、成本-精度帕累托分析、20/30 文档鲁棒性、跨模型一致性、定性案例分析，证据链较完整；对唯一不显著结果（MuSiQue vs FiM）也做了坦诚解释。
- **可复现性好**：附录给出全部 prompt 模板（图 7/8/9）、算法伪代码、权重与阈值选取依据、边界处理细节。

## 8. 不足与局限

- **剪枝的固有风险**：显式剪枝在证据表达隐晦或分散于多篇文档时可能损失上下文覆盖，对复杂多跳问题不利（MuSiQue 绝对精度仅 41.1%，过半样本双代理同错）。
- **受限于检索质量**：与所有 RAG 一样，若金标文档未被召回则无法恢复；框架不能弥补检索阶段的上限。
- **多跳实体跟踪瓶颈**：即使证据被正确检索并高分打分，最终综合阶段仍可能在近义实体链上走错分支，说明 Judge 的推理能力是新的瓶颈。
- **模型覆盖有限**：仅验证两个 7–8B 级开源模型，未涉及更大规模、闭源 API 模型或其他模型族；且注意力对比

依赖模型内部注意力权重的可获取性：闭源 API、仅暴露 logprobs 而不返回注意力的服务，或使用 FlashAttention/分块注意力导致文档级注意力难以稳定还原时，Φ_cont 无法直接计算；同时该信号对层/头聚合方式、文档边界切分及边界单边差分较敏感，跨模型迁移时需重新校准。其次，SFS 权重 α/β/γ 与 DocScore 阈值 τ 主要在 NQ 上网格搜索选定，虽附录显示邻域设置稳定，但在域外任务上仍可能需要调整；GTE 语义编码器与固定“每文档取 2 句”的压缩策略也是额外设计选择，可能影响长文档、多证据或跨句依赖较强场景。第三，成本仍显著高于 Vanilla：平均 4.10 次 LLM 调用、约 5914 tokens、端到端 21.03 s，约为 Vanilla 的 9.93×；Local/Global 虽可并行，但 SFS 的困惑度打分与注意力提取带来前置开销，对低延迟在线 RAG 不够友好。第四，评测覆盖仍有边界：NQ 每个位置仅 1000 例且为单一金标，HotpotQA 仅 10 篇文档、固定干扰配置，MuSiQue/HotpotQA 未做位置扫描；MuSiQue 绝对精度 41.1% 也说明复杂多跳推理仍有较大提升空间。第五，基线公平性需谨慎：ToA、MAIN-RAG 等按本文统一骨干与提示迁移，未必处于其原论文最优设定，部分基线也缺少与本文同等的调参预算。第六，方法为免训练流水线，未探索与微调、偏好优化或检索器联合训练的结合；DocScore 由 LLM 自评，存在过度自信与校准漂移风险，尤其当干扰文档与问题表面高度相似时。最后，句级压缩仅保留 2 句可能丢失跨句依赖、数值约束或实体链信息，对需要长距离组合的证据不友好。

## 9. 总体评价与启示

- **贡献定位**：论文把“迷失在中间”从单纯的位置重排问题，推进为“证据选择—双视图推理—质量剪枝—最终裁决”的系统性问题；将 W 形注意力尖峰形式化为注意力对比信号，是该工作最有解释力、也最轻量的创新点。
- **实践启示**：若部署环境无法获取注意力，可用“生成似然 + 语义相似度 + 重排器”替代 Φ_cont；对延迟敏感场景，可缓存 SFS 分数、按需启用 Global Agent、减少 Judge 调用，或仅在高分歧样本上触发完整流水线。
- **研究机会**：自适应选择 k 与 τ、学习式融合权重、跨层/跨头注意力聚合、将 DocScore 校准为风险控制信号，以及把该方法扩展到长文档、多证据、更多模型族与端到端检索器联合优化，都是自然延伸。
- **结论性判断**：DuQUAD 在受控 LiTM 协议与多跳干扰场景下表现稳健，消融与显著性检验较充分，适合作为 RAG 推理阶段的增强模块；但其多跳绝对性能、额外延迟与对注意力可获取性的依赖，仍是实际落地的主要瓶颈，尚不宜视为端到端 RAG 的通用替代方案。
