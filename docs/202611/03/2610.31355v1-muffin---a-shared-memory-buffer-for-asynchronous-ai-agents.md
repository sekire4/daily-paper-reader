## 摘要
智能体式 AI 系统的兴起改变了人工智能的格局，它通过专门的多智能体交互与结构化自我反思实现了强大的推理能力。然而，在目标驱动的推理任务中，单智能体与多智能体系统在性能增益上往往不相上下。一个主要挑战是：失败往往源于智能体间交互与协调过程中关键信息交换无效。与依赖同步轮流发言并在不同智能体之间共享信息的现有多智能体辩论范式不同，我们提出了一种基于共享内存缓冲区推理（shared Memory bUFFer INference，简称 MUFFIN）的智能体间协议，并将其置于异步智能体框架中。第一步，编排器根据查询的推理需求进行路由，并将高需求查询委派给多智能体环境；在该环境中，共享内存缓冲区提供中间发现的异步交换，同时智能体的私有推理仍保留在本地。我们的实验表明，Muffin 框架优于已有竞争者，在我们 20 个基准设置中的 17 个取得最佳准确率，并且相比多智能体辩论提供了更好的质量-成本权衡：Muffin 将准确率提升 19.2 个百分点，同时少用 77.4% 的 token，且无需共享完整轨迹。

## Abstract
The rise of Agentic AI systems has changed the landscape of artificial intelligence by enabling strong reasoning capabilities through specialized multi-agent interaction with structured self-reflection. However, in target-driven reasoning tasks, single- and multi-agent systems are often on par in terms of performance gains. A major challenge is that failures often arise from an ineffective exchange of critical information during inter-agent interaction and coordination. Different from existing multi-agent debate paradigms that rely on synchronous turn-taking and sharing information across different agents, we propose an inter-agent protocol based on shared Memory bUFFer INference - referred to as MUFFIN - in an asynchronous agentic framework. In the first step, an orchestrator routes queries based on their reasoning demands and delegates demanding ones to a multi-agent setting, where a shared memory buffer provides asynchronous exchange of intermediate findings while an agent's private reasoning remains local. Our experiments show that our framework Muffin outperforms established competitors, achieving the best accuracy in 17 out of 20 of our benchmark settings, and provides a better quality-cost trade-off than multi-agent debate: Muffin improves accuracy by 19.2 accuracy points while using 77.4% fewer tokens, without requiring full-trace sharing.

## 1. 核心问题与研究动机

- **背景**：Agentic AI 借助多智能体交互与结构化自我反思获得强推理能力，但在目标驱动推理任务上，单智能体与多智能体系统性能往往不相上下，多智能体并不自动带来增益。
- **核心症结**：失败多源于智能体间协调过程中**关键信息交换无效**（信息丢失、验证失败）；现有系统通常在智能体产出**完整输出后**才通信，导致部分关键中间发现对同伴不可见，同时又用冗长、与任务无关的推理轨迹淹没对方，抬高上下文开销。
- **范式局限**：主流多智能体辩论（Multi-Agent Debate）依赖**同步轮流发言**并共享完整回答/批评，成本高、延迟大。
- **研究问题**：智能体能否在推理过程中**异步共享中间发现**，让同伴按需检索复用，而**不暴露完整推理轨迹**？
- **整体含义**：提出一种介于“仅聚合最终答案”与“全轨迹交换”之间的中间路线——以共享内存缓冲区实现选择性、异步的信息协调。

## 2. 方法论（MUFFIN）

### 2.1 总体流程（四阶段）
1. **Orchestrator（编排器）**：LLM 将查询 x 映射为推理计划 π = (z, {α_i}, ρ)，其中 z ∈ {direct, multi} 为路由决策，α_i = (a_i, r_i, τ_i) 为智能体、角色与非重叠子任务，ρ 为协作协议（规定共享何种信息、什么保留本地、是否允许反应式步骤）。
2. **direct 路由**：单次调用 y ~ p_θ(·|x) 即结束，不启用缓冲区与总结器。
3. **multi 路由**：多智能体并发推理，经共享内存缓冲区异步交换发现。
4. **Summarizer（总结器）**：仅接收查询、各智能体分配信息与**最后一步摘要**，综合出最终答案。

### 2.2 共享内存缓冲区
- 缓冲区状态 B^(d) = (e_1, …, e_ℓ)，条目 e_j = (a_i, s_i^(t), t)，记录来源智能体、第 t 步的发现、来源步标识。
- **append-only 数据结构**：已有数据不可变，仅允许追加，因此 B^(d) ⪯ B^(d')（d ≤ d'），**无写冲突、无需加锁**（仅保证追加原子性）。
- **有界检索窗口** R_k(B^(d), i)：回溯读取最近 k 条**其他智能体**的发现，跳过自身条目（自身信息已在私有历史中）。

### 2.3 智能体单步流程
- 上下文构造：c_i^(t) = C_agent(x, r_i, τ_i, h_i^(t), R_k(B_{β_i,start^(t)}, i), ρ)
- 结构化输出：(m_i^(t), s_i^(t), n_i^(t)) ~ p_θi(·|c_i^(t))，分别为**步骤摘要**、**可选共享发现**、**仅本地可见的私有笔记**。
- 若产生共享发现则追加：B_{β_i,end^(t)} = B_{β_i,end^(t)}⁻ ◦ (a_i, s_i^(t), t)。
- 私有历史独立更新：h_i^(t+1) = H_i(h_i^(t), m_i^(t), n_i^(t))，**只保留压缩摘要而非完整轨迹**，控制本地状态规模。

### 2.4 异步执行机制（关键创新）
- **无全局轮次索引**：智能体完成上一步（β_i,end^(t−1)）后立即被派发，不等待其他智能体。
- **可见性条件**：a_i 在 β_i,end^(t) 提交的发现对 a_j 可见，当且仅当 β_i,end^(t) ≤ β_j,start^(t') 且落在最近 k 条窗口内；时间区间重叠的两次推理无法共享尚未提交的发现。
- **反应式步骤**：若协议 ρ 允许，每个智能体额外执行恰好一步，推理视野 T_i = T + 1，在 β_i,start^(T+1) = max_j β_j,end^(T)（所有智能体至少完成 T 步）时派发。

### 2.5 总结器
- 输入 c_sum = C_sum(x, {(α_i, m_i^(Ti))})，只含各智能体最后一步摘要；缓冲区信息通过摘要间接抵达。
- 明确约束：**不重新解题、不引入新假设、不选无智能体输出支持的答案**，仅从候选中择优并以候选聚合为“证据而非权威”。

## 6. 主要结论与发现

- **准确率**：20 个设置中 **17 个取得最佳**，其余 3 个为第二；相对最强基线平均提升 **4.4 个百分点**，OlymMATH-E 上提升 **11.8 点**，OlymMATH-H 提升 2.6 点。收益在需要多步协作推理的任务上最大，在基线本已很强的任务上边际较小。
- **质量–成本权衡**：在 OlymMATH-E 上，Muffin 相比多智能体辩论**提升 19.2 个准确率点，同时少用 77.4% token**；第 6 步即达最高性能，加入总结器后从 44.9% 升至 59.2%。
- **选择性共享 vs 全轨迹共享**：全轨迹在早期步更高，但最终仅从 85.0% 提升到 87.3%，而 token 从 41.9K 增至 160.6K；即 **Muffin 用少 73.9% 的 token 保留了大部分收益**。
- **agent 数量**：2→3 显著提升（50.6%→59.3%），4/5 个仅微增（59.7%/58.7%）但 token 持续上升，呈**收益饱和**。
- **共享预算 k**：小模型在 k=10 最优（比 k=5 高 5.0 点），继续增大反而下降；大模型对 k 不敏感（波动仅 2.0 点）——说明**适度共享即可，过多引入冗余与过时信息噪声**。
- **共享发现的作用机制**：Chess 上 20.5% 的共享发现改变了同伴答案，第一步转移高达 43.2%，随后降至 15.8%（随缓冲区填充而收敛）；改变中 wrong→correct 占优（早期 51.6% vs 14.2%），说明**早期发现的边际价值最高**。
- **总结器价值**：在 11.14% 的样本上改变最后 agent 答案，其中 32.05% 为 wrong→correct、21.20% 为 correct→wrong，**净收益 +10.85 点**，说明其不只是复制或多数投票。

## 7. 优点

- **机制设计清晰且工程友好**：append-only 缓冲区天然无写冲突、无需锁，异步派发摆脱全局轮次同步，具备良好并发可扩展性。
- **信息粒度创新**：以“结构化输出三元组（摘要 / 共享发现 / 私有笔记）”显式分离**可共享**与**须私有**的信息，避免全轨迹暴露带来的上下文污染与隐私/推理泄露风险。
- **成本意识强**：Orchestrator 路由避免简单查询被无谓地多智能体化；有界窗口 k 提供可调的信息预算旋钮。
- **评估维度完整**：不仅比准确率，还系统刻画准确率–token 的 Pareto 前沿，并做 full-trace、agent 数量、共享预算三组对照，结论具有可操作性。
- **可解释性分析到位**：对“共享发现是否改变答案、朝哪个方向改变”做逐步归因，直接支撑“早期发现价值最高”的设计洞见。
- **可复现性好**：公开代码仓库，附录给出 orchestrator / agent / summarizer / direct 四套完整 prompt 模板，并附 AI 使用声明与可复现性声明。

- **可扩展性与失效模式未讨论**：缓冲区为 append-only 且理论上无限增长，论文未说明实际实现中是否截断、内存占用如何随步数与 agent 数增长；也未讨论智能体给出**冲突或错误发现**时（错误信息经缓冲区放大）的传播风险，而错误传播恰是多智能体系统的经典失效模式。
- **隐私与安全的双面性**：论文将“不暴露完整轨迹”作为优点，但共享发现本身仍是模型生成的自由文本，是否存在敏感信息或推理线索泄露，未做任何定量或定性评估。
- **写作与呈现**：正文核心结论依赖大量附录图（B.1 的 10 张、B.2 的 18 张），主文对机制分析只给代表性示例，读者难以在主文内完整复核结论；部分指标（如“共享发现改变答案的比例”）的统计口径需借助附录定义。

## 9. 启示与可延伸方向

- **把“共享什么”变成可学习/可校准的决策**：当前由 agent 自主判断共享内容，可引入显式的价值估计（如“该发现是否可能改变他人答案”）或轻量筛选器，替代纯提示词约束。
- **将异步机制与系统指标绑定评估**：在真实并发环境下测量端到端延迟与吞吐，才能验证 append-only + 无锁设计的实际收益，这也是该工作从“算法框架”走向“系统贡献”的关键一步。
- **向真实 agentic 场景迁移**：工具调用、代码执行、长程规划等任务中，中间发现（如“某 API 不可用”“某分支已被排除”）的共享价值可能远高于问答基准，是该方法最值得验证的战场。
- **与流式/ token 级协作方法对照**：Muffin 处在“最终答案聚合”与“全轨迹交换”之间，若能与此区间的其他粒度（如摘要级流式广播、黑板系统）直接比较，其定位会更清晰。

## 10. 总体评价

Muffin 提出了一条务实且工程友好的中间路线：以 append-only 共享内存缓冲区 + 有界检索窗口 + 结构化三元组输出，把多智能体协作从“同步轮流交换完整答案”改造为“异步按需复用压缩后的中间发现”。其在 20 个设置中 17 个最优、平均 +4.4 点，并在 OlymMATH-E 上以少 77.4% 的 token 超过辩论基线 19.2 点，配合 full-trace 对照、agent 数量与共享预算扫描、“共享发现是否改变答案”的逐步归因，构成了较完整的“质量–成本”论证链条。局限主要在于任务与模型覆盖偏窄、异步收益缺乏系统级实测、路由与共享筛选机制未被单独评估，以及小样本下的显著性未做检验。总体而言，这是一篇**机制清晰、成本意识强、结论具可操作性但泛化边界尚待验证**的系统性工作。
