## 摘要
LLM 智能体在语言交互中具有灵活性，但将其用作长时程规划器成本高昂，且容易产生幻觉或无效动作。本文针对 LLM 的另一种角色：作为语言与符号规划之间的受约束桥梁。我们提出 MemPlan，一种面向部分可观测交互式文本环境的记忆条件化 PDDL 规划框架。MemPlan 保持 PDDL 域固定，并在每一步根据解析后的观测、候选假设和交互记忆重构 PDDL 问题。正向图记忆为缺失对象、位置或条件的候选假设分配基于相关性的动作代价，引导规划器朝向更合理的检查。负向记忆记录被执行反驳的假设，并将其编译为排除约束，防止重复尝试已被反馈否定的候选。一个统一的模式条件化语言—符号接口通过观测到事实的解析和符号动作到命令的落地，将文本环境连接到规划循环，并使用监督微调进行离线训练。在 TextWorld、ALFWorld 和 Robotouille 上的实验表明，与仅语言和 PDDL 感知的基线相比，MemPlan 提高了任务完成率和步骤效率，同时与 ReAct 等 LLM 规划基线相比大幅降低了在线 token 成本。同一微调接口还可在无需任务特定微调的情况下跨 TextWorld 任务类型复用。我们的代码和数据可在以下网址获取：https://github.com/tewiSong/MemPlan。

## Abstract
LLM agents are flexible in language interaction, but using them as long-horizon planners is costly and prone to hallucinated or invalid actions. This paper targets a different role for LLMs: constrained bridges between language and symbolic planning. We propose MemPlan, a memory-conditioned PDDL planning framework for partially observable interactive text environments. MemPlan keeps the PDDL domain fixed and reconstructs the PDDL problem at each step from parsed observations, candidate hypotheses, and interaction memory. Positive graph memory assigns relevance-based action costs to candidate hypotheses for missing objects, locations, or conditions, guiding the planner toward more plausible checks. Negative memory records execution-refuted assumptions and compiles them into exclusion constraints, preventing repeated attempts at candidates already contradicted by feedback. A unified schema-conditioned language--symbol interface, trained offline with supervised fine-tuning, connects text environments to the planning loop through observation-to-fact parsing and symbolic-action-to-command grounding. Experiments on TextWorld, ALFWorld, and Robotouille show that MemPlan improves task completion and step efficiency over language-only and PDDL-aware baselines, while substantially reducing online token cost compared with LLM-planning baselines such as ReAct. The same fine-tuned interface is also reused across TextWorld task types without task-specific fine-tuning. Our code and data are available at: https://github.com/tewiSong/MemPlan.

## 1. 核心问题与研究动机

- **背景**：交互式文本环境（TextWorld、ALFWorld、Robotouille）要求智能体在部分可观测、后果延迟的条件下完成长时程任务，输入输出均为自然语言。
- **LLM 直接当规划器的问题**：成本高、易产生幻觉动作、丢失早期观测、难以维持一致的长程计划；已有实证显示用经典规划器替代 LLM 规划可节省约 93.1% 的 LLM token。
- **经典规划器的互补优势与错配**：Fast Downward 等可在 PDDL 域上显式搜索前置条件与效果，但要求**闭世界、完整符号状态**，而文本环境只提供局部观测。
- **现有两条路线的缺陷**：
  - *信念/开世界补全*：先猜一个完整状态再规划，缺失对象/位置/条件可能有多种合理补全，过早承诺导致无效搜索与反复失败。
  - *迭代式 PDDL 精化*：在线让 LLM 改写域/问题文件，正确性依赖反复在线形式化，易产生畸形 PDDL、幻觉事实、无效目标或遗忘观测。
- **本文定位**：不把 LLM 当规划器，而把它约束为**语言与符号规划之间的受限桥梁**；域保持固定，每步重建问题文件，并把交互记忆编译进规划。

## 2. 方法论

### 2.1 总体框架

- 每步输入：目标 `g`、文本观测 `o_t`、可执行命令集 `A_t`；输出一条命令 `c_t ∈ A_t`。
- 固定 PDDL 域 `D`（对象类型、谓词、动作模式、前后条件），**不在线生成或修复**。
- 每步重建问题实例：
  `P_t = BuildProblem(D, g, F_t, H_t, M⁺_t, M⁻_t)`
  其中 `F_t` 为验证过的观测三元组，`H_t` 为候选假设，`M⁺/M⁻` 为正/负记忆。
- 规划器返回计划 `π_t`，**只执行第一个符号动作**，观测反馈后更新记忆并重规划（receding-horizon 式闭环）。
- 若规划为空，则执行一条可用的“观察类命令”，且**不把未实现的符号动作记为已执行**，仅用环境反馈更新记忆。

### 2.2 离线模式条件化语言—符号接口

- 单一 Qwen2.5-7B 接口，监督微调后**冻结**，承担两种指令格式，不做规划、不改域、不重写问题。
- **观测→事实解析**：输入 `(o_t, S_D, O_t)`；三元组仅当关系属于域谓词模式、参数类型匹配、实体在词表内（或作为仅规划内部使用的占位符）时才被接受。
- **符号动作→命令落地**：给定首个符号动作 `u_t`、观测与 `A_t`，用打分函数 `s_θ(u_t, o_t, c)` 在可实现 `u_t` 的候选命令子集上取 argmax；若该子集为空，则改执行观察命令并重规划。

### 2.3 记忆与候选假设

- 记忆统一存为**带类型三元组**：
  - 正记忆 `M⁺_t ⊆ E_t × R_D × E_t`：由观测或成功执行支持。
  - 负记忆 `M⁻_t ⊆ E_t × R⁻_D × E_t`：如 `searched`、`not_at`，来自“定向检查返回 not found”等被反驳的假设。
- **占位符机制**（受开世界规划 runtime objects 启发）：目标所需但未解析的实体用带类型占位符 `z` 表示；候选假设 `h = (z, r, v)`，`v` 来自已观测实体、记忆图邻域、近期到访区域、与目标兼容的取值；一旦解析为具体实体，后续问题直接用具体实体。

### 2.4 记忆条件化 PDDL 构造

- `BuildProblem` 做四件事：
  1. 对象表写入具体实体与未解析占位符，占位符放入虚拟位置 `loc_limbo`；
  2. 初始状态写入 `F_t` 与模式兼容的 `M⁺_t`；
  3. 为 `H_t` 中的候选插入**假设检查动作**；
  4. 把 `M⁻_t` 编译为排除谓词（如 `searched(r)`、`not_at(z,v)`）；目标由 `g` 导出，动作模式全部来自固定 `D`。
- **正记忆→动作代价**：
  - 用冻结的多语 mContriever 计算相关性：查询 `q_t(z) = "Goal: g; Missing: z"`，文档 `d_t(h) = "Candidate: (z,r,v); Context: Linearize(N1(v; M⁺_t))"`（正记忆图中 `v` 的一跳邻域）。
  - 余弦相似度在当前候选集上做 min–max 归一化得 `Score_t(h) ∈ [0,1]`。
  - 代价公式：`κ_t(h) = κ_base + ⌈λ · max(0, τ − Score_t(h))⌉`；物理动作取 `κ_base`。
  - 问题文件含 `(:metric minimize (total-cost))`；超参固定 `κ_base=1, τ=0.50, λ=10`。
  - 注意：规划器为 **satisficing** 配置，代价只**偏置**搜索顺序，不保证全局最优。
- **负记忆→排除约束**：被反驳候选在下次构造时被删除或通过排除谓词使其不可用，防止重复检查；与迭代式重写不同，**域不变、LLM 不在线改写 PDDL**。
- 算法 1 概括完整在线循环：解析→入正记忆→生成候选→算分与代价→剔除被排除候选→构问题→规划→落地执行→按反馈更新正/负记忆。
