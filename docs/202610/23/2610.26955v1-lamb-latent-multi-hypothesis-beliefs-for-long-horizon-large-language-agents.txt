Abstract 

Long-horizon language agents require compact memories that retain interaction evidence while preserving competing hypotheses about unobserved states. Although effective, many belief-state methods encode memory in discrete natural language, where repeated compression can omit evidence or prematurely discard plausible alternatives. We introduce LAMB, a recurrent framework for latent multi-hypothesis beliefs. A Common–Delta factorization combines a shared Common state for interaction evidence with weighted Delta components for competing hypotheses. Relative evidence from action-outcome predictions guides recurrent hypothesis updates without generating textual memory. A context-conditioned readout exposes hypotheses separately to the policy through a fixed-token belief prefix in the default configuration. The belief modules and policy are jointly trained using action imitation and auxiliary state, outcome, and observation-discrimination objectives. Across ALFWorld, BabyAI, ScienceWorld, and Crafter, LAMB matches or outperforms PABU, improving ALFWorld SR@30 and ScienceWorld success by 6.0 and 22.0 percentage points, respectively, and Crafter achievement progress by 26.37 points. On ALFWorld, it also reduces the redundant-action rate by 17.70 percentage points. These results support latent multi-hypothesis beliefs as compact memory for effective long-horizon decision making. 

Keywords: LLM agents, belief state, latent memory, long-horizon decision making 

# 1 Introduction 

Large language model (LLM) agents solve multi-step tasks through sequences of actions and observations (Yao et al., 2023), which has wide applications in many fields (Liu et al., 2024b, 2025a,b). Under partial observability, effective decisions require retaining earlier evidence while reasoning about aspects of the environment that remain unobserved. Conditioning on the full interaction history provides access to past information, but its growing length increases the context processed at each decision. Long-horizon agents therefore need memory that preserves decision-relevant information without repeatedly processing the complete trajectory. Context-management methods reduce this burden by pruning, masking, or compressing past interactions (Lindenbauer et al., 2025; Xiao et al., 2026). Belief-state methods instead

Although simple and effective, many LLM belief-state methods still represent beliefs in discrete natural language (Jiang et al., 2026; Lidayan et al., 2026; Singh et al., 2026). Even when augmented with confidence labels, these states must express retained evidence and alternatives within a limited text budget. Repeated selection and rewriting can omit earlier findings or prematurely discard plausible interpretations. For example, Figure 1 shows an agent ruling out the dresser while considering the bed, drawer, and shelf as possible laptop locations. Its memory should preserve the inspection result shared by both alternatives and revise the candidates as new evidence arrives. Updating textual beliefs through generation also incurs decoding overhead beyond action selection. These considerations motivate our central question: how can a fixed-size recurrent memory retain shared evidence while preserving and revising competing hypotheses without repeatedly verbalizing its state? 

To address this question, we propose LAMB, a latent belief framework that tracks episode information directly in continuous latent space. Through a Common–Delta factorization, a shared Common component is trained to retain interaction evidence, while weighted Delta components encode hypothesis-specific information. Rather than pooling the particles into a single representation, a context-conditioned readout exposes each Delta to the policy separately, alongside the Common readout. The default configuration produces a fixed-token belief prefix, keeping the historical contribution to policy input constant throughout the episode. To make hypothesis revision responsive to new evidence, LAMB compares each particle’s action-outcome prediction with the feedback received from the environment. The resulting relative LAMB: Latent Multi-Hypothesis Beliefs for Long-Horizon Language Agents 3

evidence guides recurrent Delta updates, after which mixture weights are recomputed from the updated Common and Delta states. We jointly train the belief modules and policy on offline interaction trajectories using action imitation, joint state-semantic prediction, outcome-semantic prediction, and observation discrimination for the Common component. Simulator-derived state labels are used only during training; online belief updates rely on observed actions and feedback. We evaluate LAMB on ALFWorld, BabyAI, ScienceWorld, and Crafter. Results show that LAMB matches or outperforms the strong baselines across these benchmarks while reducing token consumption on ALFWorld. Ablations and diagnostic analyses further assess the proposed design and characterize evidence retention, particle readouts, and agent behavior. Our main contributions are as follows: • We propose LAMB, a fixed-capacity latent belief framework that supports long-horizon decisions with a constant-size policy prefix, without generating textual memory updates. • We develop a Common–Delta representation with action-outcome prediction, evidence-guided recurrent updates, and an unpooled readout of weighted hypotheses. • We demonstrate task-performance gain across four benchmarks and inference cost on ALFWorld, complemented by ablations, redundant-action analysis, and diagnostics of evidence retention and particle readouts. 

# 2 Related Work 

2.1 Stream-based Agent Memory 

Many agent-memory systems organize past interactions as records that are retrieved, revised, or compressed for subsequent use. Generative Agents (Park et al., 2023) and MemGPT (Packer et al., 2024) keep the full record in external storage and page relevant entries into context, A-MEM (Xu et al., 2025) links and updates memory entries. Compression methods, including LLMLingua-2 (Pan et al., 2024), LongLLMLingua (Jiang et al., 2024), and ACON (Kang et al., 2026) reduce the context passed to the policy. Experience-reuse methods, including Reflexion (Shinn et al., 2023), ExpeL (Zhao et al., 2024), AWM (Wang et al., 2025), and ACE (Zhang et al., 2026c), distill cross-episode knowledge into insights, workflows, or playbooks. These approaches differ in their retention and access mechanisms; the accessibility of retained evidence can also depend on its placement within the context (Liu et al., 2024a). Our LAMB focuses on maintaining a fixed-size state of the current episode through recursive updates, which offers a different interface for carrying interaction evidence into each decision. 

2.2 Textual Belief State 

Belief-state approaches maintain a compact representation for decision making under partial observability (Kaelbling et al., 1998). MEM1 (Zhou et al., 2026) and ABBEL (Lidayan et al., 2026) learn textual states that consolidate information across interactions, while PABU (Jiang et al., 2026) tracks task progress together with selectively retained actions and observations. Agent-BRACE (Singh et al., 2026) and BeliefMem (Liao et al., 2026) further encode uncertainty through confidence labels or candidate records. Textual beliefs, however, represent uncertainty by enumeration : evidence shared across hypotheses is restated for each candidate, so a bounded state must trade evidence retention LAMB: Latent Multi-Hypothesis Beliefs for Long-Horizon Language Agents 4

against hypothesis coverage. In practice this trade-off surfaces either as forgotten findings or as premature commitment to a single hypothesis (Krishnamurthy et al., 2024). LAMB keeps hypotheses in latent form on top of a shared common state, so each additional hypothesis costs one prefix token rather than another restatement of the evidence. 

2.3 Latent Memory and Filtering 

Latent-memory methods encode context as learned continuous representations, avoiding explicit text generation for the memory itself. Recurrent Memory Transformer (Bulatov et al., 2022), AutoCompressors (Chevalier et al., 2023), Gist tokens (Mu et al., 2023), Laser (Wang et al., 2026) and ICAE (Ge et al., 2024) condense context into a small set of learned vectors. In agent settings, Mem-W (Zhang et al., 2026b) and MemGen (Zhang et al., 2026a) bring such representations to agents as within-episode and generative memory. However, particle-based belief models, such as Particle Filter Networks (Karkus et al., 2018), DVRL (Igl et al., 2018), and PF-RNN (Ma et al., 2020), make hypotheses explicit, but each particle replicates the full state, reintroducing the duplication of shared evidence. In contrast, LAMB factorizes a recurrent latent belief into a common component that stores shared evidence once and hypothesis-specific deltas that encode only how alternatives differ.

3.3 Unpooled Policy Readout 

Directly pooling particle beliefs into a single vector collapses multimodal uncertainty, blending mutually exclusive hypotheses into ambiguous mean states. To preserve discrete alternatives while anchoring the decision in established facts, we design an asymmetric readout that translates the belief into a structured prefix sequence. Specifically, the common state 𝑐 𝑡 is integrated with the current input representation Embed (𝑥 𝑡 ) via cross-attention into 𝑀 context tokens, capturing verified environmental con-straints. In parallel, each particle 𝛿 𝑖 𝑡 is projected into an individual hypothesis token 𝑒 𝑖 𝑡 ,modulated by its log-weight: ˜𝑒 𝑖 𝑡 = 𝑒 𝑖 𝑡 + 𝑣 log 𝑤 𝑖 𝑡 , where 𝑣 is a learned direction vector. Maintain-ing 𝐾 separate hypothesis tokens enables the policy’s self-attention mechanism to explicitly contrast candidate states, isolating dominant hypotheses from marginal ones without infor-mation loss. Finally, the resulting 𝑀 + 𝐾 belief tokens are prepended as a belief-conditioned continuous prefix (Li and Liang, 2021) to the embedded input 𝑥 𝑡 , and the policy 𝜋 𝜃 (fine-tuned via LoRA) generates the action 𝑎 𝑡 .

# 4 Experiments 

4.1 Experimental Setup 

Environments. We evaluate LAMB on four interactive benchmarks, reporting SR@30 on ALF-World (Xi et al., 2025), task success rate on ScienceWorld (Wang et al., 2022), AgentBoard subgoal progress on BabyAI (Ma et al., 2024), and BALROG achievement progress on Crafter (Paglieri et al., 2025). Environment interfaces and evaluation protocols are detailed in Appendix F. 

Baselines. We group baselines into three categories: (1) Open-weight API models : Qwen3-8B, Qwen3-32B (Yang et al., 2025), and GPT-OSS-120B (Agarwal et al., 2025), using full interaction histories without task-specific training; (2) Proprietary API models : GPT-5.6-luna (OpenAI, 2026), Claude-Haiku-5.5 (Anthropic, 2026), and Gemini-3-Flash (Google DeepMind, 2025), also using full interaction histories; (3) Benchmark-tuned models : fine-tuned Qwen3-8B-FH, BeliefMem (Liao et al., 2026), AgentEvol (Xi et al., 2025), PABU (Jiang et al., 2026), and Agent-BRACE (Singh et al., 2026). 

Training and inference. We jointly train the belief modules and LoRA adapters with a frozen Qwen3-8B backbone; inference updates only the latent belief. Training details and hyperparameters are provided in Appendix D.

5.2 Redundant Action Analysis 

Evidence degradation manifests in behavioral artifacts before it lowers task success: an agent re-inspects visited locations, searches for objects it has already found, or retries actions that recently failed. We utilize redundant actions as an empirical probe to evaluate what the belief retains, defining redundancy by contextual task relevance instead of literal command repetition. Specifically, an action is deemed redundant if, given past observations and environment rules, it contributes neither to advancing pending subgoals nor to resolving necessary task uncertainties. We evaluate Qwen3-8B zero-shot, PABU, and LAMB across ALFWorld, ScienceWorld, and Crafter (Figure 4). On ALFWorld and Crafter, LAMB achieves the lowest redundancy rates across all methods (16.40% and 0.94%), outperforming PABU by 17.70 and 16.04 percentage points, and improving over zero-shot prompting by more than 33 points. In addition, on ScienceWorld, LAMB cuts zero-shot redundancy from 35.55% to 9.45%. While PABU records a lower numerical redundancy rate (4.66%), this metric must be contextualized with task completion: PABU succeeds on only 61.5% of ScienceWorld tasks, terminating prematurely on complex trajectories where redundant behaviors typically accumulate. In contrast, LAMB achieves 83.5% task success (+22.0 points over PABU) while maintaining single-digit redundancy. These results demonstrate that structured latent particles systematically curtail aimless interactions across complex long-horizon environments. 

Fine-grained error breakdown. To identify which memory failures our latent belief resolves, we categorize ALFWorld redundant actions into five mutually exclusive failure modes: re-observation , unnecessary search , unnecessary manipulation , failed retries , and repeated operations 

(formal definitions in Appendix C). And Figure 5 visualizes the distribution of these failure modes across executed actions. While zero-shot Qwen3-8B exhibits high redundancy across all modes, PABU curbs re-observations but suffers severely from failed retries, which account for 20.06% of its total actions. This reveals an inherent limitation of natural-language summaries: textual memory typically logs that an action was executed, but struggles to retain whether it failed or why. In contrast, LAMB completely eliminates failed retries, unnecessary manipulations, and repeated operations (0% across all three categories). Although our re-observation rate is slightly higher, eradicating the 20-point retry failure mode reduces overall redundancy by 17.70 points. This decisive gain confirms that our observation-conditioned particle update effectively propagates failure feedback through negative evidence signals. Meanwhile, re-inspecting known information remains the primary residual source of redundancy.

We introduced LAMB, a recurrent latent belief framework that factorizes memory into a shared state and weighted hypotheses, updated using action-outcome evidence. # B Particle Count and Token Budget 

We investigate how agent performance scales when the number of Common readout tokens and Delta particles are varied jointly. # C Redundant Action Categories 

An action is redundant if it (i) reveals no new information, (ii) causes no task-relevant state change, and (iii) satisfies no precondition for a later step. Redundancy is judged only from information available before execution: exploring unverified states is not considered redundant merely because a more direct trajectory existed in retrospect. Under this definition, redundancy encompasses both literal string repetitions and non-repetitive detours made avoidable by available context. We classify redundant actions into five mutually exclusive categories. Re-observation gathers facts the agent has already observed. Unnecessary search continues exploring after the target location is established. Unnecessary manipulation performs state-changing actions that are irrelevant or destructive to the task. Failed retry re-attempts an unachieved objective without addressing the cause of its failure. Repeated operation re-applies an effect that has already been achieved and still holds.Figure 5 visualizes their rates on ALFWorld. 

Category boundaries. Three rules resolve actions that could fit two categories: (1) Re-observation vs. unnecessary search depends on whether the target location is known. Searching a previously eliminated container while the target is still unknown is a re-observation; searching other LAMB: Latent Multi-Hypothesis Beliefs for Long-Horizon Language Agents 22 

containers after the target has been found is an unnecessary search. (2) Failed retry vs. repeated operation depends on whether the intended effect has already been achieved. Re-opening a locked door without acquiring the key is a failed retry; opening a door that is already open is a repeated operation. (3) Unnecessary manipulation vs. repeated operation depends on whether the action disrupts progress. Removing an item already placed in its correct receptacle is an unnecessary manipulation; reheating an object that is already heated is a repeated operation. 

Non-redundant repetition. Repetition at the string level does not inherently indicate redun-dancy. Multi-object tasks legitimately require consecutive pick actions; combat, mining, or waiting sequences frequently demand successive identical operations; and re-inspecting an environment following a state-altering action is often necessary. Furthermore, an initial failure followed by a retry after resolving the prerequisite condition is strictly classified as valid task execution.

# F Benchmark Details 

ALFWorld (Xi et al., 2025) is a text-based household environment in which agents locate and manipulate objects across rooms, often through multi-stage operations such as cleaning, heating, and cooling. The AgentGym evaluation setting includes 200 test tasks with a 50-action limit. Performance is measured by SR@30 and SR@50, the success rates within the first 30 and 50 actions, respectively. 

BabyAI (Ma et al., 2024) tests grounded instruction following in partially observable grid worlds, requiring agents to track spatial layout, inventory, and prerequisites such as finding a key before opening a locked door. The AgentBoard evaluation setting includes 112 test instances across 28 levels, with a 30-action limit. Performance is measured by mean subgoal progress. 

Crafter (Paglieri et al., 2025) is a procedurally generated open-world survival game with 22 achievements covering resource gathering, crafting, and combat, requiring agents to track vital stats, inventory, and prerequisite chains. Evaluation uses the BALROG text interface and evaluator on ten held-out seeds, with up to 2,000 steps per episode. Performance is measured by achievement progress, the fraction of achievements unlocked averaged over seeds. 

ScienceWorld (Wang et al., 2022) is a text environment for multi-step scientific experiments, such as measuring melting points, building circuits, and classifying organisms. Because standard subsets are dominated by short-horizon tasks, we evaluate on 200 longer-horizon variations from 19 task categories of the official unseen test split, with a 30-decision limit. We use the official easy setting, which removes navigation and door- or container-opening steps but leaves the experimental procedure unchanged, so agents must still retain observations across multiple steps to complete each task. A task succeeds only if it reaches the maximum score of 100.
