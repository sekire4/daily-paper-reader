## 摘要
长期记忆使语言模型智能体能够个性化未来的交互，但有限的记忆库无法保留每个提取出的事实。现有的记忆门控策略通常在所有用户间共享，因此无法考虑用户特定的未来重用模式。本文研究事实层面的记忆门控。我们首先提出一种基于检索的标注策略，通过每个事实之后是否被检索并纳入响应来对其进行标注。然后，我们将在线记忆门控建模为具有延迟单侧反馈的上下文苹果品尝问题，并提出 Warm-Start UCB，它将基于现有数据的离线学习与对当前用户的在线适应相结合。我们的理论分析建立了当延迟窗口至多为 $O(\sqrt{T})$ 时的高概率遗憾上界 $\tilde{O}(Tε\wedge d\sqrt{T})$，其中 $T$ 是总轮数，$ε$ 是初始化误差，$d$ 是特征映射的维度，$\tilde{O}(\cdot)$ 隐藏常数和对数多项式因子。实验结果证明，我们的方法在不同记忆预算和历史长度下优于所有基线，使其成为一种有前景的个性化记忆门控策略。

## Abstract
Long-term memory enables language-model agents to personalize future interactions, but a finite memory bank cannot preserve every extracted fact. Existing memory gating policies are typically shared across users and therefore fail to account for user-specific patterns of future reuse. In this paper, we study memory gating at the fact level. We first propose a retrieval-based labeling strategy that labels each fact by whether it is later retrieved and incorporated into responses. We then formulate online memory gating as contextual apple tasting with delayed one-sided feedback, and propose Warm-Start UCB, which combines offline learning from existing data with online adaptation to the current user. Our theoretical analysis establishes a high-probability regret upper bound of $\tilde{O}(Tε\wedge d\sqrt{T})$ when the delay window is at most $O(\sqrt{T})$, where $T$ is the total number of rounds, $ε$ is the initialization error, $d$ is the dimension of the feature map, and $\tilde{O}(\cdot)$ hides constant and poly-logarithmic factors. The results of our experiment demonstrate that our method outperforms all baselines under different memory budgets and history lengths, establishing it as a promising personalized memory gating policy.

## 1. 核心问题与研究动机

- **背景**：长期记忆系统（如 MemGPT、MemoryBank、mem0）已成为 LLM 智能体的标准组件，流程通常是：从对话中抽取候选事实 → 决定是否写入有限容量的记忆库 → 在后续查询中检索。由于存储与上下文预算有限，系统必须判断哪些事实"值得保留"。
- **核心痛点**：现有记忆门控策略是**跨用户共享**的——要么是启发式规则（是否表达稳定偏好、档案属性、长期目标），要么是从长上下文数据中学到的通用策略。这类"普适标准"忽略了**用户异质性**：不同用户对同一类事实的未来复用模式差异显著。In et al. (2026) 在会话级提出 PerMem-Bench 并证实：完美个性化门控与现有因果基线之间存在巨大差距。
- **关键困难：反馈信号从何而来**。已部署系统无法观察"被丢弃的事实是否本来有用"。论文的洞察是：对**被存入**的事实，后续对话中是否被检索并真正纳入回答，是一个自然、可靠的效用信号。
- **信号的两大特性**：
  - **单侧性（one-sided）**：只有选择 `add` 的事实才可能获得反馈，`skip` 的事实永远无反馈——经典"苹果品尝（apple tasting）"结构；
  - **延迟性（delayed）**：反馈只有在未来某个未知时刻才可能显现，且延迟可能很长（实测平均 13～30 个会话）。
- **整体含义**：论文把"个性化记忆门控"从工程启发式提升为一个**可学习、可理论分析**的在线决策问题，并给出兼顾"跨用户迁移"与"单用户在线适应"的算法。

## 2. 方法论

### 2.1 基于检索的效用标注流水线（数据构造）

- **事实抽取**：按时间顺序把每个会话喂给现成记忆系统（mem0），抽取原子事实，累积得到候选事实池（无限预算下的记忆库）。
- **检索触发**：对后续每个用户回合，先用 LLM 判断"回答是否需要查询记忆"，若需要则生成自然语言查询 `q`。
- **检索命中**：用 `q` 检索当时的记忆库，事实若进入 top-k 命中，则标记为"可能被需要"。
- **LLM 裁判验证**：检索命中只是噪声较大的相关性信号（可能存在主题相关但时序错配）。用 LLM 判断该事实是否**必要或显著提升回答质量**，得到验证集 `H0`。
- **召回补充**：当所有检索分数低于阈值（无强匹配）时，让 LLM 检查 top 检索结果中是否存在**组合起来**有帮助的事实子集，得到 `H1`。
- **最终标签**：`y = 1` 当且仅当该事实在 `H = H0 ∪ H1` 中出现过（即未来被检索并确认使用）。
- **评估协议**：固定预算 `B`，逐事实决定 add/skip，满则淘汰最早条目；主指标为**检索命中保留率 RHR**（`H` 中在真正被需要时仍留在库中的比例），辅以门控决策的 F1。

### 2.2 用户异质性的实证依据（Meta 分析）

- 用事实内容的 TF-IDF + 逻辑回归预测效用标签，比较两种设定：
  - **Self**：仅用该用户自身事实做分层 k 折交叉验证；
  - **LOUO**：用其余 19 个用户的池化数据训练单一全局模型，在该用户上测试。
- 结果：LOUO 的 AUC 显著高于随机（S: 0.622，L: 0.665），说明存在**共享成分**；但 Self 的 AUC 更高（S: 0.756，L: 0.724），差距 0.134 / 0.059，说明存在**不可迁移的用户特异成分**。
- **结论**：最优策略应"既向他人学习，又向当前用户适应"——这正是 Warm-Start UCB 的设计动机。

### 2.3 问题形式化：带延迟单侧反馈的上下文苹果品尝

- **交互协议**：每轮 `t` 观察上下文 `x_t ∈ R^d`（事实及其会话上下文的嵌入），选择 `a_t ∈ {add, skip}`。
  - `skip`：丢弃，之后永远无反馈；
  - `add`：环境独立采样延迟 `D_t ~ D`，之后每轮观察截尾转化指示 `z_{t,t'} = y_t · 1{D_t ≤ t' - t}`。持续为 0 是**歧义**的：既可能是"无用事实"，也可能是"有用但延迟未到"。
- **假设**：
  - 延迟分布已知：存在已知 `m`，使 `P[D ≤ m] = κ_m = Ω(1)`；
  - 效用线性：`y_t ~ Bernoulli(η(x_t))`，`η(x) = ⟨θ*, x⟩ ∈ [0,1]`，`θ*` 为用户特异参数；
  - 特征有界 `‖x‖₂ ≤ L`；
  - **Warm-start 假设**：给定先验中心 `μ₀`、先验形状 `Σ₀ ⪰ I` 与半径 `ε`，使 `P(‖θ* - μ₀‖_{Σ₀} ≤ ε) ≥ 1 - δ₀`。附录 D 用"总体参数 + 岭回归估计"两步论证了该假设的合理性（`ε = ε_pop + ε_est`，前者为用户异质性、不随数据量消失）。
- **奖励与目标**：存储收益 `b`、误存代价 `c_store`、漏存代价 `c_miss`（`b + c_store + c_miss = 1`）。对 `y` 取期望后，`add` 优于 `skip` 当且仅当 `η(x) ≥ τ`（`τ = c_store`），故最优策略是阈值策略 `π*(x) = 1{⟨θ*, x⟩ ≥ τ}`。目标是**伪遗憾** `Regret(T)`。

### 2.4 算法：Warm-Start UCB（Algorithm 1）

- **初始化**：`V₀ = λΣ₀`，`b₀ = λΣ₀(κ_m μ₀)`，`θ̂₀ = κ_m μ₀`，置信半径初值 `α₀ = β_{λ,δ}`。
- **每轮流程**：
  1. 观察 `x_t`；
  2. 计算乐观指数 `η̂_t = ⟨θ̂_{t-1}, x_t⟩ + α_{t-1}‖x_t‖_{V_{t-1}^{-1}}`；
  3. 若 `η̂_t ≥ κ_m τ` 则 `add`，否则 `skip`；
  4. 接收本轮结束时所有已到达的延迟反馈；
  5. 更新 `V_t = λΣ₀ + Σ_{s≤t, a_s=add} x_s x_sᵀ`，`b_t = λΣ₀(κ_m μ₀) + Σ_{s≤t, a_s=add} x_s z̄_{s,t}`，`θ̂_t = V_t^{-1} b_t`；
  6. 更新 `α_t = β_{λ,δ} + Σ_{s∈P_t} ‖x_s‖_{V_t^{-1}}`。
- **两个关键技术细节**：
  - **截尾观测**：定义 `z̄_{s,t} = y_s · 1{D_s ≤ min{t-s, m}}`，即只等 `m` 轮，之后即使翻转也不再计入。这样 `E[z̄_{s,s+m} | x_s] = κ_m η(x_s) = ⟨κ_m θ*, x_s⟩`，回归目标变为 `κ_m θ*`。
