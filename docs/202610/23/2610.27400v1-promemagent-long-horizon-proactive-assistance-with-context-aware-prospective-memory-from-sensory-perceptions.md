## 摘要
大型语言模型（LLM）智能体正从被动响应转向主动辅助，能够在没有显式请求的情况下预判用户需求。然而，现有的主动智能体主要处理即时需求，而许多日常情境涉及延迟意图，这些意图只能在数小时或数天后才能执行。人类通过前瞻记忆来处理此类意图，即在恰当时机到来时记住去执行某项意图的能力。本文提出 ProMemAgent，这是首个将前瞻记忆融入日常感官上下文以实现长时程主动辅助的主动智能体。ProMemAgent 将过去的感官感知（例如第一人称视频和音频）组织为上下文感知记忆，生成前瞻线索，并将先前事件与后续发展关联起来以供未来检索。给定当前上下文，它检索相关的过去事件，并执行记忆增强的主动推理，以判断是否需要提供辅助。我们进一步提出 CPMBench，这是首个用于评估基于感官上下文的长时程主动辅助的基准，包含涵盖八个日常类别的 1,000 个实例。大量实验表明，ProMemAgent 取得了最佳的记忆检索性能，并在长时程主动辅助上持续优于所有基线。

## Abstract
Large language model (LLM) agents are moving beyond reactive responses toward proactive assistance that anticipates user needs without explicit requests. However, existing proactive agents primarily address immediate needs, while many everyday situations involve delayed intentions that can only be acted on hours or days later. Humans handle such intentions through prospective memory, the ability to remember to act on an intention when the right moment arises. In this paper, we introduce ProMemAgent, the first proactive agent to incorporate prospective memory over everyday sensory contexts for long-horizon proactive assistance. ProMemAgent organizes past sensory perceptions (e.g., egocentric video and audio) into context-aware memory, generating prospective cues and linking earlier events with subsequent developments for future retrieval. Given the current context, it retrieves relevant past events and performs memory-augmented proactive reasoning to determine whether assistance is needed. We further introduce CPMBench, the first benchmark for evaluating long-horizon proactive assistance over sensory contexts, comprising 1,000 instances across eight everyday categories. Extensive experiments show that ProMemAgent achieves the best memory retrieval performance and consistently outperforms all baselines on long-horizon proactive assistance.

## 1. 核心问题与研究动机

- **背景转变**：LLM 智能体正从"被动响应显式请求"走向"主动辅助"，即在用户未开口时预判需求并主动介入。现有主动式智能体（如 Proactive Agent、ContextAgent）主要处理**即时需求**——需求在当前情境中被推断并当场执行，历史信息只用于建模用户习惯或判断干预时机。
- **被忽视的空白**：大量日常需求是**长时程（long-horizon）**的：意图在此刻形成（如发现牙膏用完），但可执行的时机在数小时甚至数天后（如路过超市）。意图的形成时刻与行动时刻被大量无关日常活动隔开。
- **认知科学对应**：人类依靠**前瞻记忆（prospective memory）**——在恰当时机"想起"去执行延迟意图——来处理此类问题。现有商业系统（Meta Muse、OpenAI Dots）虽能跟踪目标，但仍依赖用户**显式声明**意图；而许多延迟意图是隐含在感官情境中的，从不会被明说。
- **技术挑战**：
  - LLM 在上下文变长时难以可靠触发延迟意图；
  - 无显式查询时，**当前情境是唯一检索线索**，而它与意图形成时的情境往往**语义不连续**，导致基于相似度的 RAG 失效；
  - 现有联想记忆研究仍以查询驱动为主，未解决"仅凭当前情境触发记忆"的问题；
  - 事件是否会在未来变得有用，在观察当下往往不可知，且后续事件可能改变答案（意图被解决/状态变化）。
- **论文定位**：提出 **ProMemAgent**，首个将上下文感知前瞻记忆引入日常感官情境的长时程主动辅助智能体；并构建 **CPMBench**，首个该任务的基准。

## 2. 方法论

### 2.1 任务形式化
- 在时刻 $t$，智能体接收：多模态感官感知 $S_t$（第一视角视频、音频、手机通知）、个人上下文 $P$（习惯、偏好、背景）、历史事件序列 $H_t=(e_1,\dots,e_{t-1})$。
- 输出三元组 $(T,\hat{y},R)=A(S_t,P,H_t)$：推理轨迹、主动决策、主动响应；决定不介入时保持沉默。

### 2.2 感官上下文抽取
- VLM（Qwen3-VL-32B）生成第一视角视频的视觉描述；WhisperX 转写语音并做**说话人区分**（区分用户与他人）；通知格式化为文本。
- 每个时刻形成统一事件表示 $e_t=(t,C_t)$，既作当前检索线索，也作后续入记忆的条目。

### 2.3 上下文感知记忆构建（核心创新）
- **前瞻线索生成**：对每个事件总结情境 $q_i$，抽取事实集合 $F_i$；对每个事实 $f$ 生成：
  - **事件型线索** $K_f$：该事实未来可能变得有用的情境（活动、位置、周围环境、人物等结构化字段）；
  - **时间型线索** $W_f$：未来时间点或时间窗。
  - 线索与"情境"共享同一结构化形式，因而可直接与后续事件的 $q_j$ 比对。
- **跨事件链接**：新事件 $e_j$ 到来时，对先前事件的事实 $f$ 打相关性分：
  $$\max\{\mathrm{sim}(C_j,f),\ \mathrm{sim}(C_j,C_i),\ \max_{\kappa\in K_f}\mathrm{sim}(q_j,\kappa)\}$$
  取 top-$m$（$m=8$）候选，由记忆构建 LLM 判定 $e_j$ 是否更新该事实；**仅当新事件中存在显式证据时**才建立前向链接 $L_f$。此设计对应人类"已完成意图失活"的机制。
- **记忆条目**：$\big(e_i,\ q_i,\ \{(f,K_f,W_f,L_f)\}_{f\in F_i}\big)$。

### 2.4 线索触发检索（推理时）
- **内容检索**：按 $\mathrm{sim}(C_t,C_i)$ 取 $k_C=2$ 个事件，记为 $M_C$。
- **线索触发检索**：
  - 事件型线索按 $\max_{f}\max_{\kappa\in K_f}\mathrm{sim}(C_t,\kappa)$ 打分；
  - 时间型线索：若 $t$ 落入某事实的时间窗即"时间触发"；
  - 有/无时间触发的候选**分别排序后交错**，以平衡时间相关性与情境相关性；
  - 每个候选再扩展为其事实的**最新链接事件**；
  - 取 $k_{CT}=8$ 个未被内容检索选中的事件，记为 $M_{CT}$。
- 合并 $M_C\cup M_{CT}$ 按时间排序为 $M_r$（共 $k=10$）。

### 2.5 记忆增强主动推理与推理蒸馏
- 推理器 $A_R(C_t,P,M_r)\to(T,\hat y,R)$，判断延迟意图是否**已形成、未解决、且当前可执行**，三者同时满足才介入。
- **蒸馏训练**：构造三类关键事件配置 $E\in\{\{e_f\},\{e_f,e_{sc}\},\varnothing\}$（仅有形成证据 / 形成后有状态变化 / 无形成证据），与随机干扰事件 $D_K$ 组成大小为 $K$ 的历史上下文 $H_K$；由前沿 LLM（Claude-Opus-4.6）生成证据支撑的推理轨迹；用 **LoRA 微调** Qwen3-8B 先输出轨迹再输出决策与响应。推理时 $H_K$ 替换为检索到的 $M_r$。
- 训练上下文规模 $K\in\{8,10,12\}$ 多样化，使推理器适应不同历史长度。

## 3. 实验设计

### 3.1 基准：CPMBench
- **规模与构成**：1,000 实例，源自 250 个场景（200 单意图 + 50 多意图）；每实例 **200 个事件**，形成时刻与决策时刻之间平均隔 **114.5 个事件**。
- **八类日常场景**：工作、休闲、社交、健康、饮食、购物、通勤、日常生活。
- **四变体控制设计**（同场景共享其余事件，仅替换关键事件）：
  - **Positive**：意图已形成、未解决、当前可执行 → 应介入；
  - **Negative**：无可执行机会 → 应沉默；
  - **State Change**：$e_{sc}$ 已解决意图 → 应沉默；
  - **No Formation**：以普通事件替换 $e_f$，无意图产生 → 应沉默。
- **CPMBench-Omni**：500 实例配真实传感器数据；从 S-EMBER 第一视角视频库按视觉描述检索匹配片段、用 Azure TTS 合成语音，无法匹配处用 Meta 智能眼镜自采集，全部人工核验。

### 3.2 对比方法（19 个基线，四类）
- **主动式智能体**：Proactive Agent、ContextAgent；
- **全上下文 LLM**：Qwen2.5-32B、Qwen3-4B/8B/14B/32B、Llama-3.3-70B、GPT-4o、GPT-4.1、GPT-5.4-mini、GPT-5.4；
- **RAG 方法**：BM25、all-MiniLM-L6-v2、text-embedding-3-small；
- **记忆系统**：Mem0、A-Mem、MemOS、T-Mem，以及仅用 horizon 触发检索的 T-Mem 变体。

### 3.3 评价指标
- **记忆检索**：延迟意图召回 DIR（$e_f$ 是否被召回）、状态变化召回 SCR（$e_f$ 与 $e_{sc}$ 是否都被召回）；
- **主动决策**：误检率 FD、决策准确率 Acc-P；
- **端到端**：集合级 Set-P / Set-R / Set-F1（主指标）、Acc-PA；响应内容由 LLM 裁判（GPT-5-mini）评估。

### 3.4 主要结果
- **CPMBench**：Set-F1 **75.2**，比最强基线 full-context GPT-5.4（65.5）高 **9.7 点**；DIR 81.3、SCR 72.0（次优 T-Mem horizon 仅 49.6 / 25.0）；FD 仅 4.3。
- **CPMBench-Omni**：Set-F1 **65.5**，超 GPT-5.4（55.2）**10.3 点**；32B 版本达 70.2。
- **观察**：面向即时需求的主动智能体几乎漏掉所有延迟意图；全上下文模型或漏检、或靠高误检率换召回；相似度 RAG 与记忆系统难以触及语义不连续的往事；仅用时间/情境触发（T-Mem horizon）能提升 DIR，说明"预判未来用途"确有价值。
