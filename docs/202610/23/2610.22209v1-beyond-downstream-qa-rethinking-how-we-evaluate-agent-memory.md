## 摘要
智能体记忆基准评估智能体的回答是否反映正确知识，并将下游问答准确率作为记忆质量的代理指标。我们表明这种评估范式并不完整：它将记忆正确性与检索和生成质量混为一谈，既会产生假阳性，即正确回答掩盖了损坏的记忆，也会产生假阴性，即错误回答将检索失败归咎于正确的记忆。我们提出 FEB-30，这是一个包含 30 条事实演化轨迹的基准，涵盖 6 个诊断类别和 3 个难度等级，并通过范式反转构建：文档由已知事实轨迹生成，从而无需人工标注即可获得确定性的基准真值。每条轨迹定义了一个事实应在多作者产物（文档、电子邮件、对话）中如何演化，使得在每次摄入步骤后可以直接检查记忆存储。将 FEB-30 应用于一个代表性记忆系统，我们证明内在评估与外在评估平均相差 16 个百分点，且 44% 的轨迹超过了有意义的差异阈值。诊断性分解揭示，该系统仅以 20% 的概率正确分类记忆操作（创建、更新、强化、取代），这一失败在外在评估中完全不可见，并且失败模式按类别和难度呈现系统性差异。我们发布该基准、文档生成流程和评分框架，以支持对智能体记忆系统的可复现评估。

## Abstract
Agent memory benchmarks evaluate whether an agent's responses reflect correct knowledge, measuring downstream question-answering accuracy as a proxy for memory quality. We show this evaluation paradigm is incomplete: it conflates memory correctness with retrieval and generation quality, producing both false positives where correct responses mask broken memory and false negatives where incorrect responses blame correct memory for retrieval failures. We introduce FEB-30, a benchmark of 30 fact-evolution trajectories spanning 6 diagnostic categories and 3 difficulty levels, constructed via paradigm inversion: documents are generated from known fact trajectories, yielding deterministic ground truth without human annotation. Each trajectory defines how a fact should evolve across multi-author artifacts (documents, emails, conversations), enabling direct inspection of the memory store after each ingestion step. Applying FEB-30 to a representative memory system, we demonstrate that intrinsic and extrinsic evaluation diverge by an average of 16 percentage points, with 44% of trajectories exceeding meaningful divergence thresholds. Diagnostic decomposition reveals that the system correctly classifies memory operations (create, update, reinforce, supersede) only 20% of the time, a failure entirely invisible to extrinsic evaluation, and that failure modes differ systematically by category and difficulty. We release the benchmark, document generation pipeline, and scoring framework to support reproducible evaluation of agent memory systems.

## 1. 核心问题与研究动机

- **现有评测范式的局限**：当前几乎所有智能体记忆基准（MemoryAgentBench、Memora、LongMemEval-V2、AMA-Bench、STATE-Bench、MEME 等）都采用**外在评估（extrinsic evaluation）**，即向智能体提问并给回答打分，用下游 QA 准确率作为记忆质量的代理指标。
- **核心问题**：这种单一复合分数把**记忆正确性**与**检索质量、生成质量**混为一谈，无法定位失败环节，也无法确认成功时记忆是否真的正确。
- **两类不可检测的失败模式**：
  - **假阳性（LLM 补偿）**：生成模型基于残缺/错误的检索片段仍能推理出正确答案，外在评测记为成功，掩盖了坏掉的记忆。
  - **假阴性（检索瓶颈）**：记忆库正确存储并更新了事实，但因嵌入不匹配或检索截断导致问答失败，外在评测却归咎于记忆系统。
- **研究主张**：引入**内在评估（intrinsic evaluation）**——在知识演化的每一步直接比对记忆库内容与已知真值，作为外在评估的补充。类比软件工程中的「单元测试 vs 端到端测试」，以及 NLP 史上词嵌入从「只看下游任务」转向「内在相似度/类比评测」的转变。

## 2. 方法论：FEB-30 基准与内在评估框架

### 2.1 核心思想：范式反转（Paradigm Inversion）

- 沿用并扩展 RIKER 的思路：不做人工标注，而是**由已知事实轨迹生成文档**，使轨迹本身成为确定性真值（deterministic ground truth），无需人工标注。
- 每条轨迹定义事实如何跨多作者产物（文档、邮件、会议纪要）逐步演化，从而可在每次摄入后直接检查记忆库。

### 2.2 基准结构

- **规模**：30 条事实演化轨迹，10 条 L1 / 10 条 L2 / 10 条 L3，覆盖 6 个技术领域（基础设施、安全、财务运营、机器学习、数据工程、容器），共 147 篇文档（127 篇轨迹状态文档 + 20 篇噪声文档）。
- **6 个诊断类别**（表 1）：
  - C1 LLM 补偿：记忆错误但 QA 仍能答对；
  - C2 检索瓶颈：记忆正确但难以检索；
  - C3 分类准确性：create/update/reinforce/conflict 决策是否正确；
  - C4 合成质量：多观测能否合并为正确事实；
  - C5 时序正确性：事实随时间正确演化；
  - C6 多作者归因：作者身份是否影响置信度与冲突检测。
- **3 个难度等级**：L1 主张近乎显式（200–400 词）；L2 主张嵌入上下文（400–800 词，2–3 条噪声）；L3 需推理、含 4–5 条噪声（600–1000 词）。
- **轨迹 Schema（JSON）**：ID、类别、难度、领域、演化类型（linear-evolution / contradiction / scope-expansion / retraction / stable / gradual-drift）、状态序列、每个状态的**原子化累积 claims**（期望记忆内容）、**docClaims**（该文档仅含的新信息）、期望动作（create/update/reinforce/conflict/supersede）、作者角色与文档类型元数据。
- **关键设计**：`docClaims` ≠ `claims`——文档只含新增信息，系统必须跨文档保留旧知识，从而测试真实的记忆持久性而非单文档抽取。

### 2.3 文档生成管线（Algorithm 1）

- **多模型轮换**：6 个模型、5 个提供商按状态索引轮换，模拟不同作者文风；任一模型生成文档不超过总量 30%；生成模型与系统抽取模型分属不同 LLM 家族，避免同源风格偏差。
- **风格锚定生成**：L1/L2 模仿 12 份 AMI 会议摘要与 12 封 Enron 邮件的风格；L3 采用**混合注入**，将主张注入无关领域的人类真实文档（约 90% 真实文本）。
- **三裁判验证**：3 个独立裁判模型一致通过才接受，校验（1）所有目标主张可从文档推断、（2）无轨迹外额外事实、（3）行文自然；失败则换模型重生成。人工复核中 11% 需内容修正、28% 需清除 LLM 脚手架痕迹。

### 2.4 评分框架（文字化公式）

- **内在指标**（对记忆库 F 与状态真值 Ci 比对，Entail 由嵌入相似度 > 0.8 + LLM 裁判判定）：
  - **Claim Coverage**：状态 si 下被事实库蕴含的期望主张占比；
  - **Fact Accuracy Acc(T)**：轨迹内各状态覆盖率的均值；
  - **Update Detection Recall (UDR)**：需要变更（update/supersede）的状态中，事实库确实发生改变的比例；
  - **False Update Rate (FUR)**：本应 reinforce 的状态中，事实被错误修改的比例；
  - 另报告 **Fact Count**（活跃事实数，检测碎片化/丢失）与 **Confidence MAE**。
- **外在指标**：基于最终记忆状态生成诊断性问题，系统检索后用 LLM 作答，裁判给 YES=1.0 / PARTIAL=0.5 / NO=0.0。
- **分歧指标**：
  - **MAD** = 各轨迹 |内在分 − 外在分| 的均值（无需人为阈值）；
  - **DivRate** = 分歧超过 τ=0.15 的轨迹百分比；
  - 辅以符号化分歧、Cohen's κ（通过/失败一致性）、Pearson/Wilcoxon 检验。

## 6. 主要结论与发现

- **发现 1：内在—外在分歧显著**。MAD = 0.168 ± 0.025（约 16 个百分点），44% 轨迹超过 τ=0.15；按 ≥0.5 通过/失败判据，约 21% 轨迹出现一方通过一方失败，κ=0.118 接近随机；Pearson r=0.423（r²≈0.18），即仅 18% 方差可互相解释；符号化分歧 +0.118，说明**记忆实际质量系统性优于 QA 所揭示的水平**。C1 分歧最大（MAD 0.295，内在 82.2% vs 外在 54.5%）。
- **发现 2：难度与分歧的关系**。DivRate 随难度下降（L1 55% → L3 26%）；L1 上内在显著高于外在（68.0 vs 50.9，检索未能浮现正确知识）；L3 两者都收敛在 ~47%，但个体轨迹朝相反方向分歧。
- **发现 3：类别特异性失败模式**。整体误更新率 22.2%、更新检测召回 73.6%、**动作分类准确率仅 20.1%**（C2 为 4.5%、C5 为 0.4% 近乎为零）；置信度 MAE 0.106；C6 多作者内在准确率最低（41.5%）。
- **发现 4：可操作的诊断信号**。分类准确率低（20.1%）、多作者归因弱（C6 41.5%）、误更新过多（22.2%）三项均可直接定位到管线阶段，而外在分数在各类别近乎均匀（42–55%），完全掩盖这些差异。
- **发现 5：跨配置稳健**。四种配置下内在准确率稳定在 57.6–61.4%，外在稳定在 48.5–49.2%，符号化分歧始终为正，κ 始终接近或低于随机（0.035–0.118），说明分歧不是某一实现或骨干模型的伪影。
- **诊断分解**：随难度上升，claim 遗漏率 58% → 88%，活跃事实数 9.1 → 20.7（知识碎片化），分类准确率 37% → 10%；三者互相

三者互相叠加，构成一种**复合退化**：难度升高既让抽取更容易漏掉主张，又让合成产生更多碎片化事实，还让动作分类（尤其是 update/supersede）更难做对。这解释了为何 L3 上内在与外在分数同时收敛到约 47%——不是记忆变好了，而是「记忆坏掉」与「检索/生成补偿」两种效应在高难度下相互抵消，使两个指标都落在中等水平，从而进一步说明单一外在分数无法区分「真的记住了」与「碰巧答对了」。

- **发现 6：分歧的方向性具有诊断价值**。符号化分歧（内在 − 外在）整体为正（+0.118），且在 C1（LLM 补偿）上最大，说明外在评测**系统性低估**记忆质量；但在 C2（检索瓶颈）与 C5（时序正确性）上，外在分数并不比内在低多少，因为这两类的失败主要发生在检索与分类环节而非存储环节。换言之，**分歧的符号与幅度本身就是失败环节的指纹**：正分歧指向「记忆好但 QA 没测出来」，负分歧指向「QA 靠推理掩盖了坏记忆」。

## 7. 讨论与启示

- **评测哲学的转向**：作者主张记忆评测应像软件工程一样建立**分层测试**——内在指标相当于单元测试（检查每个组件在已知输入下的输出），外在 QA 相当于端到端测试（检查整体行为）。只做端到端测试的后果是：系统能通过验收，但内部已积累大量技术债。
- **对基准设计的启示**：
  - **真值可构造性**：通过「先生成事实轨迹、再由轨迹生成文档」的范式反转，绕开了人工标注成本，同时获得确定性真值，这是 FEB-30 最可复用的方法论贡献；
  - **docClaims ≠ claims 的设计**是测试真实记忆持久性的关键，若文档直接包含全部累积主张，则任务退化为单文档抽取；
  - **多模型轮换 + 三裁判验证**为合成语料的自然性与忠实性提供了可操作的质控流程。
- **对系统设计的启示**：动作分类准确率仅 20.1%、C5 时序类别接近 0，说明当前主流「抽取—嵌入—分类—合成」管线中，**分类与合成阶段是最薄弱环节**，而外在评测完全无法暴露这一点；作者据此建议将内在指标纳入记忆系统的开发内环（inner loop），作为回归测试。
- **对指标使用的建议**：MAD 与 DivRate 不依赖人工设定的绝对阈值，可作为跨系统、跨版本的通用「一致性健康度」指标；Cohen's κ 接近随机则直接提示「外在分数不可作为记忆质量的代理」。

- **未量化成本**：论文未报告 token 消耗、API 费用与运行时长，影响复现与规模化推广的可行性评估。

## 9. 总体评价

- **贡献层面**：论文的核心贡献不在于提出新系统，而在于**提出并实证了一种评测范式**——用内在评估补充外在评估，并用 MAD/DivRate/κ 等分歧指标把「两种评测不一致」本身转化为诊断信号。这一视角对当前智能体记忆研究具有普遍方法论价值。
- **证据强度**：330 组配对评测、11 次重复、四种配置稳健性检验、完整的统计检验链条，使「内在—外在分歧显著」这一主结论具有较强说服力；但受限于单一系统与合成语料，结论的**普适性**仍需更多系统与真实数据验证。
- **实践价值**：动作分类准确率 20.1%、误更新率 22.2%、C6 多作者归因 41.5% 等具体数字，为记忆系统开发者提供了明确的优化靶点；MAD/DivRate 作为轻量指标易于集成到 CI 流程。
- **不足与改进空间**：缺少与 Mem0、Zep、MemGPT 等系统的横向对比是最主要的短板；若能补充 2–3 个真实系统的内在/外在评测，并给出成本数据，论文的工程指导意义将显著增强。
