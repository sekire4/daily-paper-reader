## 摘要
长时程语言智能体需要紧凑的记忆，既能保留交互证据，又能保留关于未观测状态的竞争性假设。尽管许多信念状态方法有效，但它们以离散自然语言编码记忆，反复压缩可能遗漏证据或过早丢弃合理备选假设。我们提出 LAMB，一种用于潜在多假设信念的循环框架。Common–Delta 分解将用于交互证据的共享 Common 状态与用于竞争性假设的加权 Delta 分量相结合。来自动作-结果预测的相对证据引导循环假设更新，而无需生成文本记忆。在默认配置中，上下文条件化读出通过固定 token 的信念前缀将各假设分别暴露给策略。信念模块与策略使用动作模仿以及辅助的状态、结果和观测判别目标进行联合训练。在 ALFWorld、BabyAI、ScienceWorld 和 Crafter 上，LAMB 匹配或优于 PABU，分别将 ALFWorld SR@30 和 ScienceWorld 成功率提升 6.0 和 22.0 个百分点，并将 Crafter 成就进度提升 26.37 点。在 ALFWorld 上，它还将冗余动作率降低 17.70 个百分点。这些结果支持将潜在多假设信念作为紧凑记忆，以实现有效的长时程决策。

## Abstract
Long-horizon language agents require compact memories that retain interaction evidence while preserving competing hypotheses about unobserved states. Although effective, many belief-state methods encode memory in discrete natural language, where repeated compression can omit evidence or prematurely discard plausible alternatives. We introduce LAMB, a recurrent framework for latent multi-hypothesis beliefs. A Common--Delta factorization combines a shared Common state for interaction evidence with weighted Delta components for competing hypotheses. Relative evidence from action-outcome predictions guides recurrent hypothesis updates without generating textual memory. A context-conditioned readout exposes hypotheses separately to the policy through a fixed-token belief prefix in the default configuration. The belief modules and policy are jointly trained using action imitation and auxiliary state, outcome, and observation-discrimination objectives. Across ALFWorld, BabyAI, ScienceWorld, and Crafter, LAMB matches or outperforms PABU, improving ALFWorld SR@30 and ScienceWorld success by 6.0 and 22.0 percentage points, respectively, and Crafter achievement progress by 26.37 points. On ALFWorld, it also reduces the redundant-action rate by 17.70 percentage points. These results support latent multi-hypothesis beliefs as compact memory for effective long-horizon decision making

## 1. 核心问题与研究背景

- **问题场景**：LLM 智能体在部分可观测环境中执行多步任务时，需要同时做到两件事：保留已观测到的交互证据，并对尚未观测到的状态维持多个竞争性假设（例如“笔记本电脑可能在梳妆台/床/抽屉/架子上”）。
- **现有方法的瓶颈**：
  - **全历史条件化**：上下文随步数线性增长，每步决策都要重复处理完整轨迹，推理成本高。
  - **上下文管理/压缩方法**（剪枝、掩码、摘要）：只压缩不建模不确定性。
  - **文本信念状态方法**（PABU、ABBEL、Agent-BRACE、BeliefMem 等）：以离散自然语言存储信念，用“枚举”表达不确定性——共享证据需对每个候选重复陈述，有限文本预算下必须在“保留证据”与“覆盖假设”之间权衡，导致**遗忘已发现事实**或**过早锁定单一假设**；且每步都要自回归解码信念文本，产生额外开销。
  - **粒子滤波类模型**（PFN、DVRL、PF-RNN）：假设显式但每个粒子复制完整状态，同样重复共享证据。
- **核心研究问题**：如何用固定大小的循环记忆，在不反复“口头化”状态的前提下，既保留共享证据，又维护并修正竞争假设？
- **整体含义**：论文主张记忆应是**预测环境的潜在状态**，而非**被动转录过去**的文本；这一转向可同时改善长时程决策质量与推理成本。

## 2. 方法论

### 2.1 总体框架
- 用固定容量信念 $B_t$ 替代历史 $h_t$：$B_0=\text{Init}(g)$，$B_t=U(B_{t-1},a_{t-1},o_t)$；策略条件于读出后的信念前缀与当前上下文 $x_t=(g,o_t,\mathcal{A}_t,a_{t-1})$。
- 信念分解为**共享 Common 状态** $c_t$、**K 个 Delta 状态** $\{\delta^i_t\}$ 与**归一化混合权重** $w_t$，即 $B_t=(c_t,\{\delta^i_t\}_{i=1}^K,w_t)$，每个 $(c_t,\delta^i_t)$ 构成一个可学习潜在粒子。

### 2.2 关键技术细节
- **耦合式联合事实预测**：$p(y_{1:Q}\mid B_t)=\sum_i w^i_t\prod_q p_\phi(y_q\mid c_t,\delta^i_t)$。乘积放在混合内部，使同一粒子内的事实相互耦合，可表达“物体只能在柜子或水槽之一”这类互斥约束（附录 E 的玩具例子表明，逐事实独立分解会给不可能状态分配 0.25 概率）。若事实分为共识集 $\mathcal{A}$ 与争议集 $\mathcal{C}$，共识项可从混合中提出作为共享乘子，这正是 Common–Delta 分解的动机。
- **相对证据信号（假设修正的核心）**：先计算各粒子对观测到的转移结果 $r_t$ 的对数似然 $\ell^i_t$，再取相对形式 $\epsilon^i_t=\ell^i_t-\frac{1}{K}\sum_j\ell^j_t$。预测更准的假设获得正反馈，冲突者被惩罚——这是一种无需反向传播到策略的“在线贝叶斯式”校正。
- **非对称门控残差更新**：
  - $c_t=\text{Gate}_c(c_{t-1},[c_{t-1};u_t])$，**不参考任何单个假设**，只聚合客观转移历史；
  - $\delta^i_t=\text{Gate}_\delta(\delta^i_{t-1},[c_{t-1};\delta^i_{t-1};u_t;\epsilon^i_t])$，同时条件于共享状态与自身证据；
  - Gate 形式为 $(1-\sigma(W_zz))\odot s+\sigma(W_zz)\odot\text{MLP}(z)$；$\text{Gate}_\delta$ 使用**逐假设 LoRA** 促进粒子分化。
- **权重重估**：$w^i_t=\text{softmax}_i\,g(c_t,\delta^i_t)$，共享打分头直接从更新后状态重算。
- **非池化读出（Unpooled Readout）**：
  - Common 经交叉注意力与当前输入嵌入融合为 $M$ 个上下文 token；
  - 每个 Delta 投影为独立假设 token，并加上学习方向 $v\log w^i_t$ 做权重调制；
  - $M+K$ 个 token 作为连续前缀（默认 4+8=12 token）前置，**保持历史贡献恒定**；不池化使策略自注意力能显式对比候选假设，避免把互斥假设平均成模糊均值。
- **训练目标**：$\mathcal{L}=\mathcal{L}_{act}+\lambda_{sem}(\mathcal{L}_{state}+\mathcal{L}_{out})+\lambda_{com}\mathcal{L}_{com}$。
  - $\mathcal{L}_{act}$：专家动作模仿；
  - $\mathcal{L}_{state}$：对模拟器潜在事实的联合预测；
  - $\mathcal{L}_{out}$：预测下一步转移反馈，直接监督证据打分头；
  - $\mathcal{L}_{com}$：对事实被篡改的负样本做对比学习
