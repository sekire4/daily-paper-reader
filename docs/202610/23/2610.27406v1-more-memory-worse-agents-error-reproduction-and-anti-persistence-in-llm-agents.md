## 摘要
LLM 智能体无需更新模型参数，即可通过将自身执行过程中的经验存储到外部记忆中，并复用这些经验指导后续决策，从而在多项任务上取得提升。一个核心设计问题是：应当仅保留观测到的轨迹和结果，还是也保留从中推断出的规则、摘要和技能。保留这些抽象内容使智能体能够复用策略，而无需反复从原始轨迹中推导。然而，存储的抽象内容中的错误会通过检索和复用传播到后续决策。这些错误还可能塑造执行轨迹，而这些轨迹随后又成为新抽象的基础，从而复现原始错误。我们将这种反馈机制称为错误复现：错误通过抽象、执行和再抽象的循环被重新生成，使其持续性超越了原始错误知识的直接复用。我们提出 Anti-Persistence（反持续性），一种记忆设计：它累积轨迹和结果，同时按需重构任务特定的指导。自适应选择器利用先前结果决定是否以及如何合成指导，该指导在执行后被丢弃。这防止其作为存储对象被直接复用，尽管通过保留轨迹产生的间接反馈仍然可能。在不同基准和骨干模型上，Anti-Persistence 在评估的记忆设计中实现了更高的总体留出成功率，以及最低的平均 LLM 调用成本。这些结果支持在基于记忆的自我改进中，将经验积累与抽象持久化分离。

## Abstract
LLM agents can improve across tasks without updating model parameters by storing experience from their own executions in external memory and reusing it to guide later decisions. A central design question is whether to retain only observed trajectories and outcomes or also the rules, summaries, and skills inferred from them. Retaining these abstractions allows agents to reuse strategies without repeatedly deriving them from raw trajectories. However, errors in stored abstractions can propagate to subsequent decisions through retrieval and reuse. They can also shape execution trajectories, which then become the basis for new abstractions that reproduce the original errors. We term this feedback mechanism error reproduction: errors are regenerated through a cycle of abstraction, execution, and re-abstraction, extending their persistence beyond direct reuse of the original faulty knowledge. We propose Anti-Persistence, a memory design that accumulates trajectories and outcomes while reconstructing task-specific guidance on demand. An adaptive selector uses prior outcomes to decide whether and how to synthesize guidance, which is discarded after execution. This prevents its direct reuse as a stored object, although indirect feedback through retained trajectories remains possible. Across different benchmarks and backbones, Anti-Persistence achieves higher overall held-out success and the lowest average LLM-call cost among the evaluated memory designs. These results support separating experience accumulation from abstraction persistence in memorybased self-improvement.

# 论文总结：《More Memory, Worse Agents: Error Reproduction and Anti-Persistence in LLM Agents》

## 1. 核心问题与研究动机

- **背景**：LLM 智能体可在不更新模型参数的前提下，通过外部记忆存储自身执行经验并在后续任务中检索复用，实现"基于记忆的自我改进"。执行、记忆更新与复用构成跨任务的反馈回路。
- **核心设计问题**：记忆中应只保留**观测到的轨迹与结果**，还是也应保留从中推断出的**抽象**（规则、摘要、技能、启发式）？
- **抽象的收益与风险**：抽象能把冗长交互历史压缩为可复用指导，但压缩过程需判断"哪些细节重要、模式在何种条件下泛化"，一旦判断有误，错误抽象会经检索复用传播到后续决策。
- **关键概念——错误复现（error reproduction）**：错误抽象会影响执行，产生的轨迹又成为下一轮抽象合成的输入；即使原抽象被删除，轨迹中仍残留其引导下的错误动作，新合成的抽象可能再次编码同一错误。这与"错误传播"（直接检索复用）不同，是经"抽象→执行→再抽象"循环的**间接再生**，使错误持久性超出原始错误知识本身。
- **含义**：删除抽象并不能修正已生成的轨迹或由其派生的后代抽象，因此需要重新审视"抽象是否必须与维护程序一同持久化"这一问题。
- **研究问题**：如何在享受抽象收益的同时限制错误复现？

## 2. 方法论：Anti-Persistence

### 2.1 形式化框架

- 智能体参数 θ 固定；第 k 个任务 τ_k 产生轨迹 e_k 与结果 y_k。
- 轨迹记忆：M_k = {(τ_j, e_j, y_j) : j < k}；抽象存储 S_k；合成算子 s = φ(H)，H ⊆ M。
- 检索：C_k = R(τ_k, M_k ∪ S_k, B)；生成：e_k ∼ π_θ(· | τ_k, C_k)。
- 记忆更新：M_{k+1} = M_k ∪ {(τ_k, e_k, y_k)}；保留抽象的方法另有 S_{k+1} = U_k(S_k, A_k; M_{k+1})。
- **Anti-Persistence 的核心设定**：持续更新 M_k，但恒有 **S_k = ∅**——当前任务的指导在执行后即丢弃，不作为存储对象复用。
- 论文明确承认：指导虽被丢弃，仍可通过"影响轨迹"间接反馈（s_parent → e_j → H → s_candidate），该路径无法被结构性消除。

### 2.2 四种使用模式 Z = {none, imitation, strategic, corrective}

- **none**：直接注入检索到的轨迹记录与结果，无额外合成调用（κ=0）。
- **imitation**：从成功轨迹中提取可复用行为模式、工具使用例程及其适用条件。
- **strategic**：用最多 top-B 成功轨迹蒸馏子目标结构、工具模式与恢复启发式。
- **corrective**：用 top-B 失败轨迹加 1 条对比成功轨迹，生成"do NOT do X because Y"式回避规则；无失败记录时返回空而非回退到 strategic，以免污染 bandit 归因。
- 三种合成模式每次调用计 κ=1，无可用记录时跳过且不计费。

### 2.3 自适应模式选择（KNN-UCB 上下文 bandit）

- **结果日志** L_k = {(τ_j, μ_j, y_j, r_j, t_j)}，只记事实性结果，不存合成指导；JSONL 追加式存储，含任务嵌入、模式、奖励、原始成功、任务类型、任务 ID、指令。
- **两段检索**：先从 L_k 检索 top-ˆB 相似任务用于选模式；再按所选模式从 M_k 检索轨迹（预算 B）用于执行或合成。
- **成本调整奖励**：r_i = clip(y_i − λκ_i, −1, 1)，λ 惩罚额外合成调用。
- **相关性权重**：w_i = max(sim(τ_i, τ), 0) · γ^{t_max − t_i}，γ 控制旧反馈衰减（默认 0.998）。
- **局部效用**：r̂(μ|τ) = Σ w_i r_i / Σ w_i（对使用该模式的检索条目加权平均）。
- **选择规则**：μ* = argmax_μ [ r̂(μ|τ) + c·sqrt(log|N_ˆB(τ)| / max(n_μ,1)) ]，c=0.5 为探索系数；论文声明该规则无置信界或 regret 保证。
- **保护机制**：前 3 轮 round-robin 预热；ε=0.1 随机探索；邻域平均相似度低于 ρ=0.7 时回退到全局最优；每模式至少 3 次强制尝试。
- **执行与反馈**：按 μ* 检索并合成 σ_τ → 执行 → 记录入 M_k、合格反馈入 L_k → 丢弃 σ_τ。骨干、提示、检索与选择规则全程固定。

### 2.4 理论分析（附录 A）

- 区分三类事件：历史暴露 C（检索到曾被标记的父代抽象）、生成 A（候选被标记）、持久接纳 W。
- 定义条件复现系数 α = Pr(A|C) 与条件接纳概率 η = Pr(W|A∩C)；Proposition 1 给出分解 Pr(A∩C∩W) = qαη（q = Pr(C)），**不假设独立性**，但仅是一步概率分解，不构成放大下界或长期性能排序。
- Remark 1：仅删除父代不改变后代集合 D_− 与轨迹 M_−；Anti-Persistence 因 S=∅ 使 Pr(A∩W)=0，但不保证 Pr(A)=0。
