## 摘要
大型语言模型在需要程序性推理的长时程任务上仍不可靠。我们认为，一个关键原因在于缺乏显式的程序性记忆：即关于任务如何完成的可访问、可修改的知识，它区别于语义记忆和情景记忆。目标导向图提供了这样一种表示，将目标和先决条件依赖编码为可检查的符号结构。我们考察其构建方式、它们带来的挑战，以及将其与神经推理相结合的原则。

## Abstract
Large language models remain unreliable on long-horizon tasks requiring procedural reasoning. We argue that a key cause is the absence of explicit procedural memory: accessible, modifiable knowledge of how tasks are accomplished, distinct from semantic and episodic memory. Goal-Oriented Graphs offer such a representation, encoding goals and prerequisite dependencies as inspectable symbolic structure. We examine their construction, the challenges they pose, and principles for integrating them with neural reasoning.

- **研究动机**：大语言模型（LLM）作为智能体的“认知核心”，在开放、动态环境中展现出强大能力，但在**长时程任务**（long-horizon tasks）上仍不可靠。作者将“长时程”定义为：任务成功依赖于一系列步骤的正确顺序与前置条件满足，且步骤跨度超出 LLM 在上下文中可靠追踪依赖的范围。
- **失败的性质**：这些失败**主要不是知识失败**。LLM 可能知道“钻石镐是什么”“部署流水线包含哪些环节”，却仍生成无效动作序列、错误追踪前置条件，并让误差逐步累积直至不可恢复。该现象已在软件工程（SWE-bench）、临床推理、网页导航等领域被记录，说明这是普遍性局限而非领域特定问题。
- **归因：表示缺陷（representational deficit）**。LLM 在预训练中吸收了程序性模式，但这些知识是**隐式的**，难以检查、修改或组合。作者主张缺少的是**显式程序性记忆**——关于“如何做事”的可访问、可修改、可检查的知识，包括任务分解、前置条件、顺序约束与终止条件。
- **三类记忆的区分**（借鉴认知科学与 SOAR/ACT-R/框架表示）：
  - **语义记忆**（RAG、知识图谱）：回答“什么是真的”，但不指定操作序列；
  - **情景记忆**（经验回放、自我反思）：回答“做过什么”，但不编码可泛化的“应该怎么做”；
  - **程序性记忆**：回答“如何完成”，是本文聚焦的、被低估的缺失组件。
- **论文定位**：这是一篇**观点性/立场性论文**（perspective），而非实证研究。作者明确声明：跨域泛化性、目标级抽象的组成性优势、表 2 的权衡评级，均为**基于表示性质的论证**，而非多域实验证明。

## 2. 方法论：目标导向图（Goal-Oriented Graphs, GoG）

### 2.1 核心思想
- 用**有向图**作为程序性记忆的符号实例化：**节点 = 目标**，**边 = 前置依赖关系**，从而把复杂任务的层级分解编码为可检查、可组合复用的结构。
- 继承自 **Goal Net** 形式化（Shen 等，2006；Leung 等，2021），但做了关键改造：原 Goal Net 用**学习到的策略**选择下一个目标；GoG 改由 **LLM 遍历图**来决定追求哪些目标及顺序。
- 目标级抽象的优势：目标（如“部署一个 Web 服务”“诊断某病症”）可用自然语言表达，且**在执行策略变化时保持稳定**——无论用何种工具，部署都需要“测试通过 + 构建产物 + 环境就绪”。这使其可跨环境、工具、执行策略复用，而动作级表示（策略、产生式规则、PDDL 算子）通常环境特定、难以迁移。
- **神经符号分工**（借双过程理论）：LLM 充当 **System 1**（快速、联想、模式驱动，擅长语言理解与歧义处理）；GoG 充当 **System 2 脚手架**（慢速、结构化、显式约束满足），通过依赖图上的约束满足**缩小 LLM 的有效搜索空间**。

### 2.2 关键技术细节

**（a）单一结构、三重角色**：同一个 GoG 同时作为①记忆表示（存储的目标-依赖图）、②检索产物（为特定任务抽取的子图）、③规划约束（引导 LLM 的前置顺序），三者共享同一底层结构。

**（b）检索–推理循环**（图 2）：
1. 给定用户目标，用**嵌入相似度检索**相关子图（含目标节点、前置条件、依赖边）；
2. 将子图**序列化为自然语言**注入 LLM 上下文；
3. LLM 在结构化上下文中推理，生成有序计划，并把抽象目标名**落地（grounding）**为可执行动作；
4. 执行失败时，GoG 提供缺失资源的前置链条，支持**定向重规划**，而非从头重新生成整个计划。

**（c）约束强度是设计选择**：最弱为软提示（soft prompt），最强为硬门控（hard gate）——把序列化子图作为硬约束块前置，并在执行前逐动作校验是否违反前置顺序，违规则拒绝或触发重规划。

**（d）偏序语义**：图编码的是**偏序**，互不依赖的前置条件可任意顺序执行，由 LLM 结合任务语境消解自由度。但作者强调：**时间紧迫性必须显式写入图**（如临床中“稳定病人”与“核对医保”同为手术前置，应直接编码依赖或标注优先级），不能留给检索顺序决定。

**（e）三条构建路径**：
- **规则化抽取**：从结构化文档（配方文件、作业指导书）抽取，精确但仅限已有正式文档的领域；
- **LLM 引导抽取**：LLM 解析自然语言文档生成目标节点与前置边，覆盖面广，但存在**自举问题**——用易犯顺序错误的 LLM 去生成本应纠正该错误的结 构，因此抽取结果只能视为**待验证的假设**，而非真值；
- **人在回路校验**：领域专家审阅修正，是高危领域最强的保证。
- 质量控制手段：一致性检查（无环性、原子目标可达性、与源文档交叉核对）、抽样专家评审、执行反馈与图冲突时更新图（把运行时失败转为维护信号）。
- 更雄心勃勃的路线：程序归纳（如 DreamCoder 从数据中学习可复用程序库）。

**（f）说明性示例**：“合成钻石斧”→ 需要钻石与木棍 → 钻石需铁镐开采 → 铁镐需铁锭与木棍 → 铁锭需铁矿石、熔炉与燃料 → …… 直至原子操作。每个节点编码前置条件（所需工具材料）与后置条件（产出物）。缺少该结构时，LLM 常生成“熔炼钻石”而非“开采钻石矿”之类的无效动作，或算错材料数量，导致级联失败。

**（g）局部主义表示与“委托式接地”**：GoG 选择显式、局部（localist）符号表示，因而可检查、支持系统性组合，但脆弱且需显式构建；其节点语义的接地**被委托给 LLM 的分布式内部知识**，因此继承了**符号接地问题**——结构可检查性与接地正确性是两回事，前者不蕴含后者。

### 2.3 与相关方法的区分
| 对比对象 | 关键差异 |
|---|---|
| Graph of Thoughts | 建模认知操作间的信息流，而非任务目标间的依赖 |

## 6. 主要结论与发现

- **核心结论**：LLM 的隐式推理不足以支撑可靠的长时程智能体；**显式程序性记忆**（以 GoG 为载体）是一个独立、重要且被低估的设计维度，它带来可检查性、模块化与跨任务复用。
- **三条设计原则**：
  1. **程序性知识宜采用显式目标导向表示**——目标分解与前置/顺序约束是独立于语义事实与情景轨迹的知识形式，但**必须同时被接地**，“可检查但接地错误”的图并不优于“流畅但不忠实的解释”。
  2. **由于 GoG 目前缺乏在线精化，混合架构是近期最可行的方向**——用快速的经验驱动组件（轨迹/模板）向慢速的结构化 GoG 存储**蒸馏更新**，即互补学习系统（CLS）思路，比让任一组件兼任两职更有前景。
  3. **显式程序表示提供了通往可审计性的实用路径，但以可靠的“目标满足判定”为前提**——高危部署中必须用**环境验证的后置条件**加固。
- **最危险的运行时失败模式**：**静默的目标误分类**——LLM 把未满足的前置条件标记为已满足。此时审计者看到的是干净连贯的遍历轨迹，但“轨迹忠实记录了智能体**相信**什么，而非**事实**是什么”，即**形式可审计性不等于实质可审计性**。最易发生于无法从上下文验证的目标（如“环境是安全的”）、措辞含糊的目标、以及早期判定已滑出注意力窗口的长子图遍历。
- **可解释性的独特价值**：GoG 下的推理轨迹不是事后合理化（post-hoc rationalization），而是对显式图结构的**遍历**，人类可检查子目标链、验证前置条件、定位未满足的依赖——这与注意力可视化/显著性图是**质性不同**的可解释性。
- **边界条件**：GoG 在三个条件同时成立时最有益——程序知识可从文档以合理保真度抽取、任务可层级分解且有可识别前置、成功依赖正确顺序。不适用于本质开放/创造性任务、高度隐式依赖（如社会推理）、以及需靠探索发现结构的任务。图不完备时会产生“**结构化但错误**”的计划——与生成式方法的无结构失败不同，GoG 失败通常**可通过检查子图诊断**。
- **开放问题**：无环性限制是否为本质（DAG 无法表达 debug–fix–retest 循环、剂量滴定、迭代冲刺）；前置条件的确定性假设（应引入 ProbLog / DeepProbLog / MLN 式**概率边**）；离线构建无法在线精化；以及最终问题——程序结构应保持为**外部记忆系统**，还是内化为基座模型中**可学习、可编辑**的表示（稀疏分布式表示、全息缩减表示是可能的中间目标）。

- **写作与结构组织清晰**：问题诊断 → 表示方案 → 构建路径 → 相关方法对照 → 证据 → 挑战 → 设计原则的递进结构完整，术语（语义/情景/程序记忆、局部主义表示、委托式接地）使用一致，便于后续研究引用与对话。

## 8. 局限与不足

- **证据基础的单薄与自证风险**：全部实证支撑来自作者自身先前的单一 Minecraft 研究，且该环境为合成/游戏域，任务结构高度规则化、前置条件可完全枚举，与论文所声称的跨域适用性（软件部署、临床诊断、制造装配）之间存在显著的**生态效度落差**。跨域主张目前仅为概念推演。
- **关键因果主张未被检验**：论文的核心命题是“显式程序性记忆的缺失是长时程失败的关键原因”，但现有证据只表明“有 GoG 时表现更好”，并未分离出**表示结构本身**与**额外注入的领域知识/上下文信息量/提示工程差异**各自的贡献。缺少控制图质量、控制上下文长度、控制信息量的消融设计。
- **对比公平性存疑**：GoG 与 GraphRAG 的构建语料、抽取流程、提示格式、检索粒度是否严格对齐，本文未作交代；GoG 图更紧凑却更强这一结果，可能同时反映表示优势与流程优势，读者无法归因。
- **表 2 的权衡评级主观性较强**：六项维度的“∼”标记缺乏评分规则、评分者与一致性检验，作为概念性预期可以接受，但易被后续文献误引为定量结论。
- **对“目标”的本体论界定不够严格**：目标的粒度（何为原子目标）、目标与动作的边界、同一目标在不同抽象层级的重复出现如何处理，均未给出判定准则；而这些直接决定图的规模、可复用性与接地难度。
- **偏序语义与时间/资源约束的表达力有限**：作者承认时间紧迫性需显式编码，但未讨论资源竞争、并行执行、超时与回滚等长时程任务中的常见约束如何在同一图结构中表示。
- **无环性（DAG）假设与实际程序知识的张力未被解决**：debug–fix–retest、剂量滴定、迭代冲刺等本质循环结构在文中仅作为开放问题提出，未给出可行的扩展方案（如分层展开、循环子图、状态化节点）。
- **对“委托式接地”的风险估计可能偏乐观**：既然节点语义的正确性完全依赖 LLM 的分布式知识，那么在 LLM 知识薄弱或存在系统性偏差的领域，GoG 的结构优势可能被接地错误系统性抵消，而文中未讨论这一交互效应。
- **缺少成本与工程可行性分析**：构建 703 节点/1,653 边图的人力与算力成本、检索延迟、图的维护负担、版本演化策略均未量化，难以评估其相对于“直接改进基座模型”的性价比。
- **未讨论与基座模型能力提升的关系**：若未来 LLM 的长上下文与隐式规划能力显著增强，显式程序记忆的边际收益如何变化，论文未作情景分析，削弱了其主张的时效稳健性。

## 9. 对研究与实践的启示

- **对智能体架构设计**：应把“程序性记忆”作为与语义记忆（RAG）、情景记忆（经验回放）并列的**一等设计维度**，而非隐含在提示或工具描述中；目标级、偏序、可检查的图结构是当前较自然的实例化选择。
- **对高风险领域部署**：可审计性必须以**环境验证的后置条件**为前提；仅靠轨迹的形式完整性不足以支撑合规与追责，需在关键节点引入外部判定器（测试、检查项、传感器读数）来对抗“静默的目标误分类”。
- **对评测方法学**：长时程智能体评测应报告**分层难度曲线**与**失败类型分布**（顺序错误、前置误判、接地错误、循环缺失），而不仅是总体成功率；同时应设置“信息量匹配”的基线，以分离表示效应与信息效应。
- **对知识工程**：从文档抽取程序结构应默认视为**待验证假设**，配套无环性检查、可达性检查、源文档交叉核对与抽样专家评审；运行期失败应回流为图的维护信号，形成“执行—校验—修订”闭环。
- **对学习范式**：短期走混合路线（经验组件向结构化存储蒸馏更新，即 CLS 思路），长期问题则是程序结构应保持外部可编辑记忆，还是内化为基座模型中可学习、可编辑的表示（稀疏分布式表示、全息缩减表示为候选中间形态）。

## 10. 总体评价

本文是一篇定位清晰、概念贡献大于实证贡献的立场论文。其真正价值不在于证明 GoG 优于某基线，而在于**把“长时程失败”重新框定为表示层面的缺陷**，并据此提出一个可讨论、可批判、可工程化的设计空间：目标级抽象、偏序依赖、单一结构三重角色（记忆/检索产物/规划约束）、以及神经符号的双过程分工。它对自身局限（自举、接地、无环性、形式 vs 实质可审计性）的坦诚，使其更适合作为**研究议程的锚点**而非**方法有效性的定论**。

若以实证标准衡量，其证据链薄弱且高度依赖单一游戏域与作者自引工作；若以议程设定标准衡量，它成功识别了一个被语义记忆与情景记忆热潮所掩盖的缺口，并给出了足够具体、可被后续工作检验与反驳的命题。对读者而言，最稳妥的采纳方式是：接受其**问题诊断与概念区分**，对其**跨域有效性主张**保持审慎，并把“控制信息量的消融实验”“跨域验证”“循环结构的表达”“接地错误的系统性评估”视为该方向最紧迫的后续工作。
