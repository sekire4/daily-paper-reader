## 摘要
由大语言模型（LLM）驱动的智能体在解决复杂推理任务方面已取得显著进展。然而，LLM智能体在长程任务上常常表现不佳，原因在于认知过载：其工作记忆被不断膨胀且无关的信息所充斥，从而稀释了注意力，并阻碍了有效的规划与推理。为缓解这一挑战，我们提出了认知资源自分配（Cognitive Resource Self-Allocation, CORAL），一种新的推理范式，使智能体能够主动优化其上下文。CORAL以智能体可调用的工作记忆管理工具集形式实现，允许智能体对其任务进展和已验证事实进行检查点保存，并通过重置杂乱的上下文、仅保留已检查点保存的信息，自适应地开启新的问题求解回合，使其能够从干净状态恢复推理。我们进一步使用多回合智能体强化策略优化算法增强智能体的检查点保存能力。在GAIA基准上，采用8B模型的CORAL取得了42.8%的平均准确率，并在最具挑战性的长程任务（Level 2和Level 3）上取得了尤为显著的提升。关键在于，这些提升以显著更低的推理成本实现：CORAL消耗的输入token数量比ReAct智能体少6-7倍。它还能泛化到多跳知识问答基准以及难度显著更高的BrowseComp，在该基准上将一款强大的专有智能体提升了8.0分。

## Abstract
Agents powered by large language models (LLMs) have demonstrated remarkable progress in solving complex reasoning tasks. However, LLM agents often falter on long-horizon tasks due to cognitive overload, as their working memory becomes cluttered with expanding and irrelevant information, which dilutes their attention and hinders effective planning and reasoning. To mitigate this challenge, we introduce Cognitive Resource Self-Allocation (CORAL), a novel reasoning paradigm that empowers agents to proactively optimize their context. Implemented as an agent-callable working memory management toolset, CORAL allows an agent to checkpoint its task progress and verified facts, and adaptively initiate a new problem-solving episode by resetting cluttered context while preserving only the checkpointed information, enabling it to resume reasoning from a clean state. We further enhance the agent's checkpointing capabilities using a Multi-episode Agentic Reinforced Policy Optimization algorithm. On the GAIA benchmark, CORAL with an 8B model achieves 42.8% average accuracy, with particularly strong gains on the most challenging long-horizon tasks (Level 2 and Level 3). Crucially, these gains come at a substantially lower inference cost: CORAL consumes 6-7$\times$ fewer input tokens than a ReAct agent. It also generalizes to multi-hop Knowledge QA benchmarks and to the considerably harder BrowseComp, where it improves a strong proprietary agent by 8.0 points.

## 1. 核心问题与研究动机

- **问题定位**：LLM 智能体在长程（long-horizon）任务上遵循 ReAct 式的 Thought–Action–Observation 循环，每一轮都会把冗长的工具返回结果、失败尝试历史写入上下文。上下文因此持续膨胀，注意力被稀释，规划与推理能力逐步退化。
- **理论类比**：作者借用认知心理学解释这一现象——Kahneman 的注意力有限资源模型、Baddeley & Hitch 的工作记忆容量限制、Sweller 的认知负荷理论，以及 Risko & Gilbert 的"认知卸载"（把中间状态写下来以释放内部容量）。LLM 的上下文即"工作记忆"，长程任务下的膨胀即"认知过载"。
- **对既有方案的批评**：现有上下文压缩方法多由**规则启发式**触发（固定间隔、上下文窗口临近饱和），并依赖截断或外接模型压缩。作者指出，冗余上下文本质上是智能体自身规划不完美的产物（劣质工具调用产生无关反馈→污染上下文→进一步降低推理质量），形成恶性循环；而智能体强化学习若只依赖最终结果奖励，在长程任务上又面临奖励稀疏与信用分配困难。
- **整体含义**：论文主张把"上下文管理"从外部控制器交给智能体自身，作为一种**正交于 RL 的能力**，同时提升推理质量与训练动态。

## 2. 方法论：CORAL 框架

### 2.1 核心思想
以"认知卸载"为蓝本，给智能体提供两个**可自主调用**的工具，实现"检查点—重置—续推"的循环，使推理可在任意长的时间跨度上维持，而不被陈旧信息淹没。

### 2.2 工具集（Working Memory Toolset）
- **Memory Management（MM）**：维护两类持久信息——
  - *Task Progress*：高层计划与子目标完成状态（要求为 YAML 结构，含 objective 与 tasks 的 PENDING/COMPLETED/FAILED）；
  - *Verified Facts*：推理中确认的中间结果、实体等原子事实。
  - 支持 ADD / UPDATE / DELETE；典型调用时机为：任务开始时写计划、发现关键信息时存事实、完成子任务后更新进度。
- **Context Optimization（CO）**：智能体判断上下文过长或充满过时信息时调用，执行**硬重置**——清空对话历史，仅把当前记忆状态作为 observation 返回，下一回合的初始上下文为 `(s, q, o_t)`。系统提示中强制要求调用 CO 前必须同步 Task Progress，否则后继回合会不连贯。

### 2.3 多回合轨迹形式化
- 将单回合轨迹扩展为 N 个回合的序列 `T = (e1, e2, …, eN)`；第 1 回合初始上下文为 `(s, q)`，第 i>1 回合为 `(s, q, o_{i-1,M})`，即上一回合 CO 返回的记忆；末回合的最后一个 Thought 含答案并立即终止。

### 2.4 两阶段训练
- **行为克隆（SFT）**：把一条完整轨迹在 CO 边界处**切分**为多个独立训练对话（而非把不同轨迹拼接）。切分是正确性要求：后续回合的输入是"系统提示 + 原问题 + 记忆状态"，与推理时字节级一致。损失对 observation token 做掩码，只监督模型自己生成的 thought 与 action（式 5）。不同位置的回合监督不同技能：非末回合教"边推进边维护记忆、判断何时该重置"，后续回合教"从紧凑检查点恢复、不重做已完成工作"。
- **Multi-episode ARPO**：将 DAPO 扩展到多回合轨迹。
  - 从**末回合**计算轨迹级奖励 `R_i`，并**等值广播**到该轨迹的所有回合（式 6）；
  - 把同一问题下所有轨迹的所有回合汇入集合 `E`，按问题维度对所有回合奖励做归一化得到共享优势 `Â`（式 7–8）；
  - 概率比以**回合自身的初始上下文** `c_ji` 为条件，而非原始问题 q；
  - 相对 DAPO 的差异：采样多回合轨迹、跨轨迹池化回合、奖励跨边界传播、按回合上下文条件化。
- **奖励设计**：`R = R_format × R_answer`，格式奖励校验整体格式与 JSON 工具调用合法性，答案奖励由 LLM-as-a-Judge 判定。

## 6. 主要结论与发现

- **GAIA 主结果**：Claude Sonnet 4 + prompting-only CORAL 达 65.0，接近 OpenAI Deep Research（67.4）；Qwen3-8B 上 prompting 20.4 → SFT 41.6 → RL 42.8。
- **增益集中在长程任务**：CK-Pro-8B 平均分更高（43.7 vs 42.8），但其优势全在 L1（56.4 vs 46.2）；CORAL RL 在 L2（45.7 vs 42.3）领先，L3 大幅超出（19.8 vs 8.3）。作者解释：短题上维护工作记忆纯属开销，单一平均值低估了方法在目标区间的作用。
- **效率是净收益而非代价**：每轨迹输入 token 136K vs ReAct 1,078K（降 87.4%），LLM 调用 15.2 vs 45.3，峰值上下文 12.7K vs 30.6K。机制有二：CO 重置给上下文长度设上界（ReAct 每轮重读全部历史，成本随轮数二次增长）；写下了计划与事实的智能体不再重复检索，轮数降至三分之一。
- **训练让 CO 用得更少而非更多**：RL 后 CO 仅 0.21 次/轨迹（prompting 为 4.3），MM 3.9–4.1 次。失败轨迹的 CO 调用约为成功轨迹的两倍（0.28 vs 0.12），说明重置频率更像"挣扎的症状"而非可最大化的杠杆。
- **迁移性**：同一 Qwen3-8B RL checkpoint 在 NQ 71.0、HotpotQA 70.4、2Wiki 79.2、Musique 43.2、Bamboogle 79.2，全面超过 Search-o1、R1-Searcher、DeepResearcher、SimpleDeepSearcher；BrowseComp 上 Claude Sonnet 4 由 22.7 升至 30.7（+8.0），为全文最大增益。
- **能力相关而非规模相关**：prompting-only 的增益随骨干能力上升（QwQ-32B +5.8、Claude Sonnet 4 +4.8、Qwen3-8B +1.0），Qwen2.5-7B-Instruct 反而 −3.9（无法稳定为 4 个工具输出 JSON），但 SFT 后该骨干可达 34.4%（基线 17.5），说明差距是工具调用缺陷而非框架天花板。
- **消融结论**：数学数据贡献 1.7 分（集中在 L2）；等量条件下"仅正确轨迹"优于随机子采样（39.3 vs 36.5），但**全量（含失败）比仅正确再高 2.3 分**——因为掩码式行为克隆监督的是过程而非结论，一条"规划合理、检查点勤勉、只在最后一跳认错实体"的失败轨迹仍然示范了全部要安装的技能。
- **记忆可信度的边界**（定性探针）：计划刚写完时的记忆损坏会被静默接受；中途损坏常能被发现（原始证据仍在上下文中）；**CO 重置后的损坏原则上不可检测**。因此对话历史是交叉验证通道，CO 会永久关闭该通道——这正是 MM 应慷慨使用、CO 应谨慎使用的结构性理由。

## 7. 优点

- **问题切口清晰且有力**：把"上下文膨胀"重构为"智能体自身规划不完美的产物"，并给出认知科学上的自洽类比，动机链条完整。
- **极简接口、正交增益**：仅两个工具、不改模型结构，可与任意 agentic RL 管线组合；prompting-only 即可在强模型上见效，降低采用门槛。
- **训练与推理的一致性设计**：按 CO 边界切分回合，使训练输入与推理时字节级一致；并明确指出"扁平拼接会训练模型见到它永远不会见到的上下文"，这一点常被同类工作忽略。
- **算法改动有针对性**：ME-ARPO 的奖励广播 + 跨回合池化归一化，直接解决"轨迹含多回合、优势如何归属"的问题；概率比按回合上下文条件化也是必要修正。
- **效率与精度同向**：6–7× token 节省与精度提升同时成立，属于少见结论，且用 824 条轨迹的细粒度埋点支撑，而非仅报总量。
- **实验诚实度高**：主动承认 CK-Pro-8B 平均分更高并解释原因；主动报告 L3 样本量导致的高方差；主动报告 Qwen2.5-7B 上的负增益；错误轨迹保留策略配有等量对照消融。
- **失败模式分析深入**：附录 D.2 的记忆损坏探针与附录 G 的 42 条搜索结果 vs 7 个检查点对比，把"为什么有效"讲到了机制层。

## 8. 不足与局限

- **跨回合信用分配过于粗糙**：ME-ARPO 将轨迹奖励**

- **跨回合信用分配过于粗糙**：ME-ARPO 将轨迹奖励**等值广播**到所有回合，隐含假设"同一轨迹的每个回合贡献相同"。但一条成功轨迹中可能既有高质量检查点维护，也有侥幸的猜测回合；一条失败轨迹也可能包含正确的中间规划。等值广播无法区分"哪一回合该被强化"，本质上是把轨迹级稀疏信号原样下推，而非真正做回合级信用分配。作者虽用"跨轨迹池化 + 按问题归一化"缓解方差，但这是**降噪**而非**归因**，与真正的过程奖励仍有距离。
- **回合级优势与回合级上下文的耦合未加验证**：概率比按回合自身上下文 `c_ji` 条件化在数学上是必要的，但也意味着同一轨迹的不同回合被当作**近似独立的策略样本**优化。多回合之间存在的策略相关性（后一回合的策略分布由前一回合的行为决定）被忽略，可能引入优化目标与真实多回合目标之间的偏差，论文未对此做理论或实证讨论。
- **硬重置的信息损失不可逆**：CO 是"清空 + 只回填记忆"，任何未被写入 Task Progress / Verified Facts 的信息将永久丢失。论文在定性探针中已承认"CO 重置后的记忆损坏原则上不可检测"，但未给出任何防护机制（如重置前的自检、记忆与原始证据的交叉校验、可回滚的摘要层），这使方法在**高风险、需可审计**的场景中难以直接采用。
- **记忆内容缺乏可信度校验**：Verified Facts 由模型自行判定"已验证"后写入，工具返回中的错误信息、被污染的网页内容、提示注入都可能被固化为"事实"，并在后续所有回合中被当作前提使用。论文未讨论对抗性输入或噪声证据下的鲁棒性，也未评估记忆被写入错误事实后的传播范围。
- **训练流程的跨骨干泛化证据薄弱**：SFT 与 RL 全流程仅在 Qwen3-8B 上完成，Qwen2.5-7B 只提供了一个辅助 SFT 结果，QwQ-32B、Qwen3-32B、Claude Sonnet 4 仅有 prompting-only 结果。因此"该训练管线能否迁移到其他模型族/规模"实际上**未被验证**，而这一点恰恰是方法能否被社区复用的关键。
- **对工具调用能力存在前置依赖**：Qwen2.5-7B-Instruct 在 prompting-only 下出现 −3.9 的负增益，作者归因于"无法稳定为 4 个工具输出合法 JSON"。这说明框架的有效性存在一个**未量化的能力门槛**，论文未给出该门槛的判定方法（例如需要多高的工具调用成功率），也未设计降级方案（如减少工具数量、结构化输出约束）。
- **评测规模与统计效力有限**：GAIA L3 仅 12 题、BrowseComp 仅 150 题且为单一专有骨干零训练对比，L3 上 19.8 vs 8.3 的差距虽醒目，但单题即对应 8.3 个百分点，作者自己标注为"方向性证据"。RL 的头条增益（41.6→42.8，+1.2）在 8 次采样的方差范围内是否稳健，正文未给出显著性检验。
- **奖励依赖外部 LLM Judge**：答案奖励由 LLM-as-a-Judge 判定，Judge 的偏差、对长答案的偏好、以及与被训模型同源时的潜在自偏好，均未做分析或校准；格式奖励与答案奖励相乘的设计也可能使格式失败直接抹除全部学习信号。
- **算力与成本披露不足**：未报告 GPU 型号/数量/训练时长，也未给出单位任务的推理成本（仅报 token 与调用次数），使读者难以评估方法的实际部署代价；BrowseComp 缩减至 150 题亦说明评测算力是真实约束，但约束规模未量化。
- **任务域覆盖偏窄**：训练与主评测集中于 web 检索式问答与多跳 QA，数学轨迹仅 241 条且只用于消融。方法声称面向"通用长程智能体"，但未在代码执行、具身/工具操作、多文件编辑等**动作空间不同、错误代价更高**的长程任务上验证。

## 9. 启示与可延伸方向

- **把"上下文管理"显式建模为动作**，而非外部调度策略，是本工作最具迁移价值的观点：它把压缩从"工程补丁"提升为"可学习的策略维度"，并天然适配任何 ReAct 式框架。
- **"失败轨迹也有监督价值"的结论**具有超出本文的意义：在过程监督（掩码 observation、只监督 thought/action）下，错误结论不污染对过程的示范，这为低成本数据构造（无需过滤正确性）提供了依据，但也提示需要谨慎设计掩码边界。
- **记忆慷慨、重置谨慎**的非对称使用原则，来自"对话历史是唯一交叉验证通道"这一结构性观察，可作为后续设计分层记忆（可回滚摘要、证据索引、置信度标注）的出发点。
- **自然的后续工作**：回合级过程奖励或 credit assignment、CO 前的记忆自检与可回滚机制、记忆写入的可信度门控（对抗注入）、能力门槛的自适应工具集裁剪，以及在非检索类长程任务上的验证。

## 10. 总体评价

论文以"认知资源自我分配"为统一视角，用**两个工具 + 两阶段训练**的极简设计，同时回答了"长程任务为何退化"与"如何让模型自己管理上下文"两个问题，并在效率（token 降约 87%）与精度（长程难度层显著领先）上取得同向收益。其最强之处在于**动机—接口—训练—评测**四层的一致性：认知卸载的类比落到具体工具，工具调用边界落到 SFT 的轨迹切分，多回合结构落到 ME-ARPO 的奖励广播与上下文条件化，最后用细粒度埋点与失败模式探针回到机制解释。其最弱之处在于**信用分配的粗糙性**与**训练管线仅在单一骨干上验证**，前者限制了 RL 阶段的天花板（增益仅 +1.2），后者限制了结论的外部有效性。总体而言，这是一篇问题定义清晰、工程实现克制、实验披露诚实的系统级工作，其核心贡献（把上下文管理交给智能体自身，并给出可训练的轨迹形式化）比其具体数值结果更具持久价值。
