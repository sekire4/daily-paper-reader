## 摘要
长上下文模型会反复解决密切相关的检索问题。注意力或全局检索可以保留大规模存储，但每次前向传播都会重新搜索什么重要。循环压缩仅通过提前决定保留哪些信息来避免这种搜索。这两种机制都没有直接利用相邻检索步骤中的有用记忆可能大幅重叠这一点。我们提出一种替代方案：检索是在地址空间中进行的持久局部遍历。我们将记忆的内容与其地址分离。效用由检索该内容所揭示的信息定义，而几何仅决定以多低的代价到达该信息。这引出一个代价正则化的索引目标：在局部邻域内保留信息价值，同时对每个变为局部可访问的记忆计费。其边际价值形式同时产生吸引压力和排斥压力。因此，当附加价值超过检索代价时，互补记忆应可共同检索；而冗余记忆不应仅因各自有用就占据同一检索集。作为原理验证，我们仅在 MiniGrid Memory 上测试最简单的固定几何实例。一个持久局部遍历头在五个 token 的上下文下经过 0.59M 训练步达到 0.95 平均回报，相比之下高斯绝对寻址为 0.94M，类别绝对寻址超过 2M。该实验未测试学习到的几何或重复检索。相反，它支持这样一个假设：有状态检索可能比无状态检索更容易学习。要检验完整的所提方法，还需要进一步实验。

## Abstract
Long-context models repeatedly solve closely related retrieval problems. Attention or global retrieval can retain large stores, but each forward pass again searches for what matters. Recurrent compression avoids this search only by deciding earlier what information to preserve. Neither mechanism directly exploits that useful memories at neighbouring retrieval steps may substantially overlap. We propose an alternative in which retrieval is a persistent local traversal through an address space. We separate a memory's content from its address. Utility is defined by the information revealed by retrieving the content, while geometry determines only how cheaply that information can be reached. This leads to a cost-regularised indexing objective that preserves information value inside local neighbourhoods while charging for every memory made locally accessible. Its marginal-value form gives both attractive and exclusion pressures. Thus, complementary memories should be co-retrievable when the additional value exceeds retrieval cost, whereas redundant memories should not occupy the same retrieval set solely because they are individually useful. As a proof of principle, we test only the simplest fixed-geometry instance on MiniGrid Memory. A persistent local traversal head reaches $0.95$ mean return after $0.59$M training steps with a five-token context, compared with $0.94$M for Gaussian absolute addressing and more than $2$M for categorical absolute addressing. The experiment does not test learned geometry or repeated retrieval. Instead, it motivates the hypothesis that stateful retrieval may be easier to learn than stateless. To test the full proposed method further experimentation is necessary.

# 《Retrieval as Traversal: Value-Indexed Memory for Stateful Long-Context Agents》论文总结

## 1. 核心问题与研究动机

- **背景问题**：长上下文模型在相邻的检索步骤中，往往反复求解高度相关的检索问题。
  - 注意力/全局检索能保留大规模记忆，但**每次前向传播都要重新搜索**“什么重要”。
  - 循环压缩虽避免了全局扫描，但**在信息需求未知前就决定保留什么**。
- **被忽视的结构**：相邻检索步骤中有用记忆集合可能**大幅重叠**，而现有方法（稀疏注意力、ANN 检索、外部检索）通常把每次查询当作全新的匹配问题，未利用这种重复性。
- **核心主张**：将检索建模为**地址空间中的持久局部遍历**，把记忆的“内容”与“地址”分离——效用由内容揭示的信息决定，几何只决定到达该信息的代价。
- **整体含义**：提出一种**有状态（stateful）检索**范式，使地址空间按未来检索的期望效用组织，并在相关查询间持久复用检索状态。

## 2. 方法论

### 2.1 核心思想：内容与地址分离

- 记忆 $j$ 的内容为随机变量 $M_j$，地址为 $z_j = \Phi(C^w_j) \in \mathbb{R}^R$，由写入时的上下文经映射 $\Phi$ 得到。
- 检索时插入工作上下文的是**记忆内容** $m_j$，而非写入上下文。
- 定义**查询前信息价值**：
  $$V(S;c) = \mathbb{E}[U(c \oplus M_S) - U(c) \mid C_t = c]$$
  其中 $U$ 为任务效用（如期望回报或负预测损失），**地址不出现在价值定义中**。
- 假设自由处置性：$S \subseteq T \Rightarrow V(S;c) \le V(T;c)$。

### 2.2 成本正则化局部索引目标

- 定义 $\varepsilon$-邻域 $B_\varepsilon(x) = \{j : \|z_j - x\| \le \varepsilon\}$，查询位置 $\Phi(c)$ 的局部可访问集为 $N_c(\Phi) = B_\varepsilon(\Phi(c))$。
- 若只最小化信息缺失，会出现**平凡解**：把所有记忆映射到同一点即可零损失。因此引入**每个可访问记忆的检索代价 $\lambda > 0$**：
  $$\mathcal{L}_\lambda(\Phi) = \mathbb{E}\left[V(\Omega_t;C_t) - V(N_{C_t}(\Phi);C_t) + \lambda |N_{C_t}(\Phi)|\right]$$
- 对固定上下文，等价于选择最大化 $J_\lambda(S;c) = V(S;c) - \lambda|S|$ 的局部集合。**$\lambda$ 取代了任意的 top-k 预算，成为价值阈值**。

### 2.3 互补性与冗余性的相反压力

- 边际价值：$\Delta_j(S;c) = V(S \cup \{j\};c) - V(S;c)$。
- 条件交互：$s_{ij}(S;c) = \Delta_j(S \cup \{i\};c) - \Delta_j(S;c)$；正为互补，负为冗余。
- **Observation 1（代价调整的共检索）**：
  $$J_\lambda(S \cup \{i,j\};c) - J_\lambda(S \cup \{i\};c) = \Delta_j(S \cup \{i\};c) - \lambda$$
  即联合检索优于单独检索，当且仅当 $\Delta_j(S \cup \{i\};c) > \lambda$。
- **吸引压力**：若 $i$ 使 $j$ 的边际价值超过 $\lambda$，局部邻域应同时包含二者；正交互 $s_{ij}$ 增加这种情况。
- **排斥压力**：若 $j$ 在已知 $i$ 后完全冗余，则 $\Delta_j = 0$，同时检索恰好损失 $\lambda$，索引无动机仅因各自高单值就把二者放入同一邻域。
- **价值等价替代品**：若对所有 $S,c$ 有 $V(S\cup\{i\};c)=V(S\cup\{j\};c)=V(S\cup\{i,j\};c)$，则二者具有相同个体价值及相同交互剖面，竞争同一协同集合。
- 强调几何应由**决策价值与交互剖面**驱动，而非原始内容相似度。

### 2.4 持久检索即遍历

- 维护持久检索头位置 $i_t \in \mathbb{R}^R$：
  $$M_t = B_\varepsilon(\Phi(c_t)) \cup B_\varepsilon(i_t), \quad W_t = \bigcup_{\tau=t-H+1}^{t} M_\tau$$
- 工作窗口保留近期遍历过的记忆，检索头继续局部移动；**移动规则保持模块化**（可由 RL 学习、移至上次前向中最高价值记忆，或扩展已有 key/value 估计器）。
- 定义代价最优检索集 $S^\star_t = \arg\max_{S \subseteq \Omega_t}[V(S;c_t) - \lambda|S|]$ 及其**一步新增漂移** $D_t = |S^\star_t \setminus S^\star_{t-1}|$；当 $D_t$ 相对 $|S^\star_t|$ 较小时，持久机制可复用上一检索状态。

## 3. 实验设计

- **数据集/场景**：MiniGrid Memory（MiniGrid-Memory-S17Random）。
  - 智能体观察线索，穿过走廊，后在 T 形路口选择对应物体。
  - 随机化任务中，相关线索位于决策前 7–17 个环境步。
- **架构**：Transformer-XL 骨干 + PPO；动作分解为环境动作 $a^{ext}_t$ 与检索头移动 $a^{mem}_t$。
- **固定几何**：实验不学习 $\Phi$，而用手工映射 $\Phi_0(C^w_j) = (x_j, y_j, t_j)$，即假设物理与时间邻近性是有用索引特征。
- **训练流程**：先在固定尺寸任务（上下文长度 64）上无检索头预训练，再在随机化变体（上下文长度 5）上微调。
- **对比方法**：
  - 无检索头基线（预训练原样，上下文 64；缩减上下文基线，上下文 5）；
  - 相对移动的持久局部遍历头（Memory Navigation）；
  - 绝对位置选择——高斯参数化；
  - 绝对位置选择——类别参数化。
- **评价指标**：跨种子平均学习曲线首次超过 0.95 回报的训练步数；辅以平均超额步数。

## 7. 优点

- **概念清晰**：将“内容—地址”分离，把几何的作用限定为“到达信息的代价”，避免语义相似度与决策价值的混淆。
- **理论优雅**：用决策论目标自然导出互补（吸引）与冗余（排斥）两种压力，并用 Observation 1 给出简洁的联合检索判据；对“价值等价替代品”的交互剖面刻画较严谨。
- **避免平凡解**：通过显式检索代价 $\lambda$ 取代 top-k 预算，使目标非退化且具有可解释的价值阈值含义。
- **诚实透明**：明确承认实验仅为最简固定几何原型，主动报告强负对照，不夸大能力差距；提供代码与复现脚本。
- **工程轻量**：实验资源需求低（<3 GB 显存、约 3 小时），便于复现与后续扩展。

## 8. 不足与局限

- **核心机制未验证**：$\Phi$ 由环境手工给定，而非从式 (5) 学习；值索引、交互几何、低漂移复用均未实验。
- **任务过于简单**：仅需检索一条信息，未测试顺序访问多个记忆、多步重复检索等真正体现“遍历”优势的场景。
- **负对照削弱主张**：缩减上下文基线可通过行为/轨迹间接编码线索，导致无法声称能力差距，结果仅反映学习效率。
- **几何表达力未知**：固定维度空间能否表示 $\mathcal{L}_\lambda(\Phi)$ 偏好的检索集尚不清楚；同一对记忆可能在不同上下文中既冗余又互补，是否存在满足条件的空间排布未讨论。
- **移动规则不统一**：检索头移动规则是模块化的，未与 $\Phi$ 的构造从同一原则导出；$\Phi$ 的训练细节（损失分解、训练流程）未给出。
- **实验覆盖不足**：单数据集、单任务、无消融、基线种子较少，统计效力有限；绝对地址方法未在预算内收敛，比较存在截断偏差。
- **应用限制**：当前形式化依赖“自由处置性”等假设，且需要可定义的检索代价与任务效用，向通用长上下文语言建模的迁移尚不明确。
