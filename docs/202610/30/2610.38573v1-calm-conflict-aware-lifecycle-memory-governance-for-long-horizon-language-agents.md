## 摘要
一条记忆对于当前推理可能已经过时，但对于重建过去却可能不可或缺。基于相关性的检索忽视了这种张力：语义相关性、基于证据的有效性以及查询特定的准入资格彼此不同。我们提出 CALM，一种冲突感知的生命周期记忆治理框架，将持久记忆保存与查询时准入解耦。CALM 将异构记录转换为基于证据的记忆单元，利用支持、冲突和依赖信号更新有效性与生命周期状态，并通过由时间适用性指导的免训练或学习式门控来准入适合查询的证据。在 LongMemEval-S 和 LoCoMo 上，以 Qwen 和 GPT 为骨干模型，CALM 优于最先进的基线，取得最佳总体准确率。与简单的过滤和重排序相比，查询条件化准入进一步改善了证据选择。冲突阻断与鲁棒性分析表明，CALM 在保留有用证据的同时抑制了错误的检索记忆。历史重建实验表明，保留被取代的记录能够支持准确的早期状态推理，同时不影响当前状态答案。

## Abstract
A memory can be outdated for present-day reasoning yet indispensable for reconstructing the past. Relevance-based retrieval overlooks this tension: semantic relevance, evidence-grounded validity, and query-specific eligibility are distinct. We propose CALM, a conflict-aware lifecycle memory governance framework that decouples persistent memory preservation from query-time admission. CALM converts heterogeneous records into evidence-grounded memory cells, updates validity and lifecycle states using support, conflict, and dependency signals, and admits query-appropriate evidence through training-free or learned gating informed by temporal applicability. Across LongMemEval-S and LoCoMo with Qwen and GPT backbones, CALM outperforms state-of-the-art baselines, achieving the best overall accuracy. Compared with simple filtering and reranking, query-conditioned admission further improves evidence selection. Conflict-blocking and robustness analyses show CALM suppresses erroneous retrieved memories while retaining useful evidence. Historical-reconstruction experiments demonstrate that preserving superseded records supports accurate earlier-state reasoning without compromising current-state answers.

## 1. 核心问题与研究动机

- **核心矛盾**：长时程语言智能体积累的记忆存在一个根本矛盾——一条记忆对当前推理可能已经**过时**，但对重建**历史状态**却不可或缺。例如用户从西雅图搬到波士顿后，“住在西雅图”这条记录对“我现在住哪”的查询是过时的，但对“我搬家前住哪”的查询是必需证据。
- **现有方法的缺陷**：主流记忆系统（MemGPT、MemoryBank、HippoRAG、A-Mem、Mem0、Zep 等）侧重存储、组织与检索，但**语义相关性 ≠ 查询可用性**。检索到的记忆可能在主题上相关，却因被取代、被矛盾或时间/范围不匹配而误导推理。
- **三个被混淆的属性**：论文明确区分
  - **语义相关性**（与查询的主题相关程度）；
  - **查询无关的有效性**（基于累积证据的持久可靠性）；
  - **查询条件化准入资格**（在给定查询的时间目标、适用范围与意图下是否应进入工作上下文）。
- **关键洞察**：记录更新或冲突本身并不能解决“哪些检索记录应被准入”的问题；删除旧记录会丢失历史证据，不加区分地准入两者则会混淆当前状态。因此需要**将持久生命周期治理与查询时准入分离**。

## 2. 方法论

### 核心思想
CALM 是一个**两层框架**：后端记忆的持久生命周期治理（查询无关）+ 查询时对检索候选的准入门控（查询条件化）。它不替换底层存储/检索架构，也不修改答案模型，而是插入在“记忆后端”与“工作上下文”之间。

### 三阶段流程

**Stage I：证据锚定的记忆适配（Evidence-Grounded Memory Adaptation）**
- 将异构后端记录（对话片段、抽取事实、摘要、结构化记录）统一为规范记忆单元：
  $$m_i^t = (c_i, E_i^t, a_i, \rho_i^t, s_i^t),\quad a_i = (\kappa_i, \tau_i, \pi_i, U_i, \Omega_i)$$
  其中 $c_i$ 为规范内容，$a_i$ 包含语义类型、时间锚点、来源溯源、实体、适用范围，$\rho_i$ 为聚合来源可靠性权重，$s_i$ 为生命周期状态。
- 仅对归一化后**完全重复**的记录做证据合并；语义相似但值不同的记录保持独立，留给 Stage II 判定冲突或不同时间状态。
- 来源可靠性采用固定启发式权重（如原始对话 span 0.74、规则派生 span 0.82、LoCoMo observation 0.95、summary 0.82–0.88），并做敏感性分析；新单元初始化为 CANDIDATE。

**Stage II：生命周期感知记忆治理（Lifecycle-Aware Memory Governance）**
- 构建生命周期图 $G^t=(M^t, E^t_{conf}, E^t_{dep})$，冲突与依赖关系由**确定性规则**识别，不依赖 LLM 裁判或学习式关系分类器。
- **冲突规则**：偏好反转 0.95、时间位置变更 0.94、约束变更 0.92、任务状态变更 0.90、槽位值更新 0.88、弱对立信号 0.70；强度 ≥0.75 且非弱类型时触发**取代（supersession）**，弱冲突仅记录不替换。
- **依赖规则**：边 $(j,i)$ 表示 $m_j$ 是 $m_i$ 的前提；显式引用 0.95，同槽位 0.55，派生同轮/语义线索/主题重叠按规则给分。
- **信号聚合**：
  - 支持 $S_i = \min(1,\ 0.55\min(1,n_i/3)+0.45\bar{c}_i)$，证据数在 3 条后饱和；
  - 冲突风险 $C_i$：被取代记忆取 1，否则取最强冲突置信度；
  - 无效依赖风险 $D_i^{(k+1)}=\min(1, D_i^{(k)}+0.4d_{ji})$，$D_i\ge0.70$ 标记验证，$d_{ji}\ge0.80$ 触发 STALE。
- **生命周期状态**：CANDIDATE → ACTIVE（直接用户证据或置信度 ≥0.60）→ STABLE（≥2 条证据或置信度 ≥0.80）；强取代将旧记录有效性上限压到 **0.15**。**单纯时间流逝不会触发 STALE**，时间仅用于确定更新顺序与适用区间；归档由可选保留策略控制。

**Stage III：查询条件化记忆门控（Query-Conditioned Memory Gating）**
- 对检索候选 $R_q$（Top-48，固定混合检索器，CALM 不新增检索轮次）构造四维特征：
  $$x_{q,i}^t = [\zeta_{q,i}^t,\ V_i^t,\ \psi_{q,i}^t,\ 1-R_{q,i}^t]$$
  分别表示语义相关性、存储有效性、查询–记忆兼容性、查询条件化风险（越低越好）。
- 兼容性 $\psi$ 为时间、实体、范围、语义类型四因子均值；风险 $R = 1-(1-r_{conf})(1-r_{dep})(1-r_{time})(1-r_{life})$。
- **硬资格过滤** $h_{q,i}\in\{0,1\}$：当前状态查询通常排除 CANDIDATE/ARCHIVED/STALE/SUPERSEDED；显式历史查询可临时准入被取代/归档记录（查询局部副本，不改持久状态）。
- **两种策略**（共享同一过滤、特征与打包规则）：
  - **CALM-ZS**（免训练）：$F_{zs}=\frac14(\zeta+V+\psi+1-R)$，阈值 0.50；
  - **CALM**（可学习）：单隐层 MLP + GELU + sigmoid，加权 BCE 训练，阈值 0.50，仅在**独立开发集**上训练，监督标签由 Support/Compatible/Mislead 三个确定性谓词构造，含“相关但过时”的难负样本。
- 最终准入 $g_{q,i}^{b,t}=h_{q,i}\cdot\mathbb{I}[F_b(x)\ge\theta_b]$，被拒记忆保留在持久存储中，供未来兼容查询使用；准入记忆按策略分数排序并贪心打包至 token 预算。
