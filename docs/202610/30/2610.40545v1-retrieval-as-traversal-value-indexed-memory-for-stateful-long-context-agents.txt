## Abstract 

Long-context models repeatedly solve closely related retrieval problems. Attention or global retrieval can retain large stores, but each forward pass again searches for what matters. Recurrent compression avoids this search only by deciding earlier what information to preserve. Neither mechanism directly exploits that useful memories at neighbouring retrieval steps may substantially overlap. We propose an alternative in which retrieval is a persistent local traversal through an address space. We separate a memory’s content from its address. Utility is defined by the information revealed by retrieving the content, while geometry determines only how cheaply that information can be reached. This leads to a cost-regularised indexing objective that preserves information value inside local neighbourhoods while charging for every memory made locally accessible. Its marginal-value form gives both attractive and exclusion pressures. Thus, complementary memories should be co-retrievable when the additional value exceeds retrieval cost, whereas redundant memories should not occupy the same retrieval set solely because they are individually useful. As a proof of principle, we test only the simplest fixed-geometry instance on MiniGrid Memory. A persistent local traversal head reaches 

0.95 mean return after 0.59 M training steps with a five-token context, compared with 0.94 M for Gaussian absolute addressing and more than 2M for categorical absolute addressing. The experiment does not test learned geometry or repeated retrieval. Instead, it motivates the hypothesis that stateful retrieval may be easier to learn than stateless. To test the full proposed method further experimentation is necessary. 

## 1 Introduction 

Long-context models face a basic trade-off. Keeping a large history available preserves information, but attention or retrieval must repeatedly determine which parts of that history matter. Compressing the past into a bounded recurrent state avoids the scan, but the compression is performed before all future information needs are known. Sparse attention, approximate nearest-neighbour search, and external retrieval reduce the cost of a query, but typically still treat successive queries as fresh matching problems [5, 7, 9, 6]. This misses repetition, a third source of cost. The memories useful at two nearby inference steps need not be independent sets. In order to avoid this cost information about value of the to be retrieved memories has to be known before retrieving them. We investigate this idea as retrieval by traversal. Memories and the current context and retrieval heads are placed in an address space. The positions of the current context and the retrieval heads aim to hold the information about the current expected value of the to be retrieved memories, as all memories in ϵ distance will be retrieved.

Our proposal differs from semantic retrieval in one important respect: addresses should be shaped by the decision value of retrieving memory contents, rather than by similarity between the contents themselves. This distinction matters because two semantically similar memories may be redundant, whereas two dissimilar memories may only be useful together. This paper makes two deliberately limited contributions. First, we give a decision-theoretic objective for learning such a geometry and derive how redundancy and complementarity affect local co-retrieval. Second, we report a small proof-of-principle experiment in which the geometry is fixed and only the persistent retrieval mechanism is learned. We do not claim that the learned value-index proposed here has yet been experimentally validated. 

Related work. External differentiable memories have long separated computation from stored state. Neural Turing Machines combine content and location addressing [3]. Differentiable Neural Computers add dynamic allocation and temporal links [4]. Lie-access Neural Turing Machines are particularly close in mechanism. Here, memories occupy a continuous address manifold and read heads move by relative transformations [12]. Neural Map instead uses physical position as an external memory index [8]. Modern sparse-attention and retrieval systems use hashing, learned routing, nearest-neighbor search, or retrieval indices to avoid attending to every stored item [5, 9, 11, 6]. We ask instead whether the address space itself can be organized by the expected utility of future retrieval and then traversed persistently across related queries.

It does not test the learned indexing objective (5), interaction-driven geometry, or the low-drift hypothesis. 

A revealing negative control. The reduced-context baseline is stronger than expected. With a short window, the agent can encode the cue indirectly into its own behaviour. With temporal encoding available, it waits for a cue-dependent number of steps and later reads the resulting clock state. When temporal and spatial encodings are removed and the window is shortened further, it can instead repeatedly turn in the corridor and encode the cue in its recent trajectory. These are legitimate solutions. They prevent us from claiming a capability gap and make the current experiment evidence only for learning and behavioural efficiency. 

## 4 Limitations 

The strongest claims of the framework remain untested. The experiment uses an environment-provided geometry rather than learning Φ from (5). Additionally, the experiment requires the retrieval of only one piece of information and therefore does not test whether the proposed method helps with sequentially accessing memories when they become useful. It has also not yet been explored how well a fixed-dimensional geometry can represent the retrieval sets favored by Lλ(Φ) . If two memories Mi and Mj are quite similar, they may be redundant in 5many contexts, i.e. sij (c) < 0, while at the same time being complementary in many other contexts, i.e. sij (c) > 0. Can the optimal Φ position zi and zj such that they are contained in the same ϵ-ball primarily in contexts in which they are complementary, or is such a spatial arrangement impossible? Additionally, the retrieval rule is left modular rather than canonical. A slight modification to the proposed method is needed so that the movement of the retrieval head and the construction of Φ arise from the same underlying principle. Finally, whilst the loss term is given, it is not described how Φ should be trained in clear detail. Exploring the behavior of sij with respect to Φ may result in a class of additional constraints such that the loss can be decomposed into multiple terms that are easier to train. The training procedure itself is also not discussed. 

## 5 Conclusion 

We propose treating long-context retrieval as persistent traversal through an address space learned from retrieval utility. Separating memory content from memory address yields a simple organizing principle. Geometry should make valuable combinations locally accessible while charging for unnecessary co-retrieval. The resulting objective naturally distinguishes complementarity from redundancy and shows that exact substitutes share the same interaction profile with other memory coalitions. Our current MiniGrid experiment tests only the traversal mechanism under fixed geometry. The next empirical tests would be learning the value-indexed space and evaluating repeated low-drift retrieval.
