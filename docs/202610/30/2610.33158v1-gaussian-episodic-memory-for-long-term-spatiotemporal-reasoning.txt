Abstract— Real-world environments undergo continual semi-
static changes, requiring a memory representation that captures
both the spatial and temporal evolution of a scene. Existing
spatio-temporal memories for robots typically rely either on
structured representations, which are limited to the entities
and attributes captured during construction, or on image-
based memories, which are constrained to previously observed
viewpoints. We introduce GEMS, a framework that combines
a persistent spatio-temporal 3D Gaussian Splatting (3DGS)
map with an agentic reasoning pipeline. The 3DGS map is
reconstructed once and subsequently updated only in regions
where the scene changes, storing only these modifications
while preserving visual detail across time. The agentic pipeline
leverages this map to render novel views on demand, iteratively
accumulating evidence to answer spatio-temporal questions and
ground objects from natural-language queries. To advance future
research, we introduce GEMS-Bench, a spatiotemporal question-
answering benchmark focused on semi-static environments. It
comprises 3 real-world and 12 synthetic environments, spanning
473 question-answer pairs. We evaluate GEMS on novel-view
synthesis quality across scene updates, 3D object grounding,
spatiotemporal question answering, and storage efficiency.

I. INTRODUCTION
Robots operating for long periods in human-centered envi-
ronments must model not only the geometry and semantics
of their surroundings but also how those surroundings evolve
over time. Real-world environments, such as homes and
offices, experience frequent semi-static changes in which
objects are moved, furniture is rearranged, and equipment
may appear, disappear, or change state. Modeling these
changes and building episodic memory that captures when
and where they occurred enables robots to reason about
the environment’s history and answer spatial, semantic, and
temporal questions, such as where an object was previously
located, when a change occurred, or how the current state of
a scene differs from an earlier one.
3D scene graphs (3DSGs) [1]–[3] have emerged as compact,
structured representations that organize spatial-semantic con-
cepts. However, typical 3DSGs represent a single snapshot of
the environment. More recent 3DSG approaches incorporate
temporal information into scene representations to model
semi-static changes [4]–[7]. However, they either preserve
only object-level states and textual descriptions, precommit-
ting to objects segmented at construction time, or preserve
observations only from fixed viewpoints, limiting access to the
underlying visual evidence. Recently, 3D Gaussian Splatting
arXiv:2610.33158v1  [cs.CV]  23 Oct 2026


(3DGS) [8] has emerged as a high-fidelity representation
that preserves fine-grained visual details, supports novel-view
synthesis, and enables localized updates [9], [10], making
it well suited for long-term embodied reasoning. Existing
3DGS-based mapping and reasoning methods, however, either
address static scenes [11], [12] or maintain only the latest
scene state [13].
To this end, we present GEMS, a persistent spatiotemporal
episodic memory based on 3D Gaussian Splatting (3DGS),
coupled with an agentic reasoning pipeline. GEMS construct
an initial 3DGS map, then detect changes from observations
collected during each subsequent scene revisit and locally
update the Gaussian primitives in affected regions. Unchanged
Gaussians are shared across temporal states, while additions,
removals, and modifications are stored as temporal deltas. As
a result, storage grows with environmental changes rather than
the number of revisits. Given a query, the agentic pipeline
can select informative viewpoints for reconstructed regions
rather than being restricted to a fixed set of viewpoints.
The 3DGS-based memory enables the agent to render the
map from a consistent virtual camera pose across different
timesteps. This controlled alignment supports cross-temporal
visual comparison and reasoning about object motion and
state changes. Moreover, photorealistic novel-view rendering
enables the agent to perform on-demand segmentation of
target objects from informative, query-dependent viewpoints.
To foster future research, we introduce GEMS-Bench, a
multi-revisit spatiotemporal embodied question-answering
benchmark. It comprises 12 synthetic household scenes and 3
real-world scenes, each with at least 3 revisits. GEMS-Bench
spans 473 question-answer pairs categorized into 5 types, as
well as posed RGB-D for each revisit.
In summary, we make the following contributions:
• We introduce GEMS, a 3DGS-based episodic memory
framework that maintains long-term scene history via
efficient, localized updates, enabling high-fidelity novel-
view rendering over time.
• We develop an agentic EQA pipeline that utilizes
spatiotemporal novel-view synthesis for query-dependent
viewpoint selection, visual alignment across time, and
on-demand object grounding.
• We introduce a new multi-visit spatiotemporal question-
answering benchmark, GEMS-Bench, comprising semi-
static environmental changes across 15 scenes and 473
question-answer pairs.
• We evaluate GEMS across four dimensions: novel-
view synthesis quality under scene updates, 3D object
grounding from natural-language queries, spatiotemporal
question answering, and storage requirements.

II. RELATED WORK
A. Spatial-Semantic and Spatiotemporal Mapping
Early works on robotics mapping [14] focused only
on geometric modeling of the environment. Subsequent
works [15], [16] augmented such 3D geometric maps with
semantic and open-vocabulary language features, enabling
object retrieval and language-guided navigation. Structured
representations, such as 3D Scene Graphs (3DSGs) [2], [3],
[17]–[20], have emerged as more efficient representations
that encode both geometric and semantic information in
a topological graph; however, they only maintain a single
snapshot of the scene state.
To extend robotics maps to also capture the temporal
aspect of the environment, Khronos [4] performs spatio-
temporal metric-semantic SLAM that jointly captures short-
term dynamics and long-term changes and can be queried
for the estimated scene state at any past timestamp. However,
its metric-semantic map does not preserve photorealistic
appearance, so visual evidence beyond that abstraction cannot
be re-examined. Other methods maintain a persistent object-
or point-level representation and revise it as the scene
changes [21], [22], whereas [5], [7] additionally retain tempo-
ral traces in the form of object trajectories and timestamped
descriptions, respectively. The former keep only the current
state and therefore cannot answer questions about earlier
configurations, while all of them precommit to the objects
and attributes instantiated at construction time and discard
the underlying visual details.
B. 3DGS-based Maps
3D Gaussian Splatting (3DGS) [8] is an explicit rep-
resentation for 3D scene reconstruction that enables pho-
torealistic rendering while preserving fine-grained visual
details. Because it stores explicit primitives, 3DGS also
supports cheap local updates, unlike implicit representations
such as NeRF [23]. Recent extensions [24] further enrich
the Gaussian primitives with high-dimensional semantic
attributes for semantic tasks. For long-term scene updates,
O-SCD [9] localizes changes by directly comparing new
observations against views rendered from the previous map,
and others [10], [25] further show the gain in time and storage
from updating only the changed area. A third line of work
uses 3DGS as the map representation for embodied reasoning.
SplatReasoner [12] synthesizes query-conditioned viewpoints
that reveal evidence missing from fixed-view memories, and
GSMem [11] renders informative viewpoints on demand for
exploration; both reason over a single static capture. GS-
LTS [13] instead keeps the map current across revisits, yet
stores only the latest state and discards the scene’s history.
GEMS renders query-conditioned views over a memory
spanning visits, so the agent can hold a viewpoint fixed
while varying the time.
C. Embodied Question Answering and Episodic Memory
Introduced by OpenEQA [26], Episodic Memory EQA
(EM-EQA) evaluates an agent’s capability to answer questions
based on past multimodal experiences. In this task, a key
requirement for the agent is to correctly retrieve historical
contexts during querying. ReMEmbR [27] retrieves by embed-
ding similarity over textual descriptions of video segments,
and so discards the visual and geometric evidence entirely;
DAAAM [7] retrieves by matching per-node descriptions,
GraphEQA [6] by traversing a semantic scene graph, and


STaR [28] by task-conditioned retrieval over saved keyframes,
textual descriptions, and object point clouds. In all cases the
information granularity is fixed when the memory is built.
3D-Mem [29] and Enter the Mind Palace [30] retain raw
images, are constrained to pre-recorded views, and segment
objects in advance, which makes queries about off-list objects
unanswerable. Our method runs object segmentation only
upon receiving a query, which makes it easy to adjust object
granularity without being fixed to predefined lists, utilizing
the photorealistic novel view synthesis capabilities of 3DGS.
Beyond memory representations, existing works also
diverge in their evaluation benchmarks. EM-EQA bench-
marks [26] predominantly assume single-session explorations
of static scenes, overlooking temporal evolution entirely. Other
temporal benchmarks, such as NaVQA [27], assess reasoning
over continuous navigation videos, focusing on when and
where an event was observed along a continuous trajectory
rather than how the environment altered between visits. While
recent efforts begin to investigate dynamic environments,
Situat3DChange [31] is confined to change understanding
between paired static 3D point scans, whereas Enter the Mind
Palace [30] focuses on multi-episode navigation in simulated
settings with limited scene scale and question diversity.
III. METHOD
The goal of this work is to construct a photorealistic
spatiotemporal memory of a semi-static scene observed over
multiple revisits. The memory supports spatial and temporal
reasoning and question answering over the scene’s history. As
illustrated in Fig. 2, GEMS consists of two main components.
First, the mapping component initializes a Gaussian splatting
map and incrementally maintains its history by detecting
and updating changes. This map represents a photorealistic
episodic memory capable of on-demand rendering of query-
related views and object segmentation across time and
space (Sec. III-A). Second, the agentic reasoning component
analyzes a query and iteratively gathers grounded evidence
from the memory using retrieval, rendering, and segmentation
tools (Sec. III-B). It then synthesizes the final answer from
the collected evidence.

Retrieval tools (Aretrieve) locate relevant views: sweep
gives a global scene overview from Ct; search retrieves
query-relevant keyframe poses by OWLv2 [35] similarity
to the cached features and renders one candidate per rele-
vant viewpoint cluster; covisible prunes candidates by
volumetric covisibility with a target frame; and recall
re-renders the cited visual evidence in the report.
Reasoning tools (Areason) inspect a located region in detail:
time_view renders one camera pose across selected revisits
for viewpoint-aligned comparison; relook refines a pose
to clarify an ambiguous region; locate segments a queried
entity with SAM3 [37] and lifts its mask to metric 3D;
obj_view renders further views of a localized entity;
compare compares two localized instances; and track
associates instances across revisits.
To structure decision-making and prevent early termination,
the agentic pipeline is designed as a finite-state machine,
in which each state restricts which tools are available
(Fig. 3). The agent starts in Sinit with global retrieval (sweep,
search), then alternates between detailed reasoning (Sreason)
and retrieval (Sretrieve); one pass through both is a retrieval-
reasoning round. conclude ends a round and purges raw
visual context from the context history to limit the number of
tokens used and speed up the process; exit ends the search;
and report compiles the evidence report.
The report, together with all cited visual and 3D evidence
E, is passed to the answer synthesizer α, which returns the
answer A = α(q, E), a rationale, and a confidence score.

V. EXPERIMENTS
A. Reconstruction Quality
We assess whether GEMS preserves rendering quality while
updating the map incrementally, holding out every 10th input
image as the test set, following the same evaluation protocol as
GaME [10]. We compare against two dedicated scene-update
methods: GaME [10], which uses depth to prune obsolete
Gaussians and initialize primitives for newly introduced
objects, and O-SCD [9], which updates the map from RGB-
only change detection and therefore neither consumes nor
predicts depth. We evaluate on two real-world benchmarks
with one temporal update per scene: GaME-Aria [10], with
two indoor scenes and dense posed RGB-D sequences, and
CL-Splats Real-World [25], with five scenes, sparser views,
and no ground-truth depth. Since GEMS and GaME both
require depth, we synthesize depth for CL-Splats using Depth
Anything 3 [41]. We report PSNR, SSIM [44], and LPIPS [45]
for photometric quality, depth L1 error for geometric accuracy,
and the wall-clock time of a single map update.

superior performance across all other spatial, color, and shape

C. Spatiotemporal Question Answering
We evaluate GEMS on spatiotemporal question answering
using our GEMS-Bench benchmark. For each scene, we first
build the episodic memory M, then run the agentic pipeline to
explore it and answer every question in that scene. Following
OpenEQA [26], we score each predicted answer with an


LLM matcher on a scale from 1 to 5, where 1 is completely
wrong and 5 is a perfect answer, and report the mean score
rescaled to [0, 1]. We use GPT-5.6-Luna as the judge.
We compare against a range of memory representations.
DAAAM [7] and Enter the Mind Palace [30] build 3D scene
graphs, ReMEmbR [27] stores textual descriptions alone, and
STaR [28] combines saved keyframes with textual descriptions
and object point clouds. We additionally compare to GEMS-
all-images, a variant that retains all posed RGB-D frames
across revisits as its memory and runs the same agentic
pipeline, except that it cannot use the NVS tools; it acts as an
upper bound on the visual information available to the agent.
We also compare against a blind LLM, Qwen3.5 [34], where
the model is purely guessing at the answers to the questions; it
serves as a lower bound. For fairness, every method, including
GEMS, uses Qwen3.5 [34] as its underlying LLM. Tab. III
breaks the results down by query type. GEMS attains the
best overall score on both splits, 60.9% on the real-world and
71.0% on the synthetic split, against 44.8% and 35.5% for
the strongest baseline, STaR. On each question class, GEMS
outperforms all the other baselines with around 10%.
On the real-world split, GEMS slightly underperforms
GEMS-all-images, yet it achieves higher performance on the
synthetic split despite storing no images. The per-class break-
down and overall metrics reveal that while GEMS-all-images
exhibits consistent performance across both splits, GEMS
shows a noticeable performance gap. Specifically, GEMS
achieves nearly a 10% improvement on the synthetic split
for movement and presence, negative, and static questions,
while yielding nearly identical results on both splits for state
change and counting questions. On the real-world split, sensor
noise and pose estimation errors result in imperfect Gaussian
maps. Although the synthesized views remain high quality
when close to the training trajectories (Sec. V-A), our novel
view synthesis (NVS) tools often query views far from the
training poses, occasionally introducing visual artifacts. These
degraded images lower the performance of GEMS on the
real-world split. Conversely, perfect depth maps and poses in
the synthetic split eliminate these artifacts, yielding significant
gains. Overall, the performance benefits provided by NVS
tools outweigh their potential drawbacks. A detailed isolation
study on the impact of NVS is presented in (Sec. V-E).
D. Storage Efficiency
Finally, we compare the growth of GEMS’s episodic
memory against two alternatives that retain images directly:
all posed RGB-D frames, and the posed keyframes only.
Fig. 5 reports all of them on one synthetic and one real-world
scene of GEMS-Bench. Since GEMS re-optimizes and stores
Gaussian primitives only where a change is detected, its
memory grows in proportion to the change observed at each
revisit rather than paying a fixed cost per visit. After four
revisits of the real-world scene, GEMS occupies 1.95 GiB
at single precision and 0.98 GiB at half precision, compared
with 2.73 GiB for the keyframes alone and 3.94 GiB for
the full-frame sequence. The absolute gap widens with each
revisit, so GEMS is more efficient whenever changes are
localized, the common case in semi-static environments.

E. Ablation Studies
To assess the contribution of NVS, we select the 245
questions for which the full agent invoked time_view or
relook, and rerun the complete pipeline on them with
both tools disabled, using the same Gaussian memory and
inference budget. Restricting to these questions separates
the agent’s decision to invoke the tools from the tools’ own
contribution. Access to the two tools improves the mean QA
score by 6.6 percentage points, with gains across all five
categories (Tab. III). This is the benefit of NVS, where the
agent elects to use it, not across the whole benchmark. Fig. 4
illustrates how viewpoint-aligned rendering supports temporal
comparison: restricted to recorded viewpoints, the agent may
fail to re-identify an object across perspective changes (right)
or mistake a viewpoint difference for a physical state change
(middle). Because both tools are removed jointly, the ablation
does not separate spatial view refinement from temporal
alignment.
VI. CONCLUSION
We presented GEMS, a persistent spatiotemporal memory
built on 3D Gaussian Splatting that stores environmental
change as compact temporal deltas and answers episodic-
memory questions by rendering novel views across space and
time. By updating and storing only the Gaussians in changed
areas, GEMS achieves superior storage efficiency and is
still able to re-render the required images on demand from
arbitrary camera poses at any time. Experiments on our long-
term spatiotemporal benchmark show that combining spatial
viewpoint selection with cross-temporal rendering improves
question-answering accuracy and consistently outperforms
established baselines.
