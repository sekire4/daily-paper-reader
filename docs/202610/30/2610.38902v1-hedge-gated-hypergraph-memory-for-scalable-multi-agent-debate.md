## 摘要
多智能体辩论系统需要智能体在多轮中保留并重新审视论点，但有限的上下文窗口和非结构化记忆使相关信息越来越难以恢复。现有的扁平记忆和成对图记忆也难以捕捉高阶关系，包括多智能体间的一致意见、冲突证据以及演化中的共识。我们提出 HEDGE，一种选择性记忆框架，将辩论轨迹表示为语义超图。超边连接跨智能体的相关主张，而超边内部的关系图保留细粒度的论证结构。一个学习到的记忆选择模块（MSM）通过监督学习和强化学习训练，将每个记忆候选路由到 STORE、BACKUP 或 OMIT，在保留有用信息的同时限制冗余。在七个多样化基准上，HEDGE 始终优于强大的单智能体、多智能体和记忆基线，在 GPT-4o-mini 的最强多智能体系统上平均提升 5.0 个百分点的准确率。在冲突密集任务上，增益达到 8.2 个百分点，同时 HEDGE 将记忆使用量降低 48%，并将辩论轮数减少 34%。

## Abstract
Multi-agent debate systems require agents to retain and revisit arguments across multiple rounds, yet limited context windows and unstructured memories make relevant information increasingly difficult to recover. Existing flat and pairwise-graph memories also struggle to capture higher-order relations, including multi-agent agreement, conflicting evidence, and evolving consensus. We introduce HEDGE, a selective memory framework that represents debate trajectories as semantic hypergraphs. Hyperedges connect related claims across agents, while intra-hyperedge relational graphs preserve fine-grained argumentative structure. A learned memory selection module (MSM), trained through supervised learning and reinforcement learning, routes each memory candidate to STORE, BACKUP, or OMIT, retaining useful information while limiting redundancy. Across seven diverse benchmarks, HEDGE consistently outperforms strong single-agent, multi-agent, and memory baselines, improving accuracy by 5.0 points on average over the strongest multi-agent system with GPT-4o-mini. The gains reach 8.2 points on conflict-heavy tasks, while HEDGE reduces memory usage by 48% and the number of debate rounds by 34%.

## 2. 方法论

### 2.1 核心思想
- **两级记忆结构**：
  - 顶层为**语义超图** \(H^{(t)}=(V^{(t)},E^{(t)})\)：节点是原子辩论元素（主张、反主张、证据、中间结论），超边是语义相关节点簇，一个节点可属于多个超边，以支持重叠话题与共享结论。
  - 超边内部为**有向类型关系图** \(G_k^{(t)}\)，保留细粒度论证结构。
- **五类关系**：SUPPORTS、REFUTES、EVIDENCE-FOR、DEPENDS-ON、LEADS-TO；由 GPT-4o-mini 对节点对进行关系预测。
- **三个路由动作**：STORE（长期保留）、BACKUP（暂存待复议）、OMIT（丢弃）。

### 2.2 记忆构建与在线维护
- **节点表示**：每个节点计算 ℓ2 归一化稠密嵌入 \(h_v\) 与稀疏语义签名 \(\sigma_v\)（实体、名词短语、数值、内容词元）。
- **超边表示**：维护未归一化嵌入和 \(s_k\)、归一化质心 \(c_k\)、签名并集 \(\sigma_k\)，支持增量更新与合并而无需全量重算。
- **节点归属**：同时用签名 Jaccard 相似度与嵌入余弦相似度判定兼容超边：
  - 若 \(J_{vk}\ge\tau_{sig}=0.30\) 且 \(S_{vk}\ge\tau_{emb}=0.70\)，节点加入所有兼容超边；否则新建超边。
- **每轮结束的维护流程**：
  1. 重新评估 BACKUP 节点，将晋升者与新 STORE 节点插入兼容超边；
  2. 合并冗余超边（\(\tau^{merge}_{sig}=0.50\)、\(\tau^{merge}_{emb}=0.85\)），合并时用未归一化嵌入和相加并做交集重叠校正，避免共享节点重复计数；
  3. 效用剪枝：超边连续 3 轮效用低于 0.10 则删除，其节点尝试重分配到存活超边；
  4. 增量关系更新：仅对新增/移动节点调用关系抽取，缓存未变关系与嵌入。

### 2.3 两级检索
- **超边级**：按签名兼容性与质心余弦相似度选 top-\(K\) 超边（默认 \(K=3\)）。
- **节点级**：在每个超边内按嵌入相似度选 top-\(M\) 节点（默认 \(M=8\)）。
- **返回**：各超边内检索节点诱导出的子图 \(G_k[V_q]\)，组合为有界记忆读出，包含主张、证据、反驳与依赖关系。

### 2.4 记忆选择模块（MSM）
- **输入**：候选节点由 GPT-4o-mini 从智能体回复中抽取为原子事实；候选 token 表示 \(X_t\)，池化表示 \(x_t\)。
- **效用特征**：
  - 候选—超边对齐 \(u_{t,k}=\cos(x_t,c_k)\)；
  - 最强对齐 \(U_t=\max_k u_{t,k}\)；
  - 特异性 \(N_t=U_t-\frac{1}{|E|}\sum_k u_{t,k}\)，衡量该候选相对其他超边的区分度。
- **记忆上下文**：将超边质心堆叠为 \(C_t\)，与候选一起投影后进行多头交叉注意力 \(Z_t=\text{MultiHeadAttn}(\tilde X_t,\tilde C_t,\tilde C_t)\)，再池化得 \(x^{pool}_t\)、\(c^{pool}_t\)。
- **路由表示**：\(\phi_t=[\phi^{UN}_t;x^{pool}_t;c^{pool}_t]\)。
- **分类器**：三层 MLP + softmax，输出 STORE / BACKUP / OMIT 的概率分布。

### 2.5 两阶段训练
- **Stage I 监督预训练**：
  - 在 HotpotQA FullWiki 训练集上模拟多智能体辩论，由 GPT-4o 生成 3–6 个智能体的角色配置；
  - 事后根据“是否被后续复用、是否参与冲突解决、是否贡献最终答案、是否冗余”生成约 6.5K 条伪标签；
  - 损失为交叉熵 + 类平衡正则，防止模型坍缩到单一动作。
- **Stage II 强化学习**：
  - 用额外 1K HotpotQA 问题在线模拟辩论，以 PPO 优化，约 10K episodes；
  - 轨迹奖励 \(R=\lambda_{task}R_{task}+\lambda_{route}R_{route}+\lambda_{eff}R_{eff}\)，其中 \(\lambda_{task}=1.0\)、\(\lambda_{route}=0.5\)、\(\lambda_{eff}=0.3\)；
  - 路由奖励鼓励“被存/被备份后确实被使用”，惩罚“被丢弃但后来有用”；
  - 效率奖励惩罚存储数量、平均记忆规模与最终记忆规模；
  - PPO 的裁剪与价值估计用于处理延迟信用分配，熵正则防止过早收敛。
