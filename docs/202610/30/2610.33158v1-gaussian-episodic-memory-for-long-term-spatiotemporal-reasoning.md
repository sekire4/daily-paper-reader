## 摘要
真实世界环境会经历持续的半静态变化，因此需要一种能够同时捕捉场景空间与时间演化的记忆表示。现有的机器人时空记忆通常依赖结构化表示，而这类表示受限于构建过程中所捕获的实体与属性；或者依赖基于图像的记忆，而这类记忆受限于先前观测到的视角。我们提出 GEMS，一个将持久化时空 3D 高斯泼溅（3DGS）地图与智能体推理流程相结合的框架。该 3DGS 地图仅重建一次，随后只在场景发生变化的区域进行更新，仅存储这些修改，同时跨时间保留视觉细节。智能体流程利用该地图按需渲染新视角，迭代积累证据以回答时空问题，并根据自然语言查询对物体进行定位。为推动未来研究，我们推出 GEMS-Bench，一个聚焦半静态环境的时空问答基准。它包含 3 个真实世界环境和 12 个合成环境，涵盖 473 个问答对。我们在场景更新后的新视角合成质量、3D 物体定位、时空问答和存储效率方面评估 GEMS。GEMS 在 3D 物体定位和时空问答上优于近期基线，同时达到与专用场景更新方法相当的渲染质量。代码与数据：https://abwerby.github.io/GEMS/

## Abstract
Real-world environments undergo continual semi-static changes, requiring a memory representation that captures both the spatial and temporal evolution of a scene. Existing spatio-temporal memories for robots typically rely either on structured representations, which are limited to the entities and attributes captured during construction, or on image-based memories, which are constrained to previously observed viewpoints. We introduce GEMS, a framework that combines a persistent spatio-temporal 3D Gaussian Splatting (3DGS) map with an agentic reasoning pipeline. The 3DGS map is reconstructed once and subsequently updated only in regions where the scene changes, storing only these modifications while preserving visual detail across time. The agentic pipeline leverages this map to render novel views on demand, iteratively accumulating evidence to answer spatio-temporal questions and ground objects from natural-language queries. To advance future research, we introduce GEMS-Bench, a spatiotemporal question-answering benchmark focused on semi-static environments. It comprises 3 real-world and 12 synthetic environments, spanning 473 question-answer pairs. We evaluate GEMS on novel-view synthesis quality across scene updates, 3D object grounding, spatiotemporal question answering, and storage efficiency. GEMS outperforms recent baselines in 3D object grounding and spatiotemporal question answering, while achieving rendering quality on par with dedicated scene-update methods. Code and data: https://abwerby.github.io/GEMS/
