## 摘要
有效的智能体记忆系统应当适应用户历史与任务需求。人工标注的监督信号可以通过提供用于评估和改进记忆设计的反馈来指导这种适应。然而，针对新的用户历史往往难以获得合适的标签，且人工构建问答对及支撑证据成本高昂。我们提出 MemSteer，将无标注的用户历史转化为带有支撑证据的问答（QA）监督，用于记忆设计优化。MemSteer 构建基于证据的答案计划，明确相关记录中的事实如何共同支撑一个参考答案。该计划指导问题生成，而基于来源的审核与盲答案恢复则用于检查生成的标注。为研究该监督的效用，我们开发了 MemSteer-Opt，它将基于 QA 的设计评估与证据引导的失败诊断相结合，在不更新模型参数的情况下修正记忆存储、检索和上下文构建。在 ATM-Bench 和 RHELM 上的实验表明，该监督与官方 QA 引导的优化相比具有竞争力。相对于 Base-BM25，MemSteer-Opt 将 ATM-Bench Question Score 提升 13.4 分，并在无外部数据和有外部数据的情况下分别将 RHELM 准确率提升 4.1 分和 6.6 分。该监督也使 ATM-Bench 上的两个现有优化器受益，而新用户实验表明，可利用由目标历史生成的监督持续进行设计优化。

## Abstract
An effective agent memory system should adapt to a user's history and task requirements. Human-annotated supervision can guide this adaptation by providing feedback for evaluating and improving memory designs. Yet suitable labels are rarely available for new user histories, and manually constructing QA pairs and supporting evidence is costly. We introduce MemSteer, which turns unlabeled user histories into question-answer (QA) supervision with supporting evidence for memory-design optimization. MemSteer constructs an evidence-grounded answer plan that specifies how facts across related records jointly support a reference answer. The plan guides question generation, while source-grounded auditing and blind answer recovery check the resulting annotations. To study the utility of this supervision, we develop MemSteer-Opt, which combines QA-based design evaluation with evidence-guided failure diagnosis to revise memory store, retrieval, and context construction without updating model parameters. Experiments on ATM-Bench and RHELM show that this supervision is competitive with official-QA-guided optimization. Relative to Base-BM25, MemSteer-Opt improves ATM-Bench Question Score by 13.4 points and RHELM accuracy by 4.1 and 6.6 points without and with external data, respectively. The supervision also benefits two existing optimizers on ATM-Bench, while new-user experiments demonstrate continued design optimization using supervision generated from the target histories.

## 1. 核心问题与研究动机

- **背景**：长期辅助用户的智能体需要借助外部记忆系统存储、组织并检索跨对话、邮件、文档积累的用户历史。存储粒度、检索策略、上下文构建方式共同决定记忆的可用性。
- **核心矛盾**：不同用户在内容、模态、组织方式上差异巨大，"一种记忆设计难以适配所有用户"，因此需要针对具体用户历史做记忆设计优化。
- **现有做法的缺口**：
  - MemEvolve、ALMA、M⋆ 等依赖下游任务的成功/失败反馈来优化记忆设计；
  - 但个人记录与日常交互往往**不存在显式的成功信号**，难以评估记忆质量；
  - 人工标注 QA 对及支撑证据成本高昂，且**新用户历史通常没有可用标签**。
- **研究问题**：能否将**未标注的用户历史**转化为监督信号，用于记忆设计的评估与迭代优化？论文提出 MemSteer（生成 QA–证据监督）与 MemSteer-Opt（证据引导的记忆设计优化器）来回答该问题。

## 2. 方法论

### 2.1 核心思想
- 从用户历史 $H$ 自动构造带来源证据的监督集 $\mathcal{D}_H=\{(q_i,a_i,E_i)\}_{i=1}^N$：参考答案用于**评估**候选记忆设计，来源证据用于**诊断**失败回答并指导修订。
- 全流程**不更新模型参数**，只优化记忆系统的设计（存储、检索、上下文构建）。

### 2.2 监督构造流程（MemSteer）
- **图引导的素材准备**：将历史记录组织为图（共享对话、相邻文档章节、显式引用、足够词汇重叠建立边），从种子做路径扩展采样连通子图，形成受上下文预算约束的素材包 $B$，并保留源跨度引用。
- **证据锚定的答案计划 + 问题生成**：
  - LLM 规划器产出一个"答案计划"，明确：问什么（主语·属性·约束）、支撑事实及跨度引用、每条证据记录的贡献、组合事实所需操作、参考答案与选中证据；
  - 计划先经**程序化检查**（结构一致性、出处覆盖），不合格者直接拒绝；
  - 再由问题生成器基于计划与素材包生成独立问题。
- **来源锚定的双重验证**：
  - *语义审计*：LLM 评审对答案支撑性、问题–计划一致性、每条事实的来源支撑、每条证据贡献逐项给出结构化判断，全部通过才进入下一步；
  - *盲答案恢复*：仅给问题、答案类型与素材包记录，由盲读者作答并给出引用；要求"可回答 + 类型归一化后精确匹配参考答案 + 引用覆盖全部选中证据记录"。
- **数据划分**：生成样本划分为不相交的训练集（用于产生修订提案）与验证集（用于选择设计）。

### 2.3 MemSteer-Opt 优化流程
- **设计空间**：$d=(s,r,c)$ 分别对应存储/索引、检索、上下文构建；记忆构建与推理为
  $M_d=\text{Store}_s(H)$，$X_{d,i}=\text{Context}_c(\text{Retrieve}_r(q_i,M_d))$，$\hat a_{d,i}=\text{Answer}(q_i,X_{d,i})$。
- **评估**：在固定验证集上计算二值正确率 $A(d)=\frac{1}{N_{val}}\sum y_{d,i}$；回答模型、指令提示、上下文预算在各设计间保持固定。
- **证据引导诊断**：对训练集错误回答，用证据标注检查所需源记录与引用段落是否完整出现在最终上下文中：
  - 完整 → 判为**回答失败**；
  - 缺失且记录不可从记忆中恢复 → **存储失败**；
  - 缺失但记录可恢复 → **检索失败**。
- **失败分层采样**：按失败类别分别采样（每类最多 10 例），避免高频失败类型挤占提案者输入预算；每例附带问题、参考答案、证据、当前回答与诊断结果。
- **反馈引导修订与接受**：LLM 提案者给出修订设计 $d'$ 及理由，重建记忆并在验证集评估，仅当 $A(d')>A(d_t)$ 才替换；接受后重跑训练集刷新诊断，共进行 **20 轮**反思进化。
- **可插拔性**：生成的 QA（及证据）也可直接供 M⋆、MemEvolve 等现有优化器在其自身设计空间内使用。

## 6. 主要结论与发现

- **生成监督确实能优化记忆设计**：相对 Base-BM25，MemSteer-Opt 在 ATM-Bench 上 QS 54.9→68.3（+13.4）、R@10 61.7→84.1（+22.4）、Hard QS 8.2→29.1（+20.9）；RHELM 准确率无/有外部数据分别 +4.1 / +6.6。
- **与人工标注监督具竞争力**：ATM-Bench 四项指标均略高于 Official-QA（主集 +1.1、Hard +1.3）；RHELM 分别低 0.1 与 0.8 个百分点。
- **可迁移到现有优化器**：M⋆ 主集 QS +6.0、MemEvolve +18.6（与 Official-QA 的 +4.4/+18.6 相当），但收益不均匀（MemEvolve 在 Hard 上增益更小，R@10 反降 0.1）。
- **优化后系统具竞争力**：ATM-Bench 上为非 oracle 系统最高 QS；RHELM 有外部数据达 39.9，显著高于最强基线 33.9，无外部数据时与 RAG(k=50) 的 28.9 相当。
- **跨基准迁移有效
