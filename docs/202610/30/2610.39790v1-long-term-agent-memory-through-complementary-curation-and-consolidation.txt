## Long-Term Agent Memory through Complementary Curation and Consolidation 

Abhishek Gupta Dongge Han Daniel Madrigal Diaz Wei-Ning Chen Mayukh Das Victor Rühle Saravan Rajmohan 

Microsoft 

Abstract 

Long-horizon dialogue agents require effective memory systems to recall facts, events, and re-lationships from interaction histories. In this work, we propose a hybrid-memory architec-ture comprising episodic memories and struc-tured relational memories and a consolidation mechanism which improves efficiency. We conduct an empirical study across two bench-marks: LoCoMo and LongMemEval-S. Our experiments demonstrate that the two memory types are consistently complementary, combin-ing both outperforms state-of-the-art memory frameworks and achieves 90.2% accuracy on LoCoMo and 85.5% on LongMemEval-S. 

1 Introduction 

Recent advances in large language models (LLMs) have enabled agentic capability of sustaining multi-turn interactions (Wang et al., 2024; Hu et al., 2025). However, their ability to recall, integrate, and reason over long interaction histories remains fundamentally limited. These limitations have motivated the development of long-term memory systems that explicitly store and retrieve learning from past interactions (Zhang et al., 2025). By enabling selective access to historical experience, these mechanisms mitigate the need for massive context windows, fostering more coherent and effi-cient agent behavior. Prior work on agentic memories can be primar-ily categorized into two types. Parametric mem-ory (Wei et al., 2025; Wang et al., 2025; Li et al., 2025) embeds knowledge directly into model pa-rameters through training, enabling low-latency in-ference; however, encoding is computationally ex-pensive, frequent updates are infeasible, and uncon-strained modifications may induce hallucination. In contrast, non-parametric memory (Chhikara et al., 2025; Rasmussen et al., 2025; Nan et al., 2025) leverages external memory systems that store and retrieve information on demand, offering scalabil-ity and adaptability without training, though at the expense of additional retrieval latency. In this work, we focus on the latter approach, and propose a hybrid memory system of episodic memory which stores distinct events from the inter-actions, preserving the temporal ordering and con-textual richness, and structured relational mem-ory which extracts entity specific tuples from dia-logues, making implicit connections between peo-ple, places, and facts explicit and enabling rela-tional inference across sessions. These two repre-sentations reflect fundamentally different assump-tions about what makes memory useful: episodic memory preserves narrative context and sequence ,while structured relational memory prioritizes com-pact, queryable relational structure . Furthermore, we introduce an offline memory consolidation mechanism that selectively merges related or re-dundant memories and removes conflicting or out-dated entries, enabling scalable and efficient long-term memory management. We evaluate our system on two long-horizon dialogue benchmarks, LoCoMo (Maharana et al., 2024) and LongMemEval-S (Wu et al., 2025). Our empirical results demonstrate that episodic and structured relational memory together deliver strong empirical performance, with our hybrid sys-tem outperforming state-of-the-art baseline meth-ods on both benchmarks. Our memory consolida-tion method further shows effective compression of the memory store by 16.34% without much loss in performance. Moreover, on the LoCoMo bench-mark, the consolidated system improves accuracy on both single-hop and multi-hop QA tasks.

3 Method 

Hybrid memory operates in three phases: an offline 

curation phase that processes each conversation session, an offline consolidation phase, and a fi-nal retrieval-and-generation phase that responds to user queries. Figure 1 presents an overview of our proposed memory system. 

3.1 Memory Curation 

Both memory stores are populated at session gran-ularity: after each conversation session concludes, we run curation over its transcript. 

Episodic Memory. For each session, we cre-ate holistic episodic memories using an LLM. As shown in Figure 1, each entry contains three fields: a short title identifying the episode, a one-sentence 

summary distilling its key point, and a details 

paragraph preserving the narrative context, includ-ing the event and any relevant background. Each episodic record is additionally annotated with the session timestamp. The prompt for episodic mem-ory curation is shown in Appendix A. 

Structured Relational Memory. We observe that conversations naturally express persistent facts about entities and their relationships, including who someone is, what they do, who they are con-nected to. These relationships are better repre-sented as structured relational tuples. To this end, we prompt an LLM to extract entity-relation tu-ples from the dialogues. Each tuple is stored as 

(e, r, o, t, c ). As shown in Figure 1, e is the en-tity , r the relation label , o the object , t the times-tamp , and c the source context which captures the richer context from which the tuple was extracted. The contextual description c provides provenance: it records not just what the tuple asserts but in what context it was mentioned, which is important for preserving nuance that structured extraction inevitably loses, such as the speaker’s intent, the circumstances under which a fact was stated, and additional details. The timestamp t additionally grounds each triplet temporally, addressing a com-mon failure mode of relation-based memory where relational facts are stored without any record of when they were true. The prompt for relational memory curation is shown in Appendix B. 

3.2 Memory Consolidation 

As interactions accumulate, the memory store grows monotonically, increasing storage costs, re-trieval overhead, and introduction of noise. To ad-dress this, we introduce a periodic clustering-based consolidation mechanism that groups semantically similar memories using HDBSCAN (Campello et al., 2013), enabling the merging of evolving concepts, resolution of conflicting information, and de-duplication of redundant entries across ses-sions. 3.3 Memory Retrieval & Question Answering 

At query time, we perform independent top-k se-mantic similarity searches over the episodic mem-ory and structured relational memory stores sepa-rately. For episodic memory, each episode’s details 

field is indexed, yielding one vector per episode. For structured relational memory, each tuple is indexed as a natural-language string concatenat-ing its components (e.g., “Subject, Relation, Ob-ject” ), yielding one vector per triplet. The two stores are searched independently, returning the top-k episodes from episodic memory and the top-

2k tuples from structured relational memory. The episodic memories are more verbose than relational tuples, so within the same budget approximately twice as many relational entries can be retrieved. We set k = 10 since performance plateaus beyond this value (see the budget analysis in Section 5.2).

Single-Hop , Multi-Hop , Temporal , and Open-domain . On average, the conversations in Lo-CoMo span multiple sessions with 24K tokens; and LONG MEM EVAL -S (Wu et al., 2025), a substan-tially more challenging evaluation setting, compris-ing 500 meticulously curated questions embedded within synthetic but realistic chat histories that av-erage 115K tokens per question.

4.2 Results Main Results. Table 1 shows the performance on the LoCoMo benchmark. Our system con-sistently outperforms all baselines when using 

gpt-4o-mini , achieving a score of 83 .5% . No-tably, this surpasses the FullContext baseline, em-pirically validating that the addition of long con-text can lead to performance degradation. With 

gpt-4.1-mini , our approach reaches 90 .2% , a significant 6.7% absolute improvement over the 

gpt-4o-mini results. While this score is slightly below the FullContext performance of 91 .3% ,our system remains highly competitive while utiliz-ing 87% fewer tokens. The most significant gains are observed in Multi-Hop and Temporal reasoning tasks, which directly reflect the strengths of our dual-memory setup. Episodic memory preserves interactions as a times-tamped timeline, allowing the model to track the order of events for temporal questions. Meanwhile, structured relational memories capture complex entity-relation dependencies, facilitating effective multi-hop inference over distinct facts. Appendix D provides an ablation study on the contribution of each component. The results demonstrate that the most substantial improvements (+6.3 points in Multi-Hop and +6.8 points in Temporal reason-ing on gpt-4o-mini ) emerge due to interaction between the two memory types. Table 2 presents the results for the LongMemEval-S benchmark. Our method attains an overall score of 85 .5% , consistently surpassing both the F ULL CONTEXT baseline and NEMORI across nearly all evaluation categories. 

Efficiency. In Table 3, we compare our system against the baselines in terms of the average num-ber of tokens consumed per question. Our approach uses comparable tokens to N EMORI , while achiev-ing a 9.1 point improvement in accuracy. Performance is largely stable for mcs ∈ [5 , 20] ,with LLM Score ranging from 0.892–0.898, all within 1 point of the no-consolidation baseline (0.902). At mcs = 2, performance drops by 2.6 points, which we attribute to over-aggressive consolidation where small groups of similar em-beddings are prematurely merged. As mcs in-creases, memory compression decreases mono-tonically from 30.9% to 9.6%, while the number of clusters (and corresponding LLM consolida-tion calls) is reduced by up to 15 ×. This high-lights a favorable trade-off: moderate cluster sizes (mcs ∈ [5 , 10] ) achieve meaningful compression (16–22%) with negligible accuracy loss. 

6 Conclusion 

We presented a Hybrid memory system for agents that curates and retrieves both episodic mem-ory and structured relational memory, and con-ducted an empirical study across LoCoMo and LongMemEval-S. Our results demonstrate strong performance combining both memory types, and improved efficiency with memory consolidation without much loss in performance. 

7 Limitations 

While our proposed memory system demonstrates strong performance, several areas remain for fur-ther refinement. First, our current evaluation fo-cuses exclusively on textual conversational data. Although the system is modality agnostic, extend-ing it to support non-textual modalities such as vision and audio remains an important direction for future work. Second, our experiments reveal that memory curation quality can vary substantially across different backbone LLMs, as observed shift-ing from gpt-4.1-mini to gpt-4o-mini resulted in a 6.7 percentage point drop. This sensitivity reflects a broader challenge faced by existing agen-tic memory systems, where memory curation and consolidation are inherently influenced by model-specific reasoning and representation biases. De-veloping memory mechanisms that are robust and consistent across diverse model families remains an open and important research problem.

The consolidation pipeline follows a two-phase architecture inspired by BERTopic (Grootendorst, 2022). In the first phase, all stored memories with their pre-computed 1536-dimensional embeddings produced by OpenAI’s text-embedding-3-small model are projected into a lower-dimensional space using UMAP (McInnes et al., 2018) with cosine dis-tance, 10 neighbors, 5 target components, and mini-mum distance of zero. The reduced representations are then clustered using HDBSCAN (Campello et al., 2013) with Euclidean distance, Excess of Mass cluster selection, minimum cluster size of 10, and minimum samples of 1.

E Extended Comparison with Prior Work 

Prior memory systems differ from ours along three axes: representation , curation strategy , and opera-tional cost . We summarize the key contrasts below. 

Representation. Zep (Rasmussen et al., 2025) maintains a temporal knowledge graph with entity nodes, fact edges, and validity intervals, enabling graph traversal at the cost of entity resolution, edge deduplication, and conflict detection. A-Mem (Xu et al., 2026) organizes memories as Zettelkasten-style notes with evolving links between entries, while H-Mem (Sun and Zeng, 2025) relies on hier-archical indexing for routing. In contrast, we use two complementary flat stores: episodic records that preserve narrative context and relational tuples retrieved by semantic similarity. This sacrifices native graph traversal but avoids the overhead of graph construction and hierarchy maintenance. 

Curation strategy. Mem0 (Chhikara et al., 2025) processes each turn individually with add/update/delete/no-op operations, which frag-ments inter-turn context. Nemori (Nan et al., 2025) adaptively distills semantic knowledge based on prediction error against an anticipatory schema, fo-cusing on what to store. Our method instead targets 

how memory should be represented: we perform a single session-level curation pass that produces episodic and relational entries, and we apply offline clustering-based consolidation to merge redundant memories and remove outdated ones. 

Operational cost. Turnwise systems such as Mem0 and A-Mem scale LLM calls linearly with conversation length, and dynamic retrieval schemes incur additional LLM rounds at query time. Our session-level curation amortizes extraction across many turns, and a fixed top-k retrieval avoids extra LLM calls. Consolidation runs offline and can be triggered infrequently (e.g., every 10-20 sessions), keeping long-horizon operation tractable while pre-serving QA accuracy.
