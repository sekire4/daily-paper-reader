## 摘要
大语言模型（LLM）智能体日益依赖持久记忆来支持长期推理和个性化交互。然而，当不可信声明（即原子陈述）随后被视为已授权的偏好、策略或权限时，从外部来源收集的信息可能引入安全风险。现有防御通常依赖基于内容的过滤或粗粒度来源追踪，这些方法要么无法阻止未经授权的记忆使用，要么会阻断合法信息，从而牺牲记忆效用。为解决这些局限，我们提出 SAFE-Mem，一个细粒度记忆治理框架，可在保留合法记忆使用的同时提升安全性。首先，SAFE-Mem 为每个声明标注三个治理标签（即类型、权限和范围），以刻画其来源和允许用途。其次，治理感知检索将查询需求与声明权限进行匹配，以阻止未经授权的影响，同时保留合法信息。第三，支持治理的记忆图连接源句子、声明和实体，以支持来源追踪和高效检索。在 MPBench 和 LoCoMo 上的四个 LLM 骨干模型上，SAFE-Mem 在保留合法记忆的防御方法中取得最低攻击成功率，至少比其中最强方法低 77%，并在所有评估的防御方法中取得最高回答准确率，最高提升 15 个百分点。代码见 https://github.com/LVenum/SAFE-Mem。

## Abstract
Large language model (LLM) agents increasingly rely on persistent memory to support long-term reasoning and personalized interactions. However, information collected from external sources can introduce security risks when untrusted claims (i.e., atomic statements) are later treated as authorized preferences, policies, or permissions. Existing defenses typically rely on content-based filtering or coarse-grained provenance tracking, which either fail to prevent unauthorized memory use or block legitimate information, sacrificing memory utility. To address these limitations, we propose SAFE-Mem, a fine-grained memory governance framework that improves security while preserving legitimate memory use. First, SAFE-Mem annotates each claim with three governance labels (i.e., kind, authority, and scope) to capture its provenance and permitted use. Second, governance-aware retrieval matches query requirements with claim permissions to block unauthorized influence while retaining legitimate information. Third, a governance-enabled memory graph connects source sentences, claims, and entities to support provenance tracking and efficient retrieval. Across four LLM backbones on MPBench and LoCoMo, SAFE-Mem attains the lowest attack success among defenses that retain legitimate memory, at least 77% below the strongest of them, and the highest answer accuracy of all evaluated defenses, improving it by up to 15 points. The code is available at https://github.com/LVenum/SAFE-Mem.
