## 摘要
在以人为中心的环境中，具身智能体需要一种记忆，能够将其观察到的内容与人类随时间告知它们的信息整合起来。然而，现有具身记忆主要基于视觉经验构建，人与人类对话如何与这一经验中遇到的对象相接地仍未明确。我们提出 DialogMem，一个两阶段基准：智能体从时间对齐的带位姿 RGB-D 观测流与对话流中构建记忆，随后将其用于实例级物体导航和问答（QA）。DialogMem 包含 27 个真实世界三维场景中的 142 个回合，以及 14,193 个问答对和 11,890 条导航指令。我们在一个统一框架内评估了九种记忆表示，该框架涵盖记忆形成、证据检索和面向任务输出的推理。实验表明，在评估时将对话附加到视觉记忆可显著提升 QA，但对导航的增益可忽略不计，这表明相关对话虽存在于记忆中，却未与具体对象相接地。受控诊断显示，导航性能随链接质量提升而改善，但即使在完美链接下仍低于真值对象级记忆。检索正确的对象条目并恢复其空间位置仍是进一步的瓶颈。这些结果识别出基于对话的具身记忆的三个瓶颈：在记忆形成阶段将对话接地并组织到对象级条目上、检索正确的条目，以及准确定位该条目。

## Abstract
Embodied agents in human-centered environments require memory that integrates what they observe with what humans tell them over time. However, existing embodied memories are built primarily from visual experience, leaving open how dialogue with humans can be grounded in the objects encountered throughout that experience. We introduce DialogMem, a two-phase benchmark in which agents build memory from time-aligned streams of posed RGB-D observations and dialogue, and later use it for instance-level object navigation and question answering (QA). DialogMem provides 142 episodes across 27 real-world 3D scenes, with 14,193 QA pairs and 11,890 navigation instructions. We evaluate nine memory representations within a unified framework of memory formation, evidence retrieval, and reasoning for task outputs. In experiments, appending dialogue to visual memory at evaluation time substantially improves QA but yields negligible navigation gains, suggesting that relevant dialogue is present in memory but not grounded to specific objects. Controlled diagnostics show that navigation improves with link quality but falls short of ground-truth object-level memory even under perfect linking. Retrieving the correct object entry and recovering its spatial location remain further bottlenecks. These results identify three bottlenecks for dialogue-grounded embodied memory: grounding and organizing dialogue at object-level entries during formation, retrieving the correct entry, and localizing it accurately.

## 一、核心问题与整体含义

- **研究动机**：在以人为中心的环境中，具身智能体不仅需要记住“看到了什么”，还需要记住“人曾经告诉过它什么”，并能把对话信息与三维场景中的具体物体关联起来。
- **核心问题**：现有具身记忆基准和系统主要从 RGB-D 观测与智能体位姿构建记忆，对话通常只作为任务时的上下文，而非持久记忆源。因此，**对话信息如何与视觉经验中遇到的物体相接地**仍缺乏系统评估。
- **整体含义**：论文提出 DialogMem，将对话视为与视觉经验并列的持久记忆来源，并通过“记忆形成—记忆使用”两阶段评测，检验智能体能否利用对话完成实例级物体导航和问答。该工作把具身记忆评估从感知记忆、情景记忆扩展到**社会记忆**，并指出对话接地、条目检索和三维定位三个关键瓶颈。

## 二、方法论

- **核心思想**：将具身记忆形式化为从时间对齐的多模态输入流中增量构建持久记忆，再在查询时检索证据并推理输出。
- **形式化流程**：
  - 每个时间步输入为 \(s_t=(I_t,p_t,D_t)\)，其中 \(I_t\) 为 RGB-D 帧，\(p_t\) 为智能体位姿，\(D_t\) 为时间对齐的对话。
  - 记忆通过更新函数增量构建：\(M_t=U(M_{t-1},s_t)\)。
  - 评测时给定查询 \(q\)，检索函数选出证据 \(z=R(M_T,q)\)，推理器输出 \(y=F(z,q)\)。
- **两阶段基准设计**：
  - **Phase 1：记忆形成**。智能体在三维环境中长时间遍历，接收带位姿 RGB-D 流和对话流，形成覆盖三类内容的记忆：
    - **感知内容**：物体外观、空间关系；
    - **情景内容**：轨迹中的观察顺序、观察频率、与导航目标的关联；
    - **社会内容**：对话提供的所有权、别名、用途、重要性，以及后续更新或纠正。
  - **Phase 2：记忆评估**。从 Phase 1 终点开始，执行两类任务：
    - **导航**：根据自然语言指令定位目标物体并预测其位置；
    - **问答**：先利用记忆识别目标物体，再回答关于该物体的问题。
- **数据构建关键细节**：
  - 基于 27 个 HM3D 验证集真实扫描场景，使用 GOAT-Bench 物体标注。
  - 用 GPT-4o 生成场景居民画像，保证对话说话人一致。
  - 对话生成采用两阶段：先构造结构化 turn specification，固定说话人、位置、回合类型、可见/引用物体及所表达的记忆内容；再由 LLM 转写为自然语言。
  - 信息选择策略：感知内容只出现在导航相关回合；社会内容出现在评论、回忆、到达后回合；**情景事实从不在对话中直接陈述**，必须从轨迹中恢复。
  - 导航指令和 QA 也由结构化规格生成，固定目标物体、识别证据和答案证据，避免自由生成导致不可验证。
  - 质量控制包括规则校验、LLM 接地审计和人工标注验证；最终人工抽检 450 项，按多数判断 98.4% 有效。

  - QA 与导航中约一半为组合多种记忆内容类型的项目。
- **Benchmark 任务**：
  - 实例级物体导航；
  - 基于记忆的问答；
  - 按目标识别所依赖的记忆内容分为感知、情景、社会、组合四类。
- **对比的九种记忆表示**：
  - **原始流存储**：Dialogue、Frames、Frames+Dialogue；
  - **结构化视觉记忆**：ConceptGraph、3D-Mem；
  - **结构化视觉记忆+评估时附加对话**：CG+Dialogue、3D-Mem+Dialogue；
  - **结构化视觉记忆+形成时链接对话**：基于 3D-Mem 的 CLIP linker 和 VLM linker。

- **指标**：

  - 导航主指标为 geodesic success，预测位置需在真值 1.0 m 测地距离内；
  - 另报告 execution success 和 SPL。
- **诊断实验**：
  - 控制对话—物体链接质量，从 0 到 100 扫描，并区分“缺失链接”和“错误链接”；
  - 设置 snapshot metadata、oracle selection、oracle position 等真值探针；
  - 比较不同推理器，包括 Qwen3-VL-4B、Qwen3-VL-8B 和 GPT-4o；
  - 按答案来源、指令内容类型、对话更新/纠正等维度分解结果。

## 六、主要结论与发现

- **对话与视觉记忆分别支持不同任务**：Dialogue 在 QA 上中等（56.5）但无法导航；Frames 可粗略定位但 QA 很弱；结构化视觉记忆导航更强但 QA 低于 Dialogue。
- **评估时附加对话显著提升 QA，但几乎不提升导航**：
  - 3D-Mem QA 从 35.1 提升到 63.4；
  - Frames QA 从 24.3 提升到 60.1；
  - 但 3D-Mem 导航仅从 31.0 到 31.1，统计不显著。
- **原因不是推理器读不懂对话**：附加对话使社会答案 QA 从 20.9 提升到 76.9，但社会导航指令仍仅约 32.1，说明对话虽在记忆中，却未接地到可定位的物体条目。
- **形成时简单链接也未可靠解决问题**：CLIP linker 和 VLM linker 未提升导航，QA 也低于直接附加对话；二者正确链接率分别仅 29.1% 和 9.5%。
- **链接质量提升可改善导航但不足**：完美链接下导航最高约 39.3，仍低于真值对象级记忆。
- **Oracle 诊断揭示瓶颈**：
  - 附加真值对象元数据后导航升至 44.1；
  - oracle 条目选择升至 56.6；
  - oracle 三维位置升至 96.2；
  - 表明检索正确条目和准确估计三维位置是主要剩余瓶颈。
- **更大推理器不会自动缩小差距**：Qwen3-VL-8B 和 GPT-4o 在子集上反而更保守，更多回答 unknown。
- **最终指出三大瓶颈**：记忆形成阶段的对话—物体接地与对象级组织、评测时正确条目检索、以及物体三维位置精确定位。

## 七、优点

- **问题定义清晰且新颖**：首次系统地将对话作为持久具身记忆源，并与视觉经验联合接地评估。
- **两阶段设计合理**：将记忆形成与记忆使用隔离，避免智能体依赖当前观测“现看现答”。
- **内容分类细致**：显式区分感知、情景、社会记忆，并覆盖组合引用，贴近真实人机交互。
- **标注与诊断可控**：结构化规格先于文本生成，保留物体级接地标注，支持链接质量扫描和 oracle 探针。
- **统一评测框架**：九种记忆表示共享推理器与接口，较好控制推理能力差异。
- **失败分析深入**：不仅报告性能，还分解出接地、检索、定位三个可操作的研究方向。
- **可复现性较好**：使用开源 VLM、公开场景与实现，并报告人工验证和评分相关性。

## 八、不足与局限

- **对话真实性有限**：对话由 LLM 基于结构化规格生成，虽便于精确标注，但缺乏自发人类对话中的歧义、噪声和动态变化。
- **仿真环境限制**：使用 HM3D 扫描场景和仿真评测，位姿无噪声；结论向真实机器人、感知误差和更广泛环境迁移仍需验证。
- **场景与规模有限**：27 个场景、142 个 episode，虽任务量较大，但场景多样性仍有限。
- **不提出新记忆架构**：论文主要是诊断现有表示，oracle 探针给出上界，但未设计能同时实现这些增益的新方法。
- **方法覆盖有限**：链接器为简单基线，分析主要基于 3D-Mem 和少量 VLM 推理器；对其他记忆架构、链接器和推理器的泛化性未知。
- **导航主指标为预测位置评分**：主实验不执行路径，虽另报 execution success 和 SPL，但仍不能完全反映规划与执行误差。
- **潜在偏差风险**：LLM 生成对话和任务可能引入语言风格、场景居民设定或标注偏差；人工验证样本为 450 项，不能完全排除长尾错误。
- **资源信息不完整**：仅说明单卡 A6000 推理，未给出总推理时长或完整算力预算。
