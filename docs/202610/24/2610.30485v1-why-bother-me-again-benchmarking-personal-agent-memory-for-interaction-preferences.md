## 摘要
个人智能系统正在承担日益复杂的日常任务，然而重复提问、不必要的确认以及不受欢迎的主动联系，可能使原本能力出色的助手变成交互负担。要减轻这种负担，智能体需要记住用户希望以何种方式获得协助。然而，现有记忆基准主要关注事实回忆和个性化回答，很少测试智能体如何学习交互偏好并据此行动。我们提出 MemPABench，一个用于对个人智能体记忆进行同策略评估的交互式环境。MemPABench 提出长时程任务，要求智能体决定何时澄清、确认或自主行动。四个基于现实情境的模拟用户在工作与个人情境中持有 14 项偏好。其反馈跨越四个月内的 99 次会话，每位用户有五次事件驱动的偏好变化，用于测试记忆更新。我们评估偏好选择、实际交付行为，以及对情境和偏好变化的敏感性。在四种 LLM 骨干模型上评估四种记忆系统后，我们发现当前记忆在偏好选择上的收益有限。基于检索的系统（即 Mem0、MemOS、简单 RAG）并未优于 No Memory，而基于文件的记忆提高了准确率，却会在相关情境之外应用偏好。我们的分析表明，当前记忆难以检索交互偏好并适应偏好变化。即使已有正确的偏好可用，覆盖智能体默认的交互习惯仍然具有挑战性。环境与数据集见 https://mempabench.com。

## Abstract
Personal intelligence systems are taking on increasingly complex everyday tasks, yet repeated questions, unnecessary confirmations, and unwanted outreach can turn capable assistance into interaction burden. Reducing this burden requires agents to remember how users want to be assisted. However, existing memory benchmarks focus on factual recall and personalized answers and rarely test how agents learn and act on interaction preferences. We introduce MemPABench, an interactive environment for on-policy evaluation of memory in personal agents. MemPABench poses long-horizon tasks requiring agents to decide when to clarify, confirm, or act autonomously. Four grounded simulated users hold 14 preferences across work and personal contexts. Their feedback spans 99 sessions over four months, with five event-driven changes per user testing memory updates. We evaluate preference selection, delivered behavior, and sensitivity to context and preference change. Evaluating four memory systems across four LLM backbones, we find that current memory brings limited gains in preference selection. Retrieval-based systems (i.e. Mem0, MemOS, simple RAG) do not outperform No Memory, while File-based memory improves accuracy but applies preferences beyond relevant contexts. Our analysis shows that current memory struggles to retrieve interaction preferences and adapt to preference changes. Even with the correct preference available, overriding the agent's default interaction habits remains challenging. The environment and dataset are available at https://mempabench.com.

## 1. 核心问题与研究动机

- **背景转向**：AI 助手正从一次性任务工具转向持久化个人智能体（Personal Agent, PA），跨消息、文件、日程和长期工作流代表用户行动。
- **核心矛盾**：任务成功与交互质量是两种不同结果。PA 可能正确完成任务，却反复提问、寻求不必要确认、过度解释或主动打扰，这些错配会累积为持续的“交互负担”。
- **交互偏好的定义**：支配 PA 如何沟通、提供多少解释、何时自主行动或主动联系、如何请求缺失信息的偏好。它与“内容偏好”（喜欢什么话题、选什么选项）不同，会在多次交互中反复出现，违反一次的代价会持续累积。
- **现有基准的缺口**：
  - 现有记忆/个性化基准多关注事实回忆与内容偏好（如 AMemGym、VitaBench 2.0、PERMA）。
  - PrefIx、BenchPreS 关注交互/沟通偏好，但缺少持久用户历史，评估模型的行为不塑造用户后续反应。
  - 没有基准同时具备：可执行任务环境、偏好条件化反应、同策略交互、情境隔离、受控偏好变化。
- **交互偏好的两个难点**：
  - **情境依赖**：同一用户在工作与个人情境下可能需要不同自主程度（如工作可自主，给家人发消息需确认）。
  - **时间变化**：偏好会因一次不良后果而改变（如消息被过早发出后，用户要求此后类似动作先确认）。
- **记忆机制的关键作用**：用户很少直接陈述交互偏好，而是通过纠正、容忍等反应分散暴露；即使记忆存储了证据，也可能在决策时检索不到，PA 于是回退到骨干模型的默认交互习惯（偏长、爱猜测、爱解释）。

## 2. 方法论

### 2.1 核心思想：偏好即状态（Preference-as-State）

- 将交互偏好形式化为由 **用户 u、情境 c、属性 a、时间 t** 索引的状态：
  - \(p^{(t)}_{u,c,a} \in P_a\)，其中 \(P_a\) 是属性 a 的离散设置集合。
  - 两个情境（work / personal）× 14 个属性 = 每位用户 28 个“情境–属性”单元。
- 世界与记忆的演化：
  - 用户消息 \(x_t \sim U_u(\cdot \mid W_t, y_{t-1}, S_t; p^{(t)}_u)\)
  - 世界状态 \(W_{t+1} = T(W_t, y_t)\)
  - 记忆状态 \(M_{t+1} = A(M_t, x_t, y_t)\)
- PA 决策流程：
  - 记忆访问 \(E_t = R(M_t, x_t)\)
  - 策略选择 \((\hat{p}^{(t)}_{u,c,a}, \tilde{y}_t) = \pi(x_t, E_t)\)
  - 交互执行 \(y_t = \Omega(\tilde{y}_t, \hat{p}^{(t)}_{u,c,a})\)
- **三阶段失败定位**：
  1. **Acquisition（获取）**：记忆系统能否把用户反应转化为偏好知识。
  2. **Selection（选择）**：能否在决策点恢复当前正确设置。
  3. **Realization（实现）**：交付的回复与动作是否真正遵循所选设置。
