## 摘要
自我改进智能体旨在部署后通过从经验中学习来持续改进其行为。然而，积累并复用更多经验并不必然带来更好的决策，尤其是当生成、交互和记忆资源同时受到约束时。在此类严格约束下，我们发现若干现有终身记忆方法相较于简单检索、甚至无记忆智能体所带来的收益有限。这揭示了资源高效自我改进的一个根本挑战：智能体不仅需要学习哪些过往经验是相关的，还需要学习哪些经验实际上值得复用以改进未来决策。当记忆容量以及推理和恢复机会有限时，检索无效经验可能消耗稀缺资源并阻碍下游执行。为应对这一挑战，我们提出 TokenWorth，一种轻量级、反馈驱动的记忆自适应框架，它从稀疏执行反馈中学习查询相关的记忆价值。TokenWorth 无需更新主干模型，而是利用学习到的价值来指导经验检索和有界记忆管理，使智能体能够持续调整其复用累积经验的方式。在三个 LifelongAgentBench 环境以及本地和基于 API 的部署中，在指定资源预算下，TokenWorth 在评估方法中取得了最高任务成功率，同时使用的输出 token 最少。这些结果表明，资源约束下的有效自我改进并不取决于积累更多经验，而取决于学习什么值得记住。我们的代码已公开于 https://github.com/AIGNLAI/TokenWorth。

## Abstract
Self-improving agents aim to continuously improve their behavior by learning from experience after deployment. However, accumulating and reusing more experience does not necessarily lead to better decisions, particularly when generation, interaction, and memory resources are jointly constrained. Under such stringent constraints, we find that several existing lifelong-memory methods provide limited benefits over simple retrieval or even no-memory agents. This reveals a fundamental challenge for resource-efficient self-improvement: agents must learn not only which past experiences are relevant, but which are actually worth reusing to improve future decisions. When memory capacity and opportunities for reasoning and recovery are limited, retrieving an ineffective experience can consume scarce resources and hinder downstream execution. To address this challenge, we propose TokenWorth, a lightweight feedback-driven memory adaptation framework that learns query-dependent memory worth from sparse execution feedback. Without updating the backbone model, TokenWorth uses the learned worth to guide both experience retrieval and bounded memory management, enabling the agent to continually adapt how it reuses accumulated experience. Across three LifelongAgentBench environments and both local and API-based deployments, TokenWorth achieves the highest task success rate while using the fewest output tokens among the evaluated methods under the specified resource budgets. These results suggest that effective self-improvement under resource constraints depends not on accumulating more experience, but on learning what is worth remembering. Our code is publicly available at https://github.com/AIGNLAI/TokenWorth.

# 论文结构化总结：Learning What to Remember

## 1. 核心问题与研究动机

- **背景**：自我改进型语言智能体希望在部署后通过积累和复用交互经验持续提升行为，无需更新主干参数。已有工作（Reflexion、ExpeL、Voyager、Mem0、MemRL、MemSkill 等）多聚焦于“如何积累与检索经验”。
- **核心问题**：当**生成、交互、记忆三类资源被联合严格约束**时，积累更多经验并不必然带来更好决策。作者形式化定义了“资源约束下的终身智能体”（Resource-Constrained Lifelong Agents），对每任务输出 token 总量、交互轮数、记忆库容量、检索条数与注入长度同时设限。
- **关键观察**：在此约束下，多种复杂终身记忆方法相对简单 RAG 甚至无记忆智能体收益有限，在 KG 等环境甚至显著劣于无记忆基线。这说明问题不只是“记忆容量不足”，而是**记忆策略选择**本身。
- **核心论点**：资源受限时，每次记忆决策都更关键；语义相关不等于下游有用，且无效经验一旦被检索会消耗稀缺预算且无法通过更多推理或交互挽回。因此真正挑战是——**学习哪些经验值得保留与复用**，而非单纯检索相关经验。

## 2. 方法论：TokenWorth

### 2.1 核心思想
- 冻结主干模型，仅通过一个轻量级“记忆控制器”在线学习**查询相关的记忆价值（memory worth）**，并用同一价值信号同时指导**即时检索**与**有界记忆库管理**。
- 不更新主干、不做任务回放、不做反事实重执行、不产生额外 LLM 调用。

### 2.2 记忆价值的分解建模
- **候选召回**：先用轻量文本相关性从记忆库中取 Top-$K_c$ 候选（$K_c=12$），与最终注入条数无关。
- **基础评分器（线性、可解释）**：
  - 特征 $\phi = [\phi_{sim}, \phi_{util}, \phi_{rel}, \phi_{recent}]$，分别刻画文本相似度、历史效用、可靠性与新近度。
  - $s_{base}(q,m)=w^\top \phi$，以信息先验 $w_0$ 初始化，并用带 $L_2$ 正则（向 $w_0$ 收缩）的 logistic 损失在线更新，配合周期重拟合、权重平滑与坐标裁剪，保证稀疏反馈下的稳定性。
- **残差 RFM 校正**：
  - 构造更丰富的查询–记忆表示 $z=[|e_q-e_i|,\ \cos(e_q,e_i),\ u,\ rel,\ rec,\ freq]$（确定性哈希文本向量，非学习嵌入）。
  - 最终得分 $s_t(q,m)=s_{base,t}(q,m)+\eta_t f_t(z)$，选取得分最高者执行。
  - 反馈标签 $y_t=2r_t-1$；残差目标 $\delta_t=y_t-\hat y^{base}_t$，仅对被选中的 query–memory 对获得监督。

### 2.3 双时间尺度自适应
- **快速残差适应**：对短 FIFO 反馈窗口做核岭回归（Laplacian 核 + 对角度量 $M_t$），系数 $\alpha=(K_{M_t}+\lambda I)^{-1}\delta$ 频繁更新。
- **慢速几何适应**：用 Average Gradient Outer Product（AGOP）估计特征重要性，$M_{t+1}=\text{NormClip}((1-\beta)M_t+\beta \tilde G_t)$，更新更保守；每次几何更新后重拟合 KRR。
- 三层互补：先验正则线性项（慢、全局）+ 快速 KRR（近期残差）+ 慢速 AGOP（特征几何），共同平衡稳定性与适应性。

### 2.4 价值引导的记忆生命周期
- 只有**外部验证成功**的交互才可成为新记忆候选。
- 用近期探针查询集 $P_t$（当前查询 + 至多 8 条历史查询）上的平均得分 $V_t(m)$ 估计记忆的“持久价值”。
- **准入**：库未满时按覆盖原则接纳；库满时需满足“足够新颖”或“探针均值超过现有最佳 + 正分比例达标”之一。
- **淘汰**：扩容后驱逐探针均值最低者；未过准入门的候选可在最近邻记忆效用低且价值提升足够大时直接替换。
- 统一思想：查询相关价值决定“现在用哪个”，探针平均价值决定“以后留哪个”。

## 3. 实验设计

- **主基准**：LifelongAgentBench 三个环境——数据库交互（DB）、操作系统任务（OS）、知识图谱推理（KG）。任务在线顺序处理，记忆库初始为空，每任务仅执行一次，只用前序经验。
- **部署设置**：
  - 本地：Qwen2.5-14B-Instruct（冻结），NVIDIA A800 GPU。
  - API：DeepSeek-V4-Flash（冻结）。
- **资源约束协议**：DB/OS/KG 的记忆容量均为 64，每任务最多检索 1 条；输出 token 预算分别为 128/512/128，交互轮数上限 3/5/15；注入长度上限 900/800/4096 字符。所有方法的辅助 LLM 调用（反思、记忆构建、技能抽取）均计入同一预算。
- **对比方法（9 个）**：Standard（无记忆）、RAG、MemRL、Mem0、MemP、MemSkill、Reflexion、EvoSC、EvoSkill。所有方法共享主干、任务流与预算。
- **指标**：任务成功率 SR↑；平均每任务输出 token 数 OutputTok↓；相对无记忆基线的 $\Delta$Tok。
- **补充实验（附录）**：
  - 泛化基准：BigCodeBench（1,140 道代码题）与 ALFWorld（574 个 episode）的在线终身变体。
  - 核心消融（DB）：Base Only / Base+RFM（固定度量）/ Full（AGOP）。
  - 效率分析：六个环境–部署组合的 token 消耗对比。
  - 超参数敏感性：DB 上逐一变动 η、λ_w、平滑系数、更新间隔、核宽 γ 等。

## 6. 主要结论与发现

- 在全部 6 个 LifelongAgentBench 环境–部署组合中，TokenWorth 均取得**最高任务成功率**，同时**输出 token 最少**：本地 DB 65.0%（超最强基线 RAG 32.0pp）、OS 59.4%、KG 36.7%；API 侧 DB 62.2%、OS 73.2%、KG 36.7%。
- 生成效率显著：本地相对无记忆基线在 DB/OS/KG 分别减少 9.3%/51.5%/18.7% 输出 token；API 侧减少 31.6%/58.3%/21.3%，且均优于各设置下最省 token 的竞争者。
- 消融表明：线性基座已较强（64.2%），单独引入固定度量的 RFM 反而降至 63.0%，加入 AGOP 几何适应后回升至 65.0%——说明**自适应特征几何**是残差学习在稀疏反馈下生效的关键。
- 核心论断：资源受限下的有效自改进**不取决于积累更多经验，而取决于学习什么值得记住**；若无法判断价值，更多记忆反而可能拖累性能。

## 7. 优点

- **问题定位精准**：将“资源联合约束”显式形式化为优化问题（预算五元组 $C$），并指出“相关性 ≠ 有用性”这一被忽视的区分，动机有说服力。
- **方法轻量且工程友好**：不更新主干、无额外 LLM 调用、无回放/反事实执行，可直接叠加在任意冻结模型上；线性基座 + 残差校正的结构兼顾可解释性与表达能力。
- **双时间尺度设计合理**：快速 KRR + 慢速 AGOP + 先验正则线性项，针对稀疏、单次、非因果反馈的稳定性问题给出了分层解决方案。
- **检索与管理价值统一**：同一“worth”信号贯穿即时检索与长期记忆生命周期（准入/替换/淘汰），概念自洽。
- **实验规范**：统一主干、统一任务流、统一预算，并将基线辅助调用计入成本，比较相对公平；效率指标定义清晰且诚实声明其局限。
- **结果差距显著**：DB 上 30+ 百分点的提升与 OS 上过半的 token 节省，实证说服力较强。

## 8. 不足与局限

- **反馈的因果性缺失**：每个任务只执行一次，仅被选中记忆获得监督，无法识别该记忆的真实因果贡献；失败也可能源于记忆之外的因素。作者将“预算高效的信用分配”列为未来工作。
- **预算覆盖单一**：仅在固定的严苛预算下评测，未验证不同预算档位下的表现，结论外推性受限。
- **泛化增益有限**：BigCodeBench/ALFWorld 上仅微弱领先甚至被 RAG 反超，说明方法优势主要集中在多轮交互型环境，对单轮代码生成类任务收益不明显。
- **超参数敏感**：KRR/AGOP 更新间隔、η、平滑系数等偏离默认值即掉点 2–3pp，且需按环境单独配置（表 A1），实际部署需调参成本。
- **表示较粗糙**：使用确定性哈希文本向量而非学习语义嵌入，可能限制对深层语义相似性的刻画；候选召回依赖轻量文本相关性，存在前置召回瓶颈。
- **评测统计性不足**：未报告多随机种子/多任务顺序的方差或显著性检验，单条任务流的偶然性风险未知。
- **应用限制**：探针集仅含近期查询（≤9 条），任务分布漂移剧烈时 $V_t(m)$ 估计可能滞后；记忆准入依赖“成功”标签，在奖励稀疏或延迟的环境中适用性存疑。
