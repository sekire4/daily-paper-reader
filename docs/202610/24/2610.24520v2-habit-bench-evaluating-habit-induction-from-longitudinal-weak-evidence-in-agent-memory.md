## 摘要
在与大语言模型（LLM）智能体的长期交互中，用户通过其选择和行动展现习惯。这些习惯承载了智能体必须跨对话推断的隐式用户信息。然而，单次观察可能仅提供关于某一习惯或其适用时机的部分证据。仅保留过往交互并不能确保智能体能够推断习惯并恰当地应用它们。我们提出 HABIT-Bench，用于评估智能体记忆系统从弱证据中推断习惯并将其应用于后续请求的能力。我们基于任务导向对话数据和受控习惯图构建合成用户历史。这些历史涵盖食品、金融、软件和旅行领域，跨越数百个会话。四选一任务评估智能体推断用户习惯并恰当应用的能力。这些任务包括临时例外、习惯变化以及用户尚未接受的建议。抽样任务经过独立人工审核。我们使用 Qwen3-235B-A22B 和 GLM-5.3-Flash 评估八种记忆方法。表现最佳的记忆方法在四个领域上达到 33.61% 的宏平均准确率。即使直接提供标注证据，性能仍然有限。这些结果揭示了在获取过往交互与推断并恰当使用用户习惯的能力之间持续存在差距。

## Abstract
In long-term interactions with large language model (LLM) agents, users reveal habits through their choices and actions. These habits capture implicit user information that agents must infer across conversations. However, individual observations may provide only partial evidence about a habit or when it applies. Retaining past interactions alone does not ensure that agents can infer habits and apply them appropriately. We introduce HABIT-Bench to evaluate how well agent memory systems infer habits from weak evidence and apply them to later requests. We construct synthetic user histories from task-oriented dialogue data and controlled habit graphs. The histories span hundreds of sessions across food, finance, software, and travel. Four-choice tasks assess agents' ability to infer user habits and apply them appropriately. They include temporary exceptions, changes in habits, and suggestions that users have not accepted. Sampled tasks undergo independent human review. We evaluate eight memory methods with Qwen3-235B-A22B and GLM-5.3-Flash. The best-performing memory method achieves 33.61\% macro accuracy across the four domains. Performance remains limited even when annotated evidence is supplied directly. These results expose a persistent gap between access to past interactions and the ability to infer and appropriately use user habits.

# HABIT-Bench 论文结构化总结

## 1. 核心问题与整体含义

- **研究动机**：LLM 智能体在长期交互中需要“从经验中学习”，而不仅是保存显式事实与偏好。用户习惯（如切菜方式、账户操作流程、酒店选择偏好）往往通过零散的选择与行动间接暴露，单次观测只能提供**部分证据（weak evidence）**：一个重复选择可能只适用于特定语境，助手的建议被记录在历史中并不意味着用户接受它，习惯也会随时间被替换。
- **核心问题**：现有基准各自覆盖了长历史回忆（LoCoMo、LongMemEval）、增量学习与遗忘（MemoryAgentBench）、隐式偏好推断（PrefEval、PersonaMem）、演化偏好（PERMA、DynamicMem）、选择性个性化（BenchPreS、OP-Bench）、记忆驱动行动（MemoryArena、Mem2ActBench）等侧面，但缺少对“**纵向弱证据下推断行为默认值，并判断其适用范围、例外、时效性与用户认可**”这一联合能力的评测。
- **问题凝练**：论文提出“何时可用的历史足以支撑对一个用户特定行为默认值的应用？”即**习惯记忆 = 推断行为默认值 + 判断证据是否支持使用它**，二者缺一不可。
- **整体含义**：能访问历史 ≠ 能推断并恰当使用习惯；论文用受控基准暴露这一持续差距，并把“默认值—支持观测—有效性条件”之间的关系保持能力确立为记忆系统的评测目标。

## 2. 方法论

- **核心思想**：用**任务型对话种子 + 受控习惯图**合成“真实提示种子化的合成人生线（synthetic lifelines）”，在数百轮会话中交错植入习惯相关证据与普通同域任务，再用**四选一决策任务**检验智能体能否从弱证据推断习惯并选出一个在目标时刻唯一有效的动作。
- **任务形式化**：
  - 用户 $u$ 的历史 $H^u_{\le t}=(s_1,\dots,s_t)$；探针 $p$ 包含请求 $x_p$、四个候选动作 $A_p$、可见性截断 $t_p$ 与目标时间 $\tau_p$。
  - 每个习惯状态 $z_{u,h}(\tau)$ 描述行为默认值及其适用性、例外、时效性与用户认可；评估方持有 $Z_u(\tau)=\{z_{u,h}(\tau)\}$。
  - 金标准动作由 $a^\star_p=\mathrm{Resolve}(x_p,A_p,Z_u(\tau_p))$ 给出：综合相关习惯并施加请求硬约束，得到唯一有效动作。该方法不限制被测方法的记忆表示形式。
- **弱证据的操作化定义**：对默认值或其有效性条件仅提供不完整支持的观测——重复选择可能留下适用范围的不确定性，后续选择可能需要结合此前的候选清单才能解读。
- **数据构造流程**：
  - 源数据集提供任务种子与交互模式；HABIT-Bench 自行构造用户连续性、习惯状态与纵向证据关系。
  - 四领域证据结构互补：**Food** 以重复选择 + 语境对比建立默认值，含弱正例与相邻近边界负例；**Travel** 侧重行为规则恢复与向新请求的迁移（先写历史、后标注证据、再盲测可恢复性）；**Finance/Software** 侧重重建用户确认的工作流并追踪其跨会话变更（“有序候选清单 + 远期序号式确认”机制，含替换链）。
  - 干扰项设计：一次性的局部例外、未被接受的助手建议、未解决的排练（rehearsal）、不同环境中的相似错误等**非约束性证据**。
  - 候选动作均满足请求硬约束，差异只在“如何使用习惯”，避免出现“唯一物理可行项”。
- **评测协议**：各方法按时间顺序将会话摄入用户隔离的记忆 $M^t_u=\mathrm{Update}(M^{t-1}_u,s^t)$，在探针处按各自预算构造 $R_p=\mathrm{Retrieve}(M^{t_p}_u,x_p)$，再由**同一比较组内的共享答案模型**输出 $\hat a_p=\mathrm{Answer}(x_p,A_p,R_p)$；方法不得访问金标准、习惯状态、证据标注、未来会话或其他用户记忆。
- **指标**：域内准确率 $Acc_d$ 与四领域非加权平均 $Macro=\frac14\sum_d Acc_d$；采用四选一**精确匹配**，避免 LLM 评审的波动，随机基线为 25%。附录另报用户宏平均与用户簇 bootstrap 区间。
- **人工验证协议**：A、B 两名评审在**不见金标与系统预测**的条件下，基于按时间排列的证据包独立选答并打 8 项质量分（可回答性、证据充分性、适用范围、边界/例外、选项平衡、自然度、来源依据、隐私安全），无法唯一判定则留空；C 在仍盲的条件下仲裁分歧；记录冻结后才揭盲比对金标，并给出 Keep/Modify/Exclude 处置。

## 6. 主要结论与发现

- **整体水平很低**：八个记忆方法的四领域宏平均准确率在 Qwen3-235B-A22B 下为 27.01%–33.06%，在 GLM-5.3-Flash 下为 30.42%–33.61%，最优也仅约三分之一，远高于 25% 随机但远不足以称为可靠。
- **记忆方法未稳定优于简单检索**：最佳记忆方法 33.06% vs BM25 32.50%（Qwen）；33.61% vs Dense 33.21%（GLM）。GLM 的 Full Memory 控制达到 **41.98%**，超过全部八个记忆方法，说明“抽取并组织记忆”未必优于检索会话或压缩历史。
- **收益高度依赖领域**：Qwen 下最佳记忆方法在 Food 提升 20.32 个百分点、Travel 提升 13.07 个百分点；Finance 中八个方法**全部低于** No Memory 的 23.54%；Software 最大增益仅 1.03 个百分点。GLM 下最佳记忆方法在 Travel 达 54.62%，而 Finance 28.29%、Software 25.44%。需要组合多个习惯、区分当前/历史状态、辨别用户承诺与未接受建议的领域最难。
- **证据可得 ≠ 决策正确**：Qwen3-235B-A22B 下 Oracle Evidence 仅 39.26%–58.25%，而 Oracle Habit State 达 98.41%–99.26%，说明“拿到相关观测”与“据此做出正确决策”之间存在显著鸿沟。
- **证据召回薄弱**：Qwen3-32B 上 6 个可溯源
