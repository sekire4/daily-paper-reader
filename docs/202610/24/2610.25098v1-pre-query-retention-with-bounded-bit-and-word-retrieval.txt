# Pre-Query Retention with Bounded Bit and Word Retrieval 

## PRANAV SINGH ∗, Indian Institute of Technology Ropar, India 

## PRASHANT SINGH ∗, Indian Institute of Technology Ropar, India 

An agent can retain information before receiving a future question and later retrieve evidence from an archive. Evaluating this arrangement requires accounting for both retained information and the width of each retrieval response. Decision-tree capacity bounds describe individual sets of distinguishable records, but a memory writer must encode every possible record before the query is known. We study fixed-length retention beside an immutable binary archive, with a worst-case limit on raw bit or word reads. We characterize feasible one-bit-read memory cells and construct encoders that partition the complete record space. Supporting pairwise exclusive disjunction and conjunction with one bit read is equivalent to supporting every Boolean query. For multiple reads, we combine explicit encoders with decision-tree counting and an entropy converse. The word-read bounds differ by at most two retained bits when the read budget is at most half the archive length. Under an explicit condition on word width and archive length, raw-word caching attains the exact optimum among all writers. A related condition preserves this optimum under positive average error. Exhaustive checks validate the implementations. In a matched dialogue-agent study, a categorical sufficient statistic preserves source decisions with less storage and lower decoding latency than the universal encoder. A catalogue-specific index reduces private state further and requires additional shared storage. The results characterize how response width and future query structure determine retention requirements. 

1 Introduction 

An agent may receive evidence before knowing which future decision will use it. A memory writer can compress that evidence into retained state, while a later reader retrieves selected parts of the original archive. The retained state and retrieval responses jointly determine which decisions remain possible. Decision-oriented compression and selective information acquisition already address this relationship [Bilgic and Getoor 2011; Permuter and Weissman 2011; Zou et al. 2026]. A useful comparison must specify the archive interface. A bit read returns one original binary coordinate. A word read returns a fixed block of original coordinates. Both interfaces differ from querying a rewritten index or a semantic retrieval service. Systematic data structures formalize storage beside original data [Gál and Miltersen 2003; Natarajan Ramamoorthy and Rashtchian 2020]. Input-dependent information available without charged probes also appears as published bits [Pătraşcu and Viola 2010]. Help-bit models study information provided before bounded decision-tree computation [Nisan et al. 1999]. Our focus is a single writer shared by all subsequent Boolean queries, where a Boolean query returns a binary decision about the record. Decision-tree capacity provides a local restriction on such a writer. A retained state identifies a set of possible records, called its memory cell. The reader must answer each query on that cell using bounded raw retrieval. Established shattering results characterize sets on which decision trees can realize every binary labeling [Leboeuf et al. 2022; Yıldız 2012, 2015]. A retention guarantee also requires a fixed-length encoding that partitions the complete record space into suitable cells. Response width must be included when interpreting the resulting savings. We study this global encoding problem with unrestricted computation and an explicit worst-case read budget. Figure 1 shows the writer and reader interfaces. A retained payload alone does not specify archive requirements or query coverage. The matched application compares these resources under fixed source observations and includes shared codebooks in its storage accounting. Our contributions are as follows: 

• We characterize one-bit-read memory cells and prove that supporting pairwise exclusive disjunction and conjunction implies support for every Boolean query. Explicit full-domain encoders attain the resulting fixed-bit retention bounds. 

• We derive word-read retention bounds with a uniform gap of at most two bits for budgets up to half the archive length. We identify a regime in which raw-word caching is exactly optimal among all writers. 

• We extend the counting converse to randomized schemes with average error and obtain an exact caching regime with positive error allowance. 

• We provide instrumented implementations, exhaustive checks, and a matched text-to-decision evaluation. The study separates preservation of source decisions from source accuracy and compares payload, archive, and shared storage across query workloads. The capacity bounds and selector constructions originate in prior decision-tree work [Yıldız 2012, 2015]. Our results concern writer partitions, workload equivalence, and their retained-state consequences under specified retrieval interfaces. 

2 Related work 

Systematic storage and bit probes. Gál and Miltersen [2003] study original data with an auxiliary index for prefix sums and substring search. Their accounting charges probes into the stored structure. Our reader sees the entire retained tier directly. Viola [2012] proves redundancy lower bounds for encoded ternary arrays and set membership under adaptive bit probes. Pătraşcu and Viola [2010] establish word-probe bounds for rank and select. Their analysis uses input-dependent published bits that the reader examines without charge. Our retained tier has this established role. We study the stated pair and universal workloads while restricting charged access to the unchanged record. 

Help bits and linear structures. Nisan et al. [1999] study help bits followed by decision trees that evaluate copies of a fixed function on disjoint inputs. Our writer supports future queries that may overlap on the same record.

Natarajan Ramamoorthy and Rashtchian [2020] relate systematic linear structures for inner products to matrix rigidity. We allow nonlinear writers and analyze universal Boolean queries, including a comparison with affine writers. 

Decision-tree capacity. Yıldız [2012] establish the capacity of binary and multiway stumps. They also provide a selector construction. A stump is a decision tree with one internal test. The journal treatment extends these results [Yıldız 2015]. Leboeuf et al. [2022] analyze partitioning and generalization for real-valued and categorical features. We use the binary-stump and selector ingredients to construct global writer partitions. Multiway tree counting yields our word-width bounds. We attribute these capacity tools to their predecessors. 

Information acquisition and decision compression. Side-information vending jointly designs a compressed description and later information-acquisition actions [Permuter and Weissman 2011]. Locally decodable source coding limits access to a coded description [Makhdoumi et al. 2013]. Our reader accesses original archive coordinates. Value-of-information methods select features using probabilistic structure [Bilgic and Getoor 2011]. Approximate information states preserve information required for planning [Subramanian et al. 2022]. Our universal-query objective provides a worst-case comparison for retention beside a raw archive. 

Agent memory. Finite recurrent-state retrieval limits [Wen et al. 2024] and rate–distortion formulations for agent memory [Zou et al. 2026] motivate explicit state accounting. Nous studies belief maintenance and certification [Singh 2026a,b]. We reuse the pretrained models and the released updater [Singh 2026c] in a matched text-to-decision evaluation. The observation stage is held fixed within each source group while the retained representation changes.

8 Implementation and evaluation 

The implementations return a fixed-length byte payload from the writer. The reader receives only that payload, a pure query evaluator, and an instrumented archive callback. The callback records every address and rejects budget overruns. Public codec objects contain dimensions and feature rules. The reader validates payload length and padding. The generic bit decoder evaluates a query on 2 𝑘 𝑛,𝑅 candidate records. Its direct implementation uses transient storage for offsets and candidate records. A specialized pair-gate decoder evaluates feature truth tables without materializing complete candidates. The word decoder reads selector words and obtains its final selected bit from the containing word. When raw caching retains fewer bits, the implementation instead reconstructs the record from cached and retrieved words. We compare the universal encoder with a matched raw-prefix cache. The cache enumerates its compatible records and selects the coordinate that maximizes answerable mass under the uniform source. A branch is answerable when every compatible record gives the same query value. The cache abstains on other branches. We also compare complete-record retention, the exact XOR encoder, and a categorical sufficient statistic for the dialogue-derived records. Appendix E specifies sampling and implementation details.

9 Limitations 

The theorems quantify over full-domain records and all Boolean queries, including long truth tables. Restricted sources or query families can admit smaller sufficient statistics. The results do not establish comparable hardness for natural-language questions. The archive must contain unchanged raw coordinates or disjoint words, and all record-dependent metadata is charged. Writing and decoding can require substantial transient storage and computation. Query purity is a caller contract. Finite computational checks do not replace the proofs. The codecs do not detect staleness or repair extraction errors. The matched evaluation uses previously trained linear text models on a source split already exposed in Nous research. 10 Conclusion 

Pre-query retention requires a writer to partition records into cells that a bounded reader can resolve. We characterize one-bit-read cells, construct full-domain encoders, and derive universal retention bounds for bit and word retrieval. Word width determines whether nonlinear retention provides any saving beyond raw caching. An explicit regime makes raw-word caching exactly optimal, including a range of positive average-error allowances. The matched evaluation favors a categorical sufficient statistic in storage and decoding latency. The catalogue index trades a smaller private state for shared storage and selective query coverage. Together, the results connect retention requirements to the retrieval interface, record support, and future query family.
