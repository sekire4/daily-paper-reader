## 摘要
对话式大语言模型（LLM）被广泛用于软件工程中的代码生成、调试和架构设计。然而，当开发者进行多会话开发任务时，技术知识会被孤立在彼此分离的线性聊天历史中。跨会话复用上下文会带来三个关键挑战：（1）平坦向量检索无法遍历相距较远的架构决策之间的多跳关系依赖；（2）软件包和 API 的时间漂移会在复用陈旧对话日志时导致静默的上下文污染；（3）原始对话拼接会导致提示膨胀和注意力退化。我们提出 CognitiveCanvas，一个交互式工具，可将对话式 AI 记忆从短暂的文本日志转化为持久、可操作且可审计的知识对象。CognitiveCanvas 集成了：（1）分层语义事实图（HSFG），将对话提炼为目标、事实和代码工件，在实现 92.2% 的 token 缩减的同时支持多跳 GraphRAG 遍历；（2）持续时序漂移审计器，将 60 多种正则启发式与基于实时日历锚定的 LLM 验证相结合，实现一键自校正；以及（3）空间-符号提示编译器（SSPC），将二维直接操作手势（Voronoi 聚类、节点缩放、合成边）直接转换为结构化的注意力指令。

## Abstract
Conversational Large Language Models (LLMs) are widely employed in software engineering for code generation, debugging, and architectural design. However, as developers engage in multi-session development tasks, technical knowledge becomes siloed in isolated, linear chat histories. Reusing context across sessions leads to three critical challenges: (1) flat-vector retrieval fails to traverse multi-hop relational dependencies between distant architectural decisions; (2) temporal drift in software packages and APIs results in silent context poisoning when reusing aged dialogue logs; and (3) raw conversation concatenation induces prompt bloat and attention degradation.   We present CognitiveCanvas, an interactive tool that transforms conversational AI memories from ephemeral text logs into persistent, manipulable, and audited knowledge objects. \textsc{CognitiveCanvas} integrates: (1) a Hierarchical Semantic Fact-Graph (HSFG) that distills dialogues into Goal, Fact, and Code artifacts, achieving a 92.2\% token reduction while enabling multi-hop GraphRAG traversal; (2) a Continuous Temporal Drift Auditor coupling 60+ regex heuristics with live calendar-anchored LLM verification for 1-click self-correction; and (3) a Spatial-Symbolic Prompt Compiler (SSPC) that translates 2D direct manipulation gestures (Voronoi clustering, node resizing, synthesis edges) directly into structured attention directives

## 1. 核心问题与整体含义

- **背景**：对话式 LLM 已广泛用于代码生成、调试和架构设计，但商业界面仍以“线性、孤立会话”为主，技术知识被困在不可检索、不可复用的聊天历史中。
- **核心问题**：开发者跨会话复用上下文时面临三个结构性瓶颈：
  1. **上下文碎片化**：多会话知识散落在聊天侧边栏，依赖复制粘贴和重复提示。
  2. **时间漂移导致的静默上下文污染**：软件包/API 快速演化，旧对话中的过时配置会被 LLM 盲目接受，产生“自信的代码幻觉”。
  3. **缺乏空间可操控性**：传统 RAG 将文本块不可见地注入提示，开发者无法检查或控制模型应强调哪些约束。
- **整体含义**：论文提出 **CognitiveCanvas**，把对话式 AI 记忆从“短暂文本日志”转化为**持久、可操作、可审计的知识对象**，并通过二维画布上的直接操作实现对 GraphRAG 检索与提示注意力的显式引导。其目标是构建一个人机协同的“对话记忆工作区”，而非单纯优化检索器。

## 2. 方法论

### 2.1 核心思想

- 采用**神经-符号混合**架构：前端是可直接操作的 2D 语义画布，后端是属性图数据存储与异步编排控制器。
- 三个组件分别对应三个瓶颈：
  - **HSFG + GraphRAG** → 解决上下文碎片化与多跳检索失效；
  - **Continuous Temporal Drift Auditor** → 解决时间漂移与上下文污染；
  - **SSPC** → 解决提示膨胀与注意力不可控。

### 2.2 分层语义事实图（HSFG）与 GraphRAG

- 将每个会话蒸馏为三元组：
  \[
  HSFG(M)=\langle G,F,A\rangle
  \]
  - **G（Goal）**：开发者目标与当前阻塞点；
  - **F（Fact）**：形式化实体-关系三元组，如 `(:FastAPI)-[:USES]->(:AsyncSession)`；
  - **A（Artifact）**：逐字保留的可执行代码工件（schema、API 路由、配置），强调 100% 语法保真。
- 论文给出一个 10 轮调试对话的压缩示例：
  \[
  Tokens(HSFG)=45(G)+120(F)+240(A)=405
  \]
  相比原始 5,210 tokens，实现 **92.2% token 缩减**，同时保留代码可复现性。
- 通过属性图支持跨会话的**多跳关联遍历**，而非平坦向量检索。

### 2.3 持续时序漂移审计器

- 使用领域校准的风险函数评估记忆过时风险：
  \[
  V(M_i,t_{now})=\exp(-\lambda_d\cdot\max(0,t_{now}-t_{anchor}-\delta_d))\cdot(1-\Phi(M_i))
  \]
  - \(\lambda_{software}=0.015\ \text{day}^{-1}\)；
  - \(\delta_d=90\) 天宽限期；
  - \(\Phi\in[0,1]\) 为漂移概率。
- **两阶段审计流程**：
  1. **Stage 1 高速正则筛查**：60+ 预编译模式，覆盖版本号（`v\d+\.\d+`）、弃用关键词（`deprecated`、`sunset`、`breaking changes`）和时间标记（`currently`、`as of`）；约 **0.02 ms**，零 token 成本。
  2. **Stage 2 LLM-as-a-Judge 验证**：若 Stage 1 触发，则结合当前日历 \(t_{now}\) 查询 LLM；确认过时后显示 **Stale 徽章**，给出弃用理由，并提供“一键自校正”按钮，重构代码并原地更新知识图谱。

### 2.4 空间-符号提示编译器（SSPC）

- 对每个记忆卡 \(M_i\) 计算重要性权重：
  \[
  W(M_i)=0.5\cdot\frac{Area(M_i)}{Area_{base}}+0.3\cdot\frac{1}{1+D(M_i,C)}+0.2\cdot Deg(M_i)
  \]
  - \(Area_{base}=160\times160\) px；
  - \(D(M_i,C)\) 为到画布质心的欧氏距离；
  - \(Deg(M_i)\) 为关联语义边数量。
- 根据权重编译为提示注意力层级：
  - **HIGHLIGHT_CONTEXT**（\(W\ge1.75\)）：作为主导架构约束注入；
  - **STANDARD_CONTEXT**（\(0.65<W<1.75\)）：标准 grounding 上下文；
  - **OBSCURE_CONTEXT**（\(W\le0.65\)）：仅作背景细节；
  - **GROUP_CONTEXT**（边连接节点）：强制跨记忆协同合成。
- 即将**节点缩放、质心邻近度、合成边连接**等二维手势直接映射为结构化注意力指令。

### 2.5 系统架构与交互设计

- 前端：硬件加速 SVG 的 2D 画布，支持平移缩放、节点缩放、Delaunay/Voronoi 主题分区与聚类图例。
- Document Inspector：查看多轮会话记录，通过垂直方形手柄提取子轮次对。
- 聊天界面：句子级 NLI 置信度热图、双向引用徽章（如 `[[1_0]]`），悬停时在画布上高亮对应记忆节点。
- 后端：异步编排控制器 + 神经-符号混合数据存储（场景中提及 Neo4j 概念图）。

## 4. 结果分析

### 4.1 三类瓶颈的对应改善

- **上下文碎片化**：HSFG 的“目标—事实—工件”三元压缩使 10 轮对话从 5,210 tokens 降至 405 tokens（−92.2%），同时因工件逐字保真，代码可复现性未受损。这说明收益并非来自“删信息”，而是来自**结构化去冗余**：自然语言闲聊与重复解释被剥离，实体关系与可执行代码被保留。
- **多跳检索**：Multi-Hop Recall@3 从 38.4%/52.1% 提升至 89.6%，是三项指标中相对增益最大的一项。合理解释是属性图支持跨会话的显式关系遍历（如“服务 A → 依赖库 B → 配置 C → 曾讨论的阻塞点 D”），而平坦向量检索在语义相似度衰减后难以召回链尾节点。
- **时间漂移**：时间性幻觉率从 31.2%/28.7% 降至 4.2%（相对降幅约 85%）。由于 Stage 1 正则筛查近乎零成本，该收益的边际代价很低；但需注意 4.2% 的残余错误可能集中在**未含显式版本号或弃用关键词**的隐式过时知识上，这正是纯模式匹配的固有盲区。
- **引用忠实度**：94.3% 表明句子级 NLI 热图与双向引用徽章确实把“模型依据哪条记忆作答”变成了可核验对象，而不仅是事后解释。这一点对审计场景尤为关键。

### 4.2 交互机制的有效性线索

- 论文将节点面积、质心距离、语义边度数线性组合为权重 \(W\)，并映射为三档注意力层级。该设计的好处是**可预测、可解释**：用户放大某节点即等于提高其提示优先级，无需理解提示工程。但固定系数（0.5/0.3/0.2）与阈值（1.75/0.65）缺乏消融证据，是否对任务类型敏感仍是开放问题。
- 画布的空间布局同时承担两种职能：**语义聚类可视化**（Delaunay/Voronoi 分区）与**提示控制信号**。这种“所见即所注”的耦合是本文最具设计价值的洞见，但也带来风险——用户为整理视觉美观而移动节点时，可能无意改变模型注意力分布。

### 4.3 实验设计的客观评价

- **优点**：采用受试者内设计 + 拉丁方平衡，能较好控制个体差异与顺序效应；任务覆盖工程、科研、物流三类异质场景，外部效度优于单一编程任务；基线设置合理（商业线性聊天 vs. 平坦 RAG vs. 完整系统），可部分归因于各组件贡献。
- **不足**：
  1. **无公开 benchmark**，指标为自建，缺乏与既有 GraphRAG/长上下文记忆系统的横向可比性；
  2. N=24 且分组较细（每类 6–12 人）， subgroup 层面的统计功效有限，论文未报告显著性检验与效应量；
  3. Token 缩减对比的是“原始对话 vs. HSFG 蒸馏”，本质上混合了**压缩策略**与**检索策略**两种变量，难以单独归因；
  4. 时间性幻觉率的判定标准（何谓“时间性幻觉”）与标注者间一致性未详述；
  5. 缺乏**长期使用研究**，无法判断画布在记忆规模增长（数百节点）后的可维护性与认知负荷。

## 5. 贡献与定位

- **概念贡献**：将“对话记忆”重构为**可审计的知识对象**，并提出“空间操作即提示控制”的交互范式，把 RAG 从不可见的注入管线变为可见、可编辑的工作面。
- **系统贡献**：HSFG 三元表示、两阶段漂移审计、SSPC 权重编译三者的组合，形成一个端到端的神经-符号记忆工作区，且各模块可独立替换。
- **实证贡献**：在小样本受控实验中给出方向一致的正向信号，尤其在多跳召回与时间性幻觉两项上差距显著。
- **定位**：属于 **HCI + GraphRAG 交叉的工具演示类工作**，价值主张偏向交互设计与系统架构，而非检索算法本身的 SOTA 突破。

## 6. 局限与可改进方向

1. **表示层**：HSFG 依赖 LLM 蒸馏，抽取错误会沿图谱传播；三元组对程序性知识（“如何做”的步骤序列）表达能力有限。
2. **审计层**：Stage 1 依赖关键词与版本号模式，对语义级弃用（如“行为静默变更但无 deprecated 标记”）无覆盖；Stage 2 的 LLM 判定本身也可能过时，形成“用可能过时的模型审计过时知识”的循环依赖。
3. **提示层**：三档离散注意力层级丢失了连续权重信息；权重公式为手工设定，缺少学习或用户自适应机制。
4. **评估层**：需要更大样本、公开基准、纵向研究，以及针对**认知负荷**与**信任校准**（用户是否过度信任 Stale 徽章）的专门测量。
5. **工程层**：图数据库规模扩展、多用户协作冲突、隐私与敏感代码在记忆图中的留存策略均未讨论。

## 7. 启示

- 对开发者工具设计者：**“让检索可见”本身就能提升可信度**，引用徽章 + 画布高亮是低成本高回报的交互模式。
- 对 RAG 研究者：时间维度是被长期忽视的检索信号；把“记忆新鲜度”作为一等公民建模，可能比单纯扩大上下文窗口更经济。
- 对评估实践：记忆系统的评测应同时报告**压缩率、召回、忠实度、时效性**四维指标，单一维度容易被“压得越狠越好”或“召回越高越好”误导。
