## 摘要
文本图问答（GraphQA）与基于图的检索增强生成（GraphRAG）作为将大语言模型（LLM）建立在结构化知识之上的一种方式，正受到越来越多关注。尽管已有大量努力，现有方法仍面临两个关键缺口。第一个是架构缺口：现有方法通常微调基于 LLM 的生成器，但并未在同一端到端“先检索后生成”流程中，将检索器本身也构建为用于图证据选择的可学习 LLM。第二个是检索监督缺口：现有检索器很少利用金标准答案信号来监督证据选择。因此，它们可能无法召回推理所需的证据节点，导致对金标准答案集的覆盖不足；同时，简单提升召回率的尝试往往会引入过多无关信息，损害紧凑性并使 LLM 不堪重负。为解决这些缺口，我们提出 TaLenT，一种面向文本图问答的基于 LLM 的端到端检索器-生成器框架。为弥合架构缺口，TaLenT 在统一的“先检索后生成”流程中，将用于证据选择的可学习、基于 LLM 的检索器与微调后的基于 LLM 的生成器配对结合。为弥合检索监督缺口，我们利用金标准答案信号作为检索器监督。具体而言，我们将图节点分层为金标准答案、答案相关节点和无关噪声。随后，我们采用加权伪标签损失，以优先考虑金标准答案，并保留答案相关节点以保证覆盖，同时丢弃无关噪声以保持紧凑性。在三个 GraphQA 数据集上的实验结果表明，TaLenT 能够持续提升下游性能。

## Abstract
Textual graph question answering (GraphQA) and graph-based retrieval-augmented generation (GraphRAG) have gained increasing attention as a way to ground large language models (LLMs) on structured knowledge. Despite extensive efforts, existing methods still face two key gaps. The first is an architectural gap: existing methods typically fine-tune an LLM-based generator, but do not also make the retriever itself a learnable LLM for graph evidence selection within one end-to-end retrieve-then-generate pipeline. The second is a retrieval-supervision gap: existing retrievers rarely use gold answer signals to supervise evidence selection. As a result, they may fail to recall evidence nodes required for reasoning, resulting in insufficient coverage of the gold answer set; meanwhile, naive attempts to boost recall often introduce excessive irrelevant information that compromises compactness and overwhelms the LLM. To address these gaps, we propose TaLenT, an LLM-based end-to-end retriever-generator framework for textual GraphQA. To bridge the architectural gap, TaLenT pairs a learnable LLM-based retriever for evidence selection with a fine-tuned LLM-based generator within one unified retrieve-then-generate pipeline. To bridge the retrieval-supervision gap, we leverage gold answer signals as retriever supervision. Specifically, we stratify graph nodes into gold answers, answer-related nodes, and irrelevant noise. We then adopt a weighted pseudo-label loss to prioritize gold answers and preserve answer-related nodes for coverage, while discarding irrelevant noise for compactness. Experimental results across three GraphQA datasets demonstrate that TaLenT consistently improves downstream performance.

## 1. 核心问题与研究动机

- **背景**：大语言模型（LLM）受参数知识截止日期与覆盖范围限制，易产生幻觉或遗漏关键证据。检索增强生成（RAG）通过外部证据为 LLM 提供依据；GraphRAG / 文本图问答（GraphQA）进一步利用文本图的显式语义与关系结构，支持更接地的复杂推理。
- **两个关键缺口**：
  - **架构缺口**：现有 GraphRAG 通常只微调基于 LLM 的生成器，而检索器仍是非参数化图搜索、GNN 或 LM 辅助流程，未将检索器本身构建为可学习的 LLM，因而缺少统一的端到端“先检索后生成”双 LLM 模块。
  - **检索监督缺口**：现有检索器主要依赖查询相似度，很少利用金标准答案信号监督证据选择。查询相似度容易偏向与查询词匹配的节点，导致两类问题：
    - **覆盖不足**：检索子图可能漏掉推理所需的金答案节点；
    - **紧凑性差**：为提升召回而扩大候选，会引入大量无关噪声，淹没生成器。
- **核心观察**：金答案集合恰好提供了缺失的检索监督——它既指明“应覆盖什么”，也帮助区分“答案相关证据”与“无关噪声”。论文据此提出 **TaLenT**，一个面向文本 GraphQA 的基于 LLM 的端到端检索器-生成器框架。

## 2. 方法论

### 2.1 整体框架

- TaLenT 包含三个阶段的统一流程：
  1. **预处理**：基于查询与文本图，用 PCST 构建高召回、适配 LLM 上下文预算的候选连通子图 \(S\)；
  2. **检索器训练**：训练可学习 LLM 检索器 \(R_\theta\)，以加权伪标签监督从 \(S\) 中选择答案相关节点集 \(\hat V\)；
  3. **生成器训练**：将 \(\hat V\) 及其关联边序列化为图上下文，用标准 SFT 微调 LLM 生成器 \(G_\phi\)。
- 推理时复用同一流程：PCST → 训练后的检索器 → 训练后的生成器。

### 2.2 候选子图构建（PCST 预处理）

- 用 SentenceBERT 编码查询、节点文本和边文本，计算余弦相似度，分别取 top-\(k_v\) 节点与 top-\(k_e\) 边。
- 按排名赋“奖金”：节点 \(p(v)=k_v-r_v\)，边 \(p(e)=k_e-r_e\)，未入选者为 0。
- 用 Prize-Collecting Steiner Tree（PCST）求解连通子图，目标为最大化“节点与边的奖金之和减去边数惩罚 \(c|E_S|\)”，在覆盖与紧凑之间折中。
- 该步骤是固定规则预处理，为后续 LLM 检索器提供高召回候选池。

### 2.3 可学习 LLM 检索器与加权伪标签监督

- **检索器形式**：指令跟随 LLM + LoRA。输入查询 \(q\) 与候选子图 \(S\) 的文本化表示，要求输出严格单行、竖线分隔的小写节点名列表，即 \(\hat V=R_\theta(q,S)\)。
- **参数知识补充**：由于检索器本身是 LLM，输出 \(\hat V\) 可包含不在候选子图 \(S\) 中的节点（即 \(\hat V \not\subseteq V_S\)），从而利用模型内部知识补充证据。
- **节点三层分层**：
  - **Level-1 强正例** \(P=V^\star\cap V_S\)：与金答案重叠的候选节点，应优先选中；
  - **Level-2 弱正例** \(W=V_S\setminus V^\star\)：候选子图中非金答案的节点，可能提供上下文，作为弱学习信号；
  - **Level-3 无关噪声**：\(V_S\) 之外的节点，训练时抑制。
- **训练目标**：构造目标串 \(y=p_1|\cdots|p_{|P|}|w_1|\cdots|w_{|W|}\)（强正例在前、弱正例在后），最小化 token 加权负对数似然：
  - \(\mathcal L_{\text{retr}}(\theta)=-\sum_{t=1}^{T}\omega_t\log p_\theta(y_t\mid x,y_{<t})\)
  - 权重：属于 \(P\) 的 token 权重为 1；属于 \(W\) 的 token 权重为 \(\lambda\)；其他为 0。
  - \(\lambda\) 为控制弱正例贡献的超参数，通常远小于 1，以突出金答案、保留上下文、丢弃噪声。

### 2.4 生成器训练与推理

- **上下文构造**：给定 \(\hat V\)，取候选子图 \(S\) 中至少一个端点在 \(\hat V\) 中的边 \(\hat E=\{(u,r,v)\in E:u\in\hat V \text{ 或 } v\in\hat V\}\)。将 \(\hat V\) 与 \(\hat E\) 序列化为 CSV 风格图文本（节点表 + 边表），与查询拼接为生成器提示。
- **允许非连通**：序列化上下文不要求构成单一连通子图，避免为保持连通而引入“桥接”噪声节点；\(\hat V\) 中来自参数知识、不在 \(S\) 内的节点作为孤立节点（如 `na1`、`na2`）保留。
- **生成器微调**：标准 SFT，最小化金答案 token 的负对数似然：
  - \(\mathcal L_{\text{gen}}(\phi)=-\sum_{t=1}^{T_a}\log p_\phi(a^\star_t\mid q,\hat V,\hat E,a^\star_{<t})\)
- **推理**：对测试实例先 PCST 得 \(S\)，再 \( \hat V=R_\theta(q,S)\)，最后 \(a=G_\phi(q,\hat V,\hat E)\)。

## 3. 实验设计

- **数据集与任务**：
  - **ExplaGraphs**（GraphQA 基准）：判断两论点支持/矛盾，指标 Accuracy；图较小，直接使用全图作为候选上下文。因金答案是二分类标签、无节点级监督，使用 LLaMA2-Chat-7B 生成伪金推理节点集作为 \(V^\star\)。
  - **WebQSP**（GraphQA 基准）：Freebase 多跳 KGQA，指标 Hit@1；金答案为实体列表，可直接作为 \(V^\star\)；PCST 取 \(k_v=k_e=10\)。
  - **CWQ**：比 WebQSP 更复杂的组合式 KGQA，指标 Hit@1；同样基于 Freebase。
- **对比基线**：
  - **推理型方法**：Zero-shot、Zero-CoT、CoT-BAG、KAPING、Graph-based Inference、StructGPT；
  - **Prompt-Tuning 方法**：Frozen LLM + Prompt Tuning、GraphToken、G-Retriever、G-Retriever w/ LoRA、TaoNa-A。
- **主干与配置**：LLaMA2-Chat-7B 同时作为检索器与生成器主干；LoRA \(r=8,\alpha=16\)、dropout 0.05；检索器训练 3 epochs、学习率 \(5\times10^{-5}\)、warmup 0.03、batch size 1 + 梯度累积 8；弱正例权重 \(\lambda=0.001\)（WebQSP）、\(0.01\)（ExplaGraphs/CWQ）。
- **附加实验**：
  - 覆盖-紧凑性分析（WebQSP，比较 PCST \(k=10\)、PCST \(k=3\) 与 TaLenT 检索器输出）；
  - PCST 外节点贡献分析；
  - 检索器消融（冻结 vs 训练）与下游 QA 消融（无检索器 vs 冻结检索器 vs 完整 TaLenT）；
  - \(\lambda\) 敏感性与 PCST 候选规模敏感性；
  - Llama-3-8B 主干消融及对应覆盖-紧凑性分析；
  - ExplaGraphs 伪金节点标注的人工检查与 GPT-4o-mini 交叉一致性检查；
  - PCST 外检索的幻觉率分析。
