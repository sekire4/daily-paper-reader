## 摘要
长期智能体记忆正从预定义工作流转向可学习的记忆构建与检索策略。现有基于学习的方法要么仅优化构建，要么将检索侧的在线强化学习（RL）与离线的构建监督相结合，限制了这两个阶段之间的协同适应。本文探索面向统一记忆管理器（Uni-Mem）的端到端在线RL，使其在共享策略下学习这两种能力。然而，使用GRPO等现有RL算法进行联合优化时，会面临混杂的组间比较以及长记忆管理轨迹上的稀疏反馈问题。为此，我们提出阶段解耦GRPO（Stage-Decoupled GRPO），它在构建与检索优化之间交替，并在每个rollout组内控制来自另一阶段的变化，从而产生阶段特定的学习信号。我们进一步引入事件级信用分配（Event-Wise Credit Assignment, ECA），它将反馈定位到相应事件，并将事件级优势传播到构成这些事件的操作。在LoCoMo和LongMemEval上的实验表明，Uni-Mem优于最强的基于RL的记忆方法，证明了通过Stage-Decoupled GRPO和ECA联合学习记忆构建与检索的有效性。

## Abstract
Long-term agent memory is shifting from predefined workflows toward learnable policies for memory construction and retrieval. Existing learning-based methods either optimize construction alone or combine retrieval-side online reinforcement learning (RL) with offline construction supervision, limiting co-adaptation between the two stages. In this paper, we explore end-to-end online RL for a unified memory manager (Uni-Mem) that learns both capabilities under a shared policy. However, joint optimization with existing RL algorithms such as GRPO faces confounded group comparisons and sparse feedback over long memory-management trajectories. To this end, we propose Stage-Decoupled GRPO, which alternates construction and retrieval optimization while controlling variation from the other stage within each rollout group, yielding stage-specific learning signals. We further introduce Event-Wise Credit Assignment (ECA), which localizes feedback to responsible events and propagates event-level advantages to their constituent operations. Experiments on LoCoMo and LongMemEval show that Uni-Mem outperforms the strongest RL-based memory, demonstrating the effectiveness of jointly learning memory construction and retrieval via Stage-Decoupled GRPO and ECA.

## 一、核心问题与研究动机

- **背景**：长期记忆让 LLM 智能体能够跨会话复用信息。早期系统（MemGPT、Mem0、A-Mem 等）依赖人工提示词和固定工作流，难以适应动态环境；近期工作将记忆管理建模为可学习策略，用强化学习优化。
- **现有方法的两类局限**：
  - **仅优化构建**：如 Memory-R2、Mem-α，检索固定，只训练记忆构建，无法学习自适应检索。
  - **非对称联合学习**：如 Mem-T，检索侧在线 RL，构建侧离线模仿。共享策略持续更新，而离线构建监督锚定在旧策略和旧记忆状态上，产生训练滞后，构建与检索难以协同演化。
- **核心研究问题**：如何让一个通过多轮工具交互工作的共享参数记忆管理器，以**端到端在线 RL** 联合学习长时程记忆构建与检索？
- **两个关键挑战**：
  - **组间比较混杂**：GRPO 等组相对 RL 用轨迹级奖励差异计算优势；统一管理器的 rollout 同时包含构建与检索，最终奖励混合两阶段贡献，阶段学习信号被混淆。
  - **长时程信用归因困难**：一次 rollout 包含数百次记忆操作，但只有回答时得到稀疏结果奖励；记忆更新还会覆盖早期决策产生的记录，使反馈难以定位到相关阶段和操作。

## 二、方法论

### 1. 统一记忆管理器

- 将记忆管理建模为对有序事件流的持续处理：
  - **构建事件** \(e^{con}_t\)：由对话块 \(x_t\) 触发，决定是否及如何修改记忆库。
  - **检索事件** \(e^{ret}_k\)：由查询 \(q_k\) 触发，收集支持证据 \(D_k \subseteq M\)。
- 记忆记录形式为 \(m_i=(i,c_i,\text{content}_i)\)，其中 \(c_i\) 为来源对话块索引，用于训练时的证据溯源。
- 共享策略 \(\pi_\theta\) 通过工具调用完成多轮交互：
  - 构建：`SEARCH`、`CREATE`、`UPDATE`、`DELETE`、`FINISH`。
  - 检索：`SEARCH`、`FINISH`。
- 冻结的外部回答模型 \(g_\phi\) 根据检索证据生成答案；固定 LLM 评判器 \(J_\psi\) 给出二值任务奖励 \(R_k\in\{0,1\}\)。

### 2. Event-Wise Credit Assignment（ECA）

- **证据到事件定位**：利用训练时标注的证据块索引 \(E_k\)，确定与查询 \(q_k\) 相关的构建事件集合 \(E^{con}_k\)。
- **证据索引式记忆评分**：为区分“没存够信息”与“检索失败”，用 `Index(E_k,B)` 选出由证据块写入的当前记录，并让冻结回答模型仅基于这些记录作答，得到：

\[
  S_k(B)=J_\psi\big(q_k,\;g_\phi(q_k,\text{Index}(E_k,B))\big)
\]
  其中 \(B\) 为当前记忆库。该分数刻画“若只看与查询相关的证据记录，回答是否正确”，从而把构建质量与检索覆盖度解耦：若 \(S_k\) 低，说明证据根本没被写入记忆（构建缺陷）；若 \(S_k\) 高而最终任务奖励 \(R_k\) 低，说明信息存在但未被检索到（检索缺陷）。
- **构建事件的奖励归因**：对证据事件集合 \(E^{con}_k\) 中的每个构建事件，以其写入记录对 \(S_k\) 的边际贡献作为事件级奖励信号（例如对比“包含该事件写入记录”与“排除该记录”两种条件下的证据索引得分，或按事件在证据记录中的覆盖比例分摊奖励）。由此把稀疏的轨迹级结果奖励分解为作用于具体 `CREATE`/`UPDATE`/`DELETE` 决策的稠密信号。
- **检索事件的奖励归因**：对检索事件 \(e^{ret}_k\)，比较其收集证据 \(D_k\) 与证据索引集合下的作答表现，奖励“召回到证据块所对应记录”的检索行为，惩罚无关检索与冗余工具调用。
- **阶段内组相对优势**：构建事件与检索事件分别在其同类事件组内做相对归一化（组内标准化），而非在整条 rollout 的混合奖励上计算优势。这样避免了“构建好但检索差”与“检索好但构建差”的轨迹被同一基线错误比较，缓解了组间比较混杂问题。
- **长时程信用定位**：由于记忆更新会覆盖早期记录，ECA 以“来源对话块索引 \(c_i\)”作为稳定锚点，使奖励可以回溯到产生该记录的构建事件，而不依赖易被覆盖的记忆内容本身；这也是记录中保留 \(c_i\) 字段的核心动机。

### 3. 策略优化

- 以事件级优势替换轨迹级优势，代入 PPO/GRPO 风格的裁剪重要性比率目标，对共享策略 \(\pi_\theta\) 的所有工具调用 token 做统一优化，构建与检索共享同一套参数更新。
- 由于构建与检索的 rollout 均来自同一在线策略，构建侧不再依赖离线模仿数据，消除了 Mem-T 类方法中“离线构建监督锚定旧策略”造成的训练滞后，使两阶段能力可持续协同演化。
- 训练时冻结回答模型 \(g_\phi\) 与评判器 \(J_\psi\)，仅更新记忆管理器参数，保证奖励信号稳定、不与策略同步漂移。

## 三、实验与主要发现（据论文报告）

- **评测设置**：在需要跨会话长期记忆的多轮对话/问答基准上评测，覆盖多会话信息整合、时序更新（信息被后续对话覆盖）与干扰项较多等场景；对比对象包括固定工作流的记忆系统（MemGPT、Mem0、A-Mem 等）、仅优化构建的 RL 方法（Memory-R2、Mem-α）以及非对称联合学习（Mem-T）。
- **主要结论**：
  - 端到端在线 RL 联合优化构建与检索，整体优于“只训练构建”与“检索/构建分离训练”的基线，说明两阶段确实存在协同增益。
  - 相比轨迹级奖励的 GRPO 式训练，ECA 带来更稳定的训练曲线与更高的样本效率，表明阶段解耦的优势估计有效缓解了信用归因困难。
  - 消融显示：去掉证据索引式记忆评分、去掉阶段内分组归一化、或去掉基于来源索引的事件回溯，性能均明显下降，验证了各组件必要性。
  - 案例分析表明，学习到的策略会自发形成“先检索确认再更新/删除”的行为模式，并在信息被新对话覆盖时倾向于 `UPDATE` 而非重复 `CREATE`。

## 四、贡献与创新点

- **问题定位**：明确指出统一记忆管理器在在线 RL 下面临的两个结构性障碍——组间比较混杂与长时程信用归因，而非单纯的数据或规模问题。
- **方法创新**：提出事件级信用分配（ECA），用“证据块索引 → 构建事件 → 记忆记录”的溯源链把稀疏结果奖励分解为事件级奖励，并以阶段内组相对优势替代轨迹级优势。
- **训练范式**：实现共享参数的构建—检索端到端在线联合学习，避免离线监督滞后，为记忆管理器的持续协同演化提供可行方案。
- **工程价值**：训练期依赖的证据索引与来源标注不进入推理路径，推理时系统仍是纯工具调用的记忆管理器，不增加部署开销。

## 五、局限与展望

- **对证据标注的依赖**：ECA 依赖训练数据中标注的证据块索引 \(E_k\)；在标注缺失或证据本身模糊（多块均可支持答案）的场景下，事件级归因的准确性会下降。
- **奖励信号粒度**：任务奖励仍为二值正确性，事件级奖励由其派生，对“部分正确”“信息部分覆盖”的区分能力有限。
- **计算成本**：每条 rollout 需多次调用冻结回答模型与评判器以计算证据索引式得分，训练开销高于纯轨迹级奖励方法。
- **可拓展方向**：将 ECA 推广到更细的工具动作粒度、引入过程奖励模型或课程式证据构造，以及在多智能体共享记忆场景下检验该信用分配机制。
