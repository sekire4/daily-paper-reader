## 摘要
长时程对话智能体需要保持用户记忆足够稳定以支持个性化，同时在用户确实发生变化时进行适应。现有记忆系统通常追加每一条观察，或按启发式规则覆盖旧条目，这使得瞬态噪声难以与真实的信念漂移区分。我们提出 PreCoMem，一个受预测编码启发的记忆巩固框架，将记忆表示为关于用户状态的置信度加权信念。其核心信号“有效惊奇”（Effective Surprisal）结合语义偏离与矛盾证据，并在检索分散且不可靠时降低该信号的权重。根据有效惊奇，双阈值门控将每一轮映射为三种确定性更新之一：MAINTAIN 强化有支持的信念，PROFILE 将歧义线索存储为低置信度假设，CORRECT 对可靠地被反驳的事实进行软衰减。PROFILE 阶段充当显式等待区，防止过早采信含噪证据。在 LoCoMo、LongMemEval-S 和 PersonaMem-v2 上的实验持续取得最先进的准确率；我们新提出的 DiMoBench 证实，PreCoMem 能够适应非平稳信念漂移，而不会对噪声过度反应。代码可在 https://github.com/ZhongWishing/PreCoMem 获取。

## Abstract
Long-horizon dialogue agents need to keep user memories stable enough for personalization while adapting when the user genuinely changes. Existing memory systems often append every observation or overwrite old entries by heuristic rules, which makes transient noise hard to distinguish from real belief drift. We introduce PreCoMem, a memory consolidation framework inspired by predictive coding that represents memory as confidence-weighted beliefs about the user's state. Its core signal, Effective Surprisal, combines semantic deviation and contradiction evidence, then downweights this signal when retrieval is diffuse and unreliable. According to effective surprisal, a two-threshold gate maps each turn to one of three deterministic updates: MAINTAIN reinforces supported beliefs, PROFILE stores ambiguous cues as low-confidence hypotheses, and CORRECT softly decays reliably contradicted facts. The PROFILE stage acts as an explicit waiting room, preventing premature commitment to noisy evidence. Experiments on LoCoMo, LongMemEval-S, and PersonaMem-v2 show consistent state-of-the-art accuracy; our new DiMoBench confirms that PreCoMem adapts to non-stationary belief drift without over-reacting to noise. The code is available at https://github.com/ZhongWishing/PreCoMem.

## 1. 核心问题与研究动机

- **背景定位**：LLM 正从无状态应答器转向需跨数百至数千轮交互的长期伙伴，仅存储对话记录不够，还需维护“用户模型”。作者将 **belief（信念）** 定义为关于用户偏好、目标或生活处境的紧凑可操作主张，并附带可强化或修正的置信权重。
- **核心难题：记忆稳定性–可塑性权衡（stability–plasticity）**。智能体既要保留稳定用户特质以支撑个性化，又要在用户真实变化时保持可塑性。
- **三类耦合困难**：
  - 多数轮次信号极弱，只有少数轮次含持久状态线索；
  - 用户偏好与生活事实随时间演化，系统须在**非平稳性（non-stationarity）与信念漂移**下适应；
  - 纠正反馈很少显式出现，长上下文检索噪声进一步模糊判断。
- **现有系统的两类相反失败**：
  - **过早纠正**：把瞬态噪声当作真实变化；
  - **旧记忆牵引（old-memory pull）**：持续依赖过时记忆，类似持续学习中的可塑性丧失与检索干扰。
- **现有方法缺口**：层次化/OS 式存储、时间戳索引、智能体检索器等主要优化**读路径（retrieval）**；**写路径（when to update）**仍依赖 recency 覆盖、固定阈值重要性或一次性追加规则，无法可靠区分持久漂移与瞬态噪声。
- **整体含义**：论文将长期记忆从“存储转录文本”重构为“对用户状态的动态预测”，并用预测编码中的**预测误差/惊奇（surprisal）**作为写路径的统一驱动信号。

## 2. 方法论

### 2.1 核心思想

- 受**预测编码（predictive coding）**启发：与当前记忆一致的事件应被强化，令人惊奇的事件可能需学习或纠正；但惊奇必须与**检索可靠性**配对，检索不确定时应保守。
- 记忆被表示为**置信度加权信念**：每个信念项带连续权重 \(w_t(m)\in[0,1]\)，而非离散的 ADD/IGNORE/UPDATE 或二元过期区间。
- 框架由两个围绕共享记忆库的主动阶段构成：**Memory Leveraging（读）** 与 **Memory Evolution（写）**，形成闭环。

### 2.2 记忆原语

- 长期记忆 \(M_t=(B_t,E_t,T_t)\)：
  - **Belief Store \(B_t\)**：可编辑的 FACT / HYPOTHESIS 节点，带置信权重、嵌入、主题、实体、时间戳与来源指针；
  - **Episodic Cache \(E_t\)**：不可变原始对话轨迹，仅作溯源，不参与置信加权 Top-K 排序；
  - **Topic table \(T_t\)**：仅作检索先验。
- **HYPOTHESIS 生命周期**：支持时强化，长期无支持时衰减，越过晋升阈值 \(\tau_{promote}=0.80\) 后**单向晋升**为 FACT；被反驳的 FACT 不降级、不删除，而是被**软衰减**为低置信“deprecated fact”，保留溯源。

### 2.3 Memory Leveraging：证据召回与生成

- 检索分数为三信号加权再乘置信权重：
  \[
  s(u_t,m)=w_t(m)\sum_{j=1}^{3}\alpha_j s_j(u_t,m)
  \]
  其中 \(s_1,s_2,s_3\) 分别为语义相似度、BM25 词法重叠、主题相关性，\(\alpha=(0.4,0.4,0.2)\)。
- 置信权重使检索天然偏向高支持项，起到**隐式重排（implicit reranker）**作用；Top-K 信念及其关联 episodic 片段共同条件化回答生成。
- 同一组召回结果 \((C_t,s_t)\) 被复用给写路径。

### 2.4 Memory Evolution：可靠性加权的惊奇与门控

- **检索可靠性 \(\rho_t\)**：对 Top-K 检索分数做平滑归一化后计算归一化熵 \(H_t\)，令 \(\rho_t=1-H_t\)。分数越集中，\(\rho_t\) 越高，代表证据越精确；检索弥散时降权。
- **原始惊奇代理**：
  \[
  S_{raw}=\lambda\, d_{sem}+(1-\lambda)\, d_{conf}
  \]
  - \(d_{sem}\)：用户输入与分数加权证据嵌入之间的余弦距离（语义偏离）；
  - \(d_{conf}\)：基于 NLI 交叉编码器（nli-deberta-v3-base，MNLI 温度校准）的矛盾概率，取 Top-K 上的最大值。
- **有效惊奇**：\(S_{eff}=\rho_t S_{raw}\)，作为门控标量 \(x_t\)。因 \(\rho_t\) 只做乘性调节，它只能**推迟**更新、不能单独**触发**更新。
- **双阈值门控**（固定 \(\theta_{low}=0.2,\ \theta_{high}=0.6\)）：
  - \(x_t\le\theta_{low}\) → **MAINTAIN**：按 \(w_{t+1}=w_t+\eta_t(1-w_t)\) 强化被支持信念，\(\eta_t\) 为子代理返回的 EVIDENCE_STRENGTH；
  - \(\theta_{low}<x_t\le\theta_{high}\) → **PROFILE**：生成低置信假设，初始权重由门控先验与子代理 INITIAL_CONFIDENCE 融合，并按 EXPLICIT（band [0.60,0.70]）/ LATENT（band [0.50,0.59]）分类限幅；
  - \(x_t>\theta_{high}\) → **CORRECT**：记录新观察为 FACT（初始 0.85），并对被反驳项按 \(w_{t+1}=w_t\exp(-\beta x_t\zeta_t(m))\) 软衰减，\(\zeta_t\) 为逐项矛盾严重度。
- **假设衰减与晋升**：未被支持的假设按 \(w_t(h)\leftarrow w_t(h)\exp(-\gamma a_t(h))\) 衰减（\(a_t\) 为距上次支持的轮数），连续 \(n\) 轮无支持时累计因子为 \(\exp(-\gamma n(n+1)/2)\)；低于 0.1 剪枝；显式事件假设受 DECAY_PROTECTION 保护。
- **混合执行机制**：LLM 子代理（Maintain/Profile/Correct-Agent）只负责识别相关项并输出**有界标量**（证据强度、严重度、初始置信），门控、置信边界、闭式更新与生命周期全部由确定性层完成。
- **理论支撑（附录）**：将 \(x_t\) 解释为长时程预测目标的蒙特卡洛代理；MAINTAIN 为凸巩固损失的梯度步；CORRECT 为 KL 近端镜像下降的解；双阈值门控为代价敏感动作选择的边界。
