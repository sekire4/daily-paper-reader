## 摘要
随着信息在对话之间发生变化，智能体的记忆必须持续保持有用。一个新事实可能会替换先前的值，但这并不意味着该值对后续问题不再相关。我们提出时序状态跟踪记忆（TEM），一种无需训练的框架，用于跟踪这些变化。TEM 将事实存储为与其来源关联的带版本记录。它检索相关版本，按来源顺序排列，并在将证据传给答案模型之前标记历史记录。事件记忆和原始对话轮次提供结构化事实中缺失的细节。我们在来自 600 个会话、涉及 60 个人物角色的 420 个问题上评估了 TEM。在四个开放权重模型上，关键实体命中率总体达到 75.71–97.62%，在历史居住地子集上达到 96.67–100.00%。在其余完全相同、按来源排序的事实上添加历史标签，使总体命中率提高了 17.14–55.95 个百分点。证据较为紧凑：每个答案 94–118 个 token，比会话感知的检索增强生成（RAG）少 48.75–56.73%。在 1,540 个 LoCoMo 问题上的进一步评估在固定证据预算下测试了混合记忆。TEM 在两种骨干模型上均超过会话感知 RAG；保守的分数差异分别为 7.92 和 10.58 个百分点。结果表明，在回答关于反复更新信息的问题时，应保留事实版本并向生成器暴露其时间状态。

## Abstract
An agent's memory must remain useful as information changes across conversations. A new fact may replace an earlier value without making that value irrelevant to a later question. We present Temporal State Tracking Memory (TEM), a training-free framework for tracking these changes. TEM stores facts as versioned records linked to their sources. It retrieves relevant versions, places them in source order and labels historical records before passing the evidence to the answer model. Event memory and original dialogue turns provide details missing from structured facts. We evaluated TEM on 420 questions drawn from 600 sessions involving 60 personas. Across four open-weight models, key-entity hit rates reached 75.71-97.62% overall and 96.67-100.00% on the historical-residence subset. Adding historical labels to otherwise identical, source-ordered facts increased overall hit rates by 17.14-55.95 percentage points. The evidence was compact: 94-118 tokens per answer, or 48.75-56.73% less than session-aware retrieval-augmented generation (RAG). A further evaluation on 1,540 LoCoMo questions tested hybrid memory under a fixed evidence budget. TEM exceeded session-aware RAG with both backbones; conservative score differences were 7.92 and 10.58 percentage points. The results support preserving fact versions and exposing their temporal status to the generator when answering questions about repeatedly updated information.

## 1. 核心问题与研究动机

- **背景**：长期运行的 LLM 智能体需要跨会话累积用户信息（居住地、职业、雇主、偏好等），而这些信息会随时间多次变化。现有记忆系统（MemGPT、MemoryBank、A-MEM、Mem0、MemoryOS、Zep 等）主要解决存储、分层组织、关联检索与图结构访问，但对“同一关系被反复更新”的场景处理不足。
- **核心矛盾**（论文用“上海→成都→苏州”的搬迁例子说明）：
  - 只保留最新值 → 能回答“现在住哪”，但无法回答“搬到成都之前住哪”；
  - 保留全部值 → 历史答案虽在库中，但多个检索到的值对问题“同等相关却指向不同状态”，生成器仍需自行判断哪个版本适用。
- **研究问题**：记忆系统如何把“版本关系/时间状态”这一信息有效地传递给答案生成模型，而不仅是把事实取回来。
- **整体含义**：作者主张“保留事实版本 + 向生成器显式暴露其时间状态”是回答反复更新类问题的关键；并把“证据选择”与“时间信息呈现”解耦为两个独立环节。

## 2. 方法论：TEM 框架

- **总体定位**：免训练（training-free）框架，抽取与回答均使用冻结模型，不微调骨干网络。
- **事实版本化存储（带来源）**
  - 事实记录：`f = (s, r, o, σ, τ)`，即主体、关系、客体、来源会话、来源序号。
  - 版本组键：`g(f) = (norm(s), r)`，主体名小写归一，**键中排除客体**，使同一关系的不同取值落入同一版本组。
  - 更新规则为“只追加不覆盖”：`F_t = F_{t-1} ∪ AttachSource(ΔF_t, σ_t)`；新会话事实由冻结模型抽取，经格式与源文一致性校验后附上会话溯源。
- **历史状态判定（核心贡献）**
  - 以完整版本组为单位计算：`τ*(g) = max{τ(f) : f ∈ F_g}`，`h(f) = 1[τ(f) < τ*(g)]`。
  - 即：来源序号小于组内最大序号者为“历史版本”（h=1），位于最大序号者视为“当前版本”（h=0）；同一最大序号的多条记录均视为当前。
  - 关键性质：状态由**全组**决定，因此即使检索漏掉最新版本，旧记录也不会被误当作当前值。
- **相关性检索与时间化证据构建**
  - 打分：`u(f,q) = cos(e(f), e(q)) · (0.4 + 0.6·w(f))`，关系权重手工设定：居住/雇主 1.0、职业 0.9、持有物 0.8、喜恶 0.6；不对旧版本做“时效惩罚”。
  - 取分数最高的至多 15 条 → **按来源序号升序排序** → 保留事实内容与会话来源 → 被取代版本加 `[historical]` 标签，最新版本不加标签。
  - 形式化：`B_q = Render(Sort_τ(TopK(F,q)), σ, h)`，`a = LLM(q, B_q)`。
  - 重要设计：**不在检索阶段用问题预先排除当前/历史版本**，把版本选择权交给生成器。
- **算法流程（Algorithm 1）**：抽取校验 → 追加并附来源 → 遍历所有版本组重算 `τ*` 与 `h(f)` → 若有查询则 Top-K 打分、按来源排序、逐条渲染并加历史标签 → 冻结 LLM 生成答案。
- **事件记忆与原文证据**：额外存储事件摘要、自由文本记忆与原始对话轮次，通过来源会话与事实版本关联；混合配置 `TEM-Hybrid-State` 在统一预算下融合两类证据，其对照 `TEM-Hybrid-Unmarked` 使用完全相同的候选与顺序，仅去掉历史标签。

## 6. 主要结论与发现

- **历史标签效果显著**：在事实内容与来源顺序完全相同的前提下，加标签使总体命中率提升 **17.14–55.95 个百分点**（Llama-3.1-8B 19.76→75.71，Qwen3.5-4B 48.10→97.62，Qwen3.5-9B 74.52→91.67，gpt-oss-20b 55.24→96.67）。
- **总体与历史子集表现**：TEM-Status 总体命中率 **75.71–97.62%**，历史居住子集 **96.67–100.00%**；相对 Session-aware RAG 总体高 1.43–40.00 点、历史子集高 10.00–88.33 点；相对 Full context 高 2.14–30.24 点。
- **只保留最新值最失败**：Overwrite 在历史居住题上仅 0–8.33%，说明“保留旧版本”是必要前提；但“保留但不标注”只到 41.67–81.67%，说明“标注”是第二个必要条件。
- **证据更紧凑**：平均每题 **94.05–117.55 token**，比 Session-aware RAG 少 **48.75–56.73%**；分布范围 84–125 token，而 RAG 与 Full context 最短也分别达 202 与 165 token。
- **LoCoMo 上仍优于 RAG 但增益来源不同**：同预算下 Llama 27.53–29.22% vs RAG 17.92–19.61%，Qwen 35.84–37.53% vs 23.70–25.26%，保守差值 **7.92 与 10.58 个百分点**；但带标签与不带标签的混合记忆分数接近，说明 LoCoMo 上的提升主要来自**混合证据组织**，而非历史标签；长上下文参考仍更高（37.66–39.55 / 53.90–56.17），但输入约 3 万 token。
- **方法论结论**：版本状态应作为“证据的一部分”显式呈现给生成器，即使理论上可由有序记录推断；同时标签只能指示“已被取代”，无法补足事件细节与跨会话关联。

## 7. 优点

- **问题刻画清晰**：把“保留旧值”和“识别适用版本”拆成两个可分别验证的需求，并用对照实验证明二者缺一不可。
- **方法极简且无需训练**：仅靠追加式存储 + 组内最大序号规则 + 排序与标签，即可在冻结模型上取得大幅提升，工程落地成本低。
- **消融设计严谨**：控制事实内容、顺序、候选集

集与顺序，唯一变量为历史标签，归因链条清晰；LoCoMo 上又用“同预算、同候选、仅去掉标签”的 Hybrid-Unmarked 作对照，使“标签有用/无用”的结论可被分别检验。
- **评价方式对生成器友好**：以“答案是否包含参考实体”为主指标，避免了语义评分器带来的额外噪声；LoCoMo 上对 216 条歧义样本给出上下界而非单点，体现了对评分不确定性的自觉。
- **失败模式分析到位**：不仅报告增益，还明确指出标签只能表达“已被取代”，无法提供事件细节、因果与跨会话关联，并据此解释 LoCoMo 上标签失效的原因，避免过度外推。
- **证据效率具备实用价值**：在更少 token（约 94–118）下取得更高命中率，说明该方法不只是“用更多上下文换分数”，对实际部署的上下文预算有直接意义。

## 8. 局限与不足

- **基准规模与覆盖面有限**：自建基准仅 60 个角色、3 类关系、420 题，且关系类型均为“单值、可被明确取代”的槽位（居住地、职业、饮品偏好）。对多值并存（如“同时持有多个职位”）、部分重叠（如“住在上海但常驻北京”）、否定与撤回（“其实我没换工作”）等情形未做考察。
- **“当前/历史”二元划分过于简化**：`h(f) ∈ {0,1}` 只能表达“是否被组内更晚记录取代”，无法表达“有效期区间”“生效时间点”“并行有效”等更细的时间语义；同一最大序号的多条记录一律视为当前，可能掩盖组内冲突。
- **状态判定依赖来源序号而非真实时间**：以会话序号 τ 作为时间代理，隐含“会话顺序即事实发生顺序”的假设。若抽取遗漏了某次更新、或同一会话内多次更新、或会话本身非时间序，则 `τ*(g)` 会失真；论文未报告抽取召回率，也未分析漏抽取对状态判定的传播影响。
- **缺少对抽取质量的系统评估**：事实抽取由冻结模型完成，仅做“格式与源文一致性校验”，但未给出抽取准确率/召回率，也未做抽取错误的误差分析。整个方法的收益高度依赖抽取环节，这一环的可靠性证据不足。
- **统计严谨性不足**：主结果均为单点百分比，无随机种子重复、无方差、无置信区间、无显著性检验；考虑到部分差值仅 1–3 个百分点（如 TEM-Status 与 Full context 的下界差距），这些结论的稳健性缺乏支撑。
- **评分与裁判的潜在偏置**：LoCoMo 使用 gpt-oss-20b 作裁判，而 gpt-oss-20b 同时是骨干之一；未报告人工标注一致性、裁判与人工的一致率或换裁判的敏感性分析。
- **与已发表系统的比较不可比**：Table 8 明确声明生成器、评分规则、预算不同，因此无法据此判断 TEM 相对 Mem0/Zep 的真实优劣，仅具参考意义。
- **算力与成本披露薄弱**：仅提及单张 A100 40GB，未报告记忆构建时延、检索时延、embedding 开销与总推理成本；对“长期运行智能体”这一目标场景而言，在线成本是关键指标，缺失使实用性评估不完整。
- **检索权重为手工设定**：关系权重（居住/雇主 1.0 … 喜恶 0.6）与 `0.4 + 0.6·w(f)` 的融合系数均未见敏感性分析或学习过程，存在针对自建基准调参的风险。
- **Top-K=15 与排序策略未做消融**：候选数量、按来源序号升序（而非降序或按相关度）的呈现顺序对生成器的影响未被单独检验，而顺序本身可能影响 LLM 的位置偏置。

## 9. 启示与可拓展方向

- **“证据选择”与“状态呈现”解耦**是本文最具迁移价值的思想：它把记忆系统的职责从“取回正确事实”扩展为“取回事实并说明其时间身份”，这一分层可套用到任何 RAG/记忆管线，而不限于本文的具体实现。
- **时间语义可进一步细化**：把二元 `h` 扩展为区间或状态机（如 `[生效, 失效)`、`superseded_by` 指针、置信度），并让生成器接收结构化时间戳而非单一标签，可能同时改善“当前值”与“任意历史时点”两类问题。
- **状态判定可引入不确定性**：当抽取缺失或来源顺序不可靠时，可对 `τ*` 给出置信度，并在证据中显式标注“可能已过时”，而非硬性二分。
- **与图结构记忆结合**：本文的版本组 `(s, r)` 本质是“槽位”，可自然嵌入 Zep/Mem0-graph 等图记忆的边上，把版本链作为边属性维护，从而兼顾多跳与时间状态。
- **评测层面**：需要更大规模、更多关系类型（多值、否定、条件性）、带真实时间戳的状态更新基准；同时应报告方差与显著性，并对裁判模型做一致性校验。

## 10. 总体评价

本文针对“长期记忆中同一关系被反复更新”这一被现有系统弱化的问题，提出了一个概念清晰、实现极简、免训练的解决方案：以 `(主体, 关系)` 为版本组、以组内最大来源序号定义“当前”、以 `[historical]` 标签把版本状态直接写进证据文本。其核心贡献不在于新模型或新架构，而在于一个被实验支持的方法论主张——**仅保留旧值不够，必须把“哪个是当前”显式告知生成器**；并且这一主张通过“同内容、同顺序、仅增删标签”的干净消融得到了较强支撑（17–56 个百分点的提升，历史子集接近饱和）。证据更紧凑（约 100 token 级）这一点也增强了其实用价值。

与此同时，论文的说服力受限于：自建基准规模小且关系类型单一、状态划分为二元且依赖会话序号、抽取质量未被评估、主结果缺乏统计检验、裁判与骨干同族、与已发表系统的比较不可比、成本披露不足。尤其值得注意的是，作者自己诚实地报告了 LoCoMo 上标签几乎无增益、提升主要来自混合证据组织——这一“负面结果”既是论文可信度的加分项，也界定了方法的适用边界：**TEM 的状态标签适用于“单值槽位被明确取代”的场景，而非通用多会话问答**。

总体而言，这是一篇问题定位精准、实验对照设计讲究、结论边界表述克制的工作；其价值更多在于提出并验证了一个可复用的设计原则，而非提供一个在所有长程记忆任务上占优的系统。后续工作若能扩展到更丰富的时间语义、更大规模且带真实时间戳的基准，并补齐抽取质量与统计稳健性证据，该方向的说服力将显著提升。
