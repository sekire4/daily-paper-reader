## 摘要
受递归自我改进（RSI）启发，我们研究 LLM 智能体如何在不更新模型参数的情况下通过外部记忆进行学习。从单次尝试中提取有用经验是困难的：有缺陷的推理也可能产生成功，而糟糕的执行则可能掩盖合理的策略。随时间保持其价值同样困难：我们不进行整合的累积基线最初有所提升，但最终表现低于无记忆基线。我们的核心思想是比较同一任务上的多次尝试，以识别可复用的决策，并细化它们何时适用。我们提出 Hippo，一个受选择性海马体编码与回放启发的记忆框架，它在诊断出缺陷时从这些比较中学习。它将由此产生的经验与现有记忆进行比较，通过显式的适用条件合并重叠部分并解决冲突。这允许修订先前的指导，而无需将每条经验教训都存储为单独的条目。在 SWE-bench Verified、WebArena 和 Mind2Web 上的实验表明，三种设置下性能均有提升，且保留的经验数量显著少于累积基线。这些增益在具有不同能力的受评估基础模型上均得到体现，表明基于记忆的适应即使对能力很强的模型也仍然有用。

## Abstract
Motivated by recursive self-improvement (RSI), we study how LLM agents can learn through external memory without updating model parameters. Extracting useful experience from a single attempt is difficult: flawed reasoning can produce success, while poor execution can obscure a sound strategy. Preserving its value over time is also difficult: our accumulation baseline without consolidation initially improves but eventually performs below a no-memory baseline. Our key idea is to compare attempts at the same task to identify reusable decisions and refine when they apply. We introduce Hippo, a memory framework inspired by selective hippocampal encoding and replay that learns from these comparisons when shortcomings are diagnosed. It compares the resulting experience with existing memory to merge overlaps and resolve conflicts through explicit applicability conditions. This allows prior guidance to be revised without storing every lesson as a separate entry. Experiments on SWE-bench Verified, WebArena, and Mind2Web show performance gains in all three settings and substantially fewer retained experiences than the accumulation baseline. The gains extend across the evaluated base models of varying capabilities, indicating that memory-based adaptation remains useful even for highly capable models.

## 1. 核心问题与研究动机

- **背景**：受递归自我改进（RSI）启发，研究 LLM 智能体如何在不更新模型参数的前提下，仅通过外部记忆实现"梯度无关"的学习与持续适应。
- **两大痛点**：
  - **经验提取难**：单次尝试的轨迹并不能直接说明该学什么——错误推理可能碰巧成功（"right for the wrong reasons"），而糟糕执行可能掩盖一个本来合理的策略；反思容易提取出错误或过度泛化的"教训"，并在后续任务中被反复检索、持续误导。
  - **经验保值难**：论文实测发现，不做整合、只做追加（append-only）的累积基线随记忆增长呈**倒 U 型**：先提升，随后下降，最终**低于无记忆基线**。
- **核心问题**：智能体应如何决定保留什么经验，以及新经验应如何**修订**已有记忆，而非简单堆叠。
- **整体含义**：把"自我演化"从"经验堆积"转向"经验整合与修订"，并用"同一任务多次尝试的对比"作为可靠的学习信号来源。

## 2. 方法论

### 2.1 核心思想
- 借鉴**海马体选择性编码**（新颖/违例信号驱动强编码）与**海马回放/互补学习系统理论**（睡眠期重激活支持新经验与旧知识的渐进整合），将记忆分为两层：
  - **L1：情景反思**——针对单次尝试的局部诊断；
  - **L2：持久智能体记忆**——跨任务整合、带显式适用条件的可复用经验。
- 关键机制：**只在"惊讶（surprise）"时反思**，并用**两次比较**决定记忆如何变化（同任务多尝试之间比较 → 蒸馏候选经验；候选经验与已有记忆比较 → 合并/消解冲突）。

### 2.2 四个组件与流程
1. **多 Rollout 探索**：对同一任务 q，用冻结策略 π 与同一检索记忆 M 并行采样 N 次（温度采样），各自在独立环境副本中执行，保证 N 个结果相互独立。
2. **惊讶驱动的情景反思（L1）**：
   - 公式：`L1 = G(q, τ, δ)` 若 `J(q, τ, r) = surprise`，否则为 ∅。
   - Judge J 判定"惊讶"：任务失败，或**成功但推理不正确**（fortuitous success / fluke）均算惊讶；δ 为诊断文本，G 为反思提取器。
3. **记忆演化引擎（L1 → L2）**：
   - **对比式经验归纳 D**：统计 N 次中验证成功数 n_c，成功率 ρ_t = n_c/N。当 ρ_t < 1 时执行 `D(q_t, E(q_t), ρ_t) → m_t`（候选经验 = 决策 + 适用条件）；ρ_t = 1 则跳过归纳、记忆不变。按四种情形处理：
     - 验证成功占多数 → 把少数失败转为"警示"；
     - 验证成功占少数（非空）→ 找出区分成功尝试的关键决策；
     - 成功/失败各半 → 同时提炼成功策略与失败陷阱；
     - 全部失败 → 汇总诊断中的失败模式，且只允许写入有输入支持的动作。
   - **记忆巩固**：检索与候选相似的记忆子集 R_t，由 LLM 比较器 C 输出新增集 Δ⁺ 与删除集 Δ⁻：
     `L2,t+1 = (L2,t \ Δ⁻_t) ∪ Δ⁺_t`
     - 重复候选丢弃；重叠/冲突通过**显式适用条件**解决；替换时"加新条 + 删旧条"，未涉及的条目原文保留。
4. **检索与注入**：先用 embedding 取 top-K 候选，再由智能体结合任务需求**判断是否真正适用**并选择 M；同一任务的 N 次 rollout 共享同一份 M。记录显示，在存在同模板经验的 WebArena 查询上选择率为 75.2%（BM25+content 为 66.4%）。

## 3. 实验设计

- **对比方法**：No Memory、Vanilla-IB（无记忆、更大步数预算）、AWM、ReasoningBank（启用 MaTTS）；均用官方实现。
- **评估协议**：每任务 8 次尝试取平均，再跨任务平均；报告 3 次不同随机种子的 mean ± std；所有方法最多 30 步交互（Vanilla-IB 为 50 步）。

## 6. 主要结论与发现

- **主结果**：Hippo 在 WebArena、SWE-bench Verified、Mind2Web 三个 setting 上全面领先：
  - WebArena 总体：GPT-5.6 Sol 64.2 → **72.9**；Claude Haiku 4.5 33.8 → **42.5**；Gemini 3 Flash 39.0 → **46.4**；Qwen3.5-27B 35.8 → **43.6**；且在**每个网站**上都超过 No Memory。
  - SWE-bench Verified：81.5 → **88.5**（GPT-5.6 Sol）、62.6 → **70.7**、74.2 → **81.6**、68.8 → **76.5**。
  - Mind2Web：三个 split 均领先。
- **强模型仍有增益**：GPT-5.6 Sol（无记忆已 90%+ 的 Mind2Web 上不再比）在 WebArena 上仍提升 8.7 个百分点，说明记忆式适应不因基座变强而失效。
- **记忆效率**：400 任务检查点时仅保留 **83 条**经验（AWM 270、ReasoningBank 665），却在已见/未见任务上分别高出最强记忆基线 24 与 22 个百分点（86% / 82%）；比自身 append-only 变体高 14.0 / 16.0 个百分点。
- **失败模式确认**：AWM 与 ReasoningBank 初期受益，随后在已见与未见任务上**双双跌破无记忆基线**，同时记忆库持续膨胀——归因于检索竞争（有用经验被挤出）与错误/无条件经验被反复检索。
- **重试基线的重要性**：无记忆时 8 次尝试"至少一次成功"比单次平均高 **9.3 个百分点**（恢复率 28.8%），故提出"自我演化方法必须胜过同等反馈与预算下的直接重试"这一评估准则。
- **学习信号来源的分布**：多数成功组 +23.0pp、多数失败组 +13.0pp、全失败组仅 +3.3pp、均衡组 +55.8pp（但仅 24 个任务）；两个多数组合计贡献 6.14pp。
- **Judge 的价值**：用纯成功/失败标签替代 judge，五个网站下降 1.8–8.5pp（Map 最大，8.5pp），因为 `N/A`/空回答等"未完成验证"的接受轨迹会被误当作成功经验。
- **组件贡献**：w/o L2 为 66.5 / 83.8，w/o L1 为 68.7 / 85.6，完整 Hippo 为 72.9 / 88.5（WebArena / SWE-bench）；更新策略上，跨 rollout 对比（70.1）优于分别总结（61.3），Hippo 增删式（72.9）优于 append-only（70.1）与反复重写（54.6）。

## 7. 优点

- **问题洞察精准**：明确刻画"倒 U 型退化"这一被忽视的失败模式，并指出"成功不等于正确学习"（correct-for-wrong-reasons），据此设计 judge 与 surprise 触发机制。
- **方法有明确的结构性对应**：L1/L2 分层、选择性编码、回放式巩固与神经科学机制一一对应，不是修辞性类比；"显式适用条件 + 增删式修订"直接针对检索污染与冲突累积。
- **对比式归纳设计合理**：同条件下多 rollout 提供因果对比证据（引 Cheng & Novick 的因果归纳模型），并按成功/失败比例分四种情形处理，含"全失败也能学到东西"的情形。
- **评估纪律较强**：统一任务顺序与种子、多次重复报均值±方差、长时程评估不污染记忆、人工审计 judge（κ=0.89）、报告重复性、报告成本与 token 开销。
- **提出可操作的评估基准**：把"直接重试"确立为自我演化方法的必要对照，对社区有方法论价值。
- **诚实报告**：案例中明确承认执行仍不完美（如 t502 队列未确认即报完成）、承认定性案例的归因局限、承认部分比较不等成本。

- **超参数与阈值的敏感性分析偏薄**：N 的取值有分析，但 top-K、embedding 相似度阈值、ρ_t 的"多数/少数/均衡"划分边界、以及触发巩固的相似度条件，缺少系统的敏感性曲线；这些参数直接决定"写什么、改什么"，是方法最脆弱的部分。此外，N=8 的并行采样本身是一种成本换信号的设计，论文未讨论 N 与收益的边际递减点在哪里。
- **统计推断不充分**：报告了 3 个种子的 mean ± std，但未见显著性检验或效应量报告；部分子组样本量很小（如均衡组仅 24 个任务，+55.8pp），其置信区间很可能很宽，不宜作为稳定结论引用。个别网站的提升幅度也接近种子间波动范围。
- **长期记忆饱和与遗忘机制缺失**：方法只有"增/删冲突项"，没有显式的衰减、时效性或容量管理策略。400 任务检查点上记忆稳定在 83 条是很好的证据，但更长时程（数千任务、跨领域迁移）下是否会饱和、是否会因删除操作误删仍有价值的历史经验，论文未做压力测试。
- **judge 与比较器的可靠性只做了单向审计**：人工审计针对的是"被评测器接受的轨迹"（κ=0.89），验证了 judge 对"侥幸成功"的识别；但**记忆巩固阶段的 LLM 比较器 C** 的决策质量（是否误删、是否保留冲突条目）没有对应的人工审计或错误率统计。这一环节恰恰是"经验保值"的核心，缺少直接证据。
- **安全与治理维度缺位**：记忆条目是自然语言指令，会被注入后续 prompt。论文未讨论记忆投毒（错误经验被写入后长期污染）、跨用户/跨任务隔离、敏感信息留存与可审计性等问题。对将被部署到真实系统的智能体框架而言，这是明显的空白。
- **可复现性的外部依赖**：主结果依赖多个闭源模型 API（GPT-5.6 Sol、Claude Haiku 4.5、Gemini 3 Flash Preview），模型版本漂移会使数值难以精确复现；prompt 模板与实现细节主要在附录，代码与数据的公开程度在文中未明确承诺。

## 9. 总体评价与启示

- **定位**：这是一篇**问题驱动强于技巧创新**的工作。其真正贡献不在于"用海马体类比做记忆"，而在于把"记忆型智能体为什么会越学越差"这一现象做了可测量的刻画（倒 U 型、检索竞争、侥幸成功），并据此把"记忆写入"重构为"记忆修订"问题。
- **方法论价值**：三条设计原则具有可迁移性——(1) 用**同任务多次尝试的对比**替代单轨迹反思作为学习信号；(2) 用**显式适用条件**而非隐式相似度来解决经验冲突；(3) 用**增删式编辑**而非追加式堆叠来控制记忆规模。这三点不依赖具体模型，对其他记忆框架同样适用。
- **评估层面的贡献可能超过方法本身**：把"同等反馈与预算下的直接重试"确立为自我演化方法的必答对照，是一条容易被忽视但很关键的评审准则；无记忆 8 次尝试"至少一次成功"高出单次平均 9.3pp 这一数字，直接抬高了对该类方法的举证门槛。
- **适用边界**：方法在**任务同质、可多次并行采样、有可靠自动验证**的场景（软件修复、Web 导航）收益最明显；对单次不可重复、验证信号缺失或任务高度异质的场景，其"对比式归纳"的前提不成立，收益预期应下调。
- **后续可跟进方向**：与轻量参数更新结合的混合方案；记忆巩固环节的可靠性与审计；跨领域长时程下的容量与遗忘策略；在线（非离线回查答案）设定下的真实收益测量；以及记忆安全（投毒、隔离、可追溯）。
