## 摘要
记忆使语言智能体能够将过去经验中的有用区分带入未来决策。其价值取决于哪些区分得以保留、有界智能体能否使用这些区分，以及在需求演化时哪些内容可以被恢复或修正。我们提出一个决策论框架，从原始历史出发，经持久状态、实际使用以及代价高昂的恢复与修正，追踪这一价值。原始价值与保留价值以避免任务损失为单位表示；风险—成本前沿刻画跨使用时可达的恢复与保持。未知需求产生价值剖面，而交互反馈改变未来工作的分布。一个成本感知的模拟条件与五个最小反例揭示了信息时序、检索访问、组件交互、反馈和需求不确定性的作用。特别地，一个与答案互信息为零的指针仍可降低精确恢复的成本。在 LoCoMo、一个双项目更新任务以及纵向案例上的诊断展示了保持、使用和测量方面的失败。在检索证据固定时，保存的账本会改变后续答案；在智能体输出固定时，评估器修订会改变分数。该框架将这些区分与操作风险界以及可检验原则联系起来，用于分配记忆、保留恢复选项和修正证据依赖关系。

## Abstract
Memory enables language agents to carry useful distinctions from past experience into future decisions. Its value depends on which distinctions survive, whether a bounded agent can use them, and what can be recovered or revised as demands evolve. We develop a decision-theoretic framework that follows this value from raw history through persistent state, operational use, and costly recovery and revision. Original and retained value are expressed in units of avoided task loss; risk-cost frontiers describe attainable recovery and preservation across uses. Unknown demand yields value profiles, while interactive feedback changes the distribution of future work. A cost-aware simulation condition and five minimal counterexamples expose the roles of information timing, retrieval access, component interaction, feedback and demand uncertainty. In particular, a pointer with zero mutual information about the answer can still reduce the cost of exact recovery. Diagnostics on LoCoMo, a two-project update task and longitudinal cases exhibit failures of preservation, use and measurement. At fixed retrieved evidence, a saved ledger changes subsequent answers; at fixed agent outputs, an evaluator revision changes scores. The framework connects these distinctions to operational risk bounds and testable principles for allocating memory, preserving recovery options and revising evidence dependencies.

## 1. 核心问题与研究动机

- **背景**：语言智能体跨对话、跨项目、跨目标持续运作，其记忆需要把决策、计划、证据与约束从过去带入未来尚未确定的请求中。但"记忆有多大价值"缺乏统一定义：存储状态可能携带相关信息而读者用不上；一个地址指针可能不含答案信息却加速恢复；一次修订可能改善一个任务而损害另一个任务。
- **核心问题**：记忆价值取决于（1）哪些区分在写入后存活；（2）有界智能体能否实际使用这些区分；（3）需求演化时能以何代价恢复或修订，以及对其他用途的影响。
- **研究缺口**：已有工作分别研究压缩（保留哪些区分）、受限决策模型（如何使用）、获取与生命周期（如何恢复/修订）、评估审计（如何测量），但缺少一条贯穿"原始历史 → 持久状态 → 操作使用 → 付费恢复与修订 → 测量"的共同价值链条与可比条件。
- **核心主张**：记忆的价值等于其对未来决策的贡献，减去保存、访问与修订该贡献的成本；潜在价值、实际表现与资源消耗是三类互补的设计信息，不能互相替代。

## 2. 方法论

### 2.1 核心思想：以"避免的任务损失"为共同单位

- 设历史 $H$、写入函数 $M=f(H)$、未来需求 $Q$、世界状态 $Y$、读者合法侧信息 $S$，在需求分布 $P$、损失 $\ell$、策略类 $\Pi$ 下定义最优风险：
  $$R^*(M;P,\ell,\Pi)=\inf_{\pi\in\Pi}\mathbb{E}_P[\ell(Y,Q,\pi(M,S,Q))]$$
- **保留价值**：$V^*(M)=R^*(\varnothing)-R^*(M)$；**原始价值** $V^*(H)$ 同理；**价值损失** $D^*(M)=R^*(M)-R^*(H)$，满足 $V^*(H)=V^*(M)+D^*(M)$。
- **实际读者价值**：$V_\pi(M)=R(\pi,\varnothing)-R(\pi,M)$，可为正、零或负；**实现遗憾** $G_\pi(M)=R(\pi,M)-R^*(M)\ge 0$，且 $V^*(M)-V_\pi(M)=G_\pi(M)-G_\pi(\varnothing)$。
- **操作化系统 $\Sigma$**：包含写入、存储、索引、恢复、修订、读取与失败处理，诱导轨迹 $\tau$、风险 $R(\Sigma;E)$ 与多维成本 $C(\tau)\in\mathbb{R}^d_+$；成本坐标（读取、token、时间、用户交互）在显式定价前保持分离。

### 2.2 关键技术组件

- **成本感知模拟（命题 1）**：若合同 $C_0$ 下任一预算 $b$ 的策略在 $C_1$ 下存在因果模拟器，保持外部交互轨迹分布且成本不超过 $C_0+\delta$，则 $R^*_{C_1}(b+\delta)\le R^*_{C_0}(b)$；推论 1 将其推广到最坏情况稳健比较。这扩展了经典 Blackwell 实验比较，显式引入访问与转换成本。
- **修订的成本前沿**：对目标用途 $T$、其他用途集合 $U$、修订 $M'=g(M,O)$，定义可行修复集 $K(\epsilon,\eta)=\{c:\exists g,\ R_T(M')\le\epsilon,\ R_U(M')-R_U(M)\le\eta,\ C_g\preceq c\}$，其非支配边界即"纠正—成本前沿"。
- **需求不确定性**：保留价值剖面 $P\mapsto V^*(M;P)$；选择混合分布或最坏情况需额外决策偏好，因此需求不确定性属于价值定义本身。
- **测量过程 $J$**：将系统行为映射为损失标签，$J$ 与 $M$、$\Sigma$ 分离，才能区分"记忆价值变化"与"测量方式变化"。
- **比较契约（表 2）**：记录信息与揭示顺序、持久状态与侧信息、恢复/更新接口、策略与计算、需求与环境、后果与损失、资源记账、测量标签状态八个维度。
- **可操作风险界**：有限读者面板给出上界 $R^*(M)\le\min_{\pi\in B}R(\pi,M)$；结合 Hoeffding 不等式与联合界得到同时置信上界；两类同时有效区间可推出价值区间 $V^*(M)\in[r_0-\overline{r_M},\overline{r_0}-r_M]$。

### 2.3 五个最小反例（结构性依赖）

- **查询时序**：$n$ 个独立比特的历史，若写入时未知查询，零错误需 $n$ 位；若写入时可见查询并可回读，仅需 1 位。$n=8$ 时差距为 7 比特。
- **零互信息指针**：$N$ 个不透明地址存放独立公平比特，指针 $M=J$ 满足 $I(M;Y)=0$，但一次付费读取即可精确恢复；无指针搜索期望需 $(N+1)/2$ 次读取。$N=4$ 时读取数从 5/2 降到 1，一次读取预算下风险从 3/8 降为 0。
- **记忆—读者交互**：空记忆/含答案 × 常量读者/有能力读者的 $2\times2$ 风险表中，联合改进为 1/2，但归因顺序决定"功劳"分配，存在互补性。
- **反馈反转排序**：两个策略在强制均匀回放下的风险均为 1/2，但在两个交互反馈环境下排序完全反转，说明回放无法确定交互价值。
- **需求不确定性**：两个记忆分别存公平比特 $A$、$B$，查询以概率 $p$ 问 $A$；仅知 $p\in[0.2,0.8]$ 时相对价值集为 $[-0.3,0.3]$，无唯一排序。

## 6. 主要结论与发现

- **价值必须联合记账**：保存、使用、恢复/修订的成本与可靠性共同决定记忆价值；仅用答案互信息或出现频率无法排序记忆方案（零互信息指针反例）。
- **信息时机决定容量需求**：写入前是否可见查询可使所需状态相差数量级（$n$ vs 1 比特）。
- **测量本身会改变结论**：固定检索证据时，保存的账本改变后续答案（F1 0.280→0.329，弃答 6→3）；固定智能体输出时，评估器从严格操作规则改为后果式检查，接受率从 17/28 升至 22/28（+17.9 个百分点）。
- **完整历史读取不等于最优风险**：完整历史原始读取平均 F1 仅 0.123（10/12 弃答），问题置后为 0.297，改用短答案指令达 0.512 且零弃答——说明观测分数位于阅读接口与任务损失之中，而非单纯信息量。
- **三类失效**：保存失效（容量内可避免的覆盖删除）、使用失效（读者弃答已保留的支持）、测量失效（无证据的完成声明因碰巧答对而被计为成功回忆；正确读出当前标识却提出有害编辑）。
- **MemOps 审计发现测量伪影**：24/400 对被标记"过度遗忘"中，删除措辞实际指向其他目标；11/400 对存在披露规则与 gold answer 的冲突；跨设置配对存在回退到不同读者的匹配缺陷，可制造虚假的 −1 配对差值。
- **设计原则**：按决策后果分配状态与恢复（式 9 的保留内容 vs 定位器比较）、为后揭示需求保留恢复选项、沿证据依赖关系修订；并给出三个可检验假设。

## 7. 优点

- **统一而严谨的理论骨架**：以决策损失为共同单位，把潜在价值、保留价值、实现价值、实现遗憾、恢复/修订成本放在同一坐标系，并明确各量的可识别条件（模拟闭包、可选无知）。
- **反例极具说服力**：五个最小构造各自隔离一个机制（时序、访问、交互、反馈、需求不确定性），特别是"零互信息指针"直接否证了以互信息排序记忆价值的做法。
- **测量与系统分离**：把评估器 $J$ 作为独立对象，并用比较契约（表 2）规定结论可迁移的条件，这在记忆评估文献中较为少见且实用。
- **诊断实验直接暴露评测伪影**：LoCoMo 的接口对照与 MemOps 的 gold-answer 回放审计，均给出可复现的、改变结论的具体证据，而非仅停留在概念批评。
- **诚实的不确定性处理**：给出有限面板上界、Hoeffding 置信界、区间相减，明确区分识别不确定性与抽样不确定性。
- **理论联系可执行设计**：式（9）的分配判据与附录 A.9 的偏好反转数值例子，把抽象框架落到具体取舍。

## 8. 不足与局限

- **实证规模小、统计力弱**：LoCoMo 仅 12 题、每条件单次抽样；作者自认控制与验收规则为事后设计，存在选择与确认偏差风险。
- **潜在量未被估计**：案例只展示"存在支持/使用失败"，未估计 $D^*(M)$ 或 $G_\pi(M)$；上界依赖有限读者面板，下界需额外的不可区分性论证。
- **单一模型与单一来源**：全部行为实验使用同一 API 模型；纵向案例来自单一所有者，频率与外推性未知；虚构双项目世界为作者自撰，重复抽样有限。
- **理论假设较强**：命题 1/3 依赖策略类可模拟、预算几乎必然约束、共同有界损失等条件；实际系统中"因果模拟器"是否可得往往未验证。
- **与现有记忆系统的横向比较缺失**：未与 MemGPT、Mem0
