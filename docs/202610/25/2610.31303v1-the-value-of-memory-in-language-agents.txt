# Abstract 

Memory enables language agents to carry useful distinctions from past experience into future decisions. Its value depends on which distinctions survive, whether a bounded agent can use them, and what can be recovered or revised as demands evolve. We develop a decision-theoretic framework that follows this value from raw history through persistent state, operational use, and costly recovery and revision. Original and retained value are expressed in units of avoided task loss; risk–cost frontiers describe attainable recovery and preservation across uses. Unknown demand yields value profiles, while interactive feedback changes the distribution of future work. A cost-aware simulation condition and five minimal counterexamples expose the roles of information timing, retrieval access, component interaction, feedback and demand uncertainty. In particular, a pointer with zero mutual infor-mation about the answer can still reduce the cost of exact recovery. Diagnostics on LoCoMo, a two-project update task and longitudinal cases exhibit failures of preservation, use and measurement. At fixed retrieved evidence, a saved ledger changes subsequent answers; at fixed agent outputs, an evaluator revision changes scores. The framework connects these distinctions to operational risk bounds and testable principles for allocating memory, preserving recovery options and revising evidence dependencies. 

# 1 Memory as a resource for future decisions 

Language agents operate across conversations, projects and changing objectives. Their memory carries decisions, plans, evidence and constraints from earlier work into requests that may not yet be known. Consider an assistant maintaining two projects: an audit in the first has just finished, while a report in the second still contains a valid citation and a separate citation requiring correction. Updating the first project’s plan should preserve the distinctions needed to resume the second. What matters is the future work that this history makes possible. This raises a valuation problem. How much decision value was available in the original history? How much survives in the stored state, and how much can a bounded agent actually use? When future demands change, what additional value can be recovered or created through revision, at what cost, and with what effects on other uses? These questions connect memory capacity, retrieval, continual updating and evaluation. 

Our thesis is that the value of memory lies in its contribution to future decisions, jointly with the cost of preserving, accessing and revising that contribution. A stored state can carry relevant information that its reader fails to use. An address can accelerate recovery while carrying no direct information about the answer. A revision can improve one task and damage another. A useful account of memory value must describe these possibilities together.

Original and retained value share a common unit of avoided decision loss; actual system effects additionally depend on the reader and its interactions. Risk–cost frontiers express what recovery and revision can achieve, while demand profiles preserve uncertainty about future use. The framework has both analytical and empirical consequences. A cost-aware simulation condition and five minimal counterexamples explain how information timing, access, component interaction, feedback and demand shape value. # 2 Foundations of memory value 

Classical comparison of statistical experiments provides the starting point: information has value relative to a decision problem and the actions it enables (Blackwell, 1951). Simulation explains why a decision maker with access to richer information can preserve the performance of a less informed one. For an implemented memory system, the relevant question is whether that simulation respects its information timing, computational constraints and access costs. Several established lines of work make these restrictions explicit. Predictive V-information measures information through an allowed prediction family and optimized log loss (Xu et al., 2020). Action-dependent side information connects information acquisition to its cost (Permuter and Weissman, 2011). Prompt-compression theory distinguishes query-aware and query-agnostic encoders (Nagle et al., 2024). These foundations motivate separate accounting for stored content, feasible computation and paid access. 2Memory architectures make these choices concrete. Memory 3 formulates memory-format choice as writing cost plus expected reuse-weighted reading cost, and implements explicit memory as sparse key-values (Yang et al., 2024). Metis and MemT-1.0 maintain native memory states that evolve within model computation (Zhang et al., 2026; MemTensor Team, 2026). MemOS organizes plaintext, activation and parameter memories through lifecycle operations and MemCubes carrying provenance and version metadata (Li et al., 2025). At the agent level, Generative Agents connects recorded experience and reflection to planning (Park et al., 2023); MemGPT manages transfers across memory tiers (Packer et al., 2023); A-Mem evolves linked notes (Xu et al., 2025); and Mem0 extracts, consolidates and retrieves conversational memories (Chhikara et al., 2025). CoALA organizes memory modules, internal and external actions, and a recurring decision process (Sumers et al., 2024). These are architectural precedents for the components whose retained and realized decision value we study under explicit information and resource conditions. Recent memory research gives concrete evaluation models for these questions. DeMem formulates decision distortion and an implementation-error bound with a query-aware encoder (Zou et al., 2026). MEM AUDIT defines a finite package optimum under representation, evidence and cost choices (Bhargava and Barrento, 2026). VitaBench evaluates lifecycle decisions over a horizon and separately studies a rollback extension (Yu and Hu, 2026); MemOps represents lifecycle operations, target binding and state transitions (Hao et al., 2026). Update-sufficiency auditing distinguishes content, delivery and scoring conventions (Zhang, 2026). These studies specify particular stages or uses of memory. Transferring conclusions between their settings requires the comparison conditions in Section 6.2. A cross-layer compaction perspective connects KV caches, prompts, bounded states and agent stores through rate–distortion trade-offs (Colaco and Lahjouji, 2026). Session-handover theory uses statistical sufficiency and comparison of experiments to distinguish capacity, writer and continuation effects, including the cost of committing before a future query is known (Kato and Kato, 2026). These results provide direct foundations for following value through storage, use and later information acquisition. These approaches address connected stages of the same problem. Compression determines which historical distinctions survive; constrained decision models determine how those distinctions can be used; acquisition and lifecycle models determine how useful support can be obtained or revised later. We connect these stages through a common account of decision loss, resource cost and future demand. Explicit comparison conditions then establish when conclusions can transfer between stages or implementations. Preservation and validity also have direct precedents. WISE evaluates unrelated behavior after edits (Wang et al., 2024). A consolidation study finds that its proposed memory-quality score fails to establish prediction of external transfer performance (Annapureddy and Thamatani, 2026). Partial identification formalizes values left undetermined by evidence (Manski, 2025), while performative prediction models decisions that change the future evaluation distribution (Perdomo et al., 2020). We use these perspectives to include uncertainty and feedback within memory evaluation. Ratio-nal metareasoning supplies a decision-theoretic account of paid computation (Hay et al., 2012); irreversible-decision theory values options retained until later information arrives (Arrow and Fisher, 1974); truth maintenance records justifications and their dependencies (Doyle, 1979). These founda-tions guide the constructive directions in Section 7.

The following constructions isolate five structural dependencies of memory value. 55.1 Query timing changes required capacity 

Let H = ( B1, . . . , B n) contain independent fair bits, and let a later query request one coordinate. With no recovery, zero error for every history and query requires n fixed-length bits when the writer commits before seeing the query. Any two distinct histories differ at a coordinate that a future query can request. Merging those histories therefore loses a required distinction. If the writer sees the query and can reread H before encoding, one answer bit suffices (Figure 2a). For n = 8 , changing revelation order changes the requirement by seven bits. That gap depends on the answers distinguished by the query family; duplicating query names for the same coordinate leaves the requirement at one bit. This coordinate-query construction also appears in session-handover analysis, where it yields a log-loss lower bound (Kato and Kato, 2026). Comparing runtime compression with persistent writing therefore requires matching when the query becomes visible. 

5.2 A pointer can have value with zero answer information 

An archive has N opaque addresses holding independent fair bits B1, . . . , B N . The target address J

is uniform and independent of the bits, and the answer is Y = BJ . A paid read returns the selected bit and an indicator of whether its address is the target. A retained pointer M = J satisfies I(M ; Y ) = 0 : knowing the address leaves the answer bit fair. Yet it enables exact recovery in one read. Without the pointer, the target is found by search; zero error requires up to N reads and an expected (N + 1) /2 reads when stopping at the first hit. At N = 4 ,

I(M ; Y ) = 0 , E[Csearch ] = 52 , E[Cpointer ] = 1 .

Under a one-read budget, risk falls from 3/8 to zero (Figure 2b). Thus answer mutual information alone cannot order the value of memory used through a paid retrieval interface. The address carries information about where to acquire the answer. The construction also distinguishes persistent bits from acquisition cost: the pointer occupies ⌈log 2 N ⌉ bits, while reads have their own unit. # 6 Identifying and measuring memory value 

The preceding account concerns retained capability, operational effects and recovery costs. Observing any of these requires a measurement process J that connects system behavior to the declared loss. Keeping J separate from the representation M and system Σ makes it possible to distinguish a change in memory value from a change in how that value is measured. 76.1 The measurement process 

The measurement process J observes evidence about τ and assigns outcomes. Its errors include rejecting equivalent actions, confusing a proposal with an executed edit, or judging against a target from the wrong time. Such errors introduce uncertainty about system performance. The task determines whether an output defect belongs to Σ or J . When a production consumer requires a machine-readable artifact, delivery in the wrong format has a real consequence. When a scorer rejects an alternative that satisfies the task, the scorer needs revision. Section 6.5 gives a concrete example in which two operation words produce the same required disposition of completed work. Measurement uncertainty propagates through the comparison. For n fixed units, w known errors and u unresolved labels under a [0 , 1] -bounded loss, empirical loss lies in [w/n, (w + u)/n ]. The interval describes uncertainty in those labels; population inference requires a sampling model as well. Applying the same distinction to both conditions preserves uncertainty about their value difference.

6.5 A two-project update with visible consequences 

The fictional world contains Cedar, an audit-and-experiment project, and Birch, a report with one valid citation and one citation requiring an owner proposal. The value framework turns memory design into three connected decisions: what to preserve now, what to acquire when needed, and what to revise when evidence or goals change. The following directions connect established theory to concrete memory mechanisms. Their predictions define the next experimental stage. 

7.1 Allocate state and recovery by decision consequences 

Information acquisition and rational metareasoning choose further evidence or computation according to the improvement it can make to a decision, together with its cost (Hay et al., 2012). Memory 3

already formulates memory-format allocation through writing cost and expected reuse-dependent reading cost (Yang et al., 2024). Bringing task loss and access failures into this account lets us compare retained content, a locator and direct archive search by their eventual decision consequences. Consider one future use opportunity, with demand probability p and upfront costs ckeep for content and cidx for a locator. Conditional on demand, retained content is used incorrectly with probability 

rk; recovery fails with probability q, and successfully recovered content is used incorrectly with conditional probability rr. Failed recovery or incorrect use incurs loss L. Let cuse and cread be the conditional expected runtime costs of direct use and the full recovery-and-use route. With costs priced in the same loss unit, retained content has no greater expected loss-plus-cost when

Consequences, access reliability, reader use and price can each change the allocation. Shared evidence and interacting uses require joint comparison, as in Section 5.3. Appendix A.9 derives the condition and gives a preference reversal caused by retained-content use failure. 

Hypothesis 1: consequence-aware allocation. When error stakes, recovery reliability and reader-use reliability vary, an allocation policy using calibrated estimates of these quantities will improve the held-out risk–cost frontier over occurrence-frequency allocation. Test this by varying stakes, access failures and use failures independently of frequency, charging prediction and indexing costs, and including a recovery-only baseline. Stress-test the value estimates and charge their computation to the same resource account. 

7.2 Preserve options for demands revealed later 

Irreversible-decision theory accounts for the options lost when a commitment precedes later informa-tion (Arrow and Fisher, 1974). A memory analogue is the choice between irreversible compression and a retained route back to an authorized source. Versioned evidence, stable locators and rollback can preserve responses to later demands, while adding storage, maintenance and recovery costs. 

Hypothesis 2: recoverability under changing demands. For workloads with later changes of objective and affordable, reliable archival access, retaining a priced recovery path will reduce the cost of reaching a target loss while preserving other uses, compared with irreversible summaries at matched total resource allowance. Test unannounced demand changes across session boundaries and measure the revision frontier in Equation (6). Include source expiry and increases in recovery cost as stress conditions. 

7.3 Revise along evidence dependencies 

Truth-maintenance systems retain justifications and revise dependent beliefs when their supporting assumptions change (Doyle, 1979). This suggests storing the source, object, version and reason behind a memory claim. A changed premise should trigger review of the claims and plans that depend on it, including dependencies crossing project boundaries. A document or project boundary alone need not contain the affected scope. 

Hypothesis 3: dependency-directed revision. With sufficiently accurate dependency records, revising the affected dependency closure will reduce stale conclusions and unnecessary overwriting 12 relative to document-scoped edits, at matched total cost. Test target correctness and preservation of other uses after each update, then remove or corrupt dependency links to measure the mechanism’s failure boundary. Use a propose–validate–commit procedure with rollback when permitted. The update scope follows the dependencies of the changed support. A next comparison pairs blinded fault diagnosis with its selected repairs, evaluated against no repair and full-state rewriting under matched information and resource budgets. Localization error, downstream task loss, effects on other uses and cost are reported separately.

A.1 Decision signatures before a query is revealed Proposition 2 (Zero-error signature bound) . Let H and Q be finite, and let query q require the deterministic answer tq (h). A deterministic writer stores f (h) before q is revealed; the reader observes only f (h) and q, with no recovery access. Define 

T (h) = ( tq (h)) q∈Q , K = |{ T (h) : h ∈ H}| .

Exact correctness for every (h, q ) requires at least K memory states and is achievable with K states. A fixed-length representation needs ⌈log 2 K⌉ bits. Proof. If T (h)̸ = T (h′), some query has distinct target answers. Merging these histories gives the reader the same input for that query, preventing correctness on both. Every distinct signature therefore needs a separate state. Conversely, an index of the signature and a shared lookup rule suffice. The specification and decoder are shared and free in this construction. For an n-bit history and arbitrary coordinate queries, K = 2 n. A writer that instead sees q and can reread the history stores only the requested bit. In both cases the reader receives the query q for free; the difference is its revelation to the writer.
